# Update Demand — feature profiles, request templates and observability

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: any change in column 1 MUST also update everything in column 2, in the SAME PR. CI fails otherwise.

Scope: a new feature and the feature-profile model, request templates (`TemplateDirs`, the document model), and the `observe` vocabulary.

### Category rows (pre-compression CLAUDE.md form)

Same trigger rule. These rows are the category-level form CLAUDE.md carried before its E1-S3 compression and that later efforts kept extending; where one disagrees in wording with a row above, the row above is the live one.

| If you change... (category) | You MUST also update... | Enforced by |
|---|---|---|
| The request-template document model (`template.Template` / `Variable` / `Summary` wrapper keys), the variable type set (`template.AllVarTypes`), the target set (`template.AllTargets`), or the substitution syntax (`$var` / `{{}}` / `$when`) | `skills/request-templating.md` + `docs/src/library/request-templating.md` + CLAUDE.md "Request templating" + `internal/template/` | `TestTemplatePackage_ImportBoundary`, `TestValidate_Matrix`, `TestRenderJSON_Matrix`, `TestRender_TargetMatrix`, `TestAllVarTypes_SpellingsAndCopy`, `TestAllTargets_SpellingsAndCopy`, `TestSkillTokenBudget` |

**Not payload-reachable.** `Options` is not a payload type and nothing under `internal/template/` lives in `types/`, so `internal/descriptor.BuildPayloadSchema` never sees the document model, `Summary`, or `Rendered`. `format_version` stays `"1.1"` and `descriptor/testdata/payload-schema.json` is untouched by a templating change; only the manifest golden moves, and only when the `PULSE_TEMPLATE_*` error family changes. If a future change makes any template shape payload-reachable (e.g. a template slot on a `types` request root, or an MCP tool returning `Summary`), that change picks up the full public-payload-contract row above as well.
