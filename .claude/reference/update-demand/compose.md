# Update Demand — Compose

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 updates everything in column 2 in the same PR.

Scope: `ComposedResponse` and the Compose facade, sweeps, banners, item `for_each`, ranking, fits, model files and `save`, `models`, `populations` (request and registered), regression `conf_level` and `covariance`. Neighbouring Compose slices: `update-demand/compose-expansion.md`, `update-demand/compose-optimize.md`, `update-demand/compose-sweep-bind.md`, `update-demand/compose-sweep-adaptive.md`.

**Finding the sites.** `make sites ARGS="slot request <json-name>"` (or `slot response …`) lists the wire type, service / predict / MCP-bind sites, error owners, feature rows and goldens for a slot; `make sites ARGS="op REG_OLS"` for a regression key. Column 2 below names what the tool cannot derive: the docs, skills and contract prose, plus the rules each site must keep.

**Shared rules for every row here.**

- **One rule set, two callers.** Each Compose expansion or check (`internal/sweep`, `internal/banner`, `internal/model`) is a leaf package fed to BOTH the service and predict — never a second copy. A copy drifts and predict and runtime disagree with no error. The leaves carry import-boundary gates (`TestSweep_ImportBoundary`, `TestBanner_ImportBoundary`, `TestModel_ImportBoundary`).
- **A gated slot** needs its `features.go` row (`Since`, edges, `gatedSlots`), the MCP bind schema, the error owner entries, `docs/src/library/feature-profiles.md` and `.claude/reference/feature-profiles.md`.
- **Topical Compose skills are HARD 6,000 B** (`skills/compose-sweeps.md`, `skills/compose-banner.md`, `skills/compose-fits.md`, `skills/item-fan-out.md`, `skills/regression-inference.md`): new prose displaces old; feature names in them are fenced (`TestSkillsCoverFeatureFences`).
- Regenerate the payload-schema / manifest / public-API goldens with `-update` and run `make docs` when a wire type, capability or skill moves. None of these rows bump `format_version` unless they rename or remove a key.
