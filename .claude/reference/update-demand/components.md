# Update Demand — Response.Components

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 updates everything in column 2 in the same PR.

Scope: `Response.Components` shape, the engine / per-request opt-out, grouped aggregator components, attribute components, grouper refit buckets, auxiliary crosstab margins, per-operator and extension `ComponentSchema`. Contract: `.claude/reference/response-components.md` — load it before any row here.

**Finding the sites.** `make sites ARGS="slot response components"` lists every emitting arm, builder, reducer and golden for the slot; `make sites ARGS="op <TYPE>"` does the same for one operator's schema. The rows below say what each site must satisfy, not where it is. Every row here is additive `omitempty`: `format_version` stays `"1.1"`; regenerate `descriptor/testdata/manifest.json` / `payload-schema*.json` / `internal/apigolden/testdata/public_api.txt` with `-update` whenever a wire or public type moves.
