`TestReferenceOracle_*` (`internal/processing/reference_oracle_test.go` + `internal/statdist/reference_oracle_test.go`): every shared distribution primitive — statdist's `StudentTTwoSidedP` / `StudentTCDF` / `StudentTQuantile` / `StudentTInverseTwoSided`, `chiSquareSurvival`, `fSurvival`, `standardNormalCDF`, `standardNormalPPF`, `kolmogorovSurvival`, `studentizedRangeSurvival`, `studentizedRangeInverse` — matches the committed R goldens under `internal/processing/testdata/reference/` to a relative `1e-10` (absolute floor only at the representable tail edge), p down to ~1e-300. The goldens come from `scripts/reference/gen_reference.R` via `make reference` (CI never runs R) and are hash-gated by processing's `TestGoldensNotHandEdited`; a failure means the primitive is wrong — fix it, never regenerate to match. `TestReferenceOracle_StudentizedRangeMatchesRBuiltins` cross-checks the studentized-range quadrature oracle against R's independent `ptukey()` / `qtukey()` at their documented accuracy, `TestStudentizedRange_TwoSampleIsStudentT` pins k = 2 to the exact Student-t identity, `TestNormalRangeSurvival_TwoSampleClosedForm` the inner integral to `erfc(t/2)` and `TestGK15_ExactOnPolynomials` the Gauss–Kronrod tables. The Student-t family has ONE implementation, `internal/statdist` (a stdlib/gonum-only leaf imported by both `internal/processing` and `internal/processing/regression`; `TestStatdistImportBoundary` holds the ceiling), and `TestStudentTFormsAgree` pins its paired forms bit for bit (`StudentTCDF` = ½·`StudentTTwoSidedP` below zero, `StudentTInverseTwoSided(α)` = −`StudentTQuantile(α/2)`) over the R grids. Its helpers keep their function boundaries on purpose — Go may fuse `a*b+c` differently on arm64 across a constant-folded operand, so restructuring them can move a p-value by an ulp. `TestExtensions_BuiltinParity`'s `TEST_PARITY_T` twin calls statdist directly, so it stays bit-identical to the engine with no copy to keep in lockstep. Normal tails: every normal-approximation p goes through `normalTwoSidedP` (`erfc(|z|/√2)`) or `normalUpperTailP` (Φ(−z)), never `2·(1 − Φ(|z|))`, which cancels to 0 past |z| ≈ 8.3; `TestNormalTwoSidedP_MatchesR` plus one `*_TinyP` test per family (`internal/processing/normal_tail_test.go`: `TestZTwoSample_TinyP`, `TestPropZ_TinyP`, `TestMannWhitney_TinyP`, `TestWilcoxonSR_TinyP`, `TestWilcoxonSRPost_TinyP`, `TestKendallTau_TinyP`, `TestKendallTauPost_TinyP`, `TestTrend_TinyP`, `TestShapiroFrancia_TinyP`, `TestTwoProportionZ_TinyP`, `TestWelchZTest_TinyP`) hold each at |z| ≈ 10 to R's `2*pnorm(-|z|)` at relative `1e-10`. A new normal-approximation family adds its own.

`TestWeightUnityParity` + `TestWeightFrequencyExpansionParity` (`internal/service/weight_parity_test.go`; contract `.claude/reference/weighting.md`, Operation-order exactness rule): operator × execution-arm harnesses over every weight-aware aggregator — buffered, streaming, grouped streaming, two-pass, shard-parallel and parallel decode, and every weight source (request `probability` / `frequency`, slot, `Options.DefaultWeight`). Unity: an all-1.0 weight marshals BYTE-identically to no weight once the weight-only keys are shed (the floor keys, pinned first to `sum_weights = n_eff = n`, `n_weight_invalid = 0`; the manifest `optional` operator keys). Frequency expansion: integer weights equal the physically duplicated rows run unweighted — 1e-12 relative, exact for counts and integer sums, `sum_weights` exactly the expanded `n`. Each arm applies when the UNWEIGHTED request reaches it and the weighted twin must engage the same arm. A `tests` subtree (`weight_tests_parity_test.go`) runs every weighted tier-1 test per advertised kind — unity byte-identical, `frequency` = expansion, `probability` = scale invariance — with coverage per (operator, kind) through the shared `assertWeightKindCoverage` (`weight_coverage_test.go`); a `regressions` subtree (`weight_regs_parity_test.go`) does the same for every weighted `REG_*` variant and `ATTR_REG_*`.

Three of those are recent and easy to mistake for duplicates of each other:

- `TestManifestEmitsTypeHoldsAtRuntime` (`internal/processing/`) is the ONLY runtime consumer `Operator.EmitsType` has. It runs every operator that declares one and checks the values it really emits against the declared domain. A new `EmitsType` declaration without a probe in its table FAILS — which is the point, since an unprobed declaration is manifest prose nothing can contradict. `descriptor.TestCapabilities_SetPopcountEmitsTypeHoldsWidestRung` remains the static half for the set-popcount rung.
- `TestCapabilities_IgnoresFieldDeclarationsAreCoherent` (`internal/descriptor/`) + `TestAggregators_IgnoredFieldSlotIsReallyIgnored` (`internal/processing/`) are the declaration and runtime halves of `Operator.IgnoresField` — the flag that distinguishes "every field type is welcome in this slot" from "this slot is never read" (AGG_RATIO). An operator that sets the flag must accept every type, must name its real inputs as `Type: "field"` params with a `FieldFilter`, and must return the identical scalar whatever its Field slot names.
- `TestWindows_IgnoresFrameMatchesRuntime` (`internal/processing/`) is the runtime half of `Operator.IgnoresFrame` (`WIN_EWMA`): every window predict requires a frame for runs under three bounded frames, and the column must be identical across them exactly when the flag is set — so a materialized description never omits a frame that shaped the values, nor echoes one nothing read.
- `TestOperators_ReadsExpressionMatchesRuntime` (`internal/processing/`) is the runtime half of `Operator.ReadsExpression` (`ATTR_FORMULA`, `FILTER_EXPRESSION`): every built-in attribute and filterer is built with no `Expression` and with a valid one; a flagged operator must refuse the first and accept the second, an unflagged one must build identically either way, and no aggregator, grouper, window or feature may declare it — so a materialized description never quotes an expression nothing read, nor names the ignored `field` of one that did.
