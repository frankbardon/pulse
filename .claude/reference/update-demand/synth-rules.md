# Update Demand — synth: structural rules

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 also updates everything in column 2, in the same PR.

Scope: the structural-rule contract (`Spec.Rules`), the row env's `lookup()`, the rule pre-claim, the profile-path rule/spec plumbing. **Contract: `.claude/reference/synthetic-data.md` — load it first.** The full rule semantics and the reason for each are in `.claude/reference/synthetic-data/structural-rules.md` (and `synthetic-data/rule-lookup.md`, `synthetic-data/rules-reporting-and-suggest.md`); the rows below keep only the rules a change most often breaks. `format_version` never moves for these (`synth.Spec` lives in `synth/`). A new `PULSE_SYNTH_RULE_*` code needs Message + ≥1 Fixup and the manifest golden.
