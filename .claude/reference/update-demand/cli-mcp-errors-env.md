# Update Demand — CLI, MCP, error codes and environment

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 updates everything in column 2 in the same PR.

Scope: error codes, CLI leaves and flags, the `--json` fatal error envelope and exit status, skill cross-references, environment variables, managed-import sidecars, MCP tools / binding / serve entry / resources, feature-profile MCP scope, architectural decisions.

**`TestSkillsCoverAllCliLeaves` enforces NAMING, not quality.** It walks the real `internal/cli.App()` command tree and requires every ACTIONABLE command path (a command with a non-nil `Action`, so `pulse convert` counts alongside its `predict` subcommand) to appear verbatim under `skills/` or `docs/src/`. The generated `docs/src/cli/reference.md` gives every leaf a section; `docs/src/cli/flags.md` holds the concepts shared flags carry. The `skills/session-bootstrap.md` and `docs/src/cli/` companions above remain author judgement.
