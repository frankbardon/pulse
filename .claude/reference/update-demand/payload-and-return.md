## Return slot contract

- **Resolution.** Preset → include → exclude; exclude wins. Include without a preset is an empty-base allowlist; exclude / precision alone shape the full response. Top-level `warnings` joins every selection; each nested `warnings` is a keep path (emitted wherever its parent is, never conjuring it) unless excluded.
- **Absent, never null.** An excluded part is absent on the wire, zero (nil when nillable) in Go. `returned` (`{preset, digest, precision?}`) is stamped only for a non-identity plan and is outside the path space (naming it is `PULSE_RETURN_INVALID`). A request without `return`, or one resolving to full, is byte-identical including `Request.Hash()`; `format_version` stays `"1.1"`.
- **Paths.** A path through a map key or an `any` value is open: accepted at predict, and the runtime warns `PULSE_RETURN_PATH_UNMATCHED` when such an include matched nothing. A hidden feature's path is `PULSE_RETURN_PATH_UNKNOWN`, exactly like a nonexistent one. `data[*].<column>` is judged against the defaults-resolved request's output columns, open under a join, a crosstab or an unknown feature type; an ungrouped run keeps every schema field. A key the bare grammar cannot spell is a quoted segment (`data[*]."emb_mean[q3]"`); `Path.String` quotes only such names, so existing spellings and `rp1:` digests stay byte-identical.
- **Companions.** A preset companion keeps a map key only beside a kept sibling, so every map walker (pruner, planned encoder, predict size walk) calls `VisitIn`, never bare `Visit`. `standard` keeps the matrix inference auxiliaries — `matrix-and-vectors.md` (Inference bullet).
- **Digest** covers include / exclude / keep / companions / precision, never the preset name, so equivalent spellings share it.
- **Leaf boundary.** `internal/returnplan` is stdlib-only and imports no pulse package (`types` carries a plan).
- **Plan cache.** `ResolveReturn` is memoized per instance snapshot on the selection only (≤64 blocks, refusals never cached). The request-derived `Plan.Exact` is never cached and every hit is the caller's own copy, so two requests never share an `Exact` set.
- **Precision** is wire-only: the planned encoder rounds float leaves (never ints) and writes exact the `precisionExempt` registry plus the request's count-semantic paths (built-in `countSemanticAggregations` or an extension's `CountSemantic`). A new count carried as a float joins one of the two.
- **Precedence.** A request block replaces the instance default entirely. Instance default = `Options.DefaultReturn` > `FeatureProfile.Return` > `full`; MCP host default (`standard` unless set) is injected at strict decode into every request / slot / stage without a block — request > host > instance > `standard`. A bad `Options.DefaultReturn` fails `New` with the resolver's code; a bad profile `return` is `PULSE_FEATURE_PROFILE_INVALID` `invalid_return`. Instance-default column paths are never column-judged.
- **DisableComponents shorthand.** The components gate is `req.DisableComponents` when set, else the engine switch; a `return` block never re-opens an engine-off gate (only an explicit request `false` does). When the gate is closed and some layer supplies a block, the effective block gains `exclude: ["components"]`. With no block on any layer nothing is added and no marker is stamped.
- **Compose / Chain.** `ComposedRequest.Return` is rooted at `ComposedResponse`, accepts `overlays…` paths only (else `PULSE_RETURN_INVALID` `root: compose`), keeps `responses` whole, and has no instance default. Each slot / stage resolves its own block. The facade applies after the overlay and multiplicity folds and after the whole chain, from defaults-resolved slot clones, so no fold or later stage reads a pruned response.
- **Compute plan.** What a selection excludes is not computed. `Service.process` resolves one `processing.ComputePlan` before dispatch and threads it through every arm. Vetoes keep what a kept consumer reads: a request overlay that reads host components (pairwise always; χ² / prop-z / Fisher only over a weighted cell) keeps `components.crosstab`; a Compose overlay keeps the Components of the slots it names; a multiplicity family keeps the tests / layers it claims. Dispatch reads the original request, and a kept figure never moves. Every build point bumps `processing.WorkStats()` (never per record).
