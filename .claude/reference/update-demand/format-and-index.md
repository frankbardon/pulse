# Update Demand — file format, decode, shards and point lookup

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 updates everything in column 2 in the same PR.

Scope: `.pulse` format and field types, `FieldWidth`, projection / `DecodePlan` / reuse-decoder records, filter precompute, slurp avoidance, the `afero` probe, shard archives (layout, set widening, parent groups), `CountRecords` and the record-count derivation, `cohort inspect` / `pulse_inspect` output, the sidecar point-lookup index, its freshness decision and manifest. Contract: **`.claude/reference/byte-layout.md` — load it BEFORE any change here**; most rules below fail SILENTLY.

None of these rows move `format_version` unless they say so: the `.pulse` format version is a function of schema content, and the sidecar / index / inspect types are not payload-reachable.
