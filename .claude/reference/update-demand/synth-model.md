## Fidelity sections

- **Score only what generation applied.** A section built off `Spec`'s unpruned slices reports a computed-looking delta for a relationship the generator never ran. Re-run generation's own arbitration (`ResolveConflicts` for the pairwise lists; `resolveConflicts` + `buildModelDrawers` for `models`) on the same `*Spec`; both are pure, so the reproduction is exact. Sections are `omitempty`; a spec with nothing of that kind stays byte-identical.
- **Decode once.** Reuse `decodeSyntheticRows`; a per-entry full decode reintroduces an O(pairs × records) blowup.
- **Non-invertible transforms.** A comparison whose left side is a non-invertible transform of the generated value (a `bernoulli` / `discrete` staircase `Q`) is calibrated on both sides or refused. A midpoint probit score is systematically attenuated — a wrong number for a correct generator. `fidelity_score.go` projects the same score from the generated values and from the captured model's conditional mean; OLS is linear in its response, so the ratio (`score_retention`, also applied to the standard error) removes the attenuation exactly. Hence no K gate and no ordered-probit refit. The trick does not extend to a correlation, so a staircase endpoint stays `no_model_fit` in `model_residual_correlations`, counted. A new derived-quantity section states which shape it is.
- **Bound quadratic sections at the source.** Carry aggregate counters over every entry, list the worst N (`maxResidualRecoveryPairs` = 20) worst-first, and count the remainder.
- **Name a section for its mechanism**, not its statistic (`pairwise` value-scale copula vs `model_residual_correlations` residual-scale).
- **Rival mechanisms are structurally disjoint.** `models` vs `categorical_numeric_pairwise` / `set_numeric_pairwise` is guarded twice (`SpecFromProfile` omits a modelled target's pair; `resolveConflicts` pre-claims the field). Retirement is per target: a captured-but-unapplied model leaves its field's pair standing, or the field is scored nowhere.

## Generation model

- **Effects are latent-scale.** A coefficient shifts `μ` on the standard-normal scale, non-linear in value space for every non-normal `Q`; never surface it as "units of the field" anywhere a coefficient is visible.
- **The value-space alternative (draw the marginal, add the prediction) is rejected** — it destroys the fitted marginal.
- **One clamp**, on the final data-scale value, model bounds winning over the marginal's.
- **Determinism is the ordering contract.** Drawers run in schema field order (never array or map order); every drawer consumes exactly one normal per row unconditionally (even when `residual_std` is 0); the correlated vector consumes one normal per participant in component order before the first drawer; fewer than two participants compiles no correlator, so a spec declaring none is byte-identical. The model stage runs last because its predictors are values earlier stages can rewrite; a new `drawRow` stage states where it sits relative to it.
