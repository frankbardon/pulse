# Update Demand — vectors and matrices

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 also updates everything in column 2, in the same PR.

Scope: `Request.Vectors` (kinds, computed members, vector-input slots on tests / attributes / groupers / aggregations, expression binding) and `Request.Matrices` / `Response.Matrices` with the `MAT_*` catalog. **Contract: `.claude/reference/matrix-and-vectors.md`** (Virtual vectors, Matrix slot). Sites: `make sites ARGS="slot request vectors"`, `make sites ARGS="slot request matrices"`, `make sites ARGS="op MAT_<NAME>"`, `make sites ARGS="new-op matrix"`.

Both slots: additive `omitempty`, `format_version` stays `"1.1"`; a vector- and matrix-free request is byte-identical including `Request.Hash()`. Both ride `capability:matrices`. Regenerate payload-schema, manifest and API goldens.
