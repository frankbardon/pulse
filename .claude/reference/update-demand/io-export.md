# Update Demand — I/O export, formats and derived cohorts

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 also updates everything in column 2, in the same PR.

Scope: `Pulse.Materialize`, export / convert includes, export time zones, transport compression, vector-field export, registered I/O formats and the `io` factory, `CohortWriter` / `CohortValidator`, the `.sav` write surface, SPSS fidelity.

Common companions, implied by every row that touches them: a new or renamed error code → `errors/codes.go` + `errors/fixup_metadata.go` + an `internal/descriptor/error_owners.go` owner (`TestCodesHaveFixups`, `TestErrorOwners_Complete`); a public symbol → the public API golden (`TestPublicAPIGolden`); a manifest change → regenerated manifest golden; a new CLI flag or leaf → its `docs/src/cli/flags.md` row. To list the exact files for a slot, run `make sites ARGS="slot request <slot>"`.
