# Update Demand — I/O import

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 also updates everything in column 2, in the same PR.

Scope: set inference and delimiters, inferred-import null promotion, `SchemaAwareReader`, float-width inference, by-name explicit schemas, `pulse_import` explicit-schema slots, import-time vector folding, the total- and partial-failure verdicts, null-aware readers/writers, source warnings, sidecar emitters.

Common companions, implied by every row that touches them: an error code → `errors/codes.go` + `errors/fixup_metadata.go` + an `internal/descriptor/error_owners.go` owner + regenerated manifest golden (`TestCodesHaveFixups`, `TestManifestErrorCodesComplete`); an `io` interface or report slot → `internal/io/io.go` + `internal/iocore/iocore.go` + `docs/src/internals/adding-io-format.md`; a public symbol → the public API golden and the embedder migration doc; a CLI flag → `docs/src/cli/flags.md`. Every `ImportJob` rule has a `ConvertJob` twin and a managed-import twin (`internal/imports`: `pulse import auto`, `Pulse.ImportFile`, `pulse_import` do not return an `io.ImportReport`, so a report channel is threaded twice).
