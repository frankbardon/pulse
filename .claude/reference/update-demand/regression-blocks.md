# Update Demand — regression opt-in result blocks

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 updates everything in column 2 in the same PR.

Scope: the opt-in blocks a regression spec adds to its `RegressionResult` — `margins`, `collinearity`, `exponentiate`, `term_tests` — the Compose nested-model comparison (`compare`), the row order (`order`), and `REG_MMM_HILL`'s in-model adstock, carry-over and tangent-plane influence. The regression operators themselves, the jackknife knobs and `holdout` live in `update-demand/operators-and-guidance.md`; `vcov` / `covariance` in `update-demand/compose.md` and `matrix-and-vectors/regression-vcov.md`.

**Finding the sites.** `make sites ARGS="op REG_OLS"` prints the **Spec sites** for a `RegressionSpec` key — the refusal pipelines, the extension shared-slot table, predict's p-value count, the return preset, precision classes, MCP schema, capability params and the R oracle fixtures — derived from code. Column 2 below names what it cannot derive.

**The shape every block follows** (each row adds only its specifics):

- An additive `omitempty` `RegressionSpec` key with a `RegressionResult` twin; `format_version` stays `"1.1"`; **absent is byte-identical** (a pinned-bits or digest test guards it).
- **One no-execute rule leaf** (`internal/regmargins`, `internal/collinearity`, `internal/regexponent`, `internal/regmultinom`, `internal/regcompare`, `internal/regorder`) called by BOTH `ValidateRegression` and predict — never a second copy; predict ≡ runtime on every refusal.
- **A row in the extension shared-slot table** (`internal/descriptor/extensions_regression_slots.go`): accepted, declared-or-refused with a `requires` value, or never declared. A missing row means an extension silently ignores the key (`TestExtensions_RegressionSharedSlotsRefused` is the every-field gate).
- Its capability param description on each admitting `REG_*`, its `outputs.*` Interpretations and `regressionOutputs`, `docs/src/contract/payload-schema.md`, `docs/src/regression.md`, the topical skill and each admitting `op-reg-*` `## Params`, the embedder migration doc, `make docs`.
- **An R oracle** under `scripts/reference/`, registered in `validation_registry.go`. Regenerate ONLY that script (`regenerating-goldens.md`); a full `make reference` drifts unrelated oracles.
- Goldens: payload-schema + manifest + public-API (+ the story goldens' `returned.digest` when the `standard` preset moves).
