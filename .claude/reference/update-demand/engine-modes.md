# Update Demand — execution modes: facet, chain, join, crosstab, decode workers, grouped tests, time zones

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 updates everything in column 2 in the same PR.

Scope: `FacetRequest` / facet overlays, `ChainRequest` / `CanChainRequest`, `Request.Joins`, the cohort union (`union` / `union_source_field`), `Request.Crosstab`, crosstab fusion, `DecodeWorkers`, grouped tier-1 tests, `time_zone` / `tz`, the zone capability table, `internal/temporal`, request `params` in expressions. Wiring prose: `.claude/reference/execution-modes.md`.

**Finding the sites.** `make sites ARGS="slot request <json-name>"` lists the wire type, the service / processing / predict / MCP sites, capability file, error owners and goldens for each slot here. Column 2 names only what the tool cannot derive.

**Shared rules.**

- **Predict ≡ runtime for every refusal.** A structural fault is DETECTED once (in `types`, or in a shared leaf such as `internal/crosstabfuse`, `internal/groupedtests`, `internal/sweep`, `formulaident`, the descriptor field-reference walk) and merely RENDERED by predict and the execution validators; a refusal in one engine path only makes the two drift on which requests they refuse.
- A payload-reachable slot regenerates the payload-schema / public-API goldens (`-update`) and updates `docs/src/contract/payload-schema.md`; additive `omitempty` keeps `format_version` at `"1.1"` and a request without the slot byte-identical.
