# Update Demand — Compose sweep-bound fits

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 updates everything in column 2 in the same PR.

Scope: a `fits` entry's `from_sweep` binding (`types.FitSpec.FromSweep`), its static rules and resolution (`internal/model`), the sweep scope both sides build, the sweep-first schedule, `sweep_axis()` / `response()`, the one-call media-mix recipe, and `capability:compose_sweep_bind`. The plain `fits` row lives in `update-demand/compose.md`.

**Finding the sites.** `make sites ARGS="slot request fits"` lists the wire types, both orchestrators, predict's twin, MCP schema, strict decoder and goldens. For an expression built-in, grep its name constant (`SweepAxisFunc`, `ResponseFunc`) — every request-bound list (extension reserved names, the optimize block's reserved variables, the scalar-slot request-bound list, predict's formula check) must carry it. **The rules live ONCE in `internal/model`, shared by service, processing, optblock and predict — never a second copy**; predict must not import the engine (`TestPredictNoExecutionImports`).
