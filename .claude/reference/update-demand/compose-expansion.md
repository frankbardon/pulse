# Update Demand — Compose expansion: base

Per-area slice of the Update Demand trigger table. Index: `.claude/reference/update-demand.md` — load it first, then only the slice(s) your change triggers. Rule: a change in column 1 updates everything in column 2 in the same PR.

Scope: what `banner.ExpandCompose` does to the EXPLICIT slots before the sweep and banner expansion — the Compose `base` (`types.ComposedRequest.Base`, `capability:compose_base`); a compose-level fan-out sharing that seam lands here too. Also the item `for_each` kinds beyond the column items (aggregations, matrices), the optimize-block `for_each`, and `Limits.MaxExpandedItems`. The sweep, banner and window / feature / attribute item `for_each` rows live in `update-demand/compose.md`, and that row's companions apply to the kinds here too.

**Finding the sites.** `make sites ARGS="slot request base"` / `slot request for_each` lists the wire types, both sides of the hidden-slot gate, MCP schema, error owners, request-reads walker, Explain, and goldens. **Every expansion has a service AND a predict call site, and every slot gate a service AND a predict side** — change one without the other and predict and runtime disagree with no error.
