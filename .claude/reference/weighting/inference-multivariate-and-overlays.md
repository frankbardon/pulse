- **Lifted, Hotelling's T² (both kinds; U25 E1-S1):** `TEST_HOTELLING_T2` folds one weighted `linalg.CoMoment` per `split_by` level (listwise; a row with an invalid or ZERO weight is excluded before the fold, as every row test does, so `n` never counts it — unlike the matrix slot). Per level N* = Σw (unweighted / frequency) or Kish n_eff (probability) and M2* = c·M2 read as `Cov(0)`·N*; one-sample S = M2*/(N* − 1), T² = N*·dᵀS⁻¹d, F on (p, N* − p); two-sample pooled S = (M2*₁ + M2*₂)/(N*₁ + N*₂ − 2), T² = N*₁N*₂/(N*₁ + N*₂)·dᵀS⁻¹d, F on (p, N* − p − 1), fractional df under probability. Paired (U25 E1-S2): one co-moment of the row-wise difference vector, then the one-sample formulas. `variance: unequal` (Krishnamoorthy–Yu): Vᵢ = M2*ᵢ/((N*ᵢ − 1)N*ᵢ), T² = dᵀ(V₁ + V₂)⁻¹d, ν from the per-level traces over N*ᵢ − 1, F on (p, ν − p + 1). `sum_weights` / `n_eff` ride `Details` shaped like `n`; `PULSE_WEIGHT_LOW_NEFF` floor p + 1 (one-sample) / p + 2 on Σ n_eff (two-sample). Frequency = the `rep()` expansion; oracle `mv_hotelling.json` (`TestHotellingT2_MatchesROracle`).
- **Lifted, MANOVA (both kinds; U25 E1-S3):** `TEST_MANOVA` folds the same per-level co-moments (listwise; invalid / zero weights excluded before the fold). E = Σ_g M2*_g with each level's OWN c_g (`TEST_ANOVA_F`'s rule), grand mean Σ N*_g·m_g/N*, H = Σ N*_g (m_g − m̄)(m_g − m̄)ᵀ, residual df N* − k (fractional under probability); the four statistics read eig(E⁻¹H). `sum_weights` / `n_eff` per level; `PULSE_WEIGHT_LOW_NEFF` floor p + k on Σ n_eff. Frequency = the `rep()` expansion; oracle `mv_manova.json` (`TestManova_MatchesROracle`) and the `manova` weight-reference rows.
- **Lifted, Bartlett sphericity and Box's M (both kinds; U25 E1-S4):** `TEST_BARTLETT_SPHERICITY` folds the matrix slot's per-merge-block co-moments (invalid / zero weights excluded before the fold) and reads the shared Bartlett core at N* = N / Σw / Kish n_eff (`sphericityNStar`), so it equals `MAT_PCA`'s `bartlett_*` bit for bit; `sum_weights` / `n_eff` scalars, `PULSE_WEIGHT_LOW_NEFF` floor 2. `TEST_BOX_M` folds `TEST_MANOVA`'s per-level co-moments: ν_g = N*_g − 1, S_g = M2*_g/ν_g, S_p = Σ M2*_g/Σ ν_g (frequency = the rep() expansion); per-level `sum_weights` / `n_eff`, `PULSE_WEIGHT_LOW_NEFF` floor p + 1 per level.
- **Lifted, Mardia (frequency only; U25 E1-S5):** `TEST_MARDIA` is `ClassFrequencyOnly`. N = Σw, the Σw-weighted mean and ML covariance, b1p = Σ w_i w_j D_ij³/N², b2p = Σ w_i D_ii²/N — exactly the unweighted test on the rep() expansion (the small-sample switch reads N = Σw). The weighted moments are well defined under probability weights too, but the χ² / z reference distributions are iid-sample results with no design-based form, so a probability weight is `PULSE_WEIGHT_UNSUPPORTED` naming the kind. Scalar `sum_weights` beside raw `n`.
- **Lifted, Mahalanobis (both kinds; U25 E3-S1):** `ATTR_MAHALANOBIS` (`attributeClasses`, `ClassAware`) folds one weighted `linalg.CoMoment` over the filtered rows `params.fit_on` admits (listwise; a row with an invalid or ZERO weight adds nothing to the fit but is STILL SCORED — an attribute owes every row a value). N* = Σw or Kish n_eff (TEST_HOTELLING_T2's `levelNStar`), S = M2*/(N* − 1) with M2* = c·M2; D² = (x − μ_w)ᵀS⁻¹(x − μ_w). N* enters S, so frequency and probability weights give DIFFERENT scores by one constant covariance factor (`TestWeightReferenceKindsAgree` asserts the ratio, not equality); unity = unweighted bit for bit, frequency = the expanded rows' fit, probability = scale invariance (`regParityOps` `attr_mahalanobis` grouped and flat). References: R `mahalanobis()` on the expansion (frequency) and the w* closed form cross-checked with statsmodels `DescrStatsW(w*, ddof = 1)` (probability), `gen_weight_reference.py`. A slot scoring against a bound vector fit (`params.fit`, U30 E2-S1 — every fitted attribute) folds nothing: the FIT's recorded basis (`model.VectorFit.Basis`) governs N* and the covariance, and the slot's own weight never refits it.
- **Lifted, PC score (both kinds; U25 E3-S2):** `ATTR_PC_SCORE` (`ClassAware`) is the same fit (weighted listwise co-moment over the `fit_on` rows, zero / invalid weights scored but not fitted); it decomposes the w* correlation (kind-free) or the M2*/(N* − 1) covariance and standardizes by √λ on that spread, so the kinds differ by one constant factor (`TestWeightReferenceKindsAgree`, constant ratio). References: R `prcomp(scale. = TRUE)` on the expansion (frequency) and the w* closed form, unit variance asserted (probability); `regParityOps` `attr_pc_score` grouped and flat.
- **Lifted, factor score (both kinds; U25 E3-S3):** `ATTR_FACTOR_SCORE` (`ClassAware`) is the same fit; MAT_FACTOR's extraction and rotation run on the w* correlation (kind-free), so the weights R⁻¹LΦ / U⁻²L(LᵀU⁻²L)⁻¹ are kind-free and only the standardizing spread M2*/(N* − 1) moves — the kinds differ by one constant factor (`TestWeightReferenceKindsAgree`, constant ratio). References: the exactly identified one-factor closed form on members x1, y, yb — base R `cor` / `solve` on the expansion (frequency) and the w* closed form (probability); `regParityOps` `attr_factor_score` grouped and flat.
- **Threading:** `StampWeightsWith` keeps the resolved weight on a `tests[i]` slot whose operator `weighting.IsAware` (or a WeightAware extension); `post_tests[i]` is stamped for extensions only; a `regressions[i]` slot is stamped when its class has a kind and it carries no `resample` / `selection`; an `attributes[i]` slot when its class has a kind (`ATTR_ZSCORE`, `ATTR_TSCORE`, `ATTR_REG_*`; E4-S2 / E5-S2); `groups[i]` and both crosstab axes through `stampGroups` (E5-S2: the weight on `GROUP_QUANTILE`, `null` on any other grouper). The factory reads `spec.Weight` (`testWeight`, `internal/processing/test_weight.go`). A row whose weight is invalid or ZERO is excluded and never enters `n`; invalid ones are tallied once per field by `WeightRowTally` (`PULSE_WEIGHT_INVALID_ROWS`, `--strict` errors).
- **Details:** `n` stays the raw row count; a weighted run adds `sum_weights` and (probability only) `n_eff` in the same shape as `n` (scalar, or per-group array in `groups` order); `df` may be fractional. Raw-n floors (`PULSE_TEST_INSUFFICIENT_N`) are unchanged.
- **`PULSE_WEIGHT_LOW_NEFF`** (warning; error under strict): probability only. Tests: one per short group — n_eff below the test's raw-n floor (2 per group; `TEST_PEARSON_R` 3; `TEST_ANOVA_F` k + 1 on N* = Σ_g n_eff_g; N* ≤ k is `PULSE_TEST_INSUFFICIENT_N` with `n_star`), details `{test, type, group (split tests), n_eff, min_required}`, raised at the three row-test finalize sites (streaming, buffered, buffered crosstab arm). Regressions: n_eff ≤ p + 1 (`REG_GLM`: n_eff < p + 1), details `{regression, type, n_eff, min_required}` (E4-S1; the OLS prose names the null figures, the GLM prose says the Wald SEs are unreliable). Never under `frequency` (N* = Σw ≥ the raw-n floor whenever the raw floor holds) and never for the count tests (their raw floor is 1). Overlays do not raise it. An OLS fit with residual df ≤ 0 reports its SEs, p-values, residual standard error and adjusted R² as null (U12 review WS-05, Regressions above). A probability-weighted `TEST_PEARSON_R` with n_eff ≤ 2 (df = N* − 2 ≤ 0) is refused `PULSE_TEST_INSUFFICIENT_N` details `{n, n_eff, df, min_required: 3}` — runtime only (predict reads no rows), mirroring `TEST_ANOVA_F`'s N* ≤ k refusal (U12 review WS-12, `TestWeightedTests_PearsonRefusesNonPositiveDF`); n_eff in (2, 3) still only warns.
- **Lifted, CI aggregators (both kinds; U12 E5-S1):** `AGG_CI_LOWER` / `AGG_CI_UPPER` are `ClassAware`. `ciAggregator` (`internal/processing/aggregator_cohort.go`) folds a `weighting.Welford` bucket when the slot is stamped (invalid / zero weight: skipped) and bounds mean ∓ z·√(s²/N*), s² = `Welford.Variance` (c·M2/(N* − 1)); z is the SAME `method: "normal"` critical value as unweighted — `normalCriticalTwoSided` = −`standardNormalPPF`(α/2), R `qnorm(1 − α/2)` to a few ulp — never a t on N* − 1, which would break unity parity with the z-based unweighted bound. N* ≤ 1 is NaN (unweighted n < 2). Partials merge through `mergeWelfordWeighted` (+ N, Σw²), so the slot stays `Mergeable` on every shard / parallel-decode arm; unity is bit-identical (the fold, the Kish scale c = 1 and the merge reduce to the unweighted operation order). **Critical-value fix (U36 #205):** the same helper replaced a Winitzki inverse-erf (~4.7e-4 relative too small at α = 0.05) in the `TEST_Z_TWO_SAMPLE` / `TEST_PROP_Z` Wald and `TEST_PEARSON_R` Fisher-z intervals, and the CI aggregators' Beasley-Springer-Moro quantile (~1e-11). Gates: `internal/processing/aggregator_ci_weighted_test.go` (R `qnorm` pin, unity / expansion / Kish closed form / scale invariance / merge / row handling), the service parity rows (`kishScaled`: probability = scale invariance) and reference rows.
- **Matrix operators (U16 E1-S2, E3-S1):** `MAT_COVARIANCE` and `MAT_CORRELATION` are `ClassAware` (`matrixClasses`, `internal/weighting`). The `matrices[i].weight` slot resolves by the usual precedence (slot → `Request.Weight` → `Options.DefaultWeight`; `null` opts out) and is stamped by `StampWeightsWith`; the slot folds rows into a weighted `linalg.CoMoment` (Welford–West), so the matrix is M2_w / (Σw − ddof) under both kinds = statsmodels `DescrStatsW(weights, ddof).cov`, with no design-based variance under probability weights. An invalid weight (null, NaN / ±Inf, negative, fractional under frequency) is handed to the co-moment as NaN, which skips the row and counts it invalid; it also rides `PULSE_WEIGHT_INVALID_ROWS` (`NewWeightRowTally` reads the matrix slots). **A row of weight 0 COUNTS toward the matrix's n but adds no mass** — CoMoment semantics, deliberately unlike the weighted aggregators, which skip it; the figures agree (`TestMatrixCovariance_DiagonalMatchesVarianceAggregators`: ddof 1 = weighted `AGG_WELFORD` variance, ddof 0 = weighted `AGG_VARIANCE`, 1e-12 relative), only the row count differs. Oracle: `TestMatrixCovariance_MatchesReference` (pinned numpy / statsmodels, `internal/service/testdata/matrix_reference/`). `MAT_CORRELATION` reads r off the same weighted co-moments (scale-free, so both kinds agree = `DescrStatsW(weights).corrcoef`, `TestMatrixCorrelation_MatchesReference`); `TEST_PEARSON_R` skips a weight-0 row the matrix counts, so `mat.n == pearson.n + zero_weight_rows` (`TestMatrixCorrelation_ZeroWeightRowsCountTowardN`). **Rank methods (U24 E1-S3):** `MAT_CORRELATION` with `params.method` `spearman` / `kendall` is `ClassFrequencyOnly` PER SPEC (`weighting.MatrixClassOf(type, rankMethod)`, read by the resolver through `weightSlot.specClass`): each cell is `TEST_SPEARMAN_R` / `TEST_KENDALL_TAU` on the frequency expansion (weighted mid-ranks; Kendall pair mass w_i·w_j), with no probability-weighted reference form, so a probability weight is `PULSE_WEIGHT_UNSUPPORTED` with `details.method`. The rank computation leaves weight-0 rows out (as the tests do); they still count in the matrix's `n`. Gate: `TestMatrixRankCorrelation_ProbabilityWeightRefused`, `TestMatrixClassOf`. Under `params.inference` (U28 E3-S3) the rank p and interval read n = Σw and the expanded tie sizes, so a frequency weight is exactly `cor.test` on the `rep()` expansion (`TestMatrixInference_RankWeightRules`). **Partial correlation (U24 E1-S4):** `MAT_PARTIAL_CORRELATION` is `ClassAware`: it inverts the same weighted correlation (corpcor `cor2pcor` on the weighted r — scale-free, so both kinds agree; an outside `params.control` field joins the weighted fold), oracle `TestMatrixPartialCorrelation_MatchesROracle` (frequency = the `rep()` expansion, probability = the weighted correlation). **Reliability (U24 E2-S2):** `MAT_RELIABILITY` is `ClassAware`: α and its item forms are ratios of the weighted covariance (scale-free), ω fits the weighted correlation; `item_sd` takes the kind's denominator — Σw − 1 under frequency (the `rep()` expansion), Σw − Σw²/Σw under probability (`cov.wt` "unbiased", = the population form × n_eff/(n_eff − 1)), PER ENTRY under pairwise deletion — each covariance entry over its own rows with its own `PairNEff` (U30 E5-S2; an entry with n_eff ≤ 1 is null), so there the factor is not uniform and α reads it too; oracle `TestMatrixReliability_MatchesROracle` (both kinds, listwise and pairwise). **PCA (U24 E3-S1):** `MAT_PCA` is `ClassAware`: it decomposes the weighted correlation (kind-free) or the weighted covariance (the kind's denominator, as reliability's `item_sd`), and Bartlett's test reads N* — Σw (frequency) or Kish n_eff (probability); pairwise the smallest pair's own N* — `basis.NStar(PairW, PairW2)`, the pair's Σw or Kish n_eff (`PULSE_MATRIX_PAIRWISE_N_STAR`; U30 E5-S2) — and a pairwise covariance takes the per-entry factor as reliability does; oracle `TestMatrixPCA_MatchesROracle` (both kinds, listwise and pairwise, `n_star` per case). **Collinearity (U24 E3-S2):** `MAT_COLLINEARITY` is `ClassAware`: VIF / tolerance and centered Belsley read the weighted correlation, uncentered Belsley the weighted moments W(Σ + μμᵀ) scaled to unit diagonal — every figure a scale-free ratio, so the two kinds agree and no N* is needed; oracle `TestMatrixCollinearity_MatchesROracle` (both kinds: weighted `car::vif` on `lm(weights =)`, colldiag on √w-scaled rows), `TestMatrixCollinearity_FrequencyIsExpansion` (a frequency weight = the `rep()` expansion). `MAT_FACTOR` (U25 E2-S2) is `ClassAware`: it factors the weighted correlation (kind-free), and Bartlett's test and the empirical chi-square read N* as `MAT_PCA` does (pairwise the smallest pair, `PULSE_MATRIX_PAIRWISE_N_STAR`); oracle `TestMatrixFactor_MatchesROracle` (both kinds, `n_star` per case). **Correlation inference (U28 E3-S2):** `params.inference` on `MAT_CORRELATION` (Pearson; rank methods above) / `MAT_PARTIAL_CORRELATION` reads N* by the one rule with the EXACT per-pair mass — `basis.NStar(PairW, PairW2)`: Σw under frequency, Kish n_eff under probability (`CoMoment.PairW2`, E3-S1; `MAT_PCA` / `MAT_FACTOR`'s pairwise N* read the same per-pair figure since U30 E5-S2) — per cell for Pearson (pairwise) and the smallest folded pair for a pairwise partial; t / p on N* − 2 (− g), Fisher se on N* − 3 (− g), `TEST_PEARSON_R`'s arithmetic; the row floors (3 + g for p, 4 + g for the interval, 5 for Kendall's) count only rows carrying mass (`CoMoment.PairNMass`, E3-G2), so a weight-0 row — still in the matrix's `n` — never admits a cell the single-pair test refuses (`TestMatrixInference_ZeroWeightRowsFloorLikeTest`). Probability n_eff below 3 + g warns `PULSE_WEIGHT_LOW_NEFF` on the `MatrixResult` (not escalated by strict). Oracle `TestMatrixInference_MatchesROracle` (frequency = `cor.test` on the `rep()` expansion, probability = the Kish closed form). Contract: `matrix-and-vectors.md` (Inference bullet).
- **Centroid distances (U25 E4-S2):** `MAT_DISTANCE` is `ClassAware`: centroids are kind-free weighted means; `standardize` divides by the w* sd and `mahalanobis` reads the w*-pooled within-bucket covariance (N* = Σw frequency, Kish n_eff probability — the one rule). ## Overlays

- **Share / index kinds are descriptive** (no `Inferential` flag, so `overlayWeightClass` never refuses them) and carry NO weight logic: they read the host payload, which is already weighted. Matrix `OVERLAY_SHARE_OF_ROW` / `_COL` / `_TOTAL` and `OVERLAY_INDEX_VS_MARGIN` (both crosstab arms), series `OVERLAY_SHARE_OF_TOTAL` and `OVERLAY_INDEX_VS_TOTAL` / `_PRIOR` / `_BASELINE` / `_ROLLING_MEAN` / `_SIBLING` (streaming fold included), Compose `OVERLAY_INDEX_VS_REF` and the panel index `OVERLAY_PANEL_INDEX_VS_REF` over weighted slots. Gate: frequency expansion — a request-weighted host's layers equal the physically expanded cohort's unweighted layers, differ from the unweighted host's, and leave the host payload byte-identical to the overlay-free run (`TestWeightShareIndexOverlaysReadWeightedHost`, `TestWeightComposeIndexOverlaysReadWeightedSlots`, `internal/service/weight_overlay_test.go`). `OVERLAY_INDEX_VS_STAGE` (chain) and `OVERLAY_INDEX_VS_POP` (facet) read the same way but their hosts carry no top-level weight in U11. An undefined series entry (the first `_PRIOR` point, an unfilled rolling window) is NaN in Go and `statistic: null` in JSON on weighted and unweighted hosts alike, so the gates compare layers on the JSON form. The full audit of non-finite producers and the JSON surfaces they reach (all routed through `types.MarshalFinite`) is `.claude/reference/response-components.md` (Undefined figures on the wire).
- **Mean overlays on a weighted host (U12 E3-S1; both kinds).** `OVERLAY_T_CELL`, `OVERLAY_Z_CELL`, `OVERLAY_T_VS_REF`, `OVERLAY_Z_VS_REF` and `OVERLAY_PAIRWISE_WELCH_T` are `ClassAware` in `overlayWeightClasses`. A host cell is WEIGHTED when it carries the floor key `sum_weights`, whatever the weight's source (its own slot weight included — before E3-S1 such a slot-only host ran these kinds on the triple's raw `n` and its frequency-form variance, silently too narrow; the bug fix). Its kind is read off the floor too (`n_eff` is stamped only under probability). The one reader is `processing.readMeanLeg` behind `CrosstabHostView.MeanLeg` (the Compose matrix arm reads `Response.Components.Crosstab` through it, the series arm a row's triple map): N* = `sum_weights` (frequency) or `n_eff` (probability) — never the triple's `n` — and the variance recomputed from `m2` as `weighting.ScaledVariance` (c·m2/(N* − 1), c = N*/Σw; `Welford.Variance`'s operation order); Welch df on N* (fractional). An unweighted cell reads `{mean, variance, n}` exactly as before (byte-identical). The welford-shape pairwise arm reads both kinds through it (`OVERLAY_PAIRWISE_TWO_MEANS_Z` stays permanently refused by class; on a slot-only host it now reads N* too). `OverlaySummary.Parameters` adds `sum_weights` = Σw over the distinct legs read and, under probability, `n_eff` = Kish over their union ((ΣΣw)²/Σ(Σw²/n_eff)); nothing on an unweighted host. Real series hosts carry `processing.WelfordTriple` values (not maps; never read — the struct has no floor keys): a Compose / chain slot narrowed to its scored `AGG_WELFORD` (`narrowSeriesHost`) takes each row's leg from that row's bucket components instead (`welfordComponentsLeg`: `mean` / `variance` / `m2` + `n` + `sum_weights` / `n_eff`), so the series arm reads the weighted leg as the matrix arm does (U46 E4-S11; before, the layer came back empty); with components disabled on such a slot (the effective gate: its `disable_components`, else `Options.DisableComponents`; a `return` never removes them, the Compose veto keeps them) the overlay is `PULSE_OVERLAY_COMPONENTS_REQUIRED` `{overlay_index, kind, slot, host, aggregation, label, reason: "components_disabled"}` — `descriptor.ComposeOverlayTwoSampleInputsRefusal` (which also requires a scalar side's variance / sample-size params — `PULSE_OVERLAY_PARAM_MISSING`, no default — U46 E4-S16), called by `ValidateComposeWithOptions` and `Service.applyComposeOverlays` and re-run at fold time against what each slot returned (`composeOverlayTwoSampleLegsPresent`, `PROCESSING_INTERNAL`) — never the empty layer it was before (U46 E4-S13; gate root `TestComposeOverlay_WelfordComponentsDisabledRefused`). **`n_source` on a weighted host** (`weighting.NSourceRefusal`, FR-27): an omitted source reads N*; `cell_n_unweighted` / `row_margin_n` / `column_margin_n` are `PROCESSING_CONFIG` ("raw row count is not a valid sample size on a weighted host"); `cell_weight_sum` is accepted under frequency and `PROCESSING_CONFIG` under probability. Wired for the welford pairwise kinds: runtime (`runPairwiseOverlay`, host basis = `CrosstabHostView.WeightBasis`) and predict (`validateOverlayPairwise`, basis = the crosstab cell's APPLIED resolved weight, `crosstabCellWeightBasis`) raise the same code and message, the predict refusal REPLACING the inertness `PULSE_OVERLAY_PARAM_MISSING` for those modes; every other mode keeps the predict-only inertness refusal. Gates: `internal/processing/overlay_weighted_host_test.go` (closed-form w* references under both kinds, raw-n answer differs, Parameters, the n_source rule), `internal/descriptor/overlay_weighted_host_nsource_test.go`, root `TestWeight_PairwiseNSourceMatchesPredict` (predict = runtime on a slot-only host), `internal/service/weight_mean_overlay_test.go` (slot-only host: frequency = expansion, probability scale invariance, Process + Compose).
- **Contingency and proportion overlays on a weighted host (U12 E3-S2).** `OVERLAY_CHISQ_ROW` / `_COL` / `_MATRIX` / `_VS_REF`, `OVERLAY_SYMMETRY` (U30 E7-S1), `OVERLAY_PROP_Z_CELL` / `_PANEL` and `OVERLAY_PAIRWISE_PROP_Z` are `ClassAware`; `OVERLAY_FISHER_EXACT_CELL` is `ClassFrequencyOnly`. A weighted host's cells and margins are Σw (weighted `AGG_COUNT`), read through the floor keys: `processing.floorLeg` / `CrosstabHostView.CellFloor` / `RowMarginFloor` give each cell's or margin's {Σw, N*}, `weightedLegTally` folds a set of them into the union's Kish scale c = n_eff/Σw (each leg's Σw² recovered as Σw²/n_eff). **χ²:** frequency = Pearson on the Σw table (the expanded rows); probability = the table (`_MATRIX`, `OVERLAY_STD_RESIDUAL`'s residuals / expected counts, U28, and `OVERLAY_SYMMETRY`'s McNemar / Bowker table), each row (`_ROW`) or column (`_COL`) scaled by the c of the cells it reads, then ordinary Pearson — `TEST_CHISQ`'s first-order Kish form, NOT Rao-Scott; the margin's own floor equals the cell union whenever the cells partition it. `_VS_REF` scales the TARGET table (the reference is the fixed distribution). `PULSE_OVERLAY_EXPECTED_LOW` and `expected_min` read the scaled expected; `Summary.Min` / `Max` stay the observed Σw. Frequency and unweighted hosts never multiply (byte-identical). **Proportions:** p̂ = Σw_success/Σw_base (the weighted cell share / cell over margin), n = N*_base. `PAIRWISE_PROP_Z` with `n_source` omitted reads the cell's N* (`pairwiseSampleSize`); `PROP_Z_CELL` and the panel's value modes scale the cell and the payload margin (or slab) by the row base's c under probability (`composeRowBases`: the row margin's floor, else the Kish union of the row's cells; a probability row with no readable floor is a missing margin, never Σw). **Host basis:** a per-Request host takes it from the STAMPED crosstab cell weight (`CrosstabHostView.withCellWeight`, set in `applyOverlaysToResponse`) — an `AGG_WEIGHTED_MEAN` cell emits its own `n_eff` under either kind, so floor keys cannot tell; Compose slots infer it from the floor keys (a components-disabled slot shows none — hence the refusal below). **`n_source` rule extended (`weighting.NSourceRefusal`, decision E3-S2):** besides FR-27's three raw sources, `n_within` (a raw slab) and every distinct-key mode (`n_within_distinct`, `row_margin_distinct`, `column_margin_distinct`, panel `row_margin_distinct_within`) are unweighted counts and `PROCESSING_CONFIG` on a weighted host, and `cell_value_weighted` joins `cell_weight_sum` as a weight sum (frequency only;
