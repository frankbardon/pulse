# Weighting — Weighted inference (continued: scores and quantile buckets, the formula total, CUPED, multivariate tests, fitted scores, CI aggregators, matrix operators)

Slice of `.claude/reference/weighting.md` — load the index first, then only the slice(s) your change touches. Every bullet applies "The one rule" (N*, w*, the frequency formula on w*) from `weighting/refusals-and-inference.md`.

- **Lifted, z / t scores and quantile buckets (both kinds).** `ATTR_ZSCORE` / `ATTR_TSCORE` fold the attribute weight through `weighting.Welford` in pass 1 (an unweighted slot folds w = 1, bit-identical) and score every row against the weighted mean and weighted POPULATION sd √(M2_w/Σw) — scale-free, so kinds agree. A zero / invalid-weight row adds nothing but is still scored. A zero weighted sd scores every row null (0/0), as unweighted. `GROUP_QUANTILE` is the one weighted grouper (stamped on `groups[i]` and both crosstab axes by `stampGroups`; a grouper slot weight alone warns `PULSE_WEIGHT_INVALID_ROWS`). The cut (`quantileGrouper.weightedBuckets`) is the weighted-quantile rule — probability rescaled to Σw = n, integer snap (`snapCumWeights`), bucket ⌊⌊C − 1⌋·k/W⌋. A heavy row spanning a cut lands whole in the higher bucket, so under frequency the cuts equal the expansion's but counts / highs need not; a zero-weight row is bucketed by value with the row below. Counts and the grouper floor stay raw.
- **Lifted, the formula total (frequency only).** `ATTR_FORMULA` calling `total(expr)` is frequency-only PER SPEC (`weighting.AttributeClassOf`, shared by resolver and stamper); the pre-pass folds `float64(w*v)`. A probability weight is refused because a total over arbitrary-scale weights silently moves every share read off it.
- **Lifted, the covariate adjustment (CUPED, both kinds).** `params.covariate` on split `TEST_T`, `TEST_WELCH`, `TEST_Z_TWO_SAMPLE`, two-proportion `TEST_PROP_Z` keeps each test's class. Each group folds (x, y, w) into a `weighting.CoWelford`; θ = CXY/M2X and x̄ are pooled over both groups on the RAW weights w (kind-free) — θ on w* would differ when c_g differs between arms, so it is not used. Adjusted moments mean′_g = ȳ_g − θ(x̄_g − x̄), M2′_g = M2Y_g − 2θ·CXY_g + θ²·M2X_g with the group's own Σw / Σw², then the test reads N*_g on y′. Frequency = the unweighted adjustment on the expansion. A null covariate drops the row before its weight is judged (`n_covariate_dropped`). Grouped requests pool θ per partition.
- **Lifted, Hotelling's T² (both kinds).** One weighted `linalg.CoMoment` per `split_by` level; a row with an invalid or ZERO weight is excluded before the fold (so `n` never counts it — unlike the matrix slot). M2* = c·M2; one-sample S = M2*/(N* − 1), F on (p, N* − p); two-sample pooled S on N*₁ + N*₂ − 2; paired = one-sample on the difference vector; `variance: unequal` (Krishnamoorthy–Yu) on N*ᵢ. Low-n_eff floor p + 1 (one-sample) / p + 2 on Σ n_eff (two-sample).
- **Lifted, MANOVA (both kinds).** Same per-level co-moments; E = Σ_g M2*_g with each level's OWN c_g (`TEST_ANOVA_F`'s rule), H = Σ N*_g (m_g − m̄)(m_g − m̄)ᵀ, residual df N* − k; low-n_eff floor p + k.
- **Lifted, Bartlett sphericity and Box's M (both kinds).** `TEST_BARTLETT_SPHERICITY` reads the shared Bartlett core at N* (`sphericityNStar`), bit-equal to `MAT_PCA`'s `bartlett_*`; floor 2. `TEST_BOX_M`: ν_g = N*_g − 1, S_g = M2*_g/ν_g; floor p + 1 per level.
- **Lifted, Mardia (frequency only).** N = Σw, Σw-weighted ML covariance, b1p = Σ w_i w_j D_ij³/N², b2p = Σ w_i D_ii²/N. The χ² / z references are iid results with no design-based form, so probability is refused.
- **Lifted, Mahalanobis (both kinds).** `ATTR_MAHALANOBIS` fits one weighted co-moment over the `params.fit_on` rows; a zero / invalid-weight row adds nothing to the fit but is STILL SCORED (an attribute owes every row a value). S = M2*/(N* − 1), so frequency and probability give DIFFERENT scores by one constant factor (`TestWeightReferenceKindsAgree` asserts the ratio). A slot scoring a bound vector fit (`params.fit`) folds nothing — the fit's recorded basis (`model.VectorFit.Basis`) governs.
- **Lifted, PC score (both kinds).** `ATTR_PC_SCORE`: same fit; decomposes the w* correlation (kind-free) or the M2*/(N* − 1) covariance; kinds differ by one constant factor.
- **Lifted, factor score (both kinds).** `ATTR_FACTOR_SCORE`: extraction and rotation on the w* correlation (kind-free); only the standardizing spread moves — one constant factor.
- **SEM score (frequency only).** `ATTR_SEM_SCORE`'s inline fit IS `MAT_SEM`'s (S = M2_w/Σw, N = Σw through its blocked merge), so frequency equals the expanded fit; an invalid or zero-weight row adds no mass but opens its merge block and is still scored. The scoring rule reads no weight. Probability refused (lavaan ML has no design-based form). A bound `params.fit` slot fits nothing. Contract: `.claude/reference/matrix-and-vectors/sem-scores.md`.
- **Threading.** `StampWeightsWith` keeps the resolved weight on a `tests[i]` slot whose operator is aware (or a WeightAware extension); `post_tests[i]` for extensions only; `regressions[i]` when the class has a kind and no bootstrap / `selection`; `attributes[i]` when the class has a kind; groupers through `stampGroups`. Test factories read `spec.Weight` (`testWeight`, `internal/processing/test_weight.go`). A row with an invalid or ZERO weight never enters `n`.
- **Details.** `n` stays raw; weighted runs add `sum_weights` and (probability) `n_eff` in the shape of `n`; `df` may be fractional. Raw-n floors (`PULSE_TEST_INSUFFICIENT_N`) unchanged.
- **`PULSE_WEIGHT_LOW_NEFF`** (warning; error under strict), probability only. Tests: one per short group whose n_eff is below the test's raw-n floor (2 per group; `TEST_PEARSON_R` 3; `TEST_ANOVA_F` k + 1 on Σ n_eff_g), `{test, type, group, n_eff, min_required}`, raised at every row-test finalize site. Regressions: see the regressions bullet. Never under frequency (Σw ≥ the raw floor whenever it holds), never for count tests, never by overlays. Refusals rather than warnings: `TEST_ANOVA_F` with N* ≤ k and a probability-weighted `TEST_PEARSON_R` with n_eff ≤ 2 (df ≤ 0) are `PULSE_TEST_INSUFFICIENT_N` (runtime only; predict reads no rows).
- **Lifted, CI aggregators (both kinds).** `AGG_CI_*` fold a `weighting.Welford` and bound mean ∓ z·√(s²/N*). z is the SAME normal critical value as unweighted (`normalCriticalTwoSided`, R `qnorm` to a few ulp) — never a t on N* − 1, which would break unity parity with the z-based unweighted bound. N* ≤ 1 is NaN. Partials merge through `mergeWelfordWeighted`, so the slot stays `Mergeable` everywhere.
- **Matrix operators.** Classes in `internal/weighting` (`matrixClasses`, per-spec `MatrixClassOf` / `DistanceClassOf`). The `matrices[i].weight` slot resolves by the usual precedence; rows fold into a weighted `linalg.CoMoment`, so `MAT_COVARIANCE` = M2_w/(Σw − ddof) under both kinds (statsmodels `DescrStatsW`), no design-based variance. An invalid weight is handed to the co-moment as NaN (skipped, counted invalid, rides `PULSE_WEIGHT_INVALID_ROWS`). **A row of weight 0 COUNTS toward the matrix's n but adds no mass** — CoMoment semantics, deliberately unlike the aggregators and tests, which skip it; figures agree, only the row count differs (`mat.n == pearson.n + zero_weight_rows`).
  - `MAT_CORRELATION` (Pearson), `MAT_PARTIAL_CORRELATION`, `MAT_COLLINEARITY`: scale-free ratios of the weighted co-moments, kinds agree.
  - Rank `params.method` (`spearman` / `kendall`) is frequency-only PER SPEC (`details.method` on refusal); weight-0 rows are left out of the ranks but count in `n`.
  - `MAT_RELIABILITY` / `MAT_PCA` covariance spreads take the kind's denominator (Σw − 1 frequency; Σw − Σw²/Σw probability), PER ENTRY under pairwise deletion (each entry its own `PairNEff`; n_eff ≤ 1 ⇒ null), so the factor is not uniform there.
  - Bartlett / empirical χ² in `MAT_PCA` / `MAT_FACTOR` read N*; pairwise, the smallest pair's own N* (`basis.NStar(PairW, PairW2)`, `PULSE_MATRIX_PAIRWISE_N_STAR`).
  - Correlation `params.inference` reads N* with the EXACT per-pair mass; row floors count only rows carrying mass (`CoMoment.PairNMass`), so a weight-0 row never admits a cell the single-pair test refuses. Probability n_eff below 3 + g warns `PULSE_WEIGHT_LOW_NEFF` on the `MatrixResult` (not escalated by strict). Contract: `matrix-and-vectors.md` (Inference bullet).
  - `MAT_DISTANCE`: centroids kind-free; `standardize` / `mahalanobis` on w*; a `GROUP_KMEANS` `params.between` reads w as coincident points, so that spec is frequency-only (`details.between`).
  - `MAT_SEM` is frequency-only (S = M2_w/Σw, N = Σw = semopy on the expansion). Contract: `.claude/reference/matrix-and-vectors/matrix-sem.md`.

Weighted-test gates: `internal/processing/test_weighted_test.go` — unity (byte-identical once floor keys are shed), frequency = expansion, closed-form w* for both kinds, exclusion, streaming = buffered, low-n_eff on every site.
