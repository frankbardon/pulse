# Weighting — Refusal rules, Weighted inference (tests, regressions, regression attributes)

Slice of `.claude/reference/weighting.md` — load the index first, then only the slice(s) your change touches.

## Refusal rules

While a weight is in force on a slot, a refused surface is `PULSE_WEIGHT_UNSUPPORTED` at predict AND runtime — raised by `ResolveWeights`, so code, message and details match (`TestWeight_InferentialRefusalsMatchPredict`). "In force" means a weight RESOLVES on the slot (own, request or `Options.DefaultWeight`): an instance default refuses too, so the slot must opt out with `weight: null`. Details `{slot, operator, field}`, plus:

- **`reason`** (also in the message, `<slot>: <op> cannot be weighted: <reason>`) on a PERMANENT refusal — `weighting.RefusalReason` for operators; slot-level `weightSlot.reason` for every post-test (reads aggregated rows), any `REG_*` with `resample: bootstrap` / `selection`, and `MAT_SEM` with `params.resample` (`reasonSEMBootstrap`); the overlay table's `reason` for refused overlay kinds.
- **`alternative`** — the weighted twin (`OVERLAY_PAIRWISE_TWO_MEANS_Z` → `OVERLAY_PAIRWISE_WEIGHTED_TWO_MEANS_Z`), omitted when the instance hides it.
- **`kind` + `supported_kinds: ["frequency"]`** on a frequency-only operator under a probability weight (`weightKindUnsupported`); fixups name `weight: null` and `kind: frequency`. The Fisher cell overlay's host-only variant adds `host: crosstab.cell` (`weighting.FrequencyOnlyHostRefusal`).
- **`value_field`, `type`** on a weight-aware aggregator over `decimal128`.

A pending refusal (no `reason`; `has no weighted form yet`) is left only for an `Inferential` overlay kind with no `overlayWeightClasses` entry.

**Overlay weighting.** Every `Inferential: true` overlay kind is classed by `overlayWeightClasses`, else refused off the flag (`overlayWeightClass`).
- **On `Request.Overlays`** the overlay's OWN resolved weight decides (slot → request → default); `weight: null` opts out and it runs over the host as before. A host weighted ONLY by its own slot weight (or `params.weight_field`) never refuses an overlay nothing else weights — shipped pairwise `n_source` modes (`cell_weight_sum`, …) read such hosts on purpose — and is read as WEIGHTED (N*, the weighted-host `n_source` rule, a frequency-only kind's host refusal; "Overlays"). `OVERLAY_PAIRWISE_WEIGHTED_TWO_MEANS_Z` is `applied` under both kinds; an inherited default is judged on its host; its host is an `AGG_WEIGHTED_MEAN` or a weighted `AGG_AVERAGE` cell.
- **On Compose** (`ComposedRequest.Overlays`, no weight of its own) `ComposeOverlayWeightRefusal` refuses a refused kind (a frequency-only kind only under an inherited probability weight) when a slot it reads (reference or target; every slot when `targets` is empty) has a REQUEST or INSTANCE default weight applied to an aggregation or crosstab cell — `{slot: "overlays[i]", operator, field, host: "requests[j].<slot>"}`; opt out with `weight: null` on that slot's aggregations. Runtime and `ValidateComposeWithOptions` both call it (`TestWeight_ComposeInferentialOverlayMatchesValidator`).
- **Facets** are never weighted: no `FacetRequest.Weight`, the default does not reach facet overlays, and a SET `weight` on a `FacetRequest.Overlays` spec is refused `{slot, operator, field, reason}` (`overlayhost.FacetSpecRefusal`) rather than silently ignored; `null` / absent run. Whole-chain overlays ship only descriptive kinds.

**Grouper slot weight (decision).** `types.Group` carries the same `SlotWeight` as every slot — without it an `Options.DefaultWeight` instance could never opt a quantile grouper out. It is how `GROUP_QUANTILE` opts in or out; a set weight on any other grouper is accepted and skipped (still projected and field-checked; the MCP binder declares it on `groups` and both crosstab axes).

**Not weightable (not a refusal code).** `ATTR_NORMALIZED` (a min-max rescale has no weighted meaning) and the not-weightable aggregators: default skipped, explicit `PROCESSING_CONFIG` `{slot, operator, field}`. Windows (no slot weight): a REQUEST weight is `PROCESSING_CONFIG`, the default is skipped. Filters, features, row-local attributes and other groupers are unaffected (`TestWeight_WindowsAndUnaffectedMatchPredict`). Share and index overlays read the host payload, so they are weighted automatically. Extension aggregators, attributes and tests follow their `WeightAware` declaration ("Extension contract").

## Weighted inference

**The one rule.** `internal/weighting/inference.go`: N* = Σw under `frequency`, Kish n_eff = (Σw)²/Σw² under `probability` (`weighting.Basis`, `NStar`, `Scale`); w* = w·N*/Σw; every weighted formula is the FREQUENCY formula on w*. Point estimates (means, r, β, proportions) are kind-free; spreads, SEs, df and p-values read N*. `weighting.Welford` is the shared bucket (raw `N`, Σw, Σw², mean, M2_w; `Variance(basis)` = c·M2/(N* − 1)); `Add` follows the operation-order rule so w ≡ 1 is the unweighted recurrence bit for bit, and built-in tests run every unweighted row through it with w = 1. Reuse the bucket and basis; do not fork them.

**Minimum-n floors.** Every minimum-n guard of a weighted test, regression and correlation-inference cell compares `weighting.Basis.FloorN(raw, Σw)`: Σw under `frequency` (so a slot refuses exactly when its `rep()` expansion does), raw rows unweighted and under `probability` (whose Σw counts nothing; a low n_eff warns instead). Below p + 1 distinct rows a design is singular however weighted. The weighted jackknife's n ≥ 3 stays on records (it deletes records, not copies). Gates: `Test*_FrequencyFloorIsExpansion`.

**What it is and is not.** Under `frequency` every weighted figure equals the unweighted figure on the `rep()`-expanded rows (the reference oracle). Under `probability`, Kish's n_eff is a first-order design-effect approximation for UNEQUAL WEIGHTING only — no strata, clusters or finite-population correction, not design-based variance, χ² not Rao-Scott — and it assumes the weights are unrelated to the outcome and the comparison. For slopes, correlations, contrasts and tables it is a heuristic; design-based answers need `survey`-style linearisation.

**n_eff output keys.** Every weighted inferential surface reports its effective size beside its raw count, absent when unweighted:

| Surface | Raw count (unchanged) | Weighted keys |
|---|---|---|
| test `details` | `n` (scalar or per-group) | `sum_weights`, `n_eff` (probability only), same shape as `n`; `df` may be fractional |
| `types.RegressionResult` | `n_obs` | `sum_weights`, `n_eff` (probability only) |
| overlay `Summary.Parameters` (weighted host) | — | `sum_weights` over what the layer read, `n_eff` (probability; Kish over the union) |
| aggregator / crosstab components | `n`, `n_null`, counts | the floor ("Floor keys") |
| groupers | `total_n`, bucket `count` | none (the cut is weighted; counts stay raw) |

Read `n_eff` (probability) or `sum_weights` (frequency) as the sample size a weighted figure rests on — never `n`.

**Guidance (`.claude/reference/guided-analysis.md`).** The keys are generic, so the reading lives in shared places: the shared p-value rule (`sharedInterpretations["p-value"]`, `TestSharedPValueRules`) carries the unequal-weights caveat; the glossary term `effective-sample-size`; the `PULSE_WEIGHT_LOW_NEFF` message. Per-output Interpretations mention weighting only where the reading changes. Purposes never move with a weight; `n_eff` / `sum_weights` carry no Interpretation.

Per family (each equals R / the expansion under frequency; reference rows in "Reference fixtures"):

- **Lifted (both kinds).** `TEST_T` (one-sample df = N* − 1; split: Welch on N*_g; `variance: pooled` reads s²_p and df on N*_g), `TEST_WELCH`, `TEST_PAIRED_T` (weight per pair; a null in either field drops the pair before the weight is judged), `TEST_Z_TWO_SAMPLE`, `TEST_ANOVA_F`, `TEST_ANOVA_WELCH` (v_j = N*_j/s_j²), `TEST_PEARSON_R` (t and df on N* − 2, Fisher CI on N* − 3). **Each group of a split test scales by its OWN c_g = N*_g/Σw_g**: a single whole-sample c misallocates effective size when weights differ BETWEEN groups (10 rows at w = 1 beside 10 at w = 10 credited 1.09 and 10.9 instead of 10 each) — `TestWeightedTests_ANOVAFPerGroupNEff`. ANOVA-F: SSB = Σ N*_g·(m_g − grand)², SSW = Σ c_g·M2_g, df_within = N* − k.
- **Lifted, count tests (both kinds).** `TEST_PROP_Z`: p̂_g = Σw_success/Σw_g, pooled on N*_g, Wald / Wilson CI on N*_g; `successes` becomes Σw (float). `TEST_CHISQ`: Pearson on the Σw table under frequency; under probability on T* = n_eff·Σw_ij/Σw (table-level n_eff) — a FIRST-ORDER KISH approximation, not Rao-Scott: exact only when weights are unrelated to both classifications; conservative when weights are constant within a margin category, anti-conservative otherwise (the χ² overlays inherit this). `correct` (Yates) applies to the table the statistic reads. The expected-count guard `PULSE_TEST_EXPECTED_COUNT_TOO_LOW` reads the scaled table (chisq) / N*_g·p̂ (prop-z); there is no separate low-n_eff floor, because n_eff ≥ 1 whenever n ≥ 1 so it could never fire. `contingency` / totals report Σw.
- **Lifted, rank tests (frequency only).** `TEST_MANN_WHITNEY_U`, `TEST_WILCOXON_SR`, `TEST_KRUSKAL_WALLIS`, `TEST_SPEARMAN_R`, `TEST_KENDALL_TAU` — helpers in `internal/processing/test_rank.go` (`weightedMidRanks`: a run of total weight W after cumulative C ranks C + (W+1)/2; unit weights reproduce `midRanks` bit for bit). Each reads Σw where it read a count and Σ w·rank where it summed ranks; Kendall weights pairs w_i·w_j. The expansion is tied, so it rides the normal approximations (R defaults); `exact` Mann-Whitney is the tied permutation p of the expansion. Raw counts stay raw. A non-integer frequency weight is an invalid row, so ranks always see integer multiplicities.
- **Lifted, exact / distribution / spread tests (frequency only).** `TEST_FISHER_EXACT` on the Σw 2×2 table (a zero-weight row never registers a level). `TEST_KS` steps each ECDF by w and compares only after a value's tie run is consumed on BOTH sides (every weighted row is a tie on the expansion); p on n = Σw (`ksTwoSampleP`): exact and tie-conditional when Σw₁·Σw₂ < 10000, else the limiting distribution — conservative on ties, so that branch warns `PULSE_TEST_TIES_DOMINATE` on the rank tests' ≥ 50% rule. `TEST_BROWN_FORSYTHE` takes each group's frequency weighted median, folds |x − median| with weight w, df_within = Σw − k.
- **Lifted, regressions.** `REG_OLS` (both kinds; plain, ridge, lasso, elastic net) and `REG_BAYES_LINEAR` (frequency only). `olsAccumulator.UpdateRowWeighted` (`internal/processing/regression/ols_accumulator.go`) folds Σw-weighted West moments in operation-order form, so `UpdateRow` = w ≡ 1 is bit-identical; its helpers `nStar` / `scale` / `residualDF` (N* − p − 1, fractional) / `residualVariances` are the API to reuse. β is WLS, kind-free; SEs, t p-values (float `DF`), CIs, AdjR², `ResidualStdErr` are the frequency formulas on w*. Penalised: the penalty scale is Σw, so β is invariant to rescaling and identical across kinds (= `glmnet(weights=)`); ridge SEs are the sandwich on N*; lasso / elastic net SEs, p and intervals are NaN plus `PULSE_ADVISORY_PENALIZED_INFERENCE_UNDEFINED`. Bayes: a_n = a₀ + Σw/2. A listwise-complete row with an invalid or zero weight never enters `NObs` (raw). **Low n_eff:** a probability fit with n_eff ≤ p + 1 (`regression.LowNEffFloor`; `REG_GLM` binomial / poisson, with no residual df, n_eff < p + 1) warns `PULSE_WEIGHT_LOW_NEFF` `{regression, type, n_eff, min_required}`. **Residual df ≤ 0 is undefined, not 0:** σ², every SE / p / bound, `DF` and `AdjR2` are NaN (`null` on the wire); β and R² stay defined — a clamp would silently report SE 0 and AdjR² > 1 (`TestWeightedRegression_UndefinedAtNonPositiveDF`). **Robust covariance (`RegressionSpec.Covariance`)** keeps the one rule: hc0–hc3 and cluster are the frequency sandwich on w* (N* in hc1 / CR1); hac reads each row as one period whose copies share one residual (score w*·e·x); GLM / Bayes / multinomial swap in their own unit score.
- **Lifted, multinomial.** `REG_MULTINOMIAL` (both kinds) reads REG_GLM's prior-weight rule: Newton maximises Σw*·log π, Cov(β) = I⁻¹ on w*; `two_log_lik` / `aic` absent under probability.
- **Weighted jackknife (JK1).** `resample: jackknife` on a weighted `REG_OLS` / `REG_GLM` (and multinomial / ordinal) runs: every replicate refits the rows outside its delete group with their OWN weights. The JK1 g/(g−1) rescale of kept rows is not applied — β is invariant to rescaling weights, so it moves no replicate. SE = √((g−1)/g·Σ(β₍ₖ₎−β̄)²) on raw replicate count g; leave-one-out deletes records (a record the fit drops anyway yields a replicate equal to the full fit); grouped / cluster arms assign only FITTED rows to groups. Unit frequency weights reproduce the unweighted jackknife bit for bit. A weighted bootstrap stays refused (`reasonResample`).
- **Lifted, GLM and regression attributes.** `REG_GLM` reads the weight as IRLS PRIOR weights w* = c·w (`buildWeightedDesign`, `internal/processing/regression/glm.go`): working weight w*·μ'²/V, Cov(β) = (XᵀW*X)⁻¹, deviances Σw*·d — R `glm(weights = w*)`. Gamma dispersion = Σw*·(y − μ)²/V over N* − p − 1 and warns low n_eff at ≤ p + 1 like OLS. Selection stays refused; its gamma score helper fixes AIC on w* and BIC on log N* (log Σw under frequency, not the row count). `ATTR_REG_FITTED` / `RESIDUAL` / `LEVERAGE` refit with the slot's weight: fitted = WLS ŷ, residual = raw y − ŷ, leverage = wᵢ·(1/Σw + (xᵢ − μ_w)ᵀM2_w⁻¹(xᵢ − μ_w)) (R `hatvalues` on weighted `lm`). Under frequency a row's leverage is the SUM over its w copies — compare hᵢ/wᵢ with per-observation cut-offs like 2(p+1)/Σw. A zero / invalid-weight row is out of the refit (leverage 0).
- **Influence figures.** `ATTR_REG_INFLUENCE` and the `standardized` / `studentized` `ATTR_REG_RESIDUAL` kinds are frequency-only and read ONE copy of the expansion: h/w, df = Σw − p − 1, s² = Σw·e²/df (`regression.InfluenceForRow`); a probability weight is refused with `weighting.ObservationKindReason`. With `params.fit` they skip their own weight and read the bound fit: **a frequency-weighted bound fit** is read as its `rep()` expansion (df = Σw − p′, h = `hatvalues(glm(weights = f))`/f, Σ f·h = p′); **a probability-weighted bound fit** (an inherited default included) is refused PERMANENTLY (`model.CheckFitDesign` `requires: unweighted`) — a sampling weight defines no observation to delete, so a design-based fit has no model-based influence. Gates: root `TestOLSInfluence_MatchesStatsmodels`, `TestGLMInfluence_FrequencyWeightedMatchesR`, `TestGLMInfluence_RefusalsMatchPredict`.
