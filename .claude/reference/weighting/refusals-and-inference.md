Per-topic slice of the weighting reference (Refusal rules, Weighted inference (through the z / t score and quantile bullets)). Index (preamble + section map): `.claude/reference/weighting.md` — load it first, then only the slice(s) your change touches.

## Refusal rules

**As of U12 (E6-S1 consolidation).** While a weight is in force on a slot, each surface below is `PULSE_WEIGHT_UNSUPPORTED` at predict AND runtime — raised by `ResolveWeights`, so the code, message and details match (`TestWeight_InferentialRefusalsMatchPredict`, `TestResolveWeights_InferentialRefused`, `TestWeight_FrequencyOnlyMatchesPredict`). "In force" means a weight RESOLVES on the slot — its own `weight`, the request weight or `Options.DefaultWeight`: an instance default refuses these slots too, so each must opt out with `weight: null`. Details `{slot, operator, field}`, plus:

- **`reason`** (and the reason in the message, `<slot>: <op> cannot be weighted: <reason>`) on a PERMANENT refusal: `TEST_SHAPIRO_WILK`, `TEST_TUKEY_HSD`, `TEST_ANOVA_RM`, `TEST_TREND`, `ATTR_PERCENTILE` (`weighting.RefusalReason`; the Shapiro-Wilk reason names the practical obstacle — Σw expected normal order statistics and Royston's calibration on a tie-heavy expansion — since the expansion argument would define W' under `frequency`, U12 review WS-09); every built-in `post_tests[i]` (it reads aggregated rows) and any `REG_*` carrying `resample` / `selection` (slot-level `weightSlot.reason`, whatever the regression's own class); `OVERLAY_PAIRWISE_TWO_MEANS_Z` and `OVERLAY_PAIRWISE_PROBIT_T` (the overlay table's `reason`).
- **`alternative`** — the weighted twin, today only `OVERLAY_PAIRWISE_TWO_MEANS_Z` → `OVERLAY_PAIRWISE_WEIGHTED_TWO_MEANS_Z`, omitted when the instance hides the twin.
- **`kind` + `supported_kinds: ["frequency"]`** on a frequency-only operator under a `probability` weight (`weightKindUnsupported`; the message names the kind); the fixups name `weight: null` and the switch to `kind: frequency`. The Fisher cell overlay's host-only variant adds `host: crosstab.cell` (`weighting.FrequencyOnlyHostRefusal`, "Overlays").
- **`value_field`, `type`** on a weight-aware aggregator over a `decimal128` value field ("decimal128" above).

A pending refusal (no `reason`; message `has no weighted form yet`) is left only for an `Inferential` overlay kind with no class entry ("Classification by family"). The full list by family is that section's "Refused" column. Overlay specifics: every overlay whose kind is declared `Inferential: true` (`internal/descriptor/capabilities_overlay.go`) is classed by `overlayWeightClasses`, else refused off the flag through `overlayWeightClass`. `OVERLAY_PAIRWISE_WEIGHTED_TWO_MEANS_Z` is listed under both kinds (since E1-S1 its resolved status is `applied`, previously `skipped_not_weight_aware`; an inherited default is judged on its host, never on the overlay) and its host is an `AGG_WEIGHTED_MEAN` OR a WEIGHTED `AGG_AVERAGE` cell (FR-18). **On `Request.Overlays`** the overlay's OWN resolved weight decides (slot → request → default — a request or instance weight that weights the host weights the overlay too); its `weight: null` opts out and it then runs over the host as before. A host weighted ONLY by its own slot weight (or `AGG_WEIGHTED_MEAN`'s `params.weight_field`) does not refuse an overlay nothing else weights: the shipped pairwise `n_source` modes (`cell_weight_sum`, …) read such a host on purpose, and refusing it would break shipped requests — since U12 E3 such a host is read as WEIGHTED (N*, the weighted-host `n_source` rule, and a frequency-only kind's host refusal; "Overlays" below). **On Compose** (`ComposedRequest.Overlays`, no weight of its own) `ComposeOverlayWeightRefusal` refuses a refused kind (a frequency-only kind only when the inherited host weight is kind `probability`) when a slot it reads (reference or a target; every slot when `targets` is empty) has a REQUEST or INSTANCE default weight applied to an aggregation or crosstab cell — the same line — with details `{slot: "overlays[i]", operator, field, host: "requests[j].<slot>"}`; the opt-out is `weight: null` on that slot's aggregations. Runtime (`Service.applyComposeOverlays`, serial and parallel) and `ValidateComposeWithOptions` call it over the raw slots (`TestWeight_ComposeInferentialOverlayMatchesValidator`). Facet-host kinds are out of scope (facets are never weighted) — a SET `weight` on a `FacetRequest.Overlays` spec is `PULSE_WEIGHT_UNSUPPORTED` `{slot: "overlays[i]", operator, field, reason}` at predict and runtime alike (`overlayhost.FacetSpecRefusal`, after the Ref / Scope / Level rules; `TestFacetOverlay_WeightRefusedLikePredict`), where it used to be ignored silently, while `null` and an absent key run (#259); whole-chain overlays ship only descriptive kinds. A host weighted ONLY by its own slot weight (or `AGG_WEIGHTED_MEAN`'s `params.weight_field`) never refuses an overlay nothing else weights — since U12 E3 it is read as WEIGHTED instead (N*, the weighted-host `n_source` rule, a frequency-only kind's host refusal; "Overlays").

**Grouper slot weight (decision, U11 E2-S3).** `types.Group` carries the same `SlotWeight` (`weight`, `omitzero`) every other slot carries — the null-opt-out pattern needed a slot, and without one an `Options.DefaultWeight` instance could never have opted a quantile grouper out while it was refused; since U12 E5-S2 it is how a `GROUP_QUANTILE` slot opts in or out of weighting. A set weight on any other grouper is accepted and skipped; the field is projected and judged by the field-reference rule like every slot weight, and the MCP binder declares it on `groups` and both crosstab axes.

**Not weightable (not a refusal code).** `ATTR_NORMALIZED` (since U12 E1-S1; a min-max rescale has no weighted meaning — before, it was refused) and the not-weightable aggregators: default skipped, explicit `PROCESSING_CONFIG` `{slot, operator, field}`.

Windows (`WIN_*`, no slot weight): a REQUEST weight is `PROCESSING_CONFIG` `{slot, operator, field}`; `Options.DefaultWeight` is skipped (`skipped_not_weight_aware`). Filters, features, row-local attributes and the other groupers are unaffected (`TestWeight_WindowsAndUnaffectedMatchPredict`). Share and index overlays read the host payload and are therefore weighted automatically ("Overlays" below). Facets are out of scope: no `FacetRequest.Weight`, `Options.DefaultWeight` does not reach facet-population overlays, and a facet overlay spec's own set `weight` is refused (above). **Extension** aggregators, attributes and tests follow their `WeightAware` declaration ("Extension contract"): a non-aware attribute or test is refused under any weight in force, an aware one is applied.

## Weighted inference

**The one rule (U12 E1-S2, reused by every later story).** One rule (`internal/weighting/inference.go`): N* = Σw under `frequency`, Kish n_eff = (Σw)²/Σw² under `probability` (`weighting.Basis`, `NStar`, `Scale`); w* = w·N*/Σw; every weighted formula is the FREQUENCY formula on w* — point estimates (means, r) are kind-free, spreads / SEs / df read N*. `weighting.Welford` is the shared weighted Welford–West bucket (raw `N`, Σw, Σw², weighted mean, M2_w = Σw(x − mean)²; `Variance(basis)` = c·M2/(N* − 1)); `Add` follows the operation-order rule, so w ≡ 1 is the unweighted recurrence bit for bit (`TestWelford_UnityBitIdentical`) and the built-in tests run every unweighted row through it with w = 1. Later stories reuse the bucket and the basis; do not fork them.

**What it is and is not.** Under `frequency` every weighted figure equals the unweighted figure on the `rep()`-expanded rows (the reference oracle). Under `probability` the effective size is Kish's n_eff — a first-order design-effect approximation for UNEQUAL WEIGHTING only: no strata, clusters or finite-population correction, so it is not design-based (Taylor-linearised / replicate) variance, and χ² is not Rao-Scott. It also ASSUMES the weights are unrelated to the outcome and to the comparison: 1 + CV²_w is the variance inflation of a weighted MEAN under that assumption (Kish 1965), and for slopes, correlations, group contrasts and contingency tables it is a heuristic — design-based answers need `survey::svyglm` / `svyttest` / `svychisq`-style linearisation (U12 review WS-03). Point estimates (means, r, β, proportions, effect sizes built on them) are kind-free; only spreads, SEs, df and p-values move with the kind.

**n_eff output keys.** Every weighted inferential surface reports its effective size beside its raw count, absent when unweighted (`omitempty` / absent map key; `format_version` stays `"1.1"`):

| Surface | Raw count (unchanged) | Weighted keys |
|---|---|---|
| test `details` (`tests[i]`) | `n` (scalar or per-group array) | `sum_weights`, `n_eff` (probability only) in the same shape as `n`; `df` may be fractional |
| `types.RegressionResult` | `n_obs` | `sum_weights`, `n_eff` (probability only) |
| overlay `Summary.Parameters` (weighted host) | — | `sum_weights` over what the layer read, `n_eff` (probability only; Kish over the union) |
| aggregator / crosstab components (incl. `AGG_CI_*`) | `n`, `n_null`, `CellCounts`, margin counts | the floor `sum_weights`, `n_eff`, `n_weight_invalid` ("Floor keys") |
| groupers | `total_n`, bucket `count` | none (the cut is weighted; counts stay raw) |

Read `n_eff` (probability) or `sum_weights` (frequency) as the sample size a weighted figure rests on — never `n`.

**Guidance (`.claude/reference/guided-analysis.md`).** The keys are generic across every weighted surface, so the reading lives in SHARED places rather than per operator: the shared p-value rule set (`sharedInterpretations["p-value"]`, cited by every p-value field) carries the caveat "under a row weight it rests on the effective sample size reported beside n … unequal weights only, not strata or clusters" (pinned by `TestSharedPValueRules`); the glossary term `effective-sample-size`; the `PULSE_WEIGHT_LOW_NEFF` message and fixups. Per-output Interpretations that read a sample size or a weighted figure say it where the reading changes: `REG_*` `n_obs` (stays the row count; SEs and df read N*), `OVERLAY_CHISQ_MATRIX` `summary.p_value` (first-order Kish, not Rao-Scott), `AGG_CI_LOWER` / `AGG_CI_UPPER` and `AGG_WEIGHTED_MEAN` `value` (n_eff / invalid-weight exclusion), `ATTR_ZSCORE` / `ATTR_TSCORE` `value` (weighted population sd). Purposes are unchanged: what each operator is FOR does not move with a weight. `n_eff` / `sum_weights` themselves carry no Interpretation (they are not declared output paths of tests or regressions).

- **Lifted (both kinds):** `TEST_T` (one-sample: t on N*, df = N* − 1; split: Welch on N*_g), `TEST_WELCH`, `TEST_PAIRED_T` (the weight is per ROW = per pair; a null in either field drops the pair before its weight is judged), `TEST_Z_TWO_SAMPLE` (Welch SE on N*_g), `TEST_ANOVA_F` (each group scales by its OWN c_g = N*_g/Σw_g, like every split test: W_g = N*_g, grand mean Σ N*_g·m_g/N*, SSB = Σ N*_g·(m_g − grand)², SSW = Σ c_g·M2_g, N* = Σ_g N*_g, df_within = N* − k; c_g = 1 under `frequency` and at w ≡ 1, so the expansion and unity parity are untouched. U12 review WS-01 replaced one whole-sample c, which misallocated effective size when weights differ BETWEEN groups — 10 rows at w = 1 beside 10 at w = 10 credited the groups 1.09 and 10.9 instead of 10 each; `TestWeightedTests_ANOVAFPerGroupNEff`. η² therefore moves with the kind), `TEST_ANOVA_WELCH` (v_j = N*_j/s_j², df on N*_j − 1), `TEST_PEARSON_R` (r scale-free; t and df = N* − 2, Fisher CI on N* − 3). Effect sizes read the same s and N*.
- **Lifted, count tests (both kinds; U12 E1-S3):** `TEST_PROP_Z` — p̂_g = Σw_success/Σw_g, N*_g per group, pooled = Σ(p̂_g·N*_g)/ΣN*_g, Wald CI on N*_g; `successes` becomes Σw_success (float, unweighted stays int); Cohen's h unchanged. `TEST_CHISQ` — the table holds Σw per cell; frequency = Pearson on the Σw table (= `chisq.test(correct=FALSE)` on the expansion); probability = Pearson on T* = n_eff·Σw_ij/Σw (table-level n_eff) — a FIRST-ORDER KISH APPROXIMATION, not Rao-Scott (`survey::svychisq`): dividing X² by n/n_eff equals the Rao-Scott δ̄ only when the weights are unrelated to both classifications; weights constant within a margin category (e.g. stratified on the row variable) make it conservative, other designs anti-conservative (U12 review WS-02; the χ² overlays inherit it). The expected-count guard (`PULSE_TEST_EXPECTED_COUNT_TOO_LOW`), `expected_min`, Cramér's V and φ read the scaled table / n_eff; `contingency` / `row_totals` / `col_totals` report Σw. Neither test adds a low-n_eff floor: the raw floor is 1 and n_eff ≥ 1 whenever n ≥ 1, so the warning could never fire; small-N* reliability is guarded only by `TEST_CHISQ`'s scaled expected-count check — `TEST_PROP_Z` has no scaled-expected guard (U12 review WS-13, open). Gates: `internal/processing/test_weighted_counts_test.go` (unity, expansion, R 4.6.1 oracle values — `chisq.test(n_eff*prop.table(wtab), correct=FALSE)`, `prop.test` on (p̂_g·N*_g, N*_g) — closed form, scaled-table guard, exclusion, streaming = buffered).
- **Lifted, rank tests (frequency only; U12 E2-S1):** `TEST_MANN_WHITNEY_U`, `TEST_WILCOXON_SR`, `TEST_KRUSKAL_WALLIS`, `TEST_SPEARMAN_R`, `TEST_KENDALL_TAU` are `ClassFrequencyOnly`. Shared helpers in `internal/processing/test_rank.go`: `weightedMidRanks(values, weights)` (a run of equal values with total weight W after cumulative weight C ranks C + (W+1)/2; ties = the W > 1 runs, i.e. the expansion's tie sizes; unit weights reproduce `midRanks` bit for bit), `tieCorrectionW` / `tiesDominateW`, and the `rankSample` buffer (values, weights, Σw, Σw²; `concatRankSamples`). Each test reads Σw where it read a count (n_A, n_i, N, the Wilcoxon pair count, Spearman df = Σw − 2) and Σ w·rank where it summed ranks; Kendall weights each row pair w_i·w_j (copies of one row tie in both and drop out). Each equals the unweighted test on the expansion (R `wilcox.test(exact = FALSE, correct = TRUE)` / `kruskal.test` / `cor.test(method = "spearman" / "kendall")` at its defaults — `exact = NULL`, `continuity = FALSE`, the p `TEST_SPEARMAN_R` / `TEST_KENDALL_TAU` share with the matrix rank cells since U28 E3-G2 (`kendallCorTestP` / `spearmanCorTestP`, `rank_cortest.go`); the expansion is tied, so its rows ride the approximations; a weighted sample is exact only when every massed weight is 1 — reference rows). Raw counts stay raw: `n`, Kruskal `n_total`, Wilcoxon `zero_diffs` and its dropped-pair warning count; Spearman tie sizes / Kendall pair counts become Σw-based floats only when weighted. A non-integer frequency weight is an invalid row (U11 validity rule), so ranks always see integer multiplicities. Gates: `internal/processing/test_weighted_rank_test.go`, the service parity rows and reference rows.
- **Lifted, exact / distribution / spread tests (frequency only; U12 E2-S2):** `TEST_FISHER_EXACT` runs the exact test on the Σw 2×2 table (`contingency` = the Σw table as floats when weighted; `n` raw rows; first-seen row/column order counts only rows that contribute, so a zero-weight row never registers a level); the p loop is O(min margin) lgamma terms, so no size guard is needed. `TEST_KS` steps each ECDF by w (`ksTwoSampleDW`; the D walk compares only after a value's tie run is consumed on BOTH sides — the unweighted walk compared inside tie runs, a pre-existing bug fixed here because every weighted row is a tie on the expansion) and reads the Stephens-corrected asymptotic p on n₁ = Σw₁, n₂ = Σw₂ — on an expansion full of tie runs, where the continuous-data asymptotic p is conservative and no ties warning fires (U12 review WS-10, open). `TEST_BROWN_FORSYTHE` takes each group's frequency weighted median (`weightedMedianSorted`, the `AGG_MEDIAN` frequency rule: the expanded rows' median), folds |x − median| with weight w into `weighting.Welford`, and runs `summariseWeightedANOVA` (df_within = Σw − k). The `n ≥ 2 per group` guards read raw rows (as the rank tests'). References: R `fisher.test` p, `ks.test` D (Pulse's p is the Stephens form, pinned via `scipy.special.kolmogorov`), and `anova(lm(|x − median| ~ k))` — `car::leveneTest(center = median)`'s own computation in base R, so no `car` pin. Gates: `internal/processing/test_weighted_exact_test.go`, the service parity rows and reference rows.
- **Lifted, regressions (U12 E4-S1):** `REG_OLS` (`ClassAware`; plain, ridge, lasso, elastic net) and `REG_BAYES_LINEAR` (`ClassFrequencyOnly`) — `regressionClasses`. The shared streaming accumulator (`olsAccumulator.UpdateRowWeighted`, `internal/processing/regression/ols_accumulator.go`) folds the Σw-weighted West moments in the operation-order form (`(w·δ)/Σw`, `(w·δ)·δ'`), so `UpdateRow` = w ≡ 1 is the unweighted fit bit for bit; it carries raw `n`, Σw, Σw² and the slot's `weighting.Basis`, and its helpers `nStar` / `scale` / `residualDF` (N* − p − 1, fractional) / `residualVariances` (RSS/df on the w-scale Gram, c·RSS/df on w*) are the API the later regression stories reuse. β is WLS, kind-free; SEs (incl. the intercept's 1/Σw term), t p-values (float df), AdjR² and `ResidualStdErr` are the frequency formulas on w*; the coefficient confidence intervals (`ci_lower` / `ci_upper`, U42) read the same t on that float df, reported as `RegressionResult.DF`. Penalised: the penalty scale (and the coordinate-descent standardisation) is Σw where it was n, so β is invariant to weight rescaling, identical across kinds and = `glmnet(weights=)` / the expansion under frequency; SEs stay plug-in approximate on N*. Bayes: X'WX, X'Wy, y'Wy and a_n = a₀ + Σw/2 (= the expansion). Engines read the stamped `RegressionSpec.Weight` (`rowWeights`, `internal/processing/regression/weight.go`): a listwise-complete row whose weight is invalid or zero is excluded and never enters `NObs`. `RegressionResult` gains `SumWeights` / `NEff` (`sum_weights` / `n_eff`, `omitempty`, weighted only; `NObs` raw). **Low n_eff:** a probability fit with n_eff ≤ p + 1 (`regression.LowNEffFloor`, the raw-row floor; `REG_GLM`, with no residual df, only n_eff < p + 1) warns `PULSE_WEIGHT_LOW_NEFF` `{regression, type, n_eff, min_required}` (error under strict; `applyRegressionLowNEff`, streaming and buffered exits). **Residual df ≤ 0 is undefined, not 0 (U12 review WS-05):** `residualVariances` returns NaN when N* − p − 1 ≤ 0, so σ², `ResidualStdErr`, every SE, t p-value and confidence bound, `DF` and `AdjR2` (`adjustedR2`) are NaN — `null` on the wire via `types.MarshalFinite` — for plain, ridge, lasso and elastic net alike; β and R² stay defined. The old clamp of a negative σ² to 0 (SEs 0, AdjR² > 1) and the ±Inf at df = 0 are gone; `sqrt`'s clamp now only absorbs rounding residue on a df > 0 fit (`TestWeightedRegression_UndefinedAtNonPositiveDF`, `TestWeightedRegressions_LowNEffAtFloor`). Streamability unchanged (a weighted OLS / Bayes spec still streams; modifiers still buffer and refuse any weight). Gates: `internal/processing/regression/weight_test.go` (unity bit-identical, frequency = expansion, closed-form WLS on w* under both kinds, probability scale invariance, penalised β kind-free, invalid / zero exclusion, streaming = buffered), `internal/processing/regression_weight_test.go` (stamp, tally, strict, low n_eff on both paths), `TestResolveWeights_AwareRegressionsApplied`, root `TestWeight_RegressionsMatchPredict`. **Robust covariance (U25 E5-S1, `RegressionSpec.Covariance`)** keeps the one rule: hc0–hc3 and cluster are the frequency sandwich on w* (meat Σ ω·w*·e²·xxᵀ; cluster sums Σ w*·e·x per cluster; N* in hc1 / CR1), equal under `frequency` to `sandwich` on the `rep()`-expanded `lm`; hac reads each row as one period whose copies share one residual, so its score is w*·e·x (lag 0 is then Σ(w*·e)²·xxᵀ, not hc0's) — R `NeweyWest(lm(weights = w*), adjust = FALSE)·N*/(N* − k)` (`mv_robust_vcov.json`, `TestRegressionCovariance_MatchesROracle`). `REG_GLM` (E5-S2) keeps the same rule with the IRLS unit score μ'·(y − μ)/V·x in place of e·x and w* its prior weight (frequency = `sandwich` on the expanded `glm`; hac = `NeweyWest(glm(weights = w*), adjust = FALSE)·N*/(N* − k)`), and `REG_BAYES_LINEAR` (frequency only, w* = w) with score (y − xᵀμ_n)·x (`mv_robust_vcov_glm.json`).
- **Lifted, GLM and regression attributes (U12 E4-S2):** `REG_GLM` (`ClassAware`, binomial / poisson / gamma) — `glmEngine.FitBuffered` reads the stamped weight through `buildWeightedDesign` (`internal/processing/regression/glm.go`): a listwise-complete row with an invalid or zero weight is dropped, the rest enter as IRLS PRIOR weights mapped onto w* = c·w (a multiply only under probability), so the working weight is w*·μ'(η)²/V(μ), Cov(β) = (XᵀW*X)⁻¹ and deviance / null deviance (null μ = the weighted ȳ) are Σw*·d — R `glm(weights = w*)` under both kinds (`glm(weights = w)` = the expansion under frequency). β is kind-free; the dispersion stays fixed at 1 (gamma caveat unchanged, owned by U36). `NObs` raw, `SumWeights` / `NEff` as OLS; the low-n_eff warning (p + 1 floor) carries GLM-specific prose (Wald z has no residual df). `ATTR_REG_FITTED` / `RESIDUAL` / `LEVERAGE` (`attributeClasses`, `ClassAware` = REG_OLS's kinds): the attribute slot is stamped (`weighting.IsAware` beside the extension check), `makeRegressionSpec` copies it onto the refit spec, the prepass buffers the weight value with each row, `FitForAttribute` folds `UpdateRowWeighted`; fitted = WLS ŷ, residual = raw y − ŷ, leverage `LeverageForRow(fit, x, w)` = wᵢ·(1/Σw + (xᵢ − μ_w)ᵀM2_w⁻¹(xᵢ − μ_w)) = diag W½X(XᵀWX)⁻¹XᵀW½ (R `hatvalues` on a weighted `lm`, scale-invariant; under `frequency` a row's leverage is the SUM over its w copies, so compare hᵢ/wᵢ with per-observation cut-offs such as 2(p+1)/Σw); a zero / invalid-weight row is out of the refit and its leverage is 0. Unity is bit-identical (w·1 and Σw = n exact). Gates: `internal/processing/regression/glm_weight_test.go` (unity, expansion, exclusion), `internal/processing/attribute_reg_weight_test.go` (unity, expansion, exclusion, slot / request / opt-out through both paths) — their external R pins moved into the generated reference rows (E4-S3, "Reference fixtures"), `TestWeightedRegressions_GLMLowNEff`, root `TestWeight_RegressionsMatchPredict` (REG_GLM rows), `TestWeight_RegressionAttributesMatchPredict`.
- **Lifted, z / t scores and quantile buckets (both kinds; U12 E5-S2):** `ATTR_ZSCORE` / `ATTR_TSCORE` (`attributeClasses`, `ClassAware`) fold the stamped attribute weight through `weighting.Welford` in their pass 1 (`popScoreState`, `internal/processing/attribute.go`; an unweighted slot folds w = 1, bit-identical) and score every row against the weighted mean and the weighted POPULATION sd √(M2_w/Σw) — scale-free, so identical under both kinds (statsmodels `DescrStatsW(ddof = 0)`); a zero / invalid-weight row adds nothing but is still scored. Both stay two-pass on the buffered and streaming arms; the parity steering `ATTR_ZSCORE` with `weight: null` is unchanged. `GROUP_QUANTILE` (`ClassAware`) is the one weighted grouper: `StampWeightsWith` now stamps `groups[i]`, `crosstab.rows[i]` and `crosstab.columns[i]` (`stampGroups`: the applied weight on a class with a kind, `null` on any other grouper that names one), `namesWeight` and `NewWeightRowTally` read those slots (so a grouper slot weight alone warns `PULSE_WEIGHT_INVALID_ROWS`). The cut (`quantileGrouper.weightedBuckets`, `internal/processing/grouper.go`) is the U11 weighted-quantile rule: C = the cumulative weight through a value-sorted row (probability weights rescaled so Σw = the contributing row count, Hmisc `normwt = TRUE`; snapped to an integer within 1e-9, `snapCumWeights`), W the total, bucket ⌊⌊C − 1⌋·k/W⌋ — bucket b opens at the order statistic x₍ᵣ₎, r = ⌈b·W/k⌉ (`quantileOrderIndex`); w ≡ 1 is rank·k/n exactly. A heavy row spanning a cut lands whole in the higher bucket (its last expanded copy's), so under `frequency` the cuts equal the expansion's but counts / highs need not; a zero / invalid-weight row carries no mass and is bucketed by value with the row below it. Bucket `count`, the grouper floor `{total_n, n_null}` and crosstab counts stay raw. Gates: `internal/processing/score_quantile_weight_test.go` (unity bit-identical, expansion, closed form, scale invariance, exclusion, knife-edge snap, group stamping and tally), root `TestWeight_ScoresAndQuantileMatchPredict`, `TestResolveWeights_AwareScoresAndQuantileApplied`, the service parity rows and reference rows.
