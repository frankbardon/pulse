## Overlays

- **Share / index kinds are descriptive** (no `Inferential` flag, never refused) and carry NO weight logic: they read the host payload, which is already weighted — matrix and series share / index kinds (streaming fold included), Compose and panel index kinds over weighted slots. Gate: a request-weighted host's layers equal the physically expanded cohort's unweighted layers and leave the host payload byte-identical to the overlay-free run (`internal/service/weight_overlay_test.go`). An undefined series entry (first `_PRIOR` point, unfilled rolling window) is NaN in Go and `null` in JSON, so gates compare layers on the JSON form (`.claude/reference/response-components.md` (Undefined figures on the wire)).
- **Mean overlays on a weighted host (both kinds).** A host cell is WEIGHTED when it carries the floor key `sum_weights`, whatever the weight's source — its own slot weight included (reading such a host on the raw `n` was silently too narrow). The kind is read off the floor too (`n_eff` is stamped only under probability). The one reader is `processing.readMeanLeg` behind `CrosstabHostView.MeanLeg`: N* = `sum_weights` (frequency) or `n_eff` (probability) — never the triple's `n` — and variance = `weighting.ScaledVariance` (c·m2/(N* − 1)); Welch df on N*. An unweighted cell reads `{mean, variance, n}` byte-identically. `OverlaySummary.Parameters` adds `sum_weights` over the distinct legs read and, under probability, `n_eff` = Kish over their union. Series hosts carry `processing.WelfordTriple` values (no floor keys), so a Compose / chain slot narrowed to its `AGG_WELFORD` reads each row's leg from the bucket components (`welfordComponentsLeg`); with components disabled on such a slot the overlay is `PULSE_OVERLAY_COMPONENTS_REQUIRED` `{…, reason: "components_disabled"}` (`descriptor.ComposeOverlayTwoSampleInputsRefusal`, called by the validator and the runtime, re-checked at fold time) — never an empty layer.
- **`n_source` on a weighted host** (`weighting.NSourceRefusal`). An omitted source reads N*. Raw-count sources (`cell_n_unweighted`, `n_within`, every distinct-key mode) are `PROCESSING_CONFIG` — a raw row count is not a valid sample size on a weighted host. Weight-sum sources (`cell_weight_sum`, `cell_value_weighted`) are accepted under frequency and `PROCESSING_CONFIG` under probability (`weighting.WeightSumNotSampleSize`: Σw is arbitrary in scale and can overstate OR understate the sample). Margin modes read a margin floor's N*. Predict (basis = the crosstab cell's applied resolved weight, `crosstabCellWeightBasis`) and runtime (basis = `CrosstabHostView.WeightBasis`) raise the same code and message (`TestWeight_OverlayNSourceRefusalsMatchPredict`).
- **Contingency and proportion overlays on a weighted host.** Cells and margins are Σw, read through the floor keys (`CrosstabHostView.CellFloor` / `RowMarginFloor` / `BaseFloor`); `weightedLegTally` folds a set of legs into the union's Kish scale c = n_eff/Σw. **χ²:** frequency = Pearson on the Σw table; probability = the table (or each row / column for `_ROW` / `_COL`) scaled by the c of the cells it reads, then ordinary Pearson — `TEST_CHISQ`'s first-order Kish form, NOT Rao-Scott. `_VS_REF` scales only the TARGET (the reference is a fixed distribution). `PULSE_OVERLAY_EXPECTED_LOW` / `expected_min` read the scaled expected; `Summary.Min` / `Max` stay observed Σw. Frequency and unweighted hosts never multiply (byte-identical). **Proportions:** p̂ = Σw_success/Σw_base, n = N* of the cell's BASE (its normalise denominator, handed per cell by both arms, never on the wire; unreadable ⇒ the pair skips — never the cell's own N*). A probability row with no readable floor is a missing margin, never Σw. **Host basis:** a per-Request host takes it from the STAMPED crosstab cell weight (an `AGG_WEIGHTED_MEAN` cell emits `n_eff` under either kind, so floor keys cannot tell); Compose slots infer it from floor keys. **Fisher** (frequency only): the exact test on the integer Σw table; a probability weight on the HOST cell alone is `PULSE_WEIGHT_UNSUPPORTED` `{slot, operator, host: crosstab.cell, kind, supported_kinds}` (`weighting.FrequencyOnlyHostRefusal`) at dispatch and in predict.
- **Components-disabled host.** The floor is the only place a probability host's n_eff shows. A kind that scales Σw onto N* (`weighting.ScalesByHostFloor` is the list) over a host weighted under probability AND built with components disabled is `PROCESSING_CONFIG` `{slot: "overlays[i]", operator, host, kind: "probability", reason: "components_disabled"}` (`weighting.HiddenFloorRefusal`) — otherwise Σw silently becomes n. Raised at dispatch and in predict for per-Request hosts, and by `descriptor.ComposeOverlayHiddenFloorRefusal` for Compose, then re-checked at fold time (`Service.composeOverlayFloorsPresent`; a hit is `PROCESSING_INTERNAL`, an engine bug). The Compose components veto keeps a slot's `components.crosstab` exactly when its crosstab cell is weighted (`CrosstabCellWeightBasis`). Frequency hosts (Σw IS N*) are untouched. Decision: refuse rather than force components on. Gate: root `TestWeight_ComponentsDisabledFloorRefusalMatchesPredict`.
- **Overlay gates.** `internal/service/weight_overlay_parity_test.go` holds a case table total over the manifest's overlay `weight_kinds`, per host (per-Request crosstab on both arms, Compose) and per source (request, slot-only, default): unity parity, frequency expansion, probability scale invariance, slot-only host reads N*. Reference rows: `TestWeightReferenceValues/overlays`.
- **`OVERLAY_PAIRWISE_WEIGHTED_TWO_MEANS_Z` hosts (FR-18).** Runtime admits a cell carrying the weighted-moment keys (`HasWeightedMomentCells`), which a weighted `AGG_AVERAGE` cell does; predict admits `AGG_WEIGHTED_MEAN` always and `AGG_AVERAGE` iff a weight resolves on the cell — the `StampWeights` precedence, so the arms agree (`TestPairwiseWeightedTwoMeansZ_PredictRuntimeParity`). The feature hard edge is the any-of group `{AGG_AVERAGE, AGG_WEIGHTED_MEAN}` (`hardEdges`). **`n_basis` vs `kind`:** `n_basis: "weights"` (Σw as n) on a probability host — including the `weight_field` sugar, which is kind probability — is `PROCESSING_CONFIG` (`weighting.NBasisRefusal`), identically in predict and runtime; `kish`, and `weights` on a frequency or unweighted host, are unaffected.
