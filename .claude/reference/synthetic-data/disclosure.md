# Synthetic data — the disclosure section

Slice of `.claude/reference/synthetic-data.md` — load the index first, then only the slice(s) your change touches.

**A twin's closeness to real records is MEASURED, never guaranteed: the disclosure section reads the tagged cohort, its own seeded stream and the instance comparison and memory limits.** `FidelityReport.Disclosure` (`internal/synth/disclosure.go`) is the one report section ON by default (opt out: `SynthOptions.DisableDisclosure` / `--no-disclosure`).
- **Exact matches**: `exact_matches` / `exact_match_rate` over ALL generated rows — a row whose stored value equals some source row's on every output column, null equal to null. The key reads exact representations (u64 word via `CaptureExactU64`, decimal digits, set mask words, vector element bits), never a lossy float echo (`TestDisclosure_ExactKeyIsFaithfulPerType`).
- **DCR**: `dcr_median` / `dcr_p5` (type-7) of each SAMPLED generated row's Gower distance to its closest source row — mean over output columns (`_synthetic` excluded) of per-column terms in [0, 1]: range-normalised |a − b| for numeric / decimal / date-family (range over SOURCE rows, clamped at 1; zero range scores 0 equal / 1 otherwise; NaN equals only NaN); 0/1 mismatch for categoricals and `packed_bool` (merged dictionary); Jaccard for `set_*` (two empties 0); mean of element terms for `vec_*`; null 0 when both, 1 when one (`TestDisclosure_GowerTerms`).
- **The sample is the section's own**: at most `SynthOptions.DisclosureSample` rows (0 → `DefaultDisclosureSample`, 10,000; negative → `SERVICE_VALIDATION`), picked by Floyd's algorithm over a splitmix64 stream keyed `drawStreamKey(seed, disclosureSampleDomain)` and sorted — so toggling or resizing the section moves no generated byte, and tagged and `--synthetic-only` runs write identical sections.
- **Bits**: distances sum in schema order with adds and divisions only; the quantile product is barriered; per-row minima are independent, so worker count moves no bit (`TestDisclosure_WorkerCountMovesNoBit`). A partial sum at or past the best is abandoned (terms are non-negative).
- **Cost and the limits**: `DisclosureComparisons` = min(sample, row count) × source rows is charged against `Limits.MaxDisclosureComparisons` (default 5 × 10^10, `docs/src/library/tuning-limits.md`) and `DisclosureMemoryEstimate` against `Limits.MaxEstimatedMemory`, both by `CheckDisclosureBudget`, which the facade runs BEFORE the fidelity-model refit and generation, reading the source header only. Past either: `PULSE_LIMIT_EXCEEDED` (memory first) and nothing is written.
- **Cancellation**: workers claim `disclosureChunkRows` (8) rows at a time and check ctx before each claim; a cancel returns `ctx.Err()` and no report is written.
- No predict side (`Synth` has no predict root). A twin of only low-cardinality columns copies rows by construction and the measure says so (rate 1, DCR 0).
- Gates: `TestDisclosure_*`, root `TestSynth_Disclosure*`, `TestSynthFromProfileCLI_DisclosureFlags`. Skill: `skills/synth-disclosure-report.md`.
