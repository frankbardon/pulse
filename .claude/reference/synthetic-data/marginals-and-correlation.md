# Synthetic data — boolean and small-integer marginals, correlation reconstruction, residual correlation capture

Slice of `.claude/reference/synthetic-data.md` — load the index first, then only the slice(s) your change touches.

**Boolean marginals: a `packed_bool` reconstructs as `bernoulli`, never as a clamped normal.** A `packed_bool` falls to the profiler's NUMERIC accumulator, and reading that as a clamped `normal(mean, std)` is silently wrong: the writer reduces each draw to one bit, so a 20%-prevalence boolean generated at ~69% (on a survey cohort, 89 of 90 boolean fields off by > 0.05). `SpecFromProfile`'s boolean arm (`isBooleanFieldType`, `internal/synth/copula.go`) runs AHEAD of `--fit-shape` — `fitNumericShape` prefers a two-spike mixture on a 0/1 field that reproduces prevalence no better and costs a bisection per draw.
- **All THREE writers that can reach a boolean are covered, because fixing one leaves the others wrong with no signal.** (1) Its own sampler draws `bernoulli`. (2) A conditional pair (`conditionalNumericDraw`) draws `Bernoulli(cell Mean)` — otherwise the defect recurs PER CELL, worst exactly where the contrast lives. **Whether the cell draw is a step is DERIVED from the target's own `FieldSpec` (`buildBernoulliConditionals`), never read off the pair**: a wire flag can disagree with the marginal it overwrites (one arm once forgot to set it). The old `bernoulli` pair flag is removed: a spec carrying it is refused `PULSE_REQUEST_UNKNOWN_FIELD` with `details.replacement` (declare the target field `bernoulli`; `withRemovedPairBernoulli`). (3) A model draws through `quantileFor`'s step Q, making the composed draw a **PROBIT** with the marginal held exactly at p.
- `fieldMoments` admits `bernoulli` with exact moments (p, √(p(1−p))) and no clamp. **`modelSpecFromProfile` admits a bernoulli target** — refusal would be invisible, because the per-target retirement rule already dropped its conditional pair. `std` is not floored at p ∈ {0, 1}; the drawer's `std <= 0` guard drops the model with a warning.
- **A bernoulli target's model recovery is NOT IDENTIFIED** (a 0/1 value does not determine its latent), so `latentFor` refuses it (`latentInvertible`); the fidelity report scores it on the interval-midpoint probit score instead of going silent (`synthetic-data/residuals-and-fidelity.md`).
- `toBool`'s float arm rounds at **0.5** (not `!= 0`), so a HAND-AUTHORED continuous distribution on a `packed_bool` is biased, never inverted.
- **A modelled boolean is CAPTURED as a probit, not read as one.** Reading a least-squares linear-probability fit through the step Q silently shrinks every effect that saturates near 0 or 1 while signs stay right. `fitProbit` (`internal/synth/profile_probit.go`) maximises the probit likelihood on the same listwise rows (Fisher scoring, step halving, same thin-level ridge); the document records `link: "probit"`, probit-scale coefficients, `residual_std` 1, McFadden pseudo-R² as `r2`. `SpecFromProfile` maps it onto the UNCHANGED composed draw (`probitSpecScale`: intercept' = p + std·(a + Φ⁻¹(1−p)), coefficient' = std·b, residual_std' = std), so generation and recovery need no probit arm. A `link` on a non-bernoulli target is "not applied". The fit is FMA-free end to end. **Separation**: η is clamped at ±7; a fit that never settles keeps its linear fit with an ATTENTION warning (`probit fit fell back to a linear fit`).
- Gates: `TestSpecFromProfile_Boolean*`, `TestSynth_Boolean*`, `TestSynthModel_BooleanTargetKeepsPrevalenceAndOrdersByPredictor` (both halves in one test — each is trivially satisfiable by abandoning the other), `TestLatentFor_EveryDistributionIsClassified` (a new distribution must be classified, not defaulted), `TestFitProbit_*`, `TestProbitSpecScale_DrawIsTheCapturedProbit`. Detail: `skills/synth-marginals.md`, `skills/op-synth-bernoulli.md`, `skills/type-packed-bool.md`.

**Small-integer marginals: a `u4`/`u8`/`u16`/`u32`/`u64` reconstructs from its own per-level HISTOGRAM (`discrete`), never as a clamped normal.** The writer stores `floor(v+0.5)`, so a clamped normal is quantized: the bell flattens the scale's shape and the clamp piles mass on the near bound while the MEAN comes back roughly right — which is how it survived (an NPS top level off by 28% of its size with the mean 3% off).
- `NumericProfile.Discrete` (additive `omitempty`) carries `{value, count, frequency}` per observed level, ascending; `SpecFromProfile` builds a `discrete` distribution (`values` + optional `weights`), moments computed FROM the support (`parseDiscreteLevels`), never read off the profile, so hand-authored and derived specs cannot disagree.
- **Which types claim the arm is not a taste judgement**: `isIntegerQuantizedFieldType` is exactly the set of writer arms applying `Floor(f+0.5)` — floats, `decimal128`, `date` and `packed_bool` are excluded.
- **`maxDiscreteLevels` (64) is where capture ABANDONS the histogram, never truncates it** — a top-64 view of a wide field makes every share a share of an arbitrary subset. ABSENCE of the `discrete` key is the record: no warning, no knob. A package constant, not an option, so two documents over the same cohort cannot disagree about what the field IS. **The boundary is pragmatic, not a fidelity cliff**: relative error of the clamped normal is scale-invariant; only absolute error shrinks (~1/K).
- Capture is UNCONDITIONAL (it fixes the default reconstruction) and rides the existing scan, bucketed by the writer's own rounding so captured and generated levels are the same integer. The arm runs AHEAD of `--fit-shape` for the boolean reason.
- **ALL THREE WRITERS are covered.** (1) `discreteSampler` draws the staircase. (2) A conditional pair locates the cell's moments ON the staircase via the same composed construction as the model draw, resolved from the target's `FieldSpec` (`buildDiscreteConditionals`), never a wire flag. (3) The model draw becomes an **ORDERED PROBIT**; `modelSpecFromProfile` admits a discrete target (refusal would be invisible). Both numeric-target pair filters in `SpecFromProfile` name `DistDiscrete`, separately — one naming it says nothing about the other.
- **A modelled discrete target's recovery is NOT IDENTIFIED**: `latentFor` refuses a staircase (`latentInvertible` = {`DistBernoulli`, `DistDiscrete`}). The fidelity report scores it on the interval-midpoint probit score; `model_residual_correlations` cannot be calibrated that way, so such pairs stay counted under `no_model_fit` — read that figure only with its participant count.
- Value-scale Pearson on a `discrete` copula participant attenuates; rank correlation holds.
- **The pre-rounding gotcha DISAPPEARS** for these fields: the row value already IS the stored integer, so `round(nps) == 9` ≡ `nps == 9`. The `round`-not-`int` advice remains for floats, over-cap integers and hand-authored continuous distributions on integer fields.
- **The writer CLAMPS an out-of-range draw at every unsigned width, `u4` included** (`clampU4`): masking to the low nibble once wrote a top rounding bucket (16) as 0 — the upper tail stored as the lowest value, silently (`TestWriter_U4ClampsLikeTheWiderUnsigned`).
- Gates: `TestSpecFromProfile_*Discrete*`, `TestSynth_Discrete*`, `TestProfileDiscrete_*`, `TestSynthModel_DiscreteTargetKeepsItsLevelsAndOrdersByPredictor`, `TestRulesCoherence_DiscreteScoreNeedsNoPreRoundingNormalisation`. Detail: `skills/synth-marginals.md`, `skills/op-synth-discrete.md`, `docs/src/cli/profile-create.md` (Small-integer fields).

**Correlation reconstruction.** The spec key is `rho` on `correlations`, `residual_correlations` and a vector's `correlations` (Go `Rho`). Every synth document decodes STRICTLY (`internal/synth/spec_decode.go`) because a misspelled key once decoded with the correlation DROPPED and generated none, silently; a field's `params` are held to `distributionParamKeys` (`TestDistributionParamsMatchManifest`, `TestDistributionParamsDeclaredMatchRead`).
- `internal/synth/copula.go` is a Gaussian copula: correlated standard normals via Cholesky → Φ → each field's own quantile Q_i (`fieldMoments` validates, `quantileFor` builds Q_i). Supported distributions are the ones `fieldMoments` admits; any other in `correlations` is `SERVICE_VALIDATION` naming it. `normal` reduces exactly to `mean + std·u`; every other marginal keeps its own shape.
- **A participant must be a SCALAR field TYPE, and that predicate is DERIVED, never transcribed**: `isNumericFieldType` reads `fieldTypeFromName` and admits every declarable non-categorical, non-set type. A hand-written list once omitted `u4` and silently emptied a cohort's whole correlation structure. `packed_bool` and `decimal128` are IN (both reach the numeric accumulator). **The boundary is TYPE, not distribution** — a `date`'s `uniform_date` is refused one call later by `fieldMoments`, naming the distribution. Gate: `TestFieldTypePredicates_ClassifyEveryDeclarableType`, driven off the `encoding.FieldType` enum (a missing name is by definition not in a sample).
- A step / staircase participant holds its marginal EXACTLY and attenuates value-scale (and, with heavy ties, rank) correlation.
- A `--fit-shape` field stays out of the value-scale matrix (pre-claimed when unmodelled; permanently refused when modelled — its structure rides `residual_correlations`). The `mixture` arm in `fieldMoments` exists for the MODEL draw.
- Fidelity gates: `TestSynth_CorrelationReconstructionWithinTolerance`, `TestSynth_CopulaPreservesLognormalMarginal`.
- **Unmeasured matrix entries: ASSUME AND RECORD, never refuse and never silently.** `buildCorrelator` fills pairs the list does not name with 0 and returns a warning counting them — an incomplete list is the NORMAL input and zero adds no unrequested structure, but silence hid that most pairs were asserted rather than measured. `cholesky` returns the diagonal jitter it needed and a non-zero ridge is its own warning, so a request bent into shape is findable. Neither warning changes a number. Detail: `skills/synth-correlations.md`.

**Residual correlation capture (`--residual-correlations`).** `ProfileOptions.FitResidualCorrelations` (requires `--fit-models`) adds the additive `residual_correlations` section (`synth.ResidualCorrelationProfile`): correlation among FITTED MODEL RESIDUALS, because raw correlation double-counts every predictor two targets share. Measured in memory off `FieldModel.Residuals`, no extra read. Shape `{fields, pairs, unmeasured}` — exhaustive and non-overlapping.
- **The FULL submatrix, never a top-K sample**: the consumer is a joint draw, and a pair left out is a hole, not a weak pair. Not implied by `--fit-models` (quadratic in modelled fields); shares no flag with `--include-correlations`.
- **Measured-zero and unmeasured are STRUCTURALLY different**: two lists, and an unmeasured entry carries NO `rho` key, so a zero can never stand in for a gap. Reasons: `insufficient_overlap` (fewer than `synth.minResidualPairObservations` = 3 shared rows — two points always give ±1) and `no_variance` (a constant residual, 0/0). That floor is not `MinPairObservations` (30): 3 decides "is there a measurement" (a GAP), 30 decides "is it stable" (a WARNING); they compose.
- **Participants are every model carrying a residual vector, INCLUDING a zero-predictor model** (it still has a residual). A model with no residual vector (a decoded document — the reservoir is `json:"-"`) is not a participant.
- Thin measured pairs reuse `thinPairWarning`, capped at `maxThinResidualPairWarnings` (20). Capture is byte-reproducible (sorted participants, slice enumeration, no map-order float folds). `SpecFromProfile` translates measured pairs onto `Spec.ResidualCorrelations` and `unmeasured` into NOTHING (`synthetic-data/residuals-and-fidelity.md`). Detail: `skills/synth-profile-capture.md`.
