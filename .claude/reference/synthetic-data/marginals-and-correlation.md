# Synthetic data — boolean and small-integer marginals, correlation reconstruction, residual correlation capture

Per-topic slice of the synthetic-data reference (boolean and small-integer marginals, correlation reconstruction, residual correlation capture). Index (preamble + section map): `.claude/reference/synthetic-data.md` — load it first, then only the slice(s) your change touches.

**Boolean marginals: a `packed_bool` reconstructs as `bernoulli`, never as a clamped normal.** A `packed_bool` is summarised by the profiler's NUMERIC accumulator (it is neither date, categorical nor set, so it falls to that default branch), and the obvious reading of that summary — `normal(mean, std)` clamped to the observed `[0, 1]` — is WRONG on the wire, severely and silently. The field holds ONE BIT, so the writer must reduce a continuous draw to 0 or 1; a clamped normal puts mass at exactly 0 only for the draws that fell BELOW zero, so under the historical `value != 0` threshold `P(false)` was `Φ(−p/σ)` and a 20%-prevalence boolean generated at **69.1%**, a 50% one at **84.2%**, an 80% one at **97.7%** — measured, and matching that formula to three digits. On the motivating 381,324-row survey cohort, where **90 of 122 fields are `packed_bool`** and **90 of 105 captured models target one**, the mean prevalence error was **0.4676** with **89 of 90 fields off by more than 0.05**: every 11–14% brand-attribute item generated at ~64%, turning a rare attribute into the majority answer. Post-fix on the same profile: mean error **0.0032**, max **0.0116**, **0** fields off by more than 0.05. `SpecFromProfile`'s boolean arm (`isBooleanFieldType`, `internal/synth/copula.go`) sits AHEAD of the `--fit-shape` arm deliberately — `fitNumericShape` happily prefers a two-component mixture on a 0/1 column, since two well-separated near-zero-variance spikes beat a normal on BIC every time, and that mixture reproduces the prevalence no better while costing a bisection per draw; a boolean's shape is not a thing to discover, it is one number. **All THREE writers that can reach a boolean are covered, because fixing one leaves the others wrong with no signal.** (1) Its own sampler draws `bernoulli` directly — exact. (2) A conditional pair overwrites the target outright from the cell's captured moments, so `conditionalNumericDraw` (`internal/synth/conditional_sample.go`) draws `Bernoulli(cell Mean)` with `Std` unused; without it the defect recurs once PER CELL and is worst exactly where the signal is — a 5% cell generated at 41%, destroying the contrast the pair exists to carry. **Whether the cell draw is a step is DERIVED from the target's own `FieldSpec` (`buildBernoulliConditionals`), never read off the pair.** `CategoricalNumericPairSpec` / `SetNumericPairSpec` carried an additive `Bernoulli bool` (`bernoulli`, `omitempty`) until it was RETIRED: the slot is still accepted so an older document parses, is read by nothing, and a pair still declaring it over a non-bernoulli target is WARNED (own taxonomy kind) rather than silently ignored. A wire flag can DISAGREE with the marginal it is overwriting, which is the failure class this whole arm exists to remove, and it was not hypothetical — `SpecFromProfile`'s SET-numeric arm admitted a `DistBernoulli` target, said in a comment that the flag was "carried the same way" as the categorical-numeric arm's, and never set it, so every profile-derived set-numeric pair over a boolean target drew a clamped normal. Deriving makes the omission unrepresentable; nothing has to remember to carry it. Byte-identical on the motivating cohort (720 categorical-numeric pairs, 705 flagged, flag ⇔ marginal agreement exact, 0 set-numeric pairs), pre- and post-change emitted specs both producing `602edfe2…` at 20,000 rows / seed 11. (3) A model draws through `quantileFor`'s step `Q`, which makes the composed draw a **PROBIT**: `P(1 | row) = Φ((μ − Φ⁻¹(1−p)) / σ)`, marginal held exactly at the captured `p` because `Φ(u)` is uniform whenever `u` is standard normal. `fieldMoments` admits `bernoulli` with exact closed-form moments (`mean = p`, `std = √(p(1−p))`) and declares NO clamp, since `Q` emits only 0 or 1. **`modelSpecFromProfile` admits a bernoulli target rather than refusing it** — refusal would be invisible, because the per-target retirement rule already drops a modelled boolean's captured conditional pair, so a refused model leaves the field with no conditioning at all. Three consequences. `std` is 0 at `p` of exactly 0 or 1 and is deliberately NOT floored: `buildModelDrawers`' own `std <= 0` guard turns that into a dropped model WITH a warning rather than an infinite `invStd`. **A bernoulli target's model recovery is NOT IDENTIFIED**: a step `Q` means a 0/1 value does not determine the latent that produced it, so `latentFor` REFUSES (`latentInvertible`, the only distribution `fieldMoments` admits and `latentFor` does not) and the fidelity report's `models` entry ships its captured coefficients with an `error` instead of a delta — the inverse-Mills alternative was rejected because a two-valued "latent" reports a large false attenuation for a generation path that is exactly correct. And `toBool`'s float arm now rounds at **0.5** rather than testing `!= 0`, which matters only for a HAND-AUTHORED spec putting a continuous distribution on a `packed_bool`: that path is still biased (22.7% for a 0.2 field, because clamping piles asymmetric mass on the near bound) but no longer inverted. `format_version` does NOT move — `synth.Spec` lives in `synth/`, not `types/`, so it is unreachable from `internal/descriptor.BuildPayloadSchema`. Gates: `TestSpecFromProfile_BooleanReconstructsAsBernoulli`, `TestSpecFromProfile_BooleanIgnoresCapturedShape`, `TestSynth_BooleanMarginalPrevalence`, `TestSynth_BooleanConditionalPairPrevalence`, `TestSynth_BooleanConditionalPairDerivesFromTheMarginal` (the retirement gate: an UNFLAGGED bernoulli target draws the step on both pair arms, and a pair still declaring the retired flag over a non-bernoulli target is ignored AND warned), `TestSynth_BooleanConditionalPairOnAContinuousMarginalIsBiased` (the deliberate negative, re-pointed at the one arm the continuous draw still legitimately reaches — a hand-authored continuous distribution on a `packed_bool`), `TestSynthModel_BooleanTargetKeepsPrevalenceAndOrdersByPredictor` (both halves in one test — each is trivially satisfiable by abandoning the other), `TestLatentFor_EveryDistributionIsClassified` (the three-way partition that forces a new distribution to be classified rather than acquiring a default), `TestToBool_ThresholdsAtHalf`. **That non-identification is a fact about the FIELD, not a licence for the fidelity report to go silent on it**: the `models` section no longer ships an `error` for a bernoulli target, it scores both sides on the interval-midpoint probit score, which for K = 2 is the lowest-retention case of that surrogate rather than a special case of it — see the Model-recovery paragraph.Detail: `skills/synth-marginals.md` (Boolean marginals) + `skills/op-synth-bernoulli.md` + `skills/type-packed-bool.md`.

**Small-integer marginals: a `u4`/`u8`/`u16`/`u32`/`u64` reconstructs from its own per-level HISTOGRAM (`discrete`), never as a clamped normal.** The boolean defect one type wider, and on a survey cohort the type family that matters most. An integer column falls to the profiler's NUMERIC accumulator and the writer stores `floor(v+0.5)`, so a `normal(mean, std)` clamped to the observed range is QUANTIZED on the way to the file: the bell flattens whatever shape the scale had and the clamp piles asymmetric mass on the near bound, while the MEAN comes back roughly right — which is exactly how it survived. Measured on the motivating 381,324-row survey cohort at 40,000 generated rows, source share → generated: `familiarity` (u4, 1–7, genuinely U-shaped) level 1 **0.2526 → 0.1373** and level 7 0.2198 → 0.1323; `nps` (u4, 0–10) level 10 **0.3200 → 0.2253** and level 0 **0.0284 → 0.0020**; `useCon` (u4, 1–6) level 6 0.3143 → 0.1806 and level 4 0.0778 → 0.2121; `sow` (u16, 0–15) level 0 **0.6469 → 0.3804** with levels 10 and 12–15 never drawn at all. `nps`'s mean came back 7.3463 against 7.5489 — 3% off while its top level was off by 28% of its own size. Post-fix on the same profile: 0.2493 / 0.2165, 0.3310 / 0.0269, 0.3154 / 0.0792, 0.6460 with every level present; worst per-level error across the four fields 0.1153 → 0.0110. `NumericProfile.Discrete` (`discrete`, additive + `omitempty`) carries one `{value, count, frequency}` entry per observed level in ascending order, and `SpecFromProfile` reconstructs the field as the new `discrete` distribution (`values` strictly ascending + optional `weights`, mirroring `weighted_categorical`'s param shape over a numeric support; exact closed-form moments computed FROM the support in `parseDiscreteLevels`, never read off the profile's mean/std, so a hand-authored and a profile-derived spec cannot disagree). A level's observed count IS its weight, so no threshold is involved. **Which types claim the arm is not a taste judgement**: `isIntegerQuantizedFieldType` is exactly the set of `writeFieldValueForField` arms applying `Floor(f+0.5)`, so `f32`/`f64` (the writer stores the float and a normal round-trips), `decimal128` (exact at its own scale), `date` (owns `uniform_date`, never reaches the numeric accumulator) and `packed_bool` (one bit — `bernoulli` runs AHEAD) are all excluded. A type list ALONE is insufficient: `sow` is a `u16` squarely in the defect while `catSpend` (u32, 0–150,000) and `respondent` (u64, 381,324 distinct) must not be, so an observed-level cap is what separates them. **`maxDiscreteLevels` (64) is where the capture ABANDONS the histogram, never truncates it** — a top-64 view of a 3,000-level column makes every share a share of an arbitrary subset, E3's own rule — and the ABSENCE of the `discrete` key is the record, structurally rather than conventionally (the same distinction `ResidualCorrelationProfile` keeps between `unmeasured` and `pairs`), so there is no warning and no knob: presence or absence of the key IS the answer to which reconstruction a field gets. It is a package constant tuned in code, deliberately NOT a `ProfileOptions` field, matching `minVarianceExplained` / `minLevelObservations` / `nullRateDivergenceThreshold` — a capture flag that moved it would make two documents over the same cohort disagree about what the field IS. 64 admits every coded scale by a wide margin (a `u4`'s ENTIRE domain is 16, an NPS is 11, a 1–7 Likert is 7, `sow` is 16) and bounds the document addition at 64 levels × 2 numbers per field (+0.22% on the motivating cohort). **The boundary is PRAGMATIC, not a fidelity cliff, and must not be read as one**: the clamped normal's per-level RELATIVE error is scale-invariant (its central levels come out ≈1.4× their true share at every K), and only the ABSOLUTE error shrinks (~1/K), so a column just over the cap is wrong by under ~1.5 points per level while one just under it can be wrong by 12. Capture is UNCONDITIONAL — no flag — because this is the DEFAULT reconstruction being wrong rather than an enhancement, and it rides the existing single scan (one bounded `map[int64]int` per eligible column, bucketed by the writer's own rounding rule so a captured level and a generated one are the same integer by construction). The arm sits AHEAD of the `--fit-shape` arm for the boolean arm's reason: `fitNumericShape` happily prefers a two-component mixture on a 7-level column and reproduces the per-level shares no better while costing a bisection per draw — a coded scale's shape is its histogram. **ALL THREE WRITERS are covered, because fixing one leaves the others wrong with no signal.** (1) `discreteSampler` draws the staircase, exact by construction. (2) A conditional pair locates the cell's captured moments ON that staircase — `value = Q(Φ((cellMean−fieldMean)/fieldStd + (cellStd/fieldStd)·z))`, the SAME composed construction `modelDrawer.transform` uses, reused so a modelled and a paired target disagree about nothing but where their location came from — and it is resolved from the target's own `FieldSpec` (`buildDiscreteConditionals`), deliberately NOT from a wire flag: a flag can disagree with the field's own reconstruction, and a marginal disagreeing with the draw that overwrites it is the whole failure class this removes. The boolean arm beside it carried exactly such a flag (`CategoricalNumericPairSpec.Bernoulli`) and it is now RETIRED and derived the same way, so the two arms resolve their target's marginal by one mechanism rather than two. Without it the defect recurs once PER CELL (measured: worst per-level error 0.0903 on an identity-cell pair). (3) The model draw becomes an **ORDERED PROBIT** through `quantileFor`'s staircase `Q`, and `modelSpecFromProfile` ADMITS a discrete target — refusing would be invisible, since the per-target retirement rule has already traded that field's conditional pair away for the model, and the cohort's most-discussed target (`nps`) is one of these. Both numeric-target pair filters in `SpecFromProfile` name `DistDiscrete`, and each is written out separately, so one naming it says nothing about the other. Three consequences. **A modelled discrete target's recovery is NOT IDENTIFIED**: `latentFor` REFUSES a staircase (`latentInvertible` is now a two-member set, `DistBernoulli` and `DistDiscrete` — the step is the two-level case of the staircase), so the fidelity report's `models` entry ships its captured coefficients with an `error` rather than a delta. That is sound and NOT free: on the motivating cohort `models` goes from 14 comparable targets of 55 to **2**, and `model_residual_correlations` from **91 compared pairs to 1**, since a residual-correlation comparison needs a refit at both endpoints. That refusal is CORRECT and it must not reach the fidelity report as an `error`: the section now scores both sides on the interval-midpoint probit score (`Φ⁻¹` of each band's midpoint), which is a monotone re-expression rather than an inversion, attenuates identically on the captured and the recovered side, and therefore divides its own bias out of the delta — restoring the motivating cohort's `models` section to **53 comparable targets of 53** (from 2). `model_residual_correlations` is NOT restored by it: the section's total is C(applied models, 2), so the figure is only readable WITH its participant count — 1 compared of 1,378 at the 53-applied-model capture the other figures in this paragraph come from, and 1 compared of 1,653 re-measured on the current tree at 58 applied models (same finding, different basis; the profile's predictor-carrying model count moved, not the behaviour). A correlation between two score residuals cannot be calibrated the way a coefficient can, and those pairs stay counted under `no_model_fit` rather than silent. See the Model-recovery paragraph for why there is no minimum-level gate and why an ordered-probit refit would be more efficient without being more correct. **Value-scale Pearson correlation on a `discrete` copula participant attenuates while RANK correlation is exact**, the documented property of every non-normal `Q`. And **the pre-rounding gotcha DISAPPEARS for these fields** — the row value already IS the stored integer, so `round(nps) == 9` and `nps == 9` select the same rows and a `{"set_expr": {"nps": "round(nps)"}}` normalisation is a no-op; E2-S4's `round`-not-`int` advice and its `!isnull` guard remain live only for an `f32`/`f64` field, an integer column too wide for the cap, and a hand-authored continuous distribution on an integer field. Gates: `TestSpecFromProfile_IntegerReconstructsAsDiscrete`, `TestSpecFromProfile_IntegerIgnoresCapturedShape`, `TestSpecFromProfile_PreDiscreteDocumentReconstructsAsNormal`, `TestSpecFromProfile_DiscreteTargetKeepsItsModel`, `TestSpecFromProfile_DiscreteTargetKeepsItsConditionalPair`, `TestSynth_DiscreteMarginalPerLevel`, `TestSynth_DiscreteBeatsTheClampedNormalItReplaced`, `TestSynth_DiscretePairKeepsTheScaleAndCarriesTheContrast`, `TestSynthModel_DiscreteTargetKeepsItsLevelsAndOrdersByPredictor`, `TestSynthDiscrete_GappedSupportStaysOnItsLevels`, `TestProfileDiscrete_AbandonsAboveTheLevelCap`, `TestProfileDiscrete_RidesTheExistingScan`, `TestProfileDiscrete_EveryIntegerTypeClaimsTheArm`, `TestLatentFor_EveryDistributionIsClassified`, `TestRulesCoherence_DiscreteScoreNeedsNoPreRoundingNormalisation`. **The writer CLAMPS an out-of-range draw at every unsigned width, `u4` included** (`clampU4`, U52 E1-S4): the `u4` arm used to MASK to the low nibble, so a `uniform` with `max: 15.999` wrote its top rounding bucket (16) as 0 — the sampler's upper tail stored as its lowest value, silently; a negative draw also rode Go's implementation-defined float-to-unsigned conversion. Pinned by `TestWriter_U4ClampsLikeTheWiderUnsigned`; every shipped spec fixture regenerates byte-identically. `format_version` does NOT move — `synth.Profile` / `synth.Spec` live in `synth/` (aliases over `internal/synth/`), not `types/`. **Correlation reconstruction.** The spec key is `rho` on `correlations`, `residual_correlations` and a vector's `correlations` (Go field `Rho`) — the profile's spelling, renamed from `correlation` in U44 #302 because a spec written as the skill documented decoded with the key DROPPED and generated with no correlation at all, silently; every synth document now decodes strictly (`internal/synth/spec_decode.go`) and a field's `params` are held to `distributionParamKeys`, which `TestDistributionParamsMatchManifest` ties to the manifest and `TestDistributionParamsDeclaredMatchRead` to the keys the samplers read. `internal/synth/copula.go` induces the requested correlation via a Gaussian-copula construction: draw a correlated standard-normal vector `u` via Cholesky, map each `u_i` through the standard normal CDF Φ (`math.Erf`) to `p_i = Φ(u_i) ~ Uniform(0,1)`, then apply each field's own quantile function `Q_i(p_i)` (clamped for `normal` fields with declared `min`/`max`) — `normal`/`uniform`/`lognormal`/`exponential` plus, since E4-S1, `mixture` and, since the boolean/small-integer marginals, `bernoulli` and `discrete` (`fieldMoments` validates, `quantileFor` builds `Q_i`); any other distribution named in `correlations` refuses with `SERVICE_VALIDATION`. **A participant must additionally be a SCALAR field TYPE, and that predicate is DERIVED, never transcribed**: `isNumericFieldType` reads `fieldTypeFromName` and admits every declarable non-`categorical_*`, non-`set_*` type (`u4`…`u64`, `f32`/`f64`, `date`, `decimal128`, `packed_bool`). It was a hand-written list until FU-20, carrying `nullable_u4`/`nullable_u8`/`nullable_u16` — spellings `fieldTypeFromName` cannot build, so no spec naming them ever reached the writer — and OMITTING `u4`, which is what `encoding.FieldType.String()` emits. `addCorrelation` gates on it, so every `u4` field was dropped from `Spec.Correlations` in SILENCE: 11 of the motivating cohort's 14 integer columns including `nps`, and ALL 16 of its captured `conditional.numeric_pairs`, leaving that cohort's reconstructed correlation structure completely empty with nothing anywhere saying so — the same stale-alias class as issue #258, which `sentinelFor` had. `packed_bool` and `decimal128` are IN deliberately: both land in the profiler's NUMERIC accumulator, so both can appear in `conditional.numeric_pairs` (`detractor`, a `packed_bool`, carries one of the 16), and excluding either reproduces the identical silent drop one type over. **The boundary is TYPE, not distribution** — a `date`'s `uniform_date` is refused one call later by `fieldMoments`, NAMING the distribution, which is the honest message for a column that plainly holds a number. A STEP/STAIRCASE participant (`bernoulli`, `discrete`) holds its own marginal EXACTLY (`p` is uniform, so each level lands at its declared share) and attenuates the realised VALUE-scale correlation, costing rank as well as Pearson once ties dominate: measured on the motivating cohort's own `regard` × `meaningfulness` pair (both `u4`, both 7-level `discrete`, captured rho +0.8400, 200,000 rows) Pearson came back +0.8072 and Spearman +0.8051 with both marginals inside 0.003 per level, against no correlation at all before the fix. On that cohort the fix is BYTE-IDENTICAL — all 16 pairs enter and `resolveConflicts` drops all 16, because every participant is already claimed by a model or a conditional pair, turning 16 silent absences into 10 aggregated arbitration warnings. Gates: `TestFieldTypePredicates_ClassifyEveryDeclarableType` (the forcing table, driven off the `encoding.FieldType` enum rather than a sample — the name that is missing is by definition not in a sample), `TestFieldTypePredicates_RefuseUndeclarableNames`, `TestSpecFromProfile_SmallIntegerPairsReachTheCorrelationMatrix`, `TestSynthCorrelation_DiscreteMarginsHoldAndCorrelate`. The `mixture` arm exists for the MODEL draw, not for `correlations` — a `--fit-shape` field is still excluded from the value-scale correlation matrix (pre-claimed by `resolveConflicts` when unmodelled; PERMANENTLY refused when modelled, with its correlation structure riding `residual_correlations` instead — see the correlated-residual paragraph below), so widening `fieldMoments` moved no correlation behaviour. `normal` reduces exactly to `mean + std*u` since `Φ⁻¹(p_i) == u_i` by construction — exact for jointly-`normal` pairs, which is what `SpecFromProfile` always reconstructs for numeric fields — and preserves each OTHER supported field's own marginal shape (not just mean/std) once correlated, unlike the removed v1 direct-override construction. This replaces a removed v0 approximation that blended only ±5%·std of the correlated draw into the original value and shipped with no test asserting how much of the requested correlation actually survived, and the removed v1 direct `mean + std*u` override that was exact for rho but forced every correlated field's marginal to Gaussian regardless of its own declared distribution. `TestSynth_CorrelationReconstructionWithinTolerance` and `TestSynth_CopulaPreservesLognormalMarginal` (`internal/synth/conditional_test.go`, `internal/synth/copula_test.go`) are the build-failing gates on that fidelity now. **Unmeasured matrix entries: ASSUME AND RECORD, never refuse and never silently.** `correlations` is a LIST and the Cholesky needs a MATRIX, so every pair among participants the list does not name has to be filled; `buildCorrelator` fills it with 0 — those two are drawn independent — and returns a warning counting how many pairs it completed by assumption, which `generate()` folds onto its warning channel. Refusal was considered and rejected because an incomplete list is the NORMAL input (a spec correlating a-b and b-c has said nothing about a-c, and a profile-derived list is capped at `CorrelationTopK` by construction), and zero is the only completion that adds no structure the caller did not ask for. What was not acceptable is silence: on a ten-field matrix built from a top-16 pair list, 29 of the 45 pairs were asserted independent with nothing anywhere saying they had been asserted rather than measured. `cholesky` now also RETURNS the accumulated diagonal jitter it needed, and a non-zero ridge is reported as its own warning — the ridge stays as the safety net for jointly-inconsistent SUPPLIED entries, but a request that was bent into shape has to be findable, and until E3-S1 the only trace was in the numbers that came back. Neither warning changes a number, so byte-identity of generated output is untouched. **Residual correlation capture (`--residual-correlations`).** `pulse profile create --residual-correlations` (`synth.ProfileOptions.FitResidualCorrelations`, requires `--fit-models`) adds a third additive, `omitempty` profile section — `residual_correlations` (`synth.ResidualCorrelationProfile`) — carrying the correlation structure among the FITTED MODEL RESIDUALS rather than among raw values. Once a numeric's systematic variation is explained by its predictors, the part still free to move at generation time is the residual, and a raw correlation double-counts every predictor two targets share (two fields both driven by `region` correlate strongly on raw values while their residuals may be independent). It is measured straight off `FieldModel.Residuals` / `ResidualPresent` after the fits, in memory, adding NO read to the single cohort scan. Shape: `{fields, pairs, unmeasured}` — `fields` the sorted participant set, `pairs[]` `{a, b, rho, n}` per MEASURED pair, `unmeasured[]` `{a, b, n, reason}` per pair that could not be measured; the three are exhaustive and non-overlapping. **The FULL submatrix, never a top-K sample**: the eventual consumer is a joint draw over every participant at once and a matrix is not a ranked list — a pair left out of it is a hole the factorization must fill, not a weak pair. `--include-correlations` / `--correlation-top-k` are untouched and keep their exact meaning (strongest top-K pairs of RAW values); this section shares neither flag, and is deliberately NOT implied by `--fit-models` because it is quadratic in modelled fields (105 targets is 5,460 pairs). **Measured-zero and unmeasured are STRUCTURALLY different, not conventionally different**: a dense N x N array has one slot per pair and every slot must hold a number, so `unmeasured` would have nowhere to live but a sentinel — and the natural sentinel, 0, is also a perfectly ordinary measurement. Two lists make the distinction survive a JSON round trip for free, and an unmeasured entry carries NO `rho` key at all, so there is no slot for a zero to be written into. Two closed reasons: `insufficient_overlap` (fewer than `synth.minResidualPairObservations` = 3 rows carry both residuals — two points always give a Pearson coefficient of exactly +-1, so a handful of rows is an artifact of the arithmetic rather than a weak measurement) and `no_variance` (the rows overlapped but one side's residual is constant, so the correlation is 0/0 — an exactly fitted model is the ordinary cause). That floor is deliberately NOT `MinPairObservations` (30): 30 answers "is this stable enough to trust" and its answer is a WARNING, this answers "is there a measurement at all" and its answer is a GAP — they compose, so a pair at or above 3 but below 30 is measured AND warned. **Participants are every model carrying a residual vector, INCLUDING a zero-predictor model** — selection can legitimately admit nothing for a target, and such a target still has a residual (its whole deviation from its own mean); excluding it would drop real structure for a reason unrelated to that structure, and asymmetrically, since the same field paired against a predictor-carrying target is exactly as measurable. A model whose residual vector is ABSENT (a `Profile` decoded from a document — the reservoir is `json:"-"`) is not a participant, because a submatrix in which every pair is unmeasured describes the reader's situation rather than the cohort's. Warnings are bounded: one summary line names the gap count, and thin measured pairs reuse `thinPairWarning` capped at `maxThinResidualPairWarnings` (20), thinnest-first. Capture is byte-reproducible (participants sorted, pairs enumerated over slices, no float folded in Go map order). `SpecFromProfile` translates the MEASURED pairs onto `Spec.ResidualCorrelations` and the `unmeasured` list into NOTHING — see the residual-draw paragraph below. `format_version` does NOT move: `synth.Profile` lives in `synth/`, not `types/`, so it is unreachable from `internal/descriptor.BuildPayloadSchema`.
