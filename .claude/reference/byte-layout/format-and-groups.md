# Byte layout — format version, parent groups, elision, import-time groups, the viability gate, retro-dedup, the cohort default zone

Per-topic slice of the byte-layout reference. Index: `.claude/reference/byte-layout.md` — load it first, then only the slice(s) your change touches.

## The contract

**Format version — `0x01` / `0x02`.** Header byte 8 is the `.pulse` format version; the accepted set is `{0x01, 0x02}` (`encoding.IsSupportedFormatVersion`, `MaxFormatVersion = 0x02`). Any other byte is `ENCODING_INVALID` with `details.version` and `details.supported_versions`; the shard peek applies the same set under `PULSE_SHARD_HEADER_INVALID`.

- **Thread the version.** `encoding.ReadHeader(r) (byte, error)` returns the version and `encoding.ReadSchema(r, version)` must be handed it. The schema block has no terminator and records begin at the next byte, so a `0x02` block parsed as `0x01` starts the record region early and every stride consumer (record count, `record_at`, segment splitting, lookup offsets, export, shard rewrite) is SILENTLY wrong. `internal/encoding.ReadPreamble` is the one-call form. Gate: `TestReadSchemaCallersThreadHeaderVersion` (every production `ReadSchema` takes the variable `ReadHeader` returned in the same function).
- **Layout-only read.** `internal/encoding.ReadSchemaLayout` (via `internal/encodingbridge`) applies the same version thread, structural validation and END byte as `ReadSchema` but reads past every inline dictionary and group entry table without allocating, so the schema carries nil `Field.Dictionary` / `Group.Entries`. Use it only for consumers that read PAST a schema block (record count, archive scan through the canonical schema, record locator, shard-admin counts, shard filter). Anything needing a dictionary, label or entry must use `ReadSchema`. Gate: `TestPeekShardRecordCount_LayoutMatchesFullDecode` (same count, end byte and stride as a full decode).
- **Layouts.** `0x01`: `u16 field_count` + field descriptors, nothing after. `0x02`: the identical descriptors, then the **schema extension block** — `u64 extension_length` + that many bytes, so the record region's start is derivable without understanding the payload. The payload is `u16 section_count` then tagged sections (`u16 tag`, `u8 flags` — bit 0 REQUIRED, bits 1-7 reserved and refused when set — `u64 length`, bytes). A reader refuses an unknown REQUIRED section (`ENCODING_INVALID`, `details.tag`) and skips an unknown optional one; a duplicated tag or a payload not consumed exactly is `ENCODING_INVALID`. This framing is how later additions stay readable or refusable without a `0x03`. Defined sections, all REQUIRED, written in ascending tag order: `1` GROUPS (below), `2` VECTORS (`byte-layout/writers-and-field-words.md`, Vector fields), `3` ZONE (below). Hooks: `writeSchemaExtension` / `readSchemaExtension` (`encoding/group_wire.go`).
- **Writers.** The version written is a FUNCTION OF SCHEMA CONTENT, never a flag: `Schema.RequiredFormatVersion` is `0x02` iff `HasGroups() || HasVectors() || HasZoneField()`, and `internal/encoding.WritePreamble(w, schema)` writes header + schema block at that version. Every production writer goes through it, so a schema using no `0x02` feature writes `0x01`. The lower-level `WriteHeader` + `WriteSchema` pair emits `0x01` and `WriteSchema` refuses a schema that requires newer.
- **`.pulse`-from-`.pulse` writers** each pick one of: copy the preamble verbatim (`service.FilterToFile` — group dictionaries carried UNCHANGED, unreferenced entries never pruned, a keep-nothing filter writes a valid empty cohort; its projection narrows only the predicate's decode, never the output fields); refuse a grouped source (`internal/encoding.RefuseGroups` — set-field widen, the byte-level shard categorical rewrite); flatten to `0x01` (synth augment); regroup from scratch (retro-dedup); or flatten-reconcile-regroup against an archive (shard create/add, `byte-layout/shards-and-index.md`). A new rewriter must choose one explicitly.
- **Compatibility.** `0x01` cohorts are readable forever: `encoding/testdata/format_v1.pulse` is read by every build and the current writer must reproduce it byte-for-byte. Never regenerate it to make a failure pass — a failure is a compatibility break (`docs/src/internals/regenerating-goldens.md`). A binary that predates `0x02` refuses a `0x02` cohort at header parse with `ENCODING_INVALID` — loud, never a misparse. An archive's `_schema.pulse` versions like any shard payload; the `SHRD` trailer follows the (possibly extension-bearing) schema block. `encoding.IsArchive`'s zip-vs-`PULSE` magic dispatch runs before any header read.

**Parent groups — the `0x02` group descriptor.** A parent group stores each distinct tuple of its member fields ONCE in a schema-block dictionary; each row carries a fixed-width `u32` index (`encoding.GroupIndexWidth`). N independent groups per cohort; no group references another; a field is in at most one group.

- **Logical vs physical.** The LOGICAL schema is `Schema.Fields` in original order — every field index in the API, `Record` position, plan index and bitmap bit a decoder hands out is LOGICAL. The PHYSICAL row is `[u32 index per INDEXED group, group order][row fields (in no group), logical order][narrowed bitmap: ceil(row_field_count/8), bit j = j-th row field, present iff a row field is nullable]`. `Schema.RecordByteSize` / `BitmapByteSize` / `HasBitmap` describe the PHYSICAL row (still fixed, still a pure function of the schema); `Schema.Logical()` is the ungrouped view over the same `Fields`. A cohort whose every nullable field is a group member has NO per-row bitmap.
- **GROUPS section (tag 1, REQUIRED):** `u16 group_count (>=1)`; per group `u8 kind` (0 indexed, 1 constant), `u8 index_width` (4 / 0 — any other pairing refused), `u8 flags` (reserved, 0), `u16 member_count (>=1)`, per member `u16 field_index` (logical, strictly ascending) + `u8 flags` (bit 0 = KEY member, rest reserved), `u32 entry_width` (must equal what the members imply), `u32 entry_count` (constant: exactly 1), then `entry_count × entry_width` bytes.
- **Entry** = each member's logical on-wire bytes in member order + a `ceil(member_count/8)` member null bitmap iff any member is nullable (bit k = member k, LSB-first, 1 = null). Raw encoded values, never strings: a categorical member's bytes are its dictionary ID and every member keeps its own inline `Field.Dictionary`, byte-identical to the ungrouped cohort — so SPSS codes, `GROUP_CATEGORY`, labels and export need no special case.
- **Bit-packed members** (`u4`, `packed_bool`) store their one whole on-wire byte verbatim — the `0x01` row never shares a byte between fields, so a group may split a bit-packed run anywhere.
- **Constant groups** (kind 1): one entry, no per-row index; a null constant is an entry with its null bit set. A physical stride of 0 (every field constant-grouped) is refused at write and read — the record count would be underivable.
- **Decode reads ONE physical row per record on every path**, never ahead. `BuildDecodePlan` on a grouped schema returns the LOGICAL plan. Two routes, one result: the map decoders read a logical stream (`encoding.NewLogicalStream`) that splices entries in and merges null bits, then run the `0x01` decoder; the reuse decoders (streaming, buffered, parallel, shard scans; `internal/encoding/group_decode.go`) read the physical row and write each field at its logical position — a group whose index is unchanged from the previous record is skipped in O(1), a changed one is written from a per-entry decoded cache (budget 8 MiB per reader per decode shape; derived at read time, never persisted). A group with no retained member is neither expanded nor decoded, but its index is still bounds-checked. An index past its dictionary is `ENCODING_INVALID`.
- **Byte-level consumers** that bypass `RecordReader` must read through `NewLogicalStream` (export and the SPSS writer do). Paths that rewrite physical bytes by logical offsets must refuse a grouped cohort via `RefuseGroups`.
- **Encode:** `encoding.GroupEncoder` (logical → physical row, dictionary by lookup-or-append) and `encoding.DedupCohort` (whole cohort → grouped twin; physical rows spool because the dictionary precedes the records). Codes: a declared KEY whose non-key member disagrees, or a constant group that changes → `PULSE_GROUP_MEMBER_NOT_CONSTANT`; `MaxGroupEntries` (2^32) exhausted → `PULSE_GROUP_ENTRIES_EXHAUSTED` (both name group / label / field / row); unknown member `PULSE_GROUP_FIELD_UNKNOWN`; field in two groups `PULSE_GROUP_FIELD_CONFLICT`; empty group, field twice in a group, or key-not-member `PULSE_GROUP_DECLARATION_INVALID`. `ENCODING_INVALID` stays reserved for a corrupt FILE. Resident cost: dictionaries load with the schema at exactly `entry_count × entry_width` bytes per group. Contract tests: `internal/encoding/group_test.go`, `group_decode_test.go`.

**Global-constant elision — opt-in, full-pass detection.** A field with exactly one distinct value across the WHOLE cohort is stored once as a member of a single constant group and dropped from the physical row. Surface: `io.ImportJob.ElideConstants` / `pulse import <fmt> --elide-constants`, reported as `ImportReport.ElidedConstants`. Default OFF, because the output is `0x02` and an older binary refuses it.

- **Detection is the trap.** Inference samples 500 rows, and a column constant across the sample may vary later — so constancy is decided ONLY by `encoding.ConstantDetector` observing every logical row of the final schema after the row pass, never from inference. Same value ⇔ same on-wire bytes AND same null bit: an all-null field is a NULL constant, one value plus some nulls is not constant, differing null placeholder bytes count as different (conservative — can forgo an elision, never make a wrong one).
- **One decision:** `encoding.PlanConstantElision(detector, reserved)`, shared by import, import-time groups and retro-dedup (declared members passed as `reserved`). Fewer than `MinElisionRows` (2) rows → nothing; every field constant → the lowest-index field stays in the row (zero stride is unwritable); the elision must shrink the file (`BytesSaved`) or nothing is elided. When nothing is elided the cohort is written `0x01`, byte-identical to elision off. Decode is ordinary group expansion, so every read matches the flat import.

**Import-time group declaration — `--group` / `ImportJob.Groups`.** `pulse import <fmt> --group KEY[,KEY...]:MEMBER[,MEMBER...]` (repeatable, one group per flag; import leaves disable the slice-flag separator so the value's commas survive) parses through `internal/io.ParseGroupDecl` into `io.GroupDecl{Key, Members}`. A decl lowers to one INDEXED `encoding.GroupSpec` with members Key ∪ Members and the KEY flag on exactly the key fields; no colon = a tuple group whose every member is key.

- **Key semantics:** non-key members must be functionally determined by the key. A row whose entry (member bytes AND null bits) disagrees with the entry its key already selected is `PULSE_GROUP_MEMBER_NOT_CONSTANT` (details `group`, `group_label`, `field`, `row` 0-based, `source_row` 1-based source row).
- **Names:** the format has no group-name slot; `GroupSpec.Label(g)` derives `group <g+1> [key: a,b]` (or `[members]`). `GroupSpec.Ordinal` pins the declared position, so labels survive a dropped group.
- **Order of checks:** names resolve against the schema BEFORE the row pass, so the declaration codes cost no row reads; the real encoder is rebuilt over the FINAL schema (after null promotion). The source is read once; physical rows spool because dictionaries precede records.
- **Composition:** declared groups come first in declaration order; `--elide-constants` reserves every declared member and appends its constant group last. Zero declarations → the `0x01` path, byte-identical. A zero-row import with declared groups writes `0x02` with empty dictionaries.
- **Managed imports:** `imports.Spec.Groups` (reached by `pulse import auto --group` and `pulse_import` `groups: [{key, members}]`, strict-decoded so a misspelled `keys` is `PULSE_GROUP_DECLARATION_INVALID`, never a keyless group) run at the default floor with findings as warnings; `Spec.SuggestGroups` returns `Result.GroupCandidates`. A `.pulse` passthrough refuses groups. Elision is CLI + library only.

**Per-group viability gate — `PULSE_GROUP_TOO_NARROW` / `PULSE_DEDUP_LOW_RATIO` / `--strict`.** A badly chosen group is a SILENT pessimization, never a decode error: every row still pays the 4-byte index, the dictionary is fully resident, and the file can come out bigger than the flat cohort. Each declared INDEXED group is judged on its own numbers by `encoding.DedupGate` (`internal/encoding/group_viability.go`), the one policy import and retro-dedup share.

- **Width floor** (schema-only, before the row pass): members no wider than the index (`member_row_bytes ≤ 4`, inclusive) can never save a byte, so the group is DROPPED — members stay row fields and become eligible for elision again — with `PULSE_GROUP_TOO_NARROW` naming the group and both widths.
- **Ratio floor** (after the dictionaries are built, before the file is written): ratio = rows ÷ distinct tuples. Below the floor OR `byte_delta ≥ 0` draws `PULSE_DEDUP_LOW_RATIO` (details include `ratio`, `ratio_floor`, `break_even_ratio` = `entry_width ÷ (member_row_bytes − 4)`, `grows_file`, `dictionary_bytes`, `byte_delta`) and the group is STILL WRITTEN — ratio alone never refuses, because a deliberate low-ratio group is legitimate.
- **Byte arithmetic** per group: `deduped = rows × 4 + entry_count × entry_width + (13 + 3 × members)`, `undeduped = rows × member_row_bytes`; the row bitmap is excluded so a delta never invents a saving. Summed over written groups plus the one-off 23-byte extension framing it IS the file-size difference against the flat import (`TestImportJob_GroupGate_PerGroup`; descriptor size pinned by `TestGroupDescriptorBytes`).
- **Floor = 2.0** (`encoding.DefaultDedupRatioFloor`), a judgement: below it most of the parent data turns resident while the saving tends to zero. Override `ImportJob.DedupRatioFloor` / `--dedup-ratio-floor` (0 → default; a value in (0, 1] disables the floor but never the grows-the-file check).
- **Strict:** `ImportJob.StrictDedup` / `--strict` makes the first finding fatal with that same code and writes nothing. Otherwise findings ride `ImportReport.GroupWarnings` into the envelope `warnings`; `ImportReport.Groups[i]` carries `verdict` (`admitted` / `low_ratio` / `dropped_too_narrow`) and the numbers. Constant groups are never gated.

**Retro-dedup — `pulse dedup` / `Pulse.Dedup` / `pulse_dedup`.** Converts an existing single-file cohort to `0x02`. Byte work `io.DedupJob` (`internal/io/dedup.go`); facade `Pulse.Dedup(ctx, path, DedupOptions{...})` → `*DedupResult`.

- **One path, not a parallel one:** the same declaration lowering, width floor, `GroupEncoder`, ratio floor, `PlanConstantElision` and candidate detector as import. Pinned: dedup of a flat cohort is byte-identical to importing its source with the same flags (`TestDedupJob_InPlaceMatchesImport`); every facade read is byte-identical before and after (`TestDedup_RoundTrip`).
- **Source is read LOGICALLY**, so a `0x02` cohort is regrouped from scratch (groups replaced, never extended). A truncated tail is `ENCODING_INVALID`.
- **Atomic, O(dictionaries) memory:** physical rows spool to `<target>.dedup-spool-*.tmp`, the result assembles into `<target>.dedup-*.tmp`, fsync, rename. Any failure (strict finding, mid-pass violation, cancellation) removes both temps and leaves the original byte-identical (`TestDedupJob_FailureLeavesOriginal`). `Out` writes a new path and refuses an existing one (`SERVICE_VALIDATION`). Nothing is written (`rewritten: false`) when suggest-only or every group is dropped with nothing to elide.
- **Shard archives and anchored shards are refused** (`SERVICE_VALIDATION`, `details.layout = "shard_archive"`): an archive-wide dedup would need a cross-shard observation pass and an atomic all-shard rewrite. Route: dedup each source shard, then `shard create`.
- **Sidecars:** an in-place rewrite changes the length, so the index and SPSS sidecar self-invalidate; `Pulse.Dedup` reports them via `InvalidatedSidecars` and rebuilds nothing. An `Out` rewrite reports none.
- **MCP** `pulse_dedup` takes `path`, `groups`, `suggest_groups`, `out` — deliberately no floor, strict or elision slot (`pulse_import`'s slot policy).

**Cohort default zone — the ZONE section.** `encoding.Schema.ZoneField` names the cohort's DEFAULT per-row zone field — a categorical field of IANA zone names, the cohort-level twin of a request's `time_zone_field`.

- **Wire:** extension section tag `3` (`encoding/zone.go`), REQUIRED, body `u16 name_length (>= 1)` + UTF-8 field name. An empty `ZoneField` emits no section and does not move `RequiredFormatVersion`, so an undeclared cohort is byte-identical (`TestZoneSection_UndeclaredByteIdentical`). A declared default alone makes the cohort `0x02`.
- **Why REQUIRED:** an older binary skipping it would SILENTLY resolve every zone-aware operator in UTC; refusing is the loud failure (`TestZoneCohort_OlderBinaryRefuses`).
- **One rule, `Schema.ValidateZoneField`,** run by the writer before any byte and by the reader after every section: the name must resolve to a field and that field must be `categorical_u8` / `u16` / `u32` (`ENCODING_INVALID`), and every dictionary entry must pass `internal/temporal.ValidZoneName` against the EMBEDDED tz database (host-independent), else `PULSE_TIMEZONE_UNKNOWN` with `details.dictionary_index`. Every refusal names `details.zone_field`. The layout-only read checks existence and type, not entries. Nullability is unrestricted (a null zone row is the resolver's concern).
- **Import / convert:** `ImportJob.ZoneField` / `ConvertJob.ZoneField` (CLI `--zone-field`, `pulse_import` `zone_field`, sidecar `zone_field`) declare it explicitly — never implied by `source_tz_field`. Checked before the row pass (re-coded `SERVICE_VALIDATION` `details.option` `zone_field` on every surface) and again at write over the full dictionaries. A managed `.pulse` passthrough refuses it.
- **Set / clear on an existing cohort:** `Pulse.SetCohortZoneField` / `ClearCohortZoneField` (CLI `pulse cohort zone {set,clear}`) is a schema-only atomic rewrite (validate first, new preamble, record region copied verbatim to a temp, fsync, rename); unchanged writes nothing; set then clear is byte-identical. A shard archive is rewritten whole (canonical schema and every shard's schema block, DIST counts carried) with the MANDATORY `PULSE_SHARD_ZONE_REWRITTEN` warning and every per-shard index listed stale; an anchored path is refused. The SPSS sidecar is carried; a single file's index is reported in `InvalidatedSidecars`.
- **Shards agree:** `ValidateStructuralCohesion` refuses a shard whose `ZoneField` differs from the canonical one (`""` included) with `PULSE_SHARD_SCHEMA_MISMATCH` `details.dimension` `zone_field`.
- **Every rewriter preserves it.** A schema-copying rewriter that forgets `ZoneField` silently drops the default. Gates: `TestCohortZone_EveryRewriterPreservesDefault` (behavioural sweep) and `TestCohortZone_SchemaLiteralsCarryZoneField` (every production `encoding.Schema{...}` literal sets `ZoneField` or is exempt by name). Materialize follows the column that copies the zone field (renamed → new name; dropped or recomputed → none); rake keeps it unless the weight column replaced it.
