## Payload schema and manifest payload

(Relocated from CLAUDE.md at recommend-explain E1-S1.)

**Payload JSON Schema.**

`internal/descriptor.BuildPayloadSchema()` returns the deterministic JSON Schema (draft 2020-12) for every public payload — the request roots, result shapes and the `Envelope` (open `data` slot). Generated by reflection over `types`, registry-injected enums (`types.All*Types()` / `AllOverlayKinds()` / `AllRegressionTypes()`) and strict unions (`OverlayRef`, `OverlayPayload`); operator `params` stay open. Golden `descriptor/testdata/payload-schema.json`; `$id` version equals `format_version`; root `$comment` carries `feature_set_digest`. **`Pulse.PayloadSchema()` is the instance's view** (enums, slots and roots it hides are absent; every registered extension operator joins its category's operator-type enum — aggregator, attribute, filterer, grouper, window, feature, test and matrix — from the profile-filtered snapshot, `TestExtensions_PayloadSchemaEnumsCarryExtensions`) and backs `pulse schema` (raw); `pulse://schema` stays full. Detail: `.claude/reference/feature-profiles.md` (Payload schema hiding). Full prose: `docs/src/contract/payload-schema.md`.

**Manifest payload.**

`internal/descriptor.BuildManifest()` returns the deterministic LLM-bootstrap blob — one fetch per session, client-cached, reachable as `pulse manifest --json` and `pulse_manifest`. Top level: `format_version`, `commands`, `components` (six operator slices), `tests` + `post_tests`, `synth_distributions`, `regressions`, `error_codes_count` + `error_domains` + `error_codes` (slim), `mcp_tools`, `cohort_types`, `skills`, `extensions`, `intents`, `return_presets`, `limits` + `limits_digest` (effective limits; cache key `(pulse_version, feature_set_digest, limits_digest)`), `feature_set_digest`, plus the capability blocks `Facet`, `Join`, `ProcessChain`, `Crosstab`, `Export`, `Import` (pointers, omitted when hidden) and `Overlays`. Sort-stable; golden at `descriptor/testdata/manifest.json`. **Intent-scoped manifest** (`Pulse.ManifestForIntent`, `pulse_manifest {intent}`, `pulse --json --intent`; `internal/descriptor.BuildManifestForIntent`): the operator-keyed sections keep only entries whose `intents` name the intent, `skills` is `SkillsForIntent`'s list, `crosstab` / `matrix` stay only when a remaining operator can use them, and the fixed sections (`descriptor.ScopedManifestElidedKeys`, `components_schemas` among them as a duplicate of each entry's `component_schema`) are ABSENT on the wire via `Manifest.MarshalJSON`'s scoped form and named in `elided`; `scope.intent` carries the intent record. `Scope == nil` encodes exactly as the default struct encoding, so the unscoped manifest is byte-identical. Size gate `TestManifestForIntent_SizeGate`: each analytic intent's scoped slim ≤ 15% of the full slim, named exceptions with a measured ceiling (`describe`, `compare_groups`) — never raise the 15%. Unknown / hidden intent: `PULSE_RECOMMEND_INTENT_UNKNOWN` via the shared `checkIntent`. Declarations live in `internal/descriptor/capabilities_*.go`; MCP tool metadata in `internal/mcp/toolmeta/meta.go`.
