## Matrix slot — decomposition operators (continued)

Continues `## Matrix slot` in `.claude/reference/matrix-and-vectors/matrix-slot.md`; the missing-data knobs and warnings these bullets cite are in `.claude/reference/matrix-and-vectors/matrix-correlation.md`. Params, outputs, KnownAs and Interpretation bands are in each operator's atomic skill `op-mat-<kebab>` and manifest entry. `MAT_SEM` is a model fit, not a decomposition: `.claude/reference/matrix-and-vectors/matrix-sem.md` and its sibling slices.

- **PSD guard and repair** (`internal/processing/matrix_psd.go`). The ONE guard every DECOMPOSITION operator (`vectors.Matrix.IsDecomposition`) runs on the matrix it factors: `guardPSD`. It judges only where `PSDRisk()` holds (so predict's `pairwise_psd_risk: false` still guarantees neither refusal nor repair) and only a judgeable matrix, with the warning check's rule. Not PSD and no `params.repair` → FATAL `PULSE_MATRIX_NOT_PSD` (`details.repair_options: ["nearest"]`; the fixup leads with it). `params.repair: "nearest"` (decomposition operators only) replaces the operator's correlation by its nearest correlation matrix and scales it back to the original diagonal (a covariance keeps its variances), and the code stays a WARNING with `repair`, `frobenius_adjustment`, `iterations`, `converged`. **Algorithm** = `Matrix::nearPD(x, corr = TRUE)` at its defaults: Higham (2002) alternating projections with Dykstra's correction, then nearPD's `do2eigen` floor so the result is strictly PD and factorable. A non-converged repair is still PD and is used — with `converged: false` and `PULSE_MATRIX_NOT_CONVERGED`, never silent. Tolerance 1e-9 per cell against `nearPD` (gonum-backed: same-machine bitwise, cross-arch within that bound; `TestNearestCorrelation_MatchesNearPD`).
- **One-factor minres** (`internal/processing/matrix_minres.go`, `MAT_RELIABILITY`'s ω). Objective: psych `fa(nfactors = 1, fm = "minres")`'s off-diagonal residual. Exact cyclic coordinate descent, FMA-free, from a fixed SMC start (reference `InverseSPD`; a singular input falls back to each row's largest |r|), so the fit is BIT-identical on every architecture — no eigensolver. Cap 1000 sweeps, tolerance 1e-12; a capped fit returns its last iterate with `PULSE_MATRIX_NOT_CONVERGED`. Sign: Σλ > 0. Members with ψ ≤ 0 are reported as Heywood, never repaired. **Oracle tolerance:** proper fits within 1e-5 of psych (psych's L-BFGS-B stops early; the test also asserts Pulse's residual is never above psych's). A Heywood fit is compared on detection only: psych bounds ψ to [0.005, 1], Pulse returns the unconstrained optimum.
- **`MAT_RELIABILITY`** (`internal/processing/matrix_reliability.go`). **Range refusals are `PROCESSING_CONFIG`**: `reverse` without a range, half a range, min ≥ max (at resolution, so predict refuses too), and any present member value outside a declared range — never clamped, never inferred from data. Reversal x' = min + max − x happens BEFORE the co-moment fold, so the operator stays streamable and mergeable. Covariances use `Cov(1)` unweighted / frequency and the per-entry Kish correction under probability weights (`CoMoment.PairNEff(i, j)` over the rows that entry rests on — never the slot-wide n_eff; an entry with n_eff ≤ 1 is null). **ω form decision:** ω = (Σλ)²/((Σλ)² + Σψ) on the one-factor minres fit — the MODEL form, not psych `omega.tot` (observed total); the two agree on a battery one factor fits and part on misfit, where α already reads low. ω is null WITH a warning: p = 2 → `PULSE_MATRIX_NOT_IDENTIFIED` (refusing would lose α); R not PSD without `repair` → the guard's refusal becomes a `PULSE_MATRIX_NOT_PSD` WARNING (`details.output: "omega"`, α still computes); a Heywood fit → `PULSE_MATRIX_HEYWOOD`. Components carry the fit's `iterations` / `converged`; a run keeping `components.matrices` without the `matrices` slot still runs the finalizer for them. Oracle: `TestMatrixReliability_MatchesROracle` (closed forms 1e-10, ω 1e-5).
- **`MAT_PCA`** (`internal/processing/matrix_pca.go`). M = the correlation or the kind's sample covariance (as `MAT_RELIABILITY`) → the PSD guard → `linalg.SymEigen` (sign, order and shape portable; values gonum-backed). `components` rules: an integer k, `"kaiser"` (correlation default, refused on a covariance), or `{"variance": s}`; required on a covariance. **KMO / Bartlett** always read the correlation (`psych::KMO`, `psych::cortest.bartlett`) through the shared core `internal/processing/sphericity.go`, which `TEST_BARTLETT_SPHERICITY` also calls — on the same rows the test equals `bartlett_*` BIT FOR BIT (`TestBartlettSphericity_EqualsPCABartlett*`); `MAT_FACTOR` reuses it. **N\*** (`weighting.md`): listwise N / Σw / Kish n_eff; pairwise the min over pairs of each pair's OWN N*, warned `PULSE_MATRIX_PAIRWISE_N_STAR`. A singular R nulls KMO and Bartlett with a `PULSE_MATRIX_SINGULAR` WARNING (components stay defined); too small an N* nulls Bartlett (`PULSE_MATRIX_INSUFFICIENT_N` scope `bartlett`). Pairwise M is `cor(use = "pairwise")`. **Rotation:** `params.rotation` takes ORTHOGONAL criteria only; an oblique name (`vectors.RotationOblique`) is `SERVICE_VALIDATION` `rotation_oblique_unsupported` — components are uncorrelated by construction, and `ATTR_PC_SCORE` needs an orthogonal T. Rotated loadings become `primary`, the unrotated ones `auxiliary.unrotated` (bit-identical to the rotation-free primary); eigenvalues, shares, communalities, eigenvectors, KMO and Bartlett never rotate. Absent / `none` is byte-identical. One rotation decoder (`vectors.decodeRotation`) serves `MAT_PCA`, `MAT_FACTOR` and both score attributes, so predict ≡ runtime. Oracle: `TestMatrixPCA_MatchesROracle` (sign / order / shape exact, values 1e-9).
- **Rotation engine** (`internal/processing/matrix_rotate.go`). Operator-agnostic `rotateLoadings` → loadings `A·Rotation` and Φ (identity when orthogonal); consumers `MAT_PCA`, `MAT_FACTOR`, the score attributes. Each criterion follows its R algorithm step for step with R's DEFAULT constants, so it stops on the iterate R stops on: varimax = `stats::varimax(normalize = TRUE)`; promax = `stats::promax(m = kappa)` (κ default 4); every gradient-projection criterion = pinned GPArotation's GPForth / GPFoblq. **Generic GPA driver:** all GPA criteria run ONE loop, `gpaRotate`, parameterised by a `gpaCriterion` callback (minimised; must not retain or mutate its input) and a geometry (`gpforth` orthogonal / `gpfoblq` oblique). **A new GPA criterion is a callback, never a new loop**; varimax and promax are not routed through it. `vectors.RotationOblique` is the ONE orthogonal/oblique classifier. Not offered, with reasons: `oblimax` (collapses factors under GPFoblq on most oracle inputs), `quartimin` (= oblimin γ = 0), the parametric `cf` family and the multi-term / target / structural criteria. **Sign-and-order rule** (psych `fa`'s, once for every criterion): columns by descending variance accounted, then each column flipped to sum positive; k < 2 is returned unrotated. A capped fit warns `PULSE_MATRIX_NOT_CONVERGED` with `details.solver` on every consumer. **Tolerance:** within 1e-9 absolute + relative per cell of R (`rotationOracleTol`), order and signs EXACT. **Sensitive runs:** the oracle records how far R's OWN loadings move under a 1e-12 cellwise perturbation; above 1e-9 the Barzilai–Borwein path amplifies rounding (a line-search tie goes the other way), so that run is compared within the GPA band 1e-4 (`rotationGPABandTol`) with order and signs still exact, and at least half the runs must be insensitive. **Never pin such a run's bits.** Oracle: `scripts/reference/gen_rotation.R` (pinned GPArotation); gates `TestRotation_MatchesROracle`, `TestRotation_Invariants`.
- **`MAT_COLLINEARITY`** (`internal/processing/matrix_collinearity.go`). Members are the PREDICTORS only. R → the PSD guard → **VIF** = diag(R⁻¹) by the REFERENCE `InverseSPD` through `internal/collinearity.GVIF`, the kernel the regression `collinearity` block shares (its VIF must stay bit for bit); a singular R is FATAL `PULSE_MATRIX_SINGULAR`. **Belsley** (`perturb::colldiag`, `scale = TRUE`): default the scaled UNCENTERED predictors with an intercept, the cross-product rebuilt from the co-moment (PSD whenever R is); `center: true` decomposes R. An eigenvalue ≤ 0 nulls the Belsley figures with a `PULSE_MATRIX_SINGULAR` WARNING, VIF kept. The intercept row is keyed `(intercept)` so it cannot collide with a member named `intercept`. `max_vif` / `condition_number` are UNBANDED (5 / 10 / 30 are rules of thumb only). Oracle: `TestMatrixCollinearity_MatchesROracle` (1e-9; the eigen path squares the conditioning).
