- **PSD guard and repair (U24 E1-S4, `internal/processing/matrix_psd.go`).** The ONE guard every DECOMPOSITION operator runs on the matrix it factors (`vectors.Matrix.Decomposition()` / `IsDecomposition`: `MAT_PARTIAL_CORRELATION`, `MAT_RELIABILITY`, `MAT_PCA`, `MAT_COLLINEARITY`, `MAT_FACTOR`): `matrixFinalizeInput.guardPSD(s, corr)`. It judges only where `PSDRisk()` holds (predict's `pairwise_psd_risk`, so `false` still guarantees neither refusal nor repair) and only a judgeable `s` (finite, positive diagonal), with the warning check's rule (`notPSD`, reference Cholesky, `psdTolerance`). Not PSD and no `params.repair` → FATAL `PULSE_MATRIX_NOT_PSD` raised with its own code (`details` matrix, pivot, member, checked, tolerance, `repair_options: ["nearest"]`; the `codeMetadata` fixup leads with `repair: "nearest"`). `params.repair: "nearest"` (accepted on decomposition operators only — `MAT_CORRELATION` / `MAT_COVARIANCE` refuse the key) → `corr` (the operator's own correlation: for a pairwise covariance `CoMoment.Corr()`, R's `cor(use = "pairwise")`; nil derives it from `s`'s diagonal) is replaced by its nearest correlation matrix and scaled back to `s`'s own diagonal (D·X·D, D = √diag(s) — a covariance keeps its variances = nearPD's `repaired_covariance`), and the code stays a WARNING with `repair`, `frobenius_adjustment` (‖X − corr‖_F, correlation scale), `iterations`, `converged`. The decomposition-operator path never emits the detection-only warning (`warnings` skips it when `Decomposition()`). **Repair algorithm** = `Matrix::nearPD(x, corr = TRUE)` with its defaults: Higham (2002) alternating projections with Dykstra's correction (`highamNearest`: PSD projection via `linalg.SymEigen` dropping eigenvalues ≤ 1e-6 × the largest, then the unit diagonal; convergence ‖Y − X‖∞ / ‖Y‖∞ ≤ 1e-7, cap 100 iterations), then nearPD's `do2eigen` floor (`nearestCorrelation`: eigenvalues below 1e-8 × the largest lifted to it, unit diagonal restored by a symmetric rescale) so the result is strictly PD and a decomposition can factor it. A non-converged repair is still PD and is used, with `converged: false` and a message saying so (never silent; E2-S1 adds `PULSE_MATRIX_NOT_CONVERGED`). **Tolerance:** 1e-9 absolute per cell and on the Frobenius adjustment against the oracle (`mv_near_pd.json`: the bare fixed point vs `do2eigen = FALSE` incl. `nearest_eigenvalues` and the iteration count; the full repair vs `do2eigen = TRUE`; the covariance path vs `repaired_covariance`) — gonum-backed, so same-machine bitwise and cross-arch within that bound. Gates `TestNearestCorrelation_MatchesNearPD`, `TestGuardPSD_RefusesOrRepairs`, `TestMatrixPartialCorrelation_NotPSDGuard`.
- **One-factor minres (U24 E2-S1, `internal/processing/matrix_minres.go`).** Unexported `minresOneFactor(s)` — MAT_RELIABILITY's ω reads it (MAT_FACTOR's k-factor solver is separate: coordinate descent does not generalise to k factors; it shares `minresStart`, the SMC start). Objective: psych::fa(nfactors = 1, fm = "minres")'s off-diagonal residual Σ_{i≠j}(s_ij − λ_iλ_j)². Algorithm: exact cyclic coordinate descent (λ_k = Σ_{j≠k} s_kj·λ_j / Σ_{j≠k} λ_j², Gauss–Seidel), FMA-free from a fixed SMC start (s_kk − 1/(S⁻¹)_kk via the reference `InverseSPD`; a singular input — the one rule, or an `InverseSPD` failure — falls back to each row's largest |r|, `StartFallback`), so the fit is BIT-identical on every architecture — no eigensolver. Constants `minresMaxIter` = 1000 sweeps, `minresConvTol` = 1e-12 (largest loading change per sweep). Sign: Σλ > 0. ψ_i = s_ii − λ_i²; `Heywood` lists the members with ψ ≤ 0 — reported, not repaired; the operator decides how it surfaces. A fit stopped at the cap returns its last iterate with `Converged` false, and `minresWarnings` turns that into `PULSE_MATRIX_NOT_CONVERGED` (details `matrix`, `solver` `minres_one_factor`, `iterations`, `max_iterations`, `tolerance`). p < 3 is not identified (runs deterministically; the caller refuses or not). **Oracle tolerance** (`TestMinresOneFactor_MatchesPsychFA`, `mv_fa_minres.json`): proper fits within 1e-5 absolute (psych's L-BFGS-B stops early — default factr, and its FAgr gradient is the ULS one — leaving ≤ ~7.4e-6; the test also asserts Pulse's residual is never above psych's), the SMC start within 1e-12. A HEYWOOD fit is compared on detection only: psych bounds ψ to [0.005, 1] and its improper loadings are an optimiser-path artefact, whereas Pulse returns the unconstrained optimum (on the 3-member `heywood` fixture the exact fit λ₁ = √(r₁₂r₁₃/r₂₃) ≈ 1.214, ψ₁ ≈ −0.474, against psych's 1.033 / −0.067).

- **`MAT_COLLINEARITY` (U24 E3-S2, `internal/processing/matrix_collinearity.go`).** The members are the PREDICTORS only (no response key). Params: `center` (bool, default `false`), `repair`, the missing-data knobs (any other key `bad_params`).
