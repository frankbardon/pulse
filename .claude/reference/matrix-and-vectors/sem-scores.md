## The operator

`ATTR_SEM_SCORE` emits one `f64` per filtered record: the record's score on ONE latent (`params.latent`, any latent, higher-order included; absent = the model's only latent) of a structural equation model. It is a new operator, never an overload of `ATTR_FACTOR_SCORE` (PRD decision). Input is a vector exactly as every fitted vector attribute takes one: `vector` or inline `fields` (+ `labels`), never `field`; `params.group` is never a member.

- **Arithmetic (`internal/sem/score.go`, `sem.NewScorer`).** lavaan's `lavPredict(type = "lv")` for an ML fit: score = E(η_j) + w_jᵀ(y − μ). `method: "regression"` (default, Thurstone) is w_j = Σ⁻¹ Cov(y, η_j), Cov(η, y) = CΨMᵀ (C = (I − B)⁻¹, M = ΛC) — every observed variable informs it, an outcome included. `method: "bartlett"` is the GLS weights (ΛᵀΣ⁻¹Λ)⁻¹ΛᵀΣ⁻¹ over lavaan's LISREL representation (an observed variable of a `~` statement is a phantom latent); a latent with no direct indicator (higher-order) takes lavaan's Λ* = Λ(I − B*)⁻¹ column. `sem.NewScorer` is a pure function of the description and one group's `sem.Params` (Λ, B, Ψ, Θ, ν, α, sample mean), so a scorer rebuilt from a stored fit gives the same bits.
- **Scale (FR-20).** With a mean structure (`meanstructure: true`, a `~ 1` line, or any `group` fit) μ = ν + ΛCα and E(η) = Cα: scores sit on the latent-mean scale, the `group_reference` level's means at 0. Without one μ is the fit rows' sample mean and E(η) = 0: scores are centered at the fit rows (lavaan's meanstructure = TRUE scores of the same covariance fit, which estimates the means saturated). Pinned by `TestSEMScore_CovarianceOnlyCenteredAtFitRows`.
- **Multi-group (FR-19).** Each row is scored with its OWN level's parameters. A null member or a null group scores null; a level with no fit rows (inline) or no parameters in the fit (bound) scores null and is tallied into ONE `PULSE_SEM_SCORE_LEVEL_UNSEEN` warning per slot. A bound fit matches a row's level to the fit's levels by LABEL (a categorical's dictionary entry, `packed_bool`'s `0` / `1`, else the integer), so a fit taken on one cohort scores any cohort holding its members and group field.
- **Oracle.** lavaan 0.7.3 `lavPredict` fixtures `internal/sem/testdata/brand_score_{ms,mg,ho,mx,xind}_lavaan.json` from `predict_lavaan.R` (single-group with means, multi-group scalar-invariant, higher-order, explicit `~ 1` lines with an observed exogenous covariate, an indicator predicting the outcome) — tolerance oracles (`TestSEMScore_MatchesLavaanPredict`, `TestSEMScore_InlineMatchesLavaan`), never stored bits.

## Ordinal fits — empirical Bayes modal scores (U59 E4-S4)

- **Arithmetic (`internal/sem/ebm.go`, `sem.NewEBMScorer`).** An ordinal fit (`estimator` `dwls` / `wlsmv`; inline, bound or loaded) is scored as lavaan's `lavPredict` scores categorical data, `lav_predict_eta_ebm_ml`: the latents' posterior mode given the row, F(η) = ½(η − μ)ᵀV⁻¹(η − μ) − Σ log f_i, μ = Cα, V = CΨCᵀ, ŷ = ν + Λη; an ordered indicator's f_i the category probability Φ((τ_k − ŷ)/s) − Φ((τ_{k−1} − ŷ)/s) (floored at the machine epsilon, lavaan's), a numeric one's N(y; ŷ, s²), s = √Θ_ii — Θ's diagonal alone (a residual covariance moves no score, as lavaan), the raw thresholds τ and an ordered indicator's delta residual 1/Δ² − common (lavaan's `delta = FALSE` scale), so a grouped fit's scale factors enter through Θ. All latents are solved jointly; the slot emits `params.latent`'s coordinate. `method: "regression"` (the default) means these scores, as in lavaan (its `method = "regression"` on a categorical fit IS EBM — the oracle checks the two are identical); `method: "bartlett"` is `SERVICE_VALIDATION` `bad_params` (`param` `method`) — lavaan's categorical Bartlett is a separate ML estimator Pulse does not compute (`vectors.SEMScoreOrdinalMethodRefusal`: inline at decode, bound at bind — on a failed fit too, before its `PULSE_FIT_UNAVAILABLE` — and in predict's field-reference step 12 off the catalog's `Signature.Ordinal`: a Compose fit request's `params.estimator`, a loaded file's `ordered`, the runtime fit). **Observed mediators.** An observed variable with an outgoing arrow (numeric — an ordered one is refused at the fit) is lavaan's ov.y dummy latent, scored by lavaan's prior / likelihood split: the solve's coordinates, μ and V are the LATENTS' block of Cα and CΨCᵀ (the mediator's paths and variance shape the prior, its row value never conditions it), and the mediator enters the likelihood as a numeric indicator, ŷ_d = α_d + B_d,lat η, s_d = √Ψ_dd. Every effect OF an observed variable on an observed one (an inner B_d,d′, an output's Λ_i,d, e.g. `s3 ~ recommend`) is DROPPED from ŷ — lavaan makes such an output a dummy too and `lav_lisrel_eyetax` zeroes dummy inputs; the oracle pins the drop (keeping the path is ~0.1 off). No refusal remains on any arm (inline, bound, loaded, predict).
- **Determinism.** Newton's method from the fixed start μ, a halving Armijo line search above decrement 1e-12 and the full step below it, stopping at decrement 1e-24, when no halving descends, or after 100 steps (F is strictly convex — V⁻¹ positive definite and −log of a normal-CDF difference convex — so the mode is unique; the brand rows stop in ~4 steps). The file is FMA-free and detmath-only (it joins `TestPolychoric_NoFusibleProducts` / `_NoFMAContraction`), so a score is a function of the row and the stored parameters — inline, bound and loaded scores are bit-equal (`TestSEMScore_OrdinalBoundAndLoadedMatchInline`).
- **Coding.** A row's ordered value is coded by the FIT's categories (`semScoreFit.cats`; a bound / saved fit's `model.SEMFit.Categories`, pooled over every group), never re-derived from the scoring cohort. A value that is none of them has no category probability: the row scores null, tallied (by its first such variable) into ONE `PULSE_SEM_SCORE_LEVEL_UNSEEN` warning per slot, `details.reason` `category_unseen`, `variables` / `rows` / `categories` — E3's unseen-level rule (null + one tally, never a refusal), since the same fit legitimately scores another cohort. A null member scores null (listwise), as on an ML fit; lavaan's EBM skips a null member's density instead — deliberately not mirrored (owner decision `ordinal-null-member`).
- **Inline.** The PrePass buffers every fit-eligible row exactly as `MAT_SEM`'s ordinal slot does (member order, a null member dropped, an invalid weight dropped, a zero weight kept; grouped, each level's rows, a null group dropped) and Finalize runs `semOrdinalCoding` + `sem.FitOrdinal` / `FitOrdinalGroups` with MAT_SEM's refusals (`semOrdinalFault`) as fit-scoped warnings (`details.n` the buffered rows). The stream is serial in record order on both arms, so the inline fit is MAT_SEM's to the bit. Params `estimator`, `ordered`, `parameterization` join `capability:sem_ordinal` (`vectors.SEMScoreFeatureParams`; hidden, unknown keys).
- **Capture and file.** A Compose `fits` entry over an ordinal `MAT_SEM` binds (E4-S2's `PULSE_FIT_INVALID` `sem_ordinal` is gone): `semCaptureOrdinal` records `Ordered` / `Categories`, each group `Thresholds`; `types.SEMFitResult` adds `ordered`, `categories`, per-group `thresholds` (`omitempty`: an ML fit is byte-identical); its file is `sem_format_version` 2 (`.claude/reference/byte-layout/long-form-and-model-files.md`, SEM fit file).
- **Oracle.** `brand_score_{ord,ordmx,ordres,ordmg,ordmed,ordmedmg}_lavaan.json` (`predict_lavaan.R` with `ordered`; lavaan 0.7.3, WLSMV): the measurement model, mixed indicators (numeric `recommend`), latent regressions with a residual covariance, the mixed model across the waves under thresholds, loadings and intercepts, and the observed mediator (`brand_ordmed_model.txt`: numeric `recommend ~ quality + value`, `service ~ recommend`, `s3 ~ recommend`, `v3` numeric) single-group and across the waves — that grouped fit by lavaan's BFGS at reltol 1e-14 (`tight` argument, `options.tight_fit`), since lavaan's default nlminb stop sits ~1.4e-5 relative off the optimum Pulse reaches. `regression` is lavaan's own EBM routine with its BFGS stop tightened from reltol 1e-8 to 1e-15 (the mode); `ebm_default` is `lavPredict`'s output, up to ~4e-4 off the mode. Gates: `TestSEMScore_EBMMatchesLavaan` (Pulse's fit, ≤ 2e-6 to the mode, held at 1e-5; 1e-3 to `lavPredict`), `TestSEMScore_EBMIsTheMode`, `TestSEMScore_OrdinalInlineMatchesLavaan` (engine, both arms), `TestSEMScore_OrdinalBartlettRefusedPredictMatchesRuntime`, `TestSEMScore_OrdinalUnseenCategory`, `TestSEMFile_RoundTripBitExact`.

## Two bindings: inline (two-pass) and bound (row-local)

- **Inline** (no `params.fit`): every `MAT_SEM` fit knob (`model`, `meanstructure`, `group`, `group_reference`, `group_equal`, `group_partial`, `solver`, `information`, `ftol`, `max_iter`, `grad_tol`, `singular`) plus `fit_on` (`"filtered"` default, or inline filterers picking the FIT rows; every filtered row is still scored). No bootstrap (`resample` is `MAT_SEM`'s alone); a `:=` line parses but moves no score — a score reads the point estimate. The PrePass folds every fit-eligible row into per-level listwise co-moments through `MAT_SEM`'s blocked merge (`BlockCoMoments` keyed by merge position, an all-NaN row still opening its block), so the inline fit is `MAT_SEM`'s fit over the same rows BIT FOR BIT at any n, `DecodeWorkers` / `ShardWorkers` count and shard split (fix e69442e0; `TestSEMScore_BoundMatchesInlineAcrossBlocks`, `TestSEMFit_BoundScoresMatchInlineAboveMergeBlock`). The fit is cohort-wide, never per request group: grouped / featured requests run buffered (predict `attributeTwoPass`), never merged. `fit_on` filterers run before the completeness check.
- **Bound** (`params.fit` naming a SEM fit — a Compose `fits` entry of kind `sem`, or a loaded `.pulse-sem.json`): the slot fits nothing. Only `latent`, `method`, `labels`, `missing` are accepted; a model knob is `SERVICE_VALIDATION` reason `fit_and_model`, `fit_on` is `fit_and_fit_on`. Members align to the fit's labels BY LABEL (`PULSE_VECTOR_REFERENCE_MISMATCH` `labels_differ`); the fit's group field must be a group field of the cohort, or — a fit grouped by a column its request computed — the same column computed ahead of the slot (`fit_group_field`; `matrix-and-vectors/sem-groups.md`). The slot closes at bind (`vectors.FitBound`, `prebuiltAttribute`): ROW-LOCAL — streams, fuses into a crosstab, merges across shards, decode workers and chain stages; the unseen-level tally folds by `MergeTally`. Predict reads the same `vectors.FitBound` (`attrTwoPass`), pinned by the Streamable parity cases in `sem_fit_bound_test.go`.
- **Bit-equality (PRD success metric).** Inline, compose-bound and loaded-file scoring of the same fit rows are bit-equal: one `semScoreFit` form (`internal/processing/attribute_sem_score.go`), one `semScoreFitFromBound` rebuild for bound and loaded fits (`vectors.RebuildSEMModel`), one scorer. Gates: `TestSEMFit_BoundScoresMatchInline`, `TestSEMFit_SaveThenLoadScoresBitEqual`, `TestSEMFit_LoadedChainStage`, `TestSEMFile_RoundTripBitExact`.

## Kinds, failures, warnings

- One fit namespace holds regression, vector and SEM fits. A SEM fit named by a vector consumer (a fitted attribute, a matrix `params.fit`) or a regression score — or a regression / vector fit named by `ATTR_SEM_SCORE` — is `PULSE_MODEL_KIND_MISMATCH` (`details.kind`, `expected`); unbound is `PULSE_MODEL_UNKNOWN`. Both ways: `TestSEMFit_KindMismatchAndUnknown`. A `MAT_SEM` `fits` entry was a vector fit before E3-S2 and is kind `sem` now (migration row).
- A fit that cannot score nulls every score with one fit-scoped warning: inline `PULSE_MATRIX_INSUFFICIENT_N`, `PULSE_MATRIX_SINGULAR`, `PULSE_MATRIX_NOT_IDENTIFIED`; a compose fit that failed on its data `PULSE_FIT_UNAVAILABLE` (FR-22). A usable fit owing a caveat scores and warns (`PULSE_MATRIX_NOT_CONVERGED`, `PULSE_MATRIX_NEAREST_PD`). Config faults (an unknown latent, a bad method) refuse at predict and runtime alike (`TestSEMScore_ConfigRefusalsPredictMatchesRuntime`).
- A score is an ordinary `f64` field: grouped means (`attributes/25_sem_score.json`), a regression predictor (`compose/10_sem_fit_scores.json`, `TestExamples_SEMFitScoresFeedRegression`, `TestSEMScore_DownstreamRegression`). No `Response.Components` entry (row-level scalars).

## Weight, features, guidance

- **Weight:** frequency only, fit only — the inline fit is `MAT_SEM`'s (N = Σw; an invalid or zero-weight row adds nothing but is scored); a probability weight is `PULSE_WEIGHT_UNSUPPORTED`. A bound slot fits nothing, so its weight moves no score (the fit's own basis governs). Long form: `.claude/reference/weighting/inference-multivariate.md` (the SEM score bullet); class table: `weighting/surface-and-classification.md`.
- **Features (`internal/descriptor/features.go`).** `op("ATTR_SEM_SCORE")`; every inline-SEM capability (`capability:sem_meanstructure`, `capability:sem_groups`, `capability:sem_defined`, `capability:sem_ordinal`) lists `ATTR_SEM_SCORE` / `MAT_SEM` as an any-of host; A compose-bound `params.fit` rides `capability:compose_fits`; loading a `.pulse-sem.json` rides `capability:models` (its host group lists `ATTR_SEM_SCORE`), writing one `capability:model_save`. Hidden params prune through `params_allowlist.go`; `TestSEMScore_HiddenSurfacesRefuseLikeUnknown`. Detail: `matrix-and-vectors/matrix-sem.md` (Predict, declared keys and feature profiles).
- **Guidance.** `builtinPurposes` (`purposes_attributes.go`) and `builtinInterpretations` (`interpretations_attributes.go`) carry the entry; skill sections render from them (`.claude/reference/guided-analysis.md`).
