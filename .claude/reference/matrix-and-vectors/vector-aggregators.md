## Virtual vectors — vector aggregators and expand

Continues `## Virtual vectors — vector-input operators (continued)` in `.claude/reference/matrix-and-vectors/vector-operators.md`: the aggregators that fold a vector element by element, and `params.expand`.

- **Vector aggregators: `AGG_VEC_MEAN` / `AGG_VEC_SUM` (U27 E2-S2) / `AGG_VEC_SD` (U30 E5-S1).** `types.Aggregation` carries `vector` / `fields` (aggregations, `crosstab.cell`, `crosstab.margin_aggregations`), resolved by `vectors.ResolveAggregations(req, schema, route, ext)` — field-reference step 11 — with the type set `vectors.VectorAggregationTypes` plus every extension aggregator registered `VectorInput` (its `labels` / `expand` params read leniently, the rest its own; `expand` needs `ArrayValued`, else `expand_not_array_valued`) — the instance classifier is `vectors.AggregationKinds` (`.claude/reference/architecture.md`, Extension surface); every other aggregator refuses the slot (`reason` `vector_not_accepted`). `Processor.prepare` and both service reducers call `processing.ResolveAggregationInputs`, which rewrites a COPY via `vectors.AggregationSlotRewrite`: literal members into `Fields`, `Vector` cleared, the default label (`types.AggregationLabelOf`) pinned, and the resolved labels into `params.labels` — the factory refuses an unresolved `Vector` with `PROCESSING_INTERNAL`. Projection reads `vectors.AggregationInputMembers`. Missing data is per ELEMENT; the floor's row is present when ANY member answered (`processing.AggregationPresent`, every floor site). The value is `Rich()` `[]float64` (NaN → `null`), components `labels` / `element_n` / `element_sum` (+ `element_sum_weights` weighted), `Mergeable`. `AGG_VEC_SD` is the per-element SAMPLE sd √(c·M2/(N* − 1)) — `weighting.ScaledVariance`, the one inference rule (N* = n / Σw / Kish n_eff), NaN when N* ≤ 1, never 0: its blocks alone carry per-element `mean` / `m2` / Σw² (`newVecMomentBlock`), folded by the weighted Welford–West step and combined by Chan's rule (`vecBlock.mergeMoments`), every product `float64(a*b)`; components add `element_mean` / `element_m2` (+ `element_sum_weights_sq` weighted). `AGG_VEC_MEAN` / `AGG_VEC_SUM` never touch the moment slices, so their words are unchanged (`TestVecAgg_MeanSumBitsFrozen`); an `AGG_VEC_SD` element cell keeps the type's recompute margin (buffered crosstab, like `AGG_STDDEV`). Bit-exact merge: each row folds into the fragment its `Record.MergeBlock()` names (global record ordinal; a non-head fragment buffers and is replayed), Finalize combines the blocks in the fixed `linalg.MergeTree` shape by block order, `MergeOnline` is a disjoint map union (a duplicate fragment or loose rows on both sides → `PROCESSING_INTERNAL`); a shard archive equals its single-file twin bit for bit, whatever the split (Blocked merge-tree contract). Array-valued (`types.AggregationType.ArrayValued`, or an extension declared `ArrayValued`: `AggregationKinds.IsArrayValued`): refused `PROCESSING_CONFIG` `reason` `array_valued` by `vectors.ArrayValuedCrosstabRefusal` (crosstab cell / margin, both arms + predict; manifest `crosstab.array_valued_aggregators`) unless the slot selects ONE element (`params.element`, U30 E4-S4: built-in only — an extension's `element` key is its own — `vectors.SelectsElement`; crosstab slots only, `element_outside_crosstab`; refused beside `expand` / naming no member label / a shared label: `element_with_expand` / `element_unknown` / `element_ambiguous`; `AggregationSlotRewrite` narrows the prepared slot to that member, so the factory folds it alone — an unnarrowed element slot is `PROCESSING_INTERNAL` — `Aggregate` / `Finalize` return its figure, `Rich` none, components are one-entry arrays and the floor is the member's presence; gates `TestVecAggCrosstab_ElementCell` (twin, every normalize, weighted, fused ≡ buffered ≡ decode split), `TestVecAggCrosstab_ElementRefusalParity`, `TestVecAgg_ElementScalar`, `TestElementSelection`), the field-ref walk (a `sort` key naming its label; `aggregations[0]` under `overlays`) and `mergegate.StageArrayValuedRefusal` (a chain stage feeding another — the `total()` / ratio route to an aggregate label; an EXPANDING slot feeds it, its element columns typed f64 by `vectors.ChainStageSchema`, U30 E4-S3). Gates: `TestResolveAggregations_*`, `TestAggregationSlotRewrite`, `TestArrayValuedCrosstabRefusal`, `TestVecAgg_*`.
- **Expand (U27 E2-S3).** `params.expand: true` writes one float64 column per member, `vectors.ExpandedColumn(label, element label)` = `<label>[<element label>]`, in place of the array (the label key absent; grouped: per row). The names exist ONCE: `vectors.AggregationOutputColumns(req, agg, schema)` — predict `AggregationPredict.Columns`, `returnOutputColumns`, chain `stage_schemas` and the field-ref walk's output set read it — and the runtime's six row builders (serial streaming, two-pass, buffered, the grouped tail, both parallel reducers) write through `processing.WriteAggregationResult`, which asks the aggregator (`ExpandedElements`). Duplicate element labels under expand: `SERVICE_VALIDATION` `expand_duplicate_labels`. Each element column is an ORDINARY nullable f64 output column (U30 E4-S1): it joins the walk's output set, so a `sort` key, a window `field` / `order_by` / `partition_by` and a post-test field read it (predict ≡ runtime, one walk; `TestVecAggExpand_ElementColumnsDownstream`, `TestFieldRefRefusals_ExpandedElementColumns`); the walk's `arrayCols` holds only the BARE label, refused there `PROCESSING_CONFIG` `array_valued` whether or not the slot expands. An element no row answered is NaN (null on the wire), and the window comparator / value reader treat NaN as a null (`window.isNullCell`: last in both directions, its own partition, skipped by value-bearing windows — so `Request.Sort` and post-test `order_by` too); a post-test reads it like any undefined f64 figure (the statistic comes back undefined, never refused). Ratios: `AGG_RATIO` `numerator_field` / `denominator_field` and `total()` read RECORD columns at their own pipeline point, never output columns, so within one request they cannot name an element column; the only route is a chain stage feeding the next (`mergegate.StageArrayValuedRefusal`). A request overlay SCORING a vector aggregation is refused by the same walk (`processOverlayArrayValuedRefusals`, shared via `Service.checkFieldRefs`): the scored one is a series kind's `params.field` (`seriesfield.Resolve`), else `aggregations[0]`, so an unscored vector aggregation beside it runs (U46 E4-S10); Compose and whole-chain overlays SCORING a vector aggregation are refused (`descx.ComposeOverlayArrayValuedRefusal` / `ChainOverlayArrayValuedRefusal`, predict and runtime, one function): the scored one is `params.field` (`seriesfield.ResolveComposeSlot` / `ResolveChainStage` on a kind that honours it), else `aggregations[0]`; a crosstab slot / stage is judged on every aggregation. Each non-crosstab slot / stage is narrowed to its group columns plus that one value column before any row is read (`processing.narrowSeriesHost`), so an unscored vector aggregation beside it — array or element columns — never reaches the fold and runs (U46 E4-S8); an unresolvable `field` is left to `PULSE_OVERLAY_FIELD_UNKNOWN`. The same three hosts refuse a NON-SCALAR scored aggregation the same way, `reason` `non_scalar` (`AggregationKinds.IsNonScalar`: `AGG_WELFORD`, `AGG_SET_UNION` / `_INTERSECTION` / `_FREQUENCY`, an extension declared `NonScalar`; a kind whose hard edge names the aggregator — `OVERLAY_T_VS_REF` / `OVERLAY_Z_VS_REF` / `OVERLAY_T_VS_PRIOR` / `OVERLAY_Z_VS_PRIOR` on the Welford triple — is exempt, and a prior-period kind scoring a measure of the prior-period vocabulary it cannot read (`AGG_WELFORD` under `OVERLAY_PROP_Z_VS_PRIOR`) gets its own `PULSE_OVERLAY_REF_INCOMPATIBLE_WITH_SHAPE` `measure_type` refusal (`priorMeasureOwns`, U47 E4-S6); on a chain a non-mergeable one is left to `PULSE_CHAIN_NOT_MERGEABLE`, which predict reports first) — it once folded as no value into an empty layer (U46 E4-S11); `mergegate.StageArrayValuedRefusal` likewise refuses a non-scalar aggregation in a chain stage feeding another (`non_scalar`; the next stage read it as null). A series overlay's `params.field` may name an element column on all three hosts (U30 E4-S2; `seriesfield.Scored`, `vectors.AggregationColumns` — long form `execution-modes/overlays.md` Series measure). Chain feeds, crosstab element selection and `return` paths over element columns are U30 E4-S3..S4's. Gates: `TestAggregationOutputColumns`, `TestVecAgg_WriteAggregationResult`, `TestVecAggExpand_*`.
