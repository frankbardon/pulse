## Virtual vectors — vector aggregators and expand

Continues `## Virtual vectors — vector-input operators (continued)` in `.claude/reference/matrix-and-vectors/vector-operators.md`: the aggregators that fold a vector element by element, and `params.expand`.

- **Vector aggregators** (`vectors.VectorAggregationTypes`, plus every extension aggregator registered `VectorInput`; the instance classifier is `vectors.AggregationKinds` — `.claude/reference/architecture.md`, Extension surface). `types.Aggregation` carries `vector` / `fields` in aggregations, `crosstab.cell` and `crosstab.margin_aggregations`, resolved by `vectors.ResolveAggregations`; every other aggregator refuses (`vector_not_accepted`). The prepared slot is rewritten on a COPY (`vectors.AggregationSlotRewrite`: literal members, default label pinned, resolved labels into `params.labels`); the factory refuses an unresolved `Vector` with `PROCESSING_INTERNAL`. Missing data is per ELEMENT; the floor's row is present when ANY member answered (`processing.AggregationPresent`, every floor site). The value is `Rich()` `[]float64` (NaN → `null`), with per-element components; `Mergeable`.
- **`AGG_VEC_SD`** is the per-element SAMPLE sd √(c·M2/(N* − 1)) through `weighting.ScaledVariance`, the one inference rule; NaN when N* ≤ 1, never 0. Only its blocks carry per-element moments (weighted Welford–West, Chan's combine, FMA-free), so `AGG_VEC_MEAN` / `AGG_VEC_SUM` bits never move when it changes (`TestVecAgg_MeanSumBitsFrozen`).
- **Bit-exact merge.** Each row folds into the fragment its `Record.MergeBlock()` names and Finalize combines blocks in the fixed `linalg.MergeTree` shape, so a shard archive equals its single-file twin bit for bit whatever the split (`linalg.md`, Blocked merge-tree contract). A duplicate fragment on merge is `PROCESSING_INTERNAL`.
- **Array-valued in a crosstab.** An array-valued aggregator (`AggregationKinds.IsArrayValued`) in a crosstab cell or margin is refused `PROCESSING_CONFIG` `array_valued` (`vectors.ArrayValuedCrosstabRefusal`, both arms + predict; manifest `crosstab.array_valued_aggregators`) unless the slot selects ONE element with `params.element` (built-in only, crosstab slots only, never beside `expand`, must name exactly one member label). The prepared slot is then narrowed to that member, so the factory folds it alone and the floor is the member's presence — which is what makes the crosstab admission rule hold for element cells (`response-components.md`, Auxiliary crosstab margin aggregations). An unnarrowed element slot is `PROCESSING_INTERNAL`.
- **Expand.** `params.expand: true` writes one nullable f64 column per member, named `<label>[<element label>]` (`vectors.ExpandedColumn`), in place of the array. **The names exist ONCE**: `vectors.AggregationOutputColumns` is read by predict, `return`, chain stage schemas and the field-ref walk; every runtime row builder writes through `processing.WriteAggregationResult`. Duplicate element labels under expand are `SERVICE_VALIDATION` `expand_duplicate_labels`. Element columns are ordinary output columns: a `sort` key, a window field and a post-test read them; an element no row answered is NaN, which windows and sort treat as null and a post-test as an undefined figure. The BARE array label stays refused (`array_valued`) wherever a scalar column is read.
- **Ratios and chains.** `AGG_RATIO` field params and `total()` read RECORD columns, never output columns, so within one request they cannot name an element column; the only route is a chain stage feeding the next. A chain stage feeding another refuses an array-valued or non-scalar aggregation (`mergegate.StageArrayValuedRefusal`) unless it expands (element columns typed f64 by `vectors.ChainStageSchema`).
- **Overlays scoring a vector or non-scalar aggregation.** Request, Compose and whole-chain overlays are refused when the aggregation they SCORE (a series kind's `params.field`, else `aggregations[0]`; every aggregation of a crosstab slot) is array-valued (`array_valued`) or non-scalar (`non_scalar`, `AggregationKinds.IsNonScalar`). Without the refusal it folded as no value into an empty layer. Kinds whose hard edge names the aggregator (the t / z kinds on the Welford triple) are exempt. An unscored vector aggregation beside the scored one runs: each host is narrowed to its group columns plus the one value column before any row is read. A series overlay's `params.field` may name an element column (`execution-modes/overlays.md` Series measure). The refusal functions are shared by predict and runtime (`descx.ComposeOverlayArrayValuedRefusal` / `ChainOverlayArrayValuedRefusal`, `processOverlayArrayValuedRefusals`).
