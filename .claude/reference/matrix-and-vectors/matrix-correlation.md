## Matrix slot — co-moment operators, inference, missing modes and warnings (continued)

- **`MAT_COVARIANCE`.** `params.ddof` ∈ {0, 1} (default 1); `primary` = `CoMoment.Cov(ddof)` = M2_w / (W − ddof), NaN where W − ddof ≤ 0. Weighted under both kinds (`.claude/reference/weighting.md`, Matrix operators). Oracle: `TestMatrixCovariance_MatchesReference` (numpy `cov` / statsmodels `DescrStatsW`, generator `internal/service/testdata/matrix_reference/`); diagonal parity `TestMatrixCovariance_DiagonalMatchesVarianceAggregators`.
- **`MAT_CORRELATION` (Pearson, U16 E3-S1).** Params: the missing-data knobs below and `summary` (any other key refused). `primary` = `CoMoment.Corr()`: r clamped to [−1, 1], diagonal exactly 1; a zero-spread member (constant, one massed row, no rows) has its whole row and column NaN → `null`, diagonal included, and the determinant is then `null`. Per-pair p-values and intervals only under `params.inference` (Inference bullet below). Weighted under both kinds (r is scale-free; `ClassAware`). **Parity with `TEST_PEARSON_R`** (`TestMatrixCorrelation_PearsonParity`, an N² battery in both field orders): every cell within `1e-12 + 1e-12·|r|`, unweighted and both weight kinds, one block and several; BITWISE for unweighted serial ≤ 4096 rows when the test's `field` is the earlier member — asserted on amd64 only, because `TEST_PEARSON_R`'s recurrence is plain Go that arm64 fuses into multiply-adds (its bits are frozen; the matrix is FMA-free). Reversed field order, weights or more than one block change the operation order, so tolerance only. A weight-0 row counts toward the matrix's n and is skipped by the test: `mat.n == pearson.n + zero_weight_rows` (`TestMatrixCorrelation_ZeroWeightRowsCountTowardN`). Oracle: `TestMatrixCorrelation_MatchesReference` (`numpy.corrcoef` / `DescrStatsW.corrcoef`); zero spread: `TestMatrixCorrelation_ZeroSpreadIsNull`. Interpretation: `primary.values` banded by Cohen's r convention (.1 / .3 / .5, fixture `statistic_bindings` → `pearson_r`) with the causation caveat (lint `CORR-CAUSAL`), `scalars.determinant` unbanded.
- **`MAT_CORRELATION` rank methods (U24 E1-S3).** `params.method` ∈ `pearson` (default; an explicit `"pearson"` is the default, streamable and mergeable) | `spearman` | `kendall` (`vectors.CorrelationMethods`; anything else `bad_params`, `details.param` = `method`; `MAT_COVARIANCE` refuses the key as unknown). A rank method is BUFFERED and NOT mergeable (`MatrixSpec.Streamable` / `Mergeable`, E1-S1): the slot keeps its `matrixRows`, the request routes buffered and the merge gate keeps it serial on every arm (`DecodeWorkers` / `ShardWorkers` never fan it out; Compose slots and chain stage 0 run it through `Process`). Finalize (`rankCorrelation`, `internal/processing/matrix_rank.go`) reads the buffered rows with the weight-0 rows left out (no mass; not on the expansion — as the tests skip them) and computes each cell with the TEST's OWN kernel: Spearman = `rankPearson` over `weightedMidRanks` (extracted from `TEST_SPEARMAN_R`), Kendall = τ-b from `kendallCounts` + `kendallTauB` (`kendall_knight.go`) — Knight's O(n log n) merge-sort count, frequency-weighted (pair mass w_i·w_j; C / D / T_x / T_y are integer-exact below 2⁵³), which `TEST_KENDALL_TAU` now runs too (its outputs unchanged: `TestKendallCounts_MatchesPairLoop` is the property test against the old O(n²) loop on random tied, zero-weighted data). Listwise ranks each member once over the complete rows; pairwise re-ranks each pair over that pair's own rows (R `cor(use = "pairwise.complete.obs", method = …)`). A cell is NaN when its rows leave a member a single distinct value; the diagonal is 1 for a member whose own massed rows have spread, else NaN (the Pearson zero-spread rule: the whole row and column null). Every other part is the shared co-moment set over the rank primary (`coMomentOutput`): warnings (from the co-moments — zero rank spread ⇔ zero spread), `scalars.determinant`, pairwise `auxiliary.n` (`PairN`, weight-0 rows counted), `vectors.top_pairs` (ranked by |ρ| / |τ|). `params.inference` on a rank method gives cor.test's rank p and a Bonett–Wright / Fieller interval (Inference bullet, U28 E3-S3; the E3-S2 `bad_params` refusal is gone). Weight class: frequency-only (`weighting.MatrixClassOf`; the resolver's `weightSlot.specClass`), so a probability weight from any source is `PULSE_WEIGHT_UNSUPPORTED` `{slot, operator, field, kind, supported_kinds: [frequency], method}`; the manifest's type-level `matrices[].weight_kinds` stays both kinds (Pearson) and the `method` param description records the rank class. Parity: every off-diagonal cell is BITWISE the test's statistic over the same rows (one kernel, the same rows in record order) — `TestMatrixRankCorrelation_TestParity` (listwise and pairwise, both field orders, unweighted and frequency with zero-weight rows). Oracle: `TestMatrixRankCorrelation_MatchesROracle` (R `cor`, `mv_rank_correlation.json`, fixtures attitude / mtcars / likert_ties / weighted / nulls, frequency = the `rep()` expansion, 1e-12 abs+rel; unweighted pairwise also pins `auxiliary.n` to R's pair n). Hosts / knobs: `TestMatrixRankCorrelation_SerialUnderParallelKnobs`, root `TestMatrixRankCorrelation_Hosts` (grouped bucket = filtered run; Compose, ComposeParallel, chain stage 0 = Process). KnownAs `rank correlation`, `spearman correlation matrix`, `kendall correlation matrix` (bare `spearman` / `kendall` belong to the tests — `TestPurposeKnownAsUnique`).
- **`MAT_PARTIAL_CORRELATION` (U24 E1-S4, `internal/processing/matrix_partial.go`).** Params: `control`, `repair`, the missing-data knobs (any other key `bad_params`). The partials are read off the precision matrix of `CoMoment.Corr()` over the FOLDED columns (`vectors.Matrix.Columns()`): `control: "all"` (default; absent / null alike) — partial_ij = −P_ij / √(P_ii·P_jj), P = R⁻¹ (`ppcor::pcor`, `corpcor::cor2pcor`); a control LIST (non-empty, distinct literal field names, no glob) — each output pair controls for exactly those fields: the correlation of (P_OO)⁻¹ = R_OO − R_OC·R_CC⁻¹·R_CO (`ppcor::pcor.test(x, y, Z)`). A listed member leaves the output axis (`Matrix.Output`, positions in `Columns`; `OutputMembers` gives `row_keys` / labels, which predict's `axis_keys` / `shape` read too); a listed field outside the members is resolved by the vector rules at `matrices[i].params.control` (`ResolveSpec`: unknown field `SERVICE_VALIDATION`, non-numeric `PULSE_VECTOR_MEMBER_TYPE`) and folded AFTER the members (`Matrix.Extra`), so it joins the co-moment, its missing-data mode, the `Components.Matrices` floor, `AccumulatorBytes`, `MaxMatrixDim` and projection (`MatrixMembers`). Every member as a control is `bad_params`. Both inversions are the REFERENCE `InverseSPD` (FMA-free; arch-independent, worker-invariant — streamable and mergeable like Pearson; `TestMatrixInvariance_{Archive,Heavy}` cover it, the pairwise variant under `repair`). Outputs: `primary` (clamped to [−1, 1], diagonal 1), pairwise `auxiliary.n` (each output pair's `PairN`), `params.inference` auxiliaries (Inference bullet), warnings; no scalars, no vectors (`summary` refused). Any undefined input r (zero spread, thin pair, no rows) → every cell NaN, the co-moment warnings explain. A singular input → `PULSE_MATRIX_SINGULAR` through `singularMatrixError` over the folded columns (`rank`, `condition_number`, `dependent_fields`). Weighted: `ClassAware`. Oracle: `TestMatrixPartialCorrelation_MatchesROracle` (`mv_partial_correlation.json`, every case incl. control lists, pairwise, both weight kinds; each control list both outside and inside the vector; 1e-10 abs + rel). Gates also `TestMatrixPartialCorrelation_{NotPSDGuard,Singular,ControlJoinsFold,Refusals}`, `TestPartialCorrelation_ControlsAreSchurComplement`, `TestResolveMatrices_PartialControls`. KnownAs `partial r`, `controlling for`, `partial correlation matrix`, `partial correlations`; Interpretation Cohen r bands (fixture binding `pearson_r`) + `CORR-CAUSAL`.
- **Inference — `params.inference` / `params.alpha` (U28 E3-S2 / E3-S3, `internal/processing/matrix_inference.go`, `matrix_rank_inference.go`).** On `MAT_CORRELATION` (every `method`) and `MAT_PARTIAL_CORRELATION` only (`vectors.InferenceTypes`; another operator refuses the key as unknown): `inference` bool (default false); `alpha` in (0, 1), default `vectors.InferenceDefaultAlpha` 0.05, `bad_params` without `inference: true` (`decodeInference`, the shared resolver, so predict refuses identically). On, the result's `auxiliary` gains `p`, `ci_lower`, `ci_upper` — `square_symmetric` twins of the primary over the OUTPUT axis in its `encoding`, diagonal NaN → `null` — so the E3-S4 multiplicity p-site reads raw p at `auxiliary.p` whatever the operator. Arithmetic: ONE helper, `correlationInference(r, df, zDF, ciOK, alpha)` (`test_pearson.go`), which `TEST_PEARSON_R` now calls too (its outputs unchanged — an undefined test interval still collapses to r there; the matrix leaves it null): t = r·√(df/(1 − r²)), p = `statdist.StudentTTwoSidedP`, |r| = 1 → t = ±Inf, p = 0, interval [r, r] (cor.test's limit); Fisher bounds tanh(atanh(r) ∓ z_{α/2}/√zDF). Size: N* = `PairN` unweighted, `basis.NStar(PairW, PairW2)` weighted (Σw frequency, exact per-pair Kish n_eff probability — E3-S1's `PairW2`); the row floors read `n` = `PairNMass` (Σw = N* under frequency, U36 E1-S7) — the rows carrying mass, the single-pair tests' raw `n` (they skip a weight-0 row), so a cell is null exactly where `TEST_PEARSON_R` refuses (p) or collapses its interval; unweighted it is `PairN`, and the components `n` keeps counting weight-0 rows (`TestMatrixInference_ZeroWeightRowsFloorLikeTest`, rank methods too). The thin-cell warning's `n` is this massed count. Pearson: per cell df = N* − 2, zDF = N* − 3, p needs n ≥ 3 ∧ df > 0, the interval n ≥ 4 ∧ zDF > 0. Partial over g controls (`control: "all"` → g = folded columns − 2, a list → its length): df = N* − 2 − g, zDF = N* − 3 − g, floors 3 + g / 4 + g rows, ONE N* for the matrix — the fold's (listwise) or the smallest folded pair's (pairwise, with `PULSE_MATRIX_PAIRWISE_N_STAR` `outputs [p, ci_lower, ci_upper]`) = ppcor's n. Nulls: diagonal, a null r (the co-moment warnings explain; no inference warning), a size failure → `PULSE_MATRIX_INSUFFICIENT_N` `scope: "inference"` (pairwise Pearson: `pairs [{row, col, n, n_star, outputs}]`; otherwise matrix-wide `{n, n_star, controls, outputs}`; `outputs` names the nulled keys); probability n_eff < 3 + g → `PULSE_WEIGHT_LOW_NEFF` (`{matrix, type, pairs [{row, col, n_eff}] | n_eff, min_required}`). Both are `MatrixResult.Warnings`, never escalated by strict (no matrix warning is). Gated by `compute.MatrixAuxiliary`: a `return` dropping `matrices[*].auxiliary` (preset `minimal`) skips the computation and its warnings (`WorkStats.MatrixInferenceBuilds`). **`standard` keeps what a spec asked for (U28 E4-G1):** its table lists `auxiliary.p` / `ci_lower` / `ci_upper` / `p_adjusted` / `significant_adjusted` (they exist only on an inference / claimed spec, so the rule is per spec) plus `matrices[*].multiplicity`, and keeps the pairwise `auxiliary.n` only beside a kept `p` — a preset COMPANION (`returnPresetCompanions` → `returnplan.Companion`, answered by `Plan.VisitIn` in the pruner, the planned encoder and the predict size walk; echoed as predict `return.companions` and manifest `return_presets[*].companions`, inside the digest). A partially kept `auxiliary` narrows the compute gate PER SPEC (`ComputePlan.ForMatrix` over `vectors.Matrix.AuxiliaryKeys`, the one key list predict's `matrixAuxiliaryNodes` reads), so a spec without inference builds no auxiliary under `standard`; a claimed spec still vetoes (`WithMatrixAuxiliary`). Gates: `TestReturnAuxiliary_PredictRuntimeParity`, `TestReturnAuxiliary_NoInferenceByteIdentical` (`internal/descriptor`, external), `TestMCPReturnDefault_StandardKeepsMatrixInference`, `TestVisitIn_Companions`. Off / absent / `false` → byte-identical (`TestMatrixInference_OffIsByteIdentical`). **Rank methods (E3-S3).** The cell rule is ONE `inferenceAux` with an `inferenceRule` (p override, Fisher-z variance, interval row floor), so the floors, nulls and warnings are Pearson's. p is R `cor.test(method = …)` at its defaults (`exact = NULL`, `continuity = FALSE`) over the cell's own massed rows (`rankCorrelation(in, withP)` computes it beside the cell; n = Σw, a frequency weight above 1 is a tie, TIES = any tie group in either column): Kendall — untied and n < 50: exact, q = C, `pKendall` (R's `ckendall` Mahonian recursion, summed in R's order over n!), p = min(1, 2·min tail); else z = (C − D)/√Var(S) with `kendallVarS` (the tie-corrected variance, extracted from `TEST_KENDALL_TAU`) and NO continuity correction. Spearman — untied and n ≤ 1290: AS 89 `pRho` on S = Σd² (exact permutation counts for n ≤ 9, cached per n; Edgeworth above, clamped to [0, 1], lower tail = 1 − upper at `round(q) + 2`); else t = ρ√((n − 2)/(1 − ρ²)) via `correlationInference`. ONE helper per method (`kendallCorTestP` / `spearmanCorTestP`, `rank_cortest.go`) that `TEST_KENDALL_TAU` / `TEST_SPEARMAN_R` (row and post variants) call too (E3-G2, a behaviour break for the tests: Kendall dropped its continuity correction and its `details.z` is now S/√Var(S); both are exact on small untied samples), so a cell and the two-field test agree in p as in the statistic (`TestMatrixInference_RankTestParity`; statistics pinned bit for bit by `TestRankTests_StatisticsUnchangedByCorTestP`). Interval: `cor.test` has none for a rank method, so Pulse emits Fisher z with the method's standard error rather than null bounds (a CI is what a matrix reader screens with; both forms are the standard published ones): Spearman se² = (1 + ρ²/2)/(n − 3) (Bonett & Wright 2000; 4 rows), Kendall se² = 0.437/(n − 4) (Fieller, Hartley & Pearson 1957; 5 rows, `ciNeed` names it in the thin warning); |r| = 1 → [r, r]. Weights: frequency only (a probability weight stays `PULSE_WEIGHT_UNSUPPORTED`; `TestMatrixInference_RankWeightRules` also pins frequency = the expansion). Oracles: `matrix_inference.json` rank cases (`cor.test` on fixtures weighted / nulls pairwise / two_factor n = 80 / attitude / likert_ties / mtcars, unweighted and the `rep()` expansion) plus `rank_rho` (R `C_pRho` grid), `rank_kendall` (`C_pKendall` grid) and `rank_pairs` (`cor.test` on single pairs across every switch: n 3–12, Kendall 49 / 50, Spearman 1290 / 1291 — those two GENERATED, not stored: `gen` holds a Park–Miller recurrence's seed and `y_div`, which R and Go (`parkMillerPair`) evaluate to the same integers, `TestRankPairs_CoverSpearmanBoundary` re-checking them untied — ties, |r| = 1) — `TestPRho_MatchesR`, `TestPKendall_MatchesR`, `TestRankCellP_MatchesCorTest`, `TestKendallVarS_IsTheTestsVariance`; byte identity `TestMatrixInference_RankOffIsByteIdentical`. Families `matrix` (default; one per RESULT — spec × bucket) and `request` (pooled with the request's tests / post-tests / overlays, every bucket). The hypotheses are the DISTINCT pairs: the off-diagonal upper triangle of a `square_symmetric` result (m = k(k − 1)/2, R `p.adjust` over `cor.test`'s pairs), every cell of a rectangular one. The fold (`internal/service/multiplicity_matrix.go`, `collectMatrixResultSites`, filed LAST by `collectRequestSites`) reads `auxiliary.p` in any encoding and writes `auxiliary.p_adjusted` / `significant_adjusted` (1 / 0 against the block's alpha; NaN beside a NaN adjusted p) mirrored under `full`, upper-shaped under `upper`, diagonal null, plus `MatrixResult.Multiplicity`; a null p is excluded from m (`excluded`). - **`PULSE_MATRIX_NOT_CONVERGED` (U24 E2-S1).** The per-matrix WARNING of every iterative matrix routine stopped at its documented cap (`notConvergedWarning`): the minres fit above, `MAT_FACTOR`'s extraction (`fa_minres` / `fa_pa` / `fa_ml`) and a rotation (`varimax` / `gpa_oblimin`), and the nearest-correlation repair — `guardPSD` returns `[]*types.ResponseWarning`, and a repair with `converged: false` emits NOT_CONVERGED (`solver` `nearest_correlation`, cap `nearestMaxIter`, `nearestConvTol`) beside its NOT_PSD warning (`repairWarnings`, `TestRepairWarnings_NotConvergedBesideNotPSD`). Owned `ownAllMats`.
- **Missing modes and warnings (U16 E3-S2).** Both operators take `params.missing` — `listwise` (default; a row with any member null is dropped) or `pairwise` (`CoMoment` `Pairwise`: each cell over the rows where both members are present, the diagonal over the member's own rows; `Corr` reads each pair's own variances, as `pandas.DataFrame.corr` does) — and `params.max_drop_share` (a share in [0, 1], NO default, listwise only: under pairwise it is refused `bad_params`). Pairwise adds `auxiliary.n`: a `MatrixValues` of the primary's kind, encoding, keys and labels whose cells are `PairN` (rows with both members present and a valid weight, `w = 0` included); listwise has no `auxiliary`. `MatrixResult.warnings` (`{code, message, details}`, the `OverlayLayer.Warnings` triple; derived in `internal/processing/matrix_warnings.go` from the merged state, so as worker-invariant as the cells), in this order:
  - `PULSE_MATRIX_INSUFFICIENT_N` — scope `matrix` (`n` < 2 or `sum_weights` = 0; the member and PSD checks are then skipped), or under pairwise scope `pairs` (`pairs` `[{row, col, n}]`, i ≤ j, each pair with `n` < 2 or no mass). Cells stay what the arithmetic gives (NaN → `null` where undefined); nothing extra is nulled.
  - `PULSE_MATRIX_ZERO_VARIANCE` — `members` whose own rows suffice (pair (i, i) `n` ≥ 2, mass > 0) but have zero spread. **Decision:** correlation nulls the member's row and column (as before); covariance KEEPS its exact 0 row and column — a defined figure, and the numpy oracle's — so FR-23's "nulls" applies to r only.
  - `PULSE_MATRIX_LISTWISE_HEAVY_DROP` — only with `max_drop_share`: `dropped / rows > max_drop_share` (strict), `rows` = every filter-passing row = `N + NWeightInvalid + dropped`; `dropped` (rows with a null member, weight never judged) is an integer the slot keeps beside its blocks and `MatrixSlots.Merge` sums, so it is worker-invariant.
  - `PULSE_MATRIX_NOT_PSD` — pairwise only (a listwise matrix is PSD by construction); a WARNING on these two operators, FATAL (or the repair warning) on a decomposition operator (PSD guard and repair, below). Members with an undefined or non-positive diagonal are left out; if any remaining cell is undefined nothing is judged. The rest is scaled by its diagonal (C_ij / (√S_ii·√S_jj) — PSD-ness is scale-invariant; a correlation matrix is unchanged) and factored by the REFERENCE `linalg.Cholesky` with `psdTolerance` = 1e-10 added to the unit diagonal, so a singular-but-PSD matrix (collinear members) and rounding do not warn. Details `pivot` (axis index of the failing pivot), `member`, `checked`, `tolerance`. FMA-free, so arch-independent. Detection only here; the repair is `params.repair` on the decomposition operators (below). The reference fixture's pairwise correlations are themselves not PD (numpy's Cholesky refuses them) and warn; its pairwise covariances do not (`TestMatrixWarnings_NotPSDOnReferenceCorrelation`).
  Oracle: `TestMatrixPairwise_MatchesReference` (per-pair numpy / statsmodels, `matrixRefPairwiseCases` / `matrixRefPairwiseN`); gates `TestMatrixPairwise_AuxiliaryNShape`, `TestMatrixWarnings_*`; worker invariance covers pairwise (with `auxiliary.n` and the matrix warnings compared, listwise variants carrying `max_drop_share: 0` so the summed drop count is exercised).
