# Matrix and vectors — `MAT_SEM` group selection: derived groups and `group_levels` (sem-group-select)

Per-topic slice of the matrix-and-vectors reference. Index: `.claude/reference/matrix-and-vectors.md` — load it first, then only the slice(s) your change touches. The joint multi-group fit itself (levels of a cohort field, configural / invariance, outputs, refusals) is `matrix-and-vectors/matrix-sem.md`; this slice is what the group may BE and how its levels are chosen.

## Derived groups

- **Resolution (`vectors.resolveSEMGroup`, predict ≡ runtime: one resolver).** `params.group` resolves against the cohort schema FIRST, then the request's computed columns (`vectors.ComputedColumns` — the map vector members read: attribute labels, built-in feature outputs, window labels when windows run over the records; a schema field of the same name is never computed). A name in neither is `bad_params` (unknown). A computed group sets `SEMPlan.GroupDerived` and `GroupType` f64; `SEMGroupFieldTypes` is unchanged for cohort fields.
- **Type gate.** A computed column must be a nullable f64 (`ComputedColumn.Type`); an `ATTR_PREVIOUS_STATE` over a categorical / packed_bool state keeps that type and is `group_field_type` (details `group_field`, `field_type`, `slot`, `slot_index`) — the message points at wrapping it in an `ATTR_FORMULA`.
- **Existing checks apply unchanged** (they run before the lookup): `group_with_groups`, the group as a member, a standardizing vector, `params.fit` (all `bad_params` except the first).
- **Projection and copy.** `appendSEMGroupField` adds nothing for a computed group (its producer's inputs decode); `MatrixComputedMembers` lists it, so a window-label group is copied onto the records (`copyWindowMembers`) before the fold. The engine reads it through `Record.NumericValue` in the same single pass as every grouped row (`semGroupState.update`).

## `params.group_levels`

- **Shape.** An ordered array `[{value, name?}]` (`semGroupLevel`, strict decode: another key inside an entry is `bad_params` "params do not decode"). Valid with a derived group only. `decodeSEMGroupLevels` refuses (`bad_params`, details `param: "group_levels"`, `index` / `value` / `name` / `count`): no `params.group`, fewer than two entries, a missing value, a value that is not an integer with |value| ≤ 2^53 (`vectors.SEMGroupIntegral`), a repeated value (−0 = 0), an empty name, a repeated label. `resolveSEMGroup` refuses it on a cohort field (details `group_field`, `field_type`).
- **Labels and order.** Label = `name`, else the integer text (`SEMGroupValueLabel`). `SEMPlan.GroupDeclared` keeps value + label; `GroupLevels` the labels, so array position = level code = the `c(...)` position (`FitGroups` receives `Level = position`, `matrix_sem_group.go`). Labels key `n_group_<l>`, `chi2_group_<l>`, the `[l]` estimate rows, `vectors.group`, the auxiliary per-level keys and `group_reference` (default: the first declared level).
- **Arity.** `c(...)` on a derived group without `group_levels` is `bad_params` (details `param: "model"`, `group_field`, `arity`); with it, `Model.CheckGroupCount(len(group_levels))`, as a cohort categorical.
- **Without `group_levels`** a derived group's levels are its observed INTEGRAL values, ascending (code = the int64 with its sign bit flipped, `semObservedCode`, so codes sort as values; label the integer text); `group_reference` must be an integer's canonical text. The state bound is `vectors.SEMObservedGroupLevelLimit` (256, the u8 range; `groupStateBound`) and it is ENFORCED: one distinct observed level more and no new level opens a state (`semGroupState.capped` / sticky `overLimit`, also on a merge whose union overflows), and finalize fails the slot alone with `PULSE_MATRIX_GROUP_LEVEL_LIMIT` (reason `observed_levels`, details `group_field`, `limit`; in `slotfail.MatrixCodes`; Strict fails the run with it). Gate: root `TestSEM_DerivedGroupObservedLevelLimit` (256 runs on, 257 fails, single file ≡ shard archive).

## Predict

The one resolver gives predict every derived-group refusal (`TestSEM_DerivedGroupRefusals`, `TestSEM_DerivedGroupComputedNamesPredict` for feature / window names). `SEMPlan.GroupLevelsKnown`: declared levels are `group_levels` with basis `declared` (`vectors.BucketBasisDeclared`; an upper bound, sized like a dictionary's); undeclared, `unknown` and no list, the states sized at the limit. Gate: `TestSEM_DerivedGroupPredictLevels`.

## Row admission

A null or NaN group value is a listwise drop (as a null cohort group). A value that is no level — not equal to a declared value (exact float match), or, undeclared, not integral — is ALSO a listwise drop counted in `n_listwise_dropped`, and the slot warns ONCE `PULSE_MATRIX_GROUP_LEVEL_UNDECLARED` (details `matrix`, `group_field`, `count`; the count merges across partitions with the per-level states, `semGroupState.merge`). It is in the closed lift set (`internal/service/matrix_warnings_lift.go`): lifted to `Response.Warnings` with `details.index`, a FAILED slot with its own code under Strict. A declared level without rows warns `PULSE_MATRIX_GROUP_LEVEL_EMPTY` (`details.levels` = the labels) exactly as a dictionary level does, and its `n_group_` / `chi2_group_` scalars are ABSENT — a level without rows is no group (the cohort-field rule), never 0 or null. Gates: root `TestSEM_DerivedGroup*`, `TestSEMInvariance_Archive` (`derived_group`), `internal/vectors` `TestMatrixComputedMembers_SEMGroup`.

## `ATTR_SEM_SCORE` on a derived group (E1-S4)

- **Inline.** `semScoreParams` takes `group_levels` (a `capability:sem_groups` key via `SEMScoreFeatureParams`; a fit knob, so `fit_and_model` beside `params.fit`). The group resolves through the SAME `resolveSEMGroup` against `vectors.SEMScoreComputed(req, schema, i)` — the feature outputs and the labels of attributes `0..i-1` ONLY (features run before the attribute pass, attributes in declared order; a window label or a later label is `bad_params` unknown). `ResolveAttributes` (predict and the runtime field-reference pass) judges it; the factory, which sees no request, takes a non-schema group as computed f64 (`SEMScoreFactoryComputed`). `AttributeInputNames` lists the group so the two-pass planner layers the slot after its producer; a bound slot is `known=false` (its fit's group is not in its params). The engine (`attribute_sem_score.go`) codes a row exactly as `semGroupState.update` (declared position, else `semObservedCode`; NaN null; no level → listwise drop opening no block), so the inline fit is MAT_SEM's bits; the 256-level cap (`admitLevel`, sticky `overLimit`) nulls every score with the fit-scoped `PULSE_MATRIX_GROUP_LEVEL_LIMIT`. Gate: root `TestSEMScore_DerivedGroupMatchesFieldGroup` (declared and observed ≡ the u8 field fit, bit for bit).
- **Level warnings on the attribute path.** An inline fit warns `PULSE_MATRIX_GROUP_LEVEL_EMPTY` over its KNOWN levels without fit rows (dictionary, `packed_bool`, declared — cohort-field groups included, as MAT_SEM; `details.attribute`, `type`, `group_field`, `levels`) ahead of its fit warnings; every scored row whose derived value is no level scores null and is tallied into ONE `PULSE_MATRIX_GROUP_LEVEL_UNDECLARED` (`details.count`, `fit` when bound; merged by `MergeTally`, reset by `resetTally`). Both ride `Response.Warnings` already (attribute warnings are top-level); under Strict `escalateAttributeGroupWarnings` (`internal/service/matrix_warnings_lift.go`) fails the RUN with the first one's code — an attribute has no slot result to fail alone. `:=` lines move no score, so no `DEFINED_NONFINITE` here. Gates: `TestSEMScore_DerivedGroupLevelMismatch`, processing `TestSEMScore_UnseenLevelAndNullGroup` / `TestSEMScore_FailedFitNullsEveryScore`.
- **Bound.** `semCaptureFit` records `model.SEMFit.GroupDerived` + `GroupLevels` (`types.SEMFitResult` `group_derived`, `group_levels [{value, label}]`, `omitempty`; file `sem_format_version` 3). `Signature.SEMGroup` / `SEMGroupDerived` (`Known` on the runtime Set and a loaded file; a static `fits` catalog judges a group that is no cohort field as derived). `vectors.SEMScoreFitGroupRefusal` — called by `vectorFitRefusals` (predict ≡ runtime, same catalog rule) and, without the computed lookup, by the bind — refuses `SERVICE_VALIDATION` `fit_group_field`: a cohort-field fit without that field (details `group`, unchanged), a derived fit whose scoring request does not compute the column ahead of the slot, computes it as a non-f64, or has a cohort field of the name (details `group_field`). A row matches the fit's declared value exactly, else (undeclared) its integer level; no level → `UNDECLARED`, a level without parameters → `PULSE_SEM_SCORE_LEVEL_UNSEEN`. Gates: `TestSEMScore_DerivedGroupBoundFit` (bound and loaded ≡ inline), `TestSEMScore_DerivedGroupBoundUndefined`.
