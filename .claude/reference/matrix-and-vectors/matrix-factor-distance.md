- **`MAT_FACTOR` (U25 E2-S2, `internal/processing/matrix_factor.go`).** Exploratory factor analysis, always of the correlation R (`CoMoment.Corr()`, listwise or pairwise `cor(use = "pairwise")`) after the shared PSD guard (a decomposition operator: `IsDecomposition`, `PSDRisk` at pairwise p ≥ 3). Params (`vectors.decodeFactor` / `resolveFactor`; any other key `bad_params`): `factors` (an integer 1 ≤ k ≤ p, or `"kaiser"`, the default — the eigenvalues of the guarded R above 1), `extraction` (`minres` default | `principal_axis` | `ml`), `rotation` (`none` default | `varimax` | `promax` | `oblimin`), `kappa` (promax only, finite > 1, default 4) and `gamma` (oblimin only, finite, default 0) — a kappa or gamma beside another rotation is refused, never ignored — `repair`, the missing-data knobs. **Extraction dispatch** `faExtractors` (keyed by `vectors.FactorExtraction*`): each starts from the SMC (`minresStart`). `principal_axis` = psych `fa(fm = "pa")` step for step: eigen-decompose R with h on the diagonal, h ← diag(LLᵀ) (L = V·√max(λ, 0) of the k leading pairs), stop when |Σh_new − Σh| ≤ 0.001 within 50 iterations (`faPATol`, `faPAMaxIter`, psych's `min.err` / `max.iter`); the loadings are the last iterate's. `minres` solves the minres optimum EXACTLY: it is the point where the diagonal residual d(h) = diag(LLᵀ) − h vanishes (the off-diagonal objective then equals the full ULS residual h minimises — i.e. the converged principal-axis fixed point), reached by damped Newton on d(h) = 0 with the exact eigen-perturbation Jacobian G_ij = P_ij² + 2Σ_{a≤k<b} λ_a/(λ_a − λ_b)·v_ai v_aj v_bi v_bj (P = Σ_{a≤k} v_a v_aᵀ; step halved until |d|² falls, else the principal-axis step), to max|d| ≤ 1e-10 within 200 steps (`faMinresTol`, `faMinresMaxIter`; 3–9 steps on the oracle). h is unconstrained — a uniqueness 1 − h ≤ 0 is reported as fitted with `PULSE_MATRIX_HEYWOOD` (`members`, `uniquenesses`), where psych bounds ψ to [0.005, 1]. **`ml`** (U25 E2-S3, `matrix_factor_ml.go`) = Jöreskog's maximum likelihood, the `stats::factanal` / psych `fm = "ml"` objective F(ψ) = Σ_{m>k}(e_m − 1 − log e_m) over the eigenvalues of Ψ^{-1/2}RΨ^{-1/2}, on psych's box ψ ∈ [0.005, 1] from psych's start 1 − SMC; solved EXACTLY by projected Newton in θ = log ψ with the exact Hessian H_ij = ½Σ_{m,n} c_mn(e_m + e_n)u_mi u_ni u_mj u_nj (Daleckii–Krein; c_mn the divided difference of h_m = e_m − 1 beyond the k leading pairs, 0 within), a ψ at a bound with an outward gradient held (active set), Armijo-halved steps, to a projected θ-gradient ≤ 1e-10 within 200 steps (`faMLTol`, `faMLMaxIter`; 5–12 steps on the oracle; a stall short of the tolerance is NOT_CONVERGED too, its message naming the stall). Loadings L = Ψ^{1/2}U_k√max(E_k − 1, 0), signed to sum positive and REORDERED by descending variance accounted (psych::fa's rule; the eigen order need not be it). A ψ held at the 0.005 floor is the ML Heywood case: `PULSE_MATRIX_HEYWOOD` (its own message; `uniquenesses` details still 1 − h). A singular guarded R (Cholesky fails) withholds the whole ML fit with `sphericityStats`' `PULSE_MATRIX_SINGULAR`, whose `outputs` then add the loadings, vectors and ML scalars. ML scalars (`faMLFitIndices` = psych `fa.stats` on the loadings): objective F_m = tr(M⁻¹R) − log det(M⁻¹R) − p (M = LLᵀ with R's diagonal), `likelihood_chisq` = max(F_m·n_m, 0) with n_m = N* − (2p + 4k + 11)/6 (= (N* − 1) − (2p + 5)/6 − 2k/3), `likelihood_p` its upper tail on `df`, `tli` = (M_0 − F_m/df)/(M_0 − 1/n_m) with M_0 = 2F_0/(p(p − 1)), F_0 = tr R − log det R − p, `rmsea` = √max(χ²/(df·N*) − 1/(N* − 1), 0) (point estimate), `rmsea_lower` / `rmsea_upper` its interval at `params.conf_level` (ml only, 0 < c < 1, default 0.9 = psych::fa's alpha 0.1; TODO #405, `faRMSEAInterval`): psych's rule — tail (1 − c)/2, the upper bound inverts the noncentral χ²(df, λ) CDF at χ² to tail when the central CDF exceeds tail (else 0), the lower to 1 − tail likewise, λ on psych's bracket [0, max(N*, χ²) + 2N*] by bisection to the last bit (psych's uniroot default tol leaves its bounds ~1e-7 off; the oracle solves at tol 1e-300 and asserts psych within 1e-5), rescaled √(λ/((N* − 1)·df)) — psych's denominator, not the point estimate's; no root in the bracket nulls the bound (an upper bound at rmsea 0 is 0), a bound on the wrong side of the point estimate is null; the noncentral CDF (`noncentralChiSquareCDF`, the Poisson mixture summed outward from the mode) is pinned to R `pchisq(x, df, ncp)` by `noncentral_chi_square_cdf.json` (relative 1e-10 below ncp 80, absolute 1e-11 above, where R's own algorithm is 1e-12-accurate); `bic` = χ² − df·log N*; all but the chi-square null at df ≤ 0, all null with `PULSE_MATRIX_INSUFFICIENT_N` scope `likelihood` (`n_star`, `min_n_star`) at n_m ≤ 0; absent on the other extractions; the pairwise N* warning names them. Sign and order: columns by descending eigenvalue, each flipped to sum positive (psych::fa), then `params.rotation` through the rotation engine (its own sign-and-order rule). **Guards:** (p − k)² < p + k (`vectors.FactorIdentified`; the model df < 0) → `PULSE_MATRIX_NOT_IDENTIFIED` WARNING (`factors`, `max_factors`) and k null columns, null vectors and fit scalars (KMO / Bartlett still compute; an integer k > p is `bad_params` at resolution); an extraction or rotation at its cap → `PULSE_MATRIX_NOT_CONVERGED` (`solver` `fa_minres` / `fa_pa` / `fa_ml` / `varimax` / `gpa_oblimin`), the last iterate kept; an undefined input nulls everything; the Kaiser rule keeping 0 factors emits the zero-factor fit (every correlation residual). Outputs: `primary` the p × k loadings (rectangular, `F1` … `Fk`; rotated when set), `auxiliary.unrotated` (rotated runs), `auxiliary.factor_correlation` (promax / oblimin: Φ, kind `square_symmetric` keyed `F1` … `Fk`, always full), pairwise `auxiliary.n`; `vectors` `communalities` diag(LLᵀ) (rotation-invariant), `uniquenesses` 1 − h, `variance_accounted` (diag(Φ·LᵀL) per output column); `scalars` `rmsr` = √(Σ_{i<j} res²/(p(p − 1))) (psych's `rms`), `empirical_chisq` = Σ_{i<j} res²·N* on `df` = p(p − 1)/2 − pk + k(k − 1)/2 with `empirical_p` its upper tail (null at df ≤ 0) — psych's empirical chi-square, a residual size, NOT a likelihood test — `kmo`, `bartlett_chisq` / `_df` / `_p` (the shared `sphericityStats` over the guarded R, N* = `pcaNStar`, the pairwise `PULSE_MATRIX_PAIRWISE_N_STAR` naming the empirical figures too), `iterations`, `converged` (1 / 0), `factors_retained` (the four integer scalars `precisionExempt`). Weighted: `ClassAware`. **Oracle tolerances** (`mv_factor.json`, `scripts/reference/gen_factor.R`; 10 cases — attitude k = 1 / 2 / 3, attitude probability k = 2 (an improper minres optimum, a capped principal axis), mtcars k = 2 / 3 and frequency k = 3, likert_ties k = 2 (capped principal axis), weighted frequency k = 1, the heywood fixture): principal axis vs psych within 1e-9 abs + rel with the iteration count and convergence flag EXACT (`TestFactorPrincipalAxis_MatchesPsych`); minres vs psych's exact optimum (`fm = "pa"`, `min.err = 1e-14`) within 1e-7, vs psych's own early-stopped L-BFGS-B fit within 2e-4 (worst seen ~7e-5) with Pulse's residual never above psych's, an improper optimum compared with psych on detection only (`TestFactorMinres_MatchesPsych`); ml vs the exact ML optimum (generator: L-BFGS-B at factr = pgtol = 0, then Newton with `optimHess` to a free gradient < 1e-13; `factanal` asserted within 1e-6 where it starts) within 1e-9 (worst seen 6e-11) — loadings, the residual and likelihood figures, every rotation but oblimin — with the floor-bound ψ flagged exactly where R's sit on the bound (4 cases; `TestFactorML_MatchesExactOptimum`), vs psych's own early-stopped fit within 1e-4 (worst seen 2.2e-5) with Pulse's F never above psych's (`TestFactorML_BeatsPsych`), the fit indices from psych's own loadings vs `fa.stats` within 1e-9 (`TestFactorMLFitIndices_MatchPsychFaStats`), the exact Hessian vs a finite difference (`TestFactorMLHessian_MatchesFiniteDifference`), the guards `TestFactorMLFitIndices_Guards` / `TestMatrixFactor_MLGuards`; rotations of the fit at the same bounds except oblimin over minres or ml loadings, 1e-4 — GPA stops on a 1e-5 gradient norm, so a 1e-11 input change can move its stopping iterate (worst seen 4.8e-5). psych::fa's own varimax / oblimin (single start, `n.rotations = 1`) are asserted equal in the generator; psych's `"promax"` is kaiser() around GPArotation::Varimax, not `stats::promax`, so the engine's definition is used. End to end `TestMatrixFactor_MatchesROracle` (every extraction × all four rotations × every case; ml within 1e-8), gates also `TestMatrixFactor_{Guards,UndefinedAndNotPSD,Refusals}`, `TestFactorSolvers_NotConvergedAtCap`, `TestResolveMatrices_Factor`, `TestFactorIdentified`, the worker-invariance gate (minres listwise, ml listwise weighted, principal axis pairwise). KnownAs `exploratory factor analysis`, `efa`, `principal axis factoring`, `minres`, `maximum likelihood factor analysis`, `factanal`; intent `measure_construct` (its third operator declarer after `MAT_RELIABILITY` / `MAT_PCA`); glossary `factor`; Interpretation: `scalars.kmo` banded by Kaiser (1974), loadings and `rmsr` unbanded (excluded in `conventions.json`), `bartlett_p` / `empirical_p` / `likelihood_p` the shared p-value rules, `likelihood_chisq` / `tli` / `rmsea` / `bic` unbanded (`tli` and `rmsea` excluded in `conventions.json`: their cut-offs are confirmatory-model rules of thumb).
- **`MAT_DISTANCE` (U25 E4-S2, `internal/processing/matrix_distance.go`).** The k × k distances between the centroids of the buckets a grouper cuts the rows into. Params: `between` (REQUIRED; a `types.Group` decoded strictly — any built-in (`vectors.DistanceBetweenTypes()` = `AllGroupTypes()`) or a registered extension grouper (`ResolveMatricesRouted`'s `ext`, the runtime's `LookupGrouper` / the descriptor's `ExtensionsSnapshot.Groupers` through `resolveMatricesFor`, exactly `ResolveGroups`' rule); an unknown or instance-hidden type is `unknown_between_type`; no own `weight` (`bad_params`); a `tz` only on a date-family between (`vectors.IsDateBetween`, else `bad_params`); a `GROUP_KMEANS` between resolves its `vector` / `fields` / params by the `resolveGroup` leaf at slot `matrices[i].params.between` and is rewritten members-into-`Fields`; an extension between's `vector` / `fields` are judged by `resolveExtensionMembers` and rewritten the same way (its `params` its own business); every other between, and an extension one without a vector input, needs a schema `field` (`unknown_field`), which an extension with a vector input may also set), `metric` (the registry's `MAT_DISTANCE` consumer list, `metric.ResolveFor(ConsumerMatDistance, name, Distance)` in `decodeDistance`; default `vectors.DistanceDefaultMetric` = `euclidean`; an unknown or unaccepted name — `sqeuclidean` included, renamed `sq_euclidean` with no alias in U27 — is `bad_params` with `details.valid` the registry list; a non-negative-domain metric (`hellinger`, `aitchison`) beside `standardize` is `bad_params`), `standardize` (default `false`), `min_valid` (int, default 1, 1 … p, else `bad_params`), `max_drop_share`; `missing` listwise only (`pairwise_unsupported`); `between_required` when absent. **Date-family between (TODO #411).** `GROUP_DATE` / `GROUP_DATE_RANGES` read their zone like a top-level grouper: `ResolveZones` walks each `MAT_DISTANCE` between LAST, as slot `matrices[i].params.between` (after the crosstab columns), so precedence, refusals (an explicit `tz` on a non-capable or extension between, on a `date` field, an unknown zone, a non-UTC zone on a derived field) and the predict `time_zones` echo are the shared pass's; `ZonedRequest` writes an inherited non-UTC zone into a COPY of the spec's params (`zonedMatrices` re-encodes them with the between's `tz`, every other key kept), so the factory reads it through `resolveDateField` with no new plumbing and the caller's request stays pristine. Predict also runs `validateGroupDateParams` over the between (a bad `component` / `week_start`, an `hour` off a `datetime`). `GROUP_DATE` buffers (not `Streamable`), `GROUP_DATE_RANGES` streams and merges. **Extension between.** No new hook: the engine's buffered between already drives `extend.Grouper.Group` (its whole-set pass), so an extension between is buffered and serial (`GroupType.Streamable` is false for an unknown name), keys alphabetical (or its include list); it reads no weight (the matrix's weight applies to the centroids; `DistanceClassOf` leaves `MAT_DISTANCE`'s class); projection adds its `FieldInputs` hook's columns, or decodes wide without one, as in `Request.Groups` (`NeededFields`). Engine: the slot's `distanceState` builds the grouper through the registry (`ApplyGrouperExtensions`; a k-means between gets the slot's stamped weight, no other grouper reads one). A streaming grouper (`GroupType.Streamable`) keys each row through `GroupKeyer` and folds it into the base state once and into one `BlockCoMoments` per bucket key (fan-out: every key); the spec is then `Streamable`, and `Mergeable` when the grouper's keys merge (`mergeSlotSets` absorbs bucket by bucket). Any other grouper (`GROUP_KMEANS`, `GROUP_QUANTILE`) keeps the records and at finalize runs ONE `Grouper.Group` pass, then folds in record order — buffered, serial. Rows in no bucket (null key, include rejection, k-means null member) are `n_null_key`, excluded from the floor, which counts bucketed rows once. Bucket order: the grouper's emission order (`orderKeysByInclude(includeFilterOf(...))`, k-means by size). Centroid = bucket `CoMoment.Mean()`; standardize z = (c − μ)/sd over the bucketed rows, sd on w* (`Cov(1)` unweighted / frequency, `Cov(0)·n_eff/(n_eff − 1)` probability); every cell is `centroidDistance` — the registry's `Eval` under its pairwise-complete policy (a coordinate undefined on either centroid is dropped, the Scaled sums rescaled by p/p_observed; fewer than `min_valid` complete pairs, or none, is null; ±Inf an ordinary value — pre-U27 any NaN or Inf coordinate nulled the whole pair); a zero-spread member under standardize has NO z-score (NaN, never the ±Inf a rounding residual over sd 0 would give), so it is skipped rather than nulling the pair (`PULSE_MATRIX_ZERO_VARIANCE` still names it); a `*metric.DomainError` (a negative coordinate under hellinger / aitchison, an aitchison zero part) nulls the cell and the slot raises ONE `PULSE_MATRIX_METRIC_DOMAIN` (details `metric`, `pairs` refused — diagonal included —, `buckets` of those pairs, `reasons`); cosine 1 − cos clamped, null at zero length; diagonal forced to exactly 0 where defined; mahalanobis (`Fit() == FitInverseCovariance`) is the registry's √(dᵀS⁻¹d) — same loop order as before, bit-identical — on the RAW centroids, null on any undefined coordinate (`Complete`), S = (N*/Σw)·Σ_b M2_b/(N* − k_massed) summed in emission order, the singular DECISION the shared `rankDeficient` rule (a `PULSE_MATRIX_SINGULAR` warning, distances null), the value the reference `InverseSPD`; N* ≤ k is `PULSE_MATRIX_INSUFFICIENT_N` scope `pooled`, a massless bucket scope `buckets`. Outputs: `primary` square keyed by bucket label in the slot's encoding, `auxiliary.centroids` (k × p rectangular, rows the buckets), `centroids_standardized`, `pooled_covariance`, `vectors.sizes` (Σw) / `counts` (rows, `[]int`); components operator keys `metric`, `standardize`, `buckets`, `n_null_key`. Projection: `MatrixMembers` adds the between field and inline fields; `vectors.Referenced` counts a between's vector. Weighted `ClassAware`; a k-means between is frequency-only (`weighting.DistanceClassOf`, refusal `details.between`).
