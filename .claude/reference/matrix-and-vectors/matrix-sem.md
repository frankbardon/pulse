## Matrix slot — `MAT_SEM` (continued)

Continues `## Matrix slot` in `.claude/reference/matrix-and-vectors/matrix-slot.md`. Params, outputs and prose: skill `op-mat-sem` (+ `sem-defined-parameters`) and the manifest entry.

- **What it is.** A structural equation model (CFA, path model, higher-order factors) fitted by maximum likelihood to the slot's merged co-moment. Estimator: `internal/sem` (stdlib + gonum, no-execute safe, so `internal/vectors` imports it for resolution and predict); finalizer `finalizeSEM` (`internal/processing/matrix_sem.go`). Co-moment tier: streamable and mergeable; the fit reads only S and N, so it is a deterministic function of the merged bits and worker-invariant.
- **The default setup is a semopy clone.** semopy 2.3.11's `semopy.Model(desc).fit(data)` (`obj="MLW"`, `solver="SLSQP"`, `mimic_lavaan=False`) is reproduced, not approximated, so code written against semopy ports 1 for 1:
  1. **Specification** (`internal/sem/model.go`) is semopy's variable classification and effect rules statement by statement (variable ordering, first indicator fixed to 1, bounded variances, observed-exogenous (co)variances fixed to the sample and hidden, free exogenous latent covariances, `label*` equality, `number*` fixings).
  2. **Starting values** are `semopy/startingvalues.py`'s.
  3. **Objective** is `obj_mlw` over the BIASED covariance (`CoMoment.Cov(0)`), `+Inf` on a non-PD Σ or a negative loss.
  4. **Optimiser** is the public `optimize.Minimize` — an FMA-free Go port of SciPy's SLSQP over transcribed reference BLAS / LAPACK (BSD-3 notice in `optimize/SCIPY_LICENSE.txt`) — with semopy's settings (`ftol` 1e-6, `maxiter` 10000), simple bounds only.
  5. **SEs** invert the expected information (Cholesky, else the Moore–Penrose diagonal), with semopy's small-negative-variance clamp and z = θ/(SE + 1e-12).
  6. **Standardized** estimates are `inspect(std_est=True)`'s.
  7. **Fit indices** are `calc_stats`' with its conventions (`loglik` IS the minimised F, AIC = 2(k − F), GFI = NFI, RMSEA 0 when χ² < dof); the baseline is semopy's independence model, always fitted with SLSQP defaults.

  Parity: ≤ 3e-13 relative on every figure against semopy's default fit, same iteration counts (`TestFit_MatchesSemopy`); the residual is OpenBLAS summation order.
- **Options.** `solver` `slsqp` (default) | `fisher` (damped Fisher scoring to every free gradient entry < `grad_tol`); `information` `dense` (default, as semopy) | `rank2` (rank-2 derivative form, O(k²p), equal to dense to 1e-12). **A knob beside the other solver is `bad_params`, never ignored.**
- **Resolution** (`internal/vectors/matrix_sem.go`, field-reference step 7, predict ≡ runtime). The model is parsed and specified (`bad_params`, `details.error`); each observed variable matches a member by display label. A model variable that is not a member (`details.not_members`) or a member the model never names (`details.unused_members`) is `bad_params` — never silently dropped (semopy ignores extra columns). `missing: "pairwise"` is refused (the likelihood is one sample's covariance). Predict sizes `estimates` from the description alone.
- **Outputs.** `primary` Σ(θ̂) in MEMBER order; `auxiliary.estimates` rows are semopy's inspect rows `"lval op rval"` (SE / z / p null on a fixed parameter; under `records` each row also carries `lval`, `op`, `rval`, `parameter`, `free`); `auxiliary.residual_covariance` S − Σ(θ̂). semopy orients a free covariance between exogenous latents by Python SET order (varies run to run): compare `~~` rows symmetrically.
- **Refusals and warnings.** An undefined input (N < 2, no mass, a non-finite member, or zero spread under `singular: "refuse"`) nulls every figure, estimate rows still listed. A solver stop short of success keeps the last iterate with `PULSE_MATRIX_NOT_CONVERGED` (`solver` `sem_slsqp` / `sem_fisher`); negative dof is fitted as semopy fits it with `PULSE_MATRIX_NOT_IDENTIFIED`.
- **Standardized input.** A `standardize: "zscore"` vector fits the correlation matrix (S = members' correlation, N = W) — exactly semopy fitted to externally z-scored members (population SD, listwise rows). Gate `TestMatrixSEM_StandardizedMatchesSemopy`.
- **Singular fallback.** `params.singular` `nearest` (default) | `refuse`. Under `nearest` the ONLY trigger is a failed Cholesky of S (the test semopy's `load_cov` makes with `dpotrf`): a near-exact dependency the one singular rule calls singular but whose factorization succeeds is fitted RAW, as semopy does, without warning. On a failure the fit runs on `sem.CovNearest(S, 1e-2)` — statsmodels `cov_nearest(method="clipped")` ported step for step — with the Lambda starts still from the data's S (semopy's split), and always warns `PULSE_MATRIX_NEAREST_PD`. A zero-spread member has no substitute (semopy raises `LinAlgError`), so under `nearest` it fails the slot with `PULSE_MATRIX_SINGULAR`. `refuse`: every rank-deficient S under the one rule is fatal `PULSE_MATRIX_SINGULAR`, a zero-spread member nulls every figure. **The `near_*` default-ftol fixture is ANCHORED** (estimates 1e-3, statistics 1e-7, iterations ±1): that early stop is chaotic under one ulp of rounding — evidence at `nearDefaultEstimateTol` in `internal/sem/nearest_test.go`; never tighten it.
- **Weights.** Frequency only: S = M2_w/Σw and N = Σw — exactly semopy on the expanded rows. A probability weight is `PULSE_WEIGHT_UNSUPPORTED` (no design-based form to clone).
- **Mean structure and the lavaan conventions.** `params.meanstructure: true`, or any `~ 1` model term, adds intercepts (observed exogenous means fixed to the sample, as lavaan's `fixed.x`, and hidden; other latent means fixed to 0) and switches the model to `Model.Lavaan()` — **the switch every lavaan-only feature joins**. Under it: default solver `fisher` (explicit `slsqp` honoured), unbounded variances, unclamped SEs, Wald `ci_lower` / `ci_upper` columns, mean starts, and lavaan 0.7's statistics (`lavaanStats`: chi2 = N·F, closed-form baseline, divisor-N RMSEA, LISREL GFI, h0 log-likelihood). Fixtures: the generated brand survey (`internal/brandfixture`, the ONE generator) with lavaan 0.7.3 references from `fit_lavaan.R` (CI never runs R). Tolerance 1e-4 relative on estimates / SEs (nlminb's stop), 1e-3 on fit indices. The semopy path is untouched (`TestSEM_LegacyConventionsUnchanged`).
- **Joint multi-group fit.** `params.group` fits ONE model jointly over the levels of a categorical (dictionary order), `packed_bool` or `u4` / `u8` field — lavaan's configural `group =`: every parameter free per group except that a LABELLED parameter is one value in every group. Forces the mean structure. Statistics combine per group as lavaan does (RMSEA × √G). Engine (`internal/processing/matrix_sem_group.go`): one block co-moment per level code, absorbed level by level at merge, so it stays streamable, mergeable and worker-invariant; a null group is a listwise drop. Levels are the codes that hold rows. Config refusals are `bad_params` (request `groups` / `crosstab`, wrong field type, one-entry dictionary, `params.fit`, …); data refusals fail the slot alone (`PULSE_MATRIX_INSUFFICIENT_N` for fewer than two populated levels or a level with N ≤ p; `PULSE_MATRIX_SINGULAR` for a level's non-PD S — no nearest substitute). Level selection, derived groups: `sem-groups.md`.
- **Invariance and per-group modifiers.** `params.group_equal` / `group_partial` (a list or one comma-separated string, so a Compose sweep axis can carry the invariance ladder) reproduce lavaan's `group.equal` / `group.partial` (`internal/sem/invariance.go`). A label takes a row OUT of its equality class (lavaan's user labels override); `group_reference` is the identification reference. Per-group modifiers `c(m1, m2, …)*x` bind to LEVEL INDEX order and their length must equal the level count (an integer group field, whose levels are unknown at predict, refuses them). lavaan-path fixes: the first indicator is ALWAYS the marker; `std_estimate` of a covariance row is the residual correlation. Gate: `TestSEM_MultiGroupMatchesLavaan`.
- **Predict, declared keys and feature profiles.** (1) A per-level output key is declared with the placeholder `vectors.SEMOutputKeyLevel` (`"<level>"`), built from the runtime's own key functions and matched by `vectors.MatrixOutputKeyMatches`. (2) `MatrixPredict.GroupLevels` is an UPPER BOUND (a level without rows after filters is no group), `unknown` on an integer field (the size model then leaves the section unsized); state count = 1 + the level bound. (3) Capability rows `capability:sem_meanstructure`, `capability:sem_groups`, `capability:sem_defined`, `capability:sem_bootstrap`, `capability:sem_ordinal` own their params and syntax (`vectors.SEMFeatureParams`). A hidden capability's keys leave the params allowlist (`PULSE_REQUEST_UNKNOWN_FIELD`, byte-identical to a never-read key); its owned syntax is `bad_params` naming neither surface (`semHiddenSyntaxRefusal`); the manifest drops the params, outputs and every sentence naming an owned wire token (`semProseTokens` — never bare `group`, which is everyday English). `ATTR_SEM_SCORE` is gated by the same capabilities, refused before its model resolves. Gate: `TestSEM_HiddenSurfacesRefuseLikeUnknown`.
- **Defined parameters.** A `name := expr` line (`internal/sem/defined.go`) is lavaan's defined parameter (labels, numbers, `+ - * / ^` with R precedence, `sqrt` / `exp` / `log` / `abs`, earlier names) and switches to lavaan conventions. Evaluated after the fit with forward-mode dual numbers; SE by the delta method over the inverse expected information. **abs' derivative is its sign, but lavaan's complex-step jacobian reads it as 0**, so a `:=` through `abs()` matches lavaan's estimate, not its SE. Rows append after the parameter table (unprefixed when grouped). Non-finite at the estimate → null with `PULSE_MATRIX_DEFINED_NONFINITE`. Refusals: `defined_invalid` (unknown label, forward / cyclic reference, duplicate, syntax) and lavaan `==` / `<` / `>` lines `constraint_unsupported`. **Multiplicity:** `MAT_SEM` joins only through its OWN `multiplicity` block (an inherited block never reaches it, so request-level corrections stay byte-identical); the fold writes rectangular `p_adjusted` / `significant_adjusted` over the estimates rows.
- **Bootstrap.** `params.resample: "bootstrap"` is lavaan's `se = "bootstrap"` with percentile intervals. It makes the spec buffered (`params.fit` is then `fit_unsupported`), resamples rows WITHIN each group on one PCG stream, refits each replicate with the slot's options, and replaces SE / z / p / bounds; estimates and fit statistics stay the full data's. `rng_seed` 0 or absent derives the seed with REG_RESAMPLE's ONE rule (`regression.DeriveSeed`). Failed replicates are skipped; fewer than 10 successes fail the slot alone (`PULSE_MATRIX_NOT_CONVERGED`, `reason: bootstrap_too_few`). No `Options.Limits` cap on iterations (REG_RESAMPLE's policy). Any weight is `PULSE_WEIGHT_UNSUPPORTED`. Oracle tolerances are sampling tolerances (15% SE, 0.75·SE bounds).
- **Wald level.** `params.ci_level` is lavaan's `level` on the Wald interval too (0.95 keeps the default bits); estimates, SEs and p never move. On a semopy-convention fit (no interval) it is `bad_params`.
- **Ordinal estimators.** `params.estimator` `dwls` / `wlsmv` + `params.ordered`: `.claude/reference/matrix-and-vectors/sem-ordinal.md`.
- **Not covered** (semopy surfaces outside its default `Model`). FIML and the other objectives, robust or observed-information SEs, `std_est="lv"`, `mimic_lavaan=True`, `cov_diag=True`, semopy operation commands, a covariance between an inner and an output variable.
- **Reference fixtures, release and same-shape parity:** `.claude/reference/matrix-and-vectors/matrix-sem-fixtures.md`. **Per-row latent scores** (`ATTR_SEM_SCORE`): `.claude/reference/matrix-and-vectors/sem-scores.md`.
