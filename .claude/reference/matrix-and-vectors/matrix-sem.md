## Matrix slot — `MAT_SEM` (continued)

Continues `## Matrix slot` in `.claude/reference/matrix-and-vectors/matrix-slot.md`.

- **What it is.** A structural equation model (CFA, path model, higher-order factors) fitted by maximum likelihood to the slot's merged co-moment. Estimator: `internal/sem` (no-execute safe — stdlib + gonum — so `internal/vectors` imports it for resolution and predict, `internal/processing` for the finalizer `finalizeSEM`, `matrix_sem.go`). Co-moment tier: streamable and mergeable like `MAT_COVARIANCE`; the fit reads only S and N, so serial == every worker count bitwise up to the fit itself (the fit is a deterministic function of the merged bits).
- **The default setup is a semopy clone (owner decision 2026-10-16).** semopy 2.3.11's `semopy.Model(desc).fit(data)` — `obj="MLW"`, `solver="SLSQP"`, `mimic_lavaan=False` — reproduced, not approximated, so code written against semopy ports 1 for 1: (1) **specification** (`internal/sem/model.go`) is semopy's `ModelBase.classify_variables` + `Model.finalize_variable_classification` / `preprocess_effects` / `effect_*` statement by statement — outputs (no outgoing arrow) are Lambda rows, inner = sorted latents then sorted observed inner, observed = sorted outputs then the rest; the first indicator of each `=~` fixed to 1; every endogenous and latent variance free (bound ≥ 0); observed-exogenous (co)variances fixed to the sample (hidden from the table, as semopy's inspect hides them); exogenous latents covary freely; `label*` equality and `number*` fixings; (2) **starting values** (`startRule`) are `semopy/startingvalues.py`'s (Beta 0, a Lambda loading the marker-chain slope cov/var, latent variances 0.05, Theta and observed inner variances S/2); (3) **objective** is `obj_mlw` over the BIASED covariance (`CoMoment.Cov(0)`, numpy `bias=True`) with `+Inf` on a non-PD Σ or a negative loss; (4) **optimiser** `internal/sem/slsqp.go` is a Go port of SciPy 1.18.1's SLSQP (`scipy/optimize/src/slsqp.c`, `nnls.c`, `_slsqp_py.py`; BSD-3, notice in `internal/sem/SCIPY_LICENSE.txt`) restricted to what semopy exercises — simple bounds, no general constraints (LSQ → LSEI(me = 0) → LSI → LDP → NNLS, the L1 line search, the BFGS LDLᵀ update, the reset / LABEL255 stops) — over transcribed reference BLAS / LAPACK (`lapack.go`: `dlarfg`, `dlarfgp`, `dlarf`, `dgeqr2`, `dorm2r`, `dtrsm`, `dtrsv`, `dtpmv`, `dtpsv`, `dlartgp`, `dnrm2`), with semopy's settings (`ftol` 1e-6, `maxiter` 10000); (5) **SEs** invert the expected information (N/2)·tr(Σ⁻¹∂ΣₖΣ⁻¹∂Σₗ) (Cholesky, else the Moore–Penrose diagonal), semopy's small-negative-variance clamp, z = θ/(SE + 1e-12), p = 2(1 − Φ(|z|)); (6) **standardized** estimates are `inspect(std_est=True)`'s; (7) **fit indices** are `calc_stats`' with its conventions — `loglik` IS the minimised F, AIC = 2(k − F), BIC = ln(N)k − 2F, GFI = NFI, RMSEA 0 when χ² < dof — and the baseline is semopy's independence model, ALWAYS fitted with SLSQP defaults under `solver: slsqp` (semopy's `__get_chi2_base` passes no options). Parity: ≤ 3e-13 relative on every figure against semopy's DEFAULT fit on four models, same iteration counts (`TestFit_MatchesSemopy`); the residual is OpenBLAS summation order, not the model.
- **Options (params).** `model` (absent: `vectors.SEMDefaultModel`, one factor `F1` over every member label), `solver` `slsqp` (default) | `fisher` (damped Fisher scoring — Levenberg–Marquardt on the expected information, active-set bounds — to every free gradient entry < `grad_tol`, default 1e-10, cap `max_iter` 500), `information` `dense` (default: every ∂Σₖ a dense p × p matrix, as semopy) | `rank2` (`internal/sem/rank2.go`: ∂Σₖ = Σ(a·bᵀ + b·aᵀ) per location — Beta a = M[:,i], b = D[j,:]; Lambda a = eᵢ, b = D[j,:]; Psi a = M[:,i], b = M[:,j]; Theta a = eᵢ, b = eⱼ, b halved on a diagonal — so g = Σ2aᵀWb and H = Σ2[(aᵀKc)(bᵀKd) + (aᵀKd)(bᵀKc)], O(k²p) instead of O(kp³ + k²p²); equal to dense to 1e-12, `TestRank2MatchesDense`), `ftol` (slsqp only), `max_iter`, `grad_tol` (fisher only). A knob beside the other solver is `bad_params`, never ignored.
- **Resolution** (`internal/vectors/matrix_sem.go`, field-reference step 7, so predict ≡ runtime): `decodeSEM` (strict params) then `resolveSEM` after the members — `sem.NewModel` parses and specifies the model (`bad_params`, `details.error`); each observed variable matches a member by `FitLabels` (display label, else name) into `SEMPlan.Order`; a model variable that is not a member (`details.not_members`) or a member the model never names (`details.unused_members`) is `bad_params` — never silently dropped (semopy ignores extra data columns). `missing: "pairwise"` is `pairwise_unsupported` (the likelihood is one sample's covariance). `AuxiliaryKeys` lists `estimates`, `residual_covariance`; predict sizes `estimates` as `len(sem.SpecifiedRows(model))` × `vectors.SEMEstimateColumns()` from the description alone.
- **Outputs.** `primary` Σ(θ̂) over the members in MEMBER order (the slot's encoding; semopy's variable order is internal); `auxiliary.estimates` rectangular, rows semopy's inspect rows `"lval op rval"` (matrix order Beta, Lambda, Psi, Theta; parameter insertion order within), columns `estimate`, `std_estimate`, `std_err`, `z_value`, `p_value` (SE / z / p NaN → null on a fixed parameter; under `encoding: "records"` each row also carries `lval`, `op`, `rval`, `parameter`, `free` — `MatrixValues.RecordFields`, matrix-slot.md Records encoding); `auxiliary.residual_covariance` S − Σ(θ̂); `vectors.parameter` / `free`; `scalars` (manifest order) `dof`, `dof_baseline`, `chi2`, `chi2_p_value`, `chi2_baseline`, `cfi`, `gfi`, `agfi`, `nfi`, `tli`, `rmsea`, `aic`, `bic`, `loglik`, `objective`, `n`, `n_params`, `iterations`, `converged` — `dof`, `dof_baseline`, `n_params` join `precisionExempt` (`iterations` / `converged` already there). semopy orients a free covariance between exogenous latents by Python SET order (it varies run to run); compare `~~` rows symmetrically.
- **Refusals and warnings.** An undefined input (N < 2, no mass, a non-finite member, or a zero-spread one under `singular: "refuse"`) nulls every figure, the estimate rows still listed (`sem.SpecifiedRows`), the co-moment warnings saying why. A rank-deficient S is, by default (`singular: "nearest"`), fitted as semopy's default fit fits it — raw while it factors, else semopy's substitute (Singular fallback, below); under `singular: "refuse"` one that fails the one singular rule (`singularUnderRule`) is a FATAL `PULSE_MATRIX_SINGULAR` with `dependent_fields`, as before the knob. A solver stop short of success (an SLSQP exit mode ≠ 0, Fisher scoring before `grad_tol`) keeps the last iterate with `PULSE_MATRIX_NOT_CONVERGED` (`solver` `sem_slsqp` / `sem_fisher`, `status` the SLSQP message, `iterations`); negative degrees of freedom are fitted as semopy fits them with `PULSE_MATRIX_NOT_IDENTIFIED` (`dof`, `n_params`).
- **Standardized input (sem-contribution E2-S1).** A vector with `standardize: "zscore"` fits the correlation matrix: the slot's merged co-moment is z-scored once after the merge tree (`vectors.md` (Standardize)), so S = `Cov(0)` is the members' correlation and N stays W — exactly semopy fitted to the members z-scored externally with population SD (ddof 0) over the listwise rows. Fixture `internal/sem/testdata/std_*` (synthetic two-factor model, raw `std_data.csv`; `zscore.py` materializes the z-scores in `gen_semopy.sh`); gate `TestMatrixSEM_StandardizedMatchesSemopy` (1e-6 vs default and tight), `TestMatrixStandardize_EqualsMaterializedZScore` (weighted and unweighted vs the materialized twin).
- **Singular fallback (sem-contribution E2-S3; default changed in E2-G2 to match semopy's default fit).** `params.singular` `nearest` (default) | `refuse` (`vectors.SEMSingular`, `SEMPlan.Singular`). Under `nearest`, the trigger is gonum's Cholesky of S (model order) failing — `sem.PositiveDefinite`, the test semopy's `load_cov` makes with LAPACK `dpotrf`, and ONLY that: a near-exact dependency that the one singular rule calls singular but whose factorization succeeds is fitted RAW, as semopy fits it, with no warning (`invLogDet` accepts gonum's `mat.Condition` report and keeps the inverse, like semopy's `chol_inv2` — dpotrf then dpotri). On a failure `finalizeSEM` fits `sem.CovNearest(S, sem.NearestThreshold = 1e-2)` — statsmodels' `cov_nearest(method="clipped")` ported step for step (`cov2corr`, `clip_evals` with `eigh` → gonum `EigenSym`, `corr_clipped`'s rescale, `corr2cov`; same-machine stable, portable within the eigen tolerance, like the Higham repair) — via `sem.FitCovNearest(model, adj, raw, …)`: the objective, Psi / Theta starts, SEs, statistics, the baseline and `residual_covariance` read the adjusted matrix (semopy's `mx_cov`), the Lambda starts the data's S (semopy's `linregress` over `mx_data`). It always warns `PULSE_MATRIX_NEAREST_PD` (`matrix`, `n` = W, `p`, `min_eigenvalue` of the correlation form before the clip). A zero-spread member — raw, or the all-zero z-scores of a standardized (P2) one — has no substitute (`CovNearest` refuses a zero variance; semopy raises `LinAlgError`), so under `nearest` it is not an undefined input (`semJudgeable` admits the zero diagonal) but fails the slot with `PULSE_MATRIX_SINGULAR` (+ `PULSE_SLOT_FAILED`). `refuse` keeps the pre-knob behaviour: every rank-deficient S under the one rule is `PULSE_MATRIX_SINGULAR`, a zero-spread member nulls every figure. Fixtures `internal/sem/testdata/singular_*` (n = 8 < p = 10, semopy's own substitution from the rows, `fit_semopy_nearest.py`), `near_*` (`gen_near_data.py`: 64 rows whose biased covariance is EXACTLY L·Lᵀ with l55 = 2⁻²⁴ — the rule fires, Cholesky is exact on every platform, a streaming Welford co-moment reaches the same bits; `fit_semopy_exact.py` fits semopy to that exact matrix, its baseline included), `constant_*` (a `FitCovNearest`-only reference: its wrapped `cov_nearest` enters the zero variance at 1, which MAT_SEM no longer does); `nearest_statsmodels.json` (`gen_nearest.py`). Gates: `TestCovNearest_MatchesStatsmodels`, `TestFit_NearestMatchesSemopy` (1e-9 default, 1e-6 Fisher vs tight), `TestFit_NearSingularRawMatchesSemopy` (1e-6 converged; the default early stop 1e-4 — on that S the stopping iterate moves at that level with summation order, semopy's own included), `TestMatrixSEM_SingularNearestMatchesSemopy`, `TestMatrixSEM_NearSingularFactorsFitsRaw`, `TestMatrixSEM_SingularRefuse`.
- **Weights.** `ClassFrequencyOnly` (`internal/weighting`): S = M2_w/Σw and N = Σw — exactly semopy's fit on the expanded rows; a probability weight is `PULSE_WEIGHT_UNSUPPORTED` (no design-based form to clone).
- **Mean structure and the lavaan conventions (sem-extensions E1-S1).** `params.meanstructure: true` (`vectors.SEMPlan.MeanStructure` → `sem.ModelOptions`), or any `~ 1` term in the model (`sem.OpIntercept`; `x ~ 1` free, `x ~ 0*1` fixed, `x ~ a*1` labelled, `y ~ 1 + x` beside predictors; a `1` on `=~` / `~~` or a `~ 1` on a variable the model does not use is `bad_params`), sets `sem.Model.MeanStructure` and `Model.Lavaan()`. Spec (`model.go` `effectMeans`): the `~ 1` statements first, then every other observed intercept free — an observed exogenous mean fixed to the sample mean (lavaan's `fixed.x`) and hidden like its (co)variances (`hiddenRow`) — then every other latent mean fixed to 0; an intercept sits in Alpha for an inner variable, else in Nu (new matrices `mNu` / `mAlpha`, μ = ν + ΛCα). Objective F + (ȳ − μ)ᵀΣ⁻¹(ȳ − μ) over the co-moment's means in model order (`sem.FitMoments`; a covariance-only model is `FitCovNearest` bit for bit); gradient W with S → S + rrᵀ plus −2∂μᵀΣ⁻¹r, expected information + 2∂μₖᵀΣ⁻¹∂μₗ (dense and rank2 alike). Under `Lavaan()` — the switch every lavaan-only feature joins — the default solver is `fisher` (an explicit `slsqp` is honoured; `ftol` without it is `bad_params`, `grad_tol` is accepted), variances are unbounded, SEs unclamped with z = θ/SE, Wald `ci_lower` / `ci_upper` (±1.959963984540054·SE) join the estimate columns (`vectors.SEMEstimateColumnsOf`), starts move a marker-identified latent mean and the free intercepts to the sample means (`meanStarts`; never the optimum), and `ComputeStats` is `lavaanStats`: dof over p(p+1)/2 + p less the exogenous block's moments, chi2 = N·F, the closed-form independence baseline, lavaan 0.7's CFI / TLI / NFI / RMSEA (divisor N), `gfi` / `agfi` = `gfi_lisrel` / `agfi_lisrel` (normal-theory weight at Σ(θ̂), exogenous block zeroed), `loglik` the h0 log-likelihood less the exogenous marginal, AIC / BIC from it. Outputs add `~1` rows (key `"x ~1"`, records `rval` empty) and `auxiliary.implied_means` / `observed_means` (member rows, one `mean` column; `AuxiliaryKeys`, predict p × 1). Fixtures: the generated brand survey (`brand_spec.json` + seed → `brand_data.csv`, `TestSEM_BrandSurveyRegenerates`, `-regen-brand`), models `brand_ms` / `brand_mx`, lavaan 0.7.3 references `*_lavaan.json` from `fit_lavaan.R` via `gen_lavaan.sh` (each records its lavaan and R release; CI never runs R). Gates: `TestSEM_MeanStructureMatchesLavaan` (`internal/sem`: 1e-4 relative estimates / SEs / z / intervals, 1e-4 absolute p, 1e-3 fit indices — the residual is nlminb's rel.tol 1e-10 stop, ~8e-5 on a weak slope), `TestMatrixSEM_MeanStructureMatchesLavaan` (engine, plus plan ≡ runtime auxiliaries and estimates shape), `TestSEM_ParseIntercepts`, `TestSEM_LegacyConventionsUnchanged`; the semopy gates above are unchanged.
- **Joint multi-group fit (sem-extensions E1-S2).** `params.group` (`vectors.SEMPlan.Group`; `group_reference` → `GroupReference`) fits ONE model jointly over the levels of a categorical (levels in DICTIONARY order, GROUP_CATEGORY's label keys), `packed_bool` (`"0"`, `"1"`) or `u4` / `u8` (ascending values) field (`vectors.SEMGroupFieldTypes`) — lavaan's `group =`, configural: every parameter free per group, except that a LABELLED parameter is one value in every group (lavaan's reading of a label; lavaan warns, Pulse does not). `sem.NewGroupModel` forces the mean structure (and so lavaan conventions); `sem.FitGroups` minimises F = Σ_g (n_g/N) F_g over a joint free vector (`jointState.idx`: per-group auto parameters, one shared index per label), Fisher scoring by default, SEs from the joint information Σ_g (n_g/2) H_g; statistics `lavaanCombine` over per-group `lavaanPart`s — chi2 = Σ n_g F_g (per group `chi2_group_<level>`), dof and baseline summed, logl summed, BIC with ln N total, RMSEA × √G (lavaan's multiple-group factor), gfi_lisrel the n-weighted mean, agfi from the summed moments. Engine (`internal/processing/matrix_sem_group.go`): `semGroupState` keeps one `BlockCoMoments` per level code beside the base state (the MAT_DISTANCE bucket pattern), absorbed level by level at merge, so the fit stays streamable / mergeable and bit-identical across `DecodeWorkers`, `ShardWorkers` and a shard archive; a null group is a listwise drop (`n_listwise_dropped`); the group field joins the projected decode (`vectors.MatrixMembers`). Levels are the codes that hold rows (an upper bound in predict: `AuxiliaryKeys` lists the dictionary's / packed_bool's levels, unknown on an integer field). Output: estimate rows `"[level] lval op rval"` in level order, lavaan's 7 columns, records fields + `group` / `label`; `vectors.group` / `label` (model label, "" unlabelled) beside `parameter` / `free`; `primary` the reference level's Σ̂; auxiliary per level `vectors.SEMGroupAuxiliaryKeys` (`implied_covariance.<l>`, `residual_covariance.<l>`, `implied_means.<l>`, `observed_means.<l>`; no unprefixed residual); scalars joint + `vectors.SEMGroupChi2Key` / `SEMGroupNKey` (n_g = Σw under a frequency weight). Config refusals (`resolveSEMGroup`, predict ≡ runtime): request `groups` / `crosstab` (`group_with_groups`), another field type (`group_field_type`), a one-entry dictionary (`group_one_level`), a member / unknown field, `meanstructure: false`, a standardizing vector, `params.fit`, an unknown `group_reference` or one without `group` (`bad_params`). Data refusals fail the slot alone: fewer than two levels with rows (`one_level`), a level with N ≤ p rows or Σw ≤ p (`level_too_thin`), a reference level without rows (`reference_absent`) — `PULSE_MATRIX_INSUFFICIENT_N`; a level's non-PD S — `PULSE_MATRIX_SINGULAR` (no nearest substitute). Oracle: `brand_mg_configural_lavaan.json` (equal groups) and `brand_mg_misfit_lavaan.json` (600 / 400 rows `brand_uneq_data.csv`, misfit, shared label), `fit_lavaan.R` with a group argument; gates `TestSEM_MultiGroupMatchesLavaan`, `TestSEM_MultiGroupSharedLabel` (`internal/sem`), `TestSEM_MultiGroupProcessMatchesLavaan`, `TestSEM_MultiGroupWorkerAndShardInvariant`, `TestSEM_MultiGroupFrequencyWeight`, `TestSEM_MultiGroupRefusals` (root).
- **Not covered (semopy surfaces outside its default `Model`).** FIML and the other objectives (ULS, GLS, WLS, DWLS), ordinal / polychoric input, robust or observed-information SEs, `std_est="lv"`, `mimic_lavaan=True`, `cov_diag=True`, semopy operation commands (`START`, `BOUND`, `DEFINE`, `CONSTRAINT`), a covariance between an inner and an output variable.
- **Reference fixtures.** `internal/sem/testdata`: four models (a synthetic three-level hierarchy, Bollen's political democracy, Holzinger–Swineford and an extended variant with labels, covariates, fixed / labelled covariances and an output regression) with semopy's default (`*_semopy_default.json`) and `ftol` 1e-14 (`*_semopy_tight.json`) fits; regenerate with `gen_semopy.sh` (a venv with semopy 2.3.11), compare a run with `compare.py`. Gates: `TestFit_MatchesSemopy` (five setups × four models: 1e-9 vs default, 1e-6 vs tight), `TestRank2MatchesDense`, `TestParse_Refusals`, `TestResolveMatrices_SEM`, `TestMatrixSEM_*` (`internal/service`).
- **Reference release.** MAT_SEM targets semopy 2.3.11 and its default fit (`semopy.Model(desc).fit(data)`, no options) — the release `gen_semopy.sh` installs and every `*_semopy_default.json` is; `*_semopy_tight.json` is the same release at `ftol` 1e-14. No other semopy release is a reference.
- **Same-shape parity (sem-contribution E2-S5).** A synthetic model with a production-like shape — four outputs on one factor (`y1, y2, y3, y4 ~ g`), a mediator over constructs (`g ~ m + c1`, `m ~ c1 + …`), two-level hierarchies (constructs `c*` over first-order factors `f*` over items), 63 (`shape63_model.txt`) and 89 (`shape89_model.txt`) indicators, mostly 0/1 items (the mediator's and outcome factor's items 1–5, outputs 0–10) — over 600 seeded rows (`shape_data.csv`, `gen_shape_data.py`; `f3` generated with NO disturbance; blank `x05` / `y2` cells drop listwise), every column z-scored over the listwise rows (`fit_semopy_shape.py`); `shape63_singular_*` is the 63 model on ids < 50 (n = 47 < p = 67, semopy's `cov_nearest`). Gates: `TestSEMShape_OneRequestMatchesSemopy` (root package: ONE request, six slots — the three cases at the defaults and at `ftol` 1e-14 — over a z-scored vector whose `x01` is a formula attribute, the n < p vector's computed `x01s` labelled `x01`, every slot `encoding: "records"` and read from the records wire; the n < p slots warn `PULSE_MATRIX_NEAREST_PD`, the rest none) and `TestFit_ShapeMatchesSemopy` (`internal/sem`, the default fits from the rows' own S). **Finding (the near-zero latent variance outlier).** The smallest latent variance (`f3 ~~ f3` ≈ 0.033, SE 0.016, generated as 0) is not where the objective is flattest: the expected information's smallest eigenvalue (~11 against ~1.1e4 at full n; ~0.7 against ~1.7e3 at n < p) is a first-order factor's SCALE — its free loadings moving together against its construct path and its small disturbance variance (`f5`, `f8`, `f11`). Along it semopy's default `ftol` 1e-6 stop sits ~1e-3 (relative) short of the optimum, yet MAT_SEM reproduces that stopping iterate — same iteration count, every figure within 4e-10 through the engine (streamed, merged, z-scored co-moment), 2e-10 from the rows' S — so this shape's default pin is 1e-8 (unlike near_*, whose near-singular S moves the stop at 1e-4). At `ftol` 1e-14 the optimum itself is resolved along that direction only to ~√(ε·F/h) ≈ 1e-7…1e-6 (estimates up to 9e-7 apart, iteration counts up to five apart), so the tight pin is 5e-6. semopy alone varies at both levels: two runs (Python set order differs per process) differ by up to 3e-10 default, 3e-7 tight.
