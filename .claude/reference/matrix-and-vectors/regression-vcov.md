## Regression vcov — `RegressionSpec.Vcov`

Opt-in per regression: `vcov: true` (a flat `RegressionSpec` field — regressions carry flat params) adds `RegressionResult.Vcov` and `.Correlation`, both `*types.MatrixValues` (`square_symmetric`, `full`, keys `(intercept)` then the predictors in spec order). Off by default: both are `omitempty`, so a fit without it is byte-identical. It has no feature row (a param), so the ungated `regressions` slot makes `MatrixValues` reachable even with `capability:matrices` hidden. Engine: `internal/processing/regression/` (`vcov.go`, `covariance.go`, `resample.go`).

- **Sources.** `REG_OLS` unpenalized: σ̂²·M2_xx⁻¹ for the slopes, the intercept row from the centring identity; ridge: the same over the sandwich. `REG_GLM`: φ·(XᵀWX)⁻¹ at the CONVERGED β's working weights (the expected information under every link, R `summary.glm`); φ = 1 for binomial / poisson, θ̂-based variance for negative binomial, Pearson φ̂ for gamma; under `penalty: l2` the penalised-Fisher sandwich. `REG_BAYES_LINEAR`: the POSTERIOR covariance b_n/(a_n−1)·Λ_n⁻¹ (null when a_n ≤ 1) — not StdErrors² (those are marginal-t scales).
- **Diagonal = SE² exactly** on OLS / ridge / GLM: the diagonal is the clamped variance the SE is `math.Sqrt` of, so `√diag == StdErrors` bit for bit. Weighted fits inherit the N* basis.
- **Dispersion.** Beside a classical vcov whose φ is estimated (unpenalized `REG_OLS`, `REG_GLM` gamma) the result carries `RegressionResult.Dispersion` (null when df ≤ 0), so `Vcov / Dispersion` = (XᵀWX)⁻¹ — what a bound fit's leverage / influence figures read (`regression.BoundInfluence`, rule `model.CheckFitDesign`). Absent where φ is fixed, on robust, penalized and Bayesian fits, and under Resample. Kept in the model file.
- **Penalized inverse.** A penalized fit's design is NOT its vcov, so every penalized `REG_OLS` / `REG_GLM` fit without resample / selection carries `RegressionResult.PenalizedInverse` — **`json:"-"`: in memory and in the model file, never on the wire** — the penalized design inverse on the inference basis, which `BoundInfluence` reads instead of Vcov/φ (leverage only). A singular active design is carried all-null, never a fit failure.
- **Correlation** is R's `cov2cor`, computed on the upper triangle and mirrored so both matrices are exactly symmetric; a zero or undefined variance makes its row / column `null`.
- **Modifiers.** Under Resample the vcov is the REPLICATE covariance whose √diag the SEs are, over the same replicate set (jackknife (g−1)/g·Σ…, bootstrap the B−1 sample covariance); the analytical matrix is replaced, never kept. The bootstrap seed derivation (`rng_seed: 0`) drops `vcov` and `margins`, so asking for them never moves the replicates. A Compose Wald `compare` over a resampled fit reads this replicate covariance whether or not `vcov` is set (χ² on q). Under Selection it is the final refit's matrix on the selected predictors. `REG_MULTINOMIAL` follows the same rules over its `"<level>:<term>"` keys. Bayes never reaches a modifier (`PROCESSING_CONFIG`).
- **Refusal.** Lasso / elastic net, alone or under a modifier → `PROCESSING_REGRESSION_VCOV_UNSUPPORTED` (`reason` `penalty`): there is no sampling covariance of a data-dependent active set, and a refusal (rather than an all-null matrix) means a caller never mistakes an asked-for matrix for a computed one. One rule for predict and engine: `internal/regpenalty.VcovRefusal`.
- **Oracle.** `mv_vcov.json` (vcov(lm), vcov(glm); unweighted, frequency, probability): OLS 1e-10, GLM 1e-11. R's raw `vcov(glm)` inverts at the working weights from the START of the last IRLS iteration, one β update behind its coefficients (≈ 1e-7 off on a near-separated fit), so the generator refines each fit to the IRLS fixed point and inverts there — the point Pulse evaluates at. Modifiers pinned at 1e-10; bootstrap has no oracle and is pinned by invariants (diag = SE², symmetry, PSD, seed determinism).
- **Robust covariance.** `RegressionSpec.Covariance {type, cluster, cluster2, entity, order_by, lags}` (absent = `classical`, byte-identical) swaps the estimator behind `StdErrors`, `PValues`, the intervals AND `Vcov`. One sandwich engine (`covariance.go`) fed per model type; √diag == `StdErrors` bit for bit. Types and which models compute them: `regcov.Types` / `regcov.robustTypes`; one rule for predict and runtime, `internal/regcov.Check` (shape → `PROCESSING_CONFIG`; an unsupported combination → `PROCESSING_REGRESSION_VCOV_UNSUPPORTED` with `details.reason`). A robust type makes the spec non-streamable; `cluster` / `entity` / `order_by` enter projection and the field-reference rule; a null key drops the row listwise; `RegressionResult.Covariance` echoes the estimator. Contract points:
  - `cluster` is CR1 with G − 1 df; fewer than 2 clusters refused. `hac` is Newey–West Bartlett (`prewhite = FALSE`), rows sorted by `order_by`, a repeated value refused. **`lags: "auto"` = ⌊4(n/100)^(2/9)⌋ computed exactly as the largest L with 625·L⁹ ≤ 2¹⁴·n²** — a float power drops a lag at every n = 100·m⁹.
  - GLM's sandwich uses the IRLS scores at the converged weights (R `sandwich` on `glm`; dispersion cancels), Wald z. Bayes uses Müller's (2013) sandwich posterior (mean kept, covariance replaced), normal intervals. Multinomial supports `hc0` / `hc1` / `cluster` only.
  - **Panel:** `hac` + `entity` = per-entity Newey–West, `driscoll_kraay` = Driscoll–Kraay. Periods are the distinct `order_by` values, ranked; a lag counts periods, not rows. Rows sort by (entity, order) before any sum, so summation order is a function of the keys. An entity repeating an `order_by` value is refused at runtime (`order_by_ties`).
  - **Two-way cluster** (`cluster2`): G₁/(G₁−1)·M₁ + G₂/(G₂−1)·M₂ − G₁₂/(G₁₂−1)·M₁₂ (`sandwich::vcovCL(multi0 = FALSE)`). **A negative variance is KEPT in `Vcov` and its SE is NaN** — never the one-way clamp to 0.
  - Oracles: `scripts/reference/gen_robust_vcov*.R` (`sandwich`, `plm` pins) at 1e-10. Skill `regression-panel-covariance`. The model file records the estimator.
- **Marginal effects.** `RegressionSpec.Margins` reads the same matrix the SEs read (classical or robust) whether or not `vcov` is set: Var(effect) = J·V·Jᵀ. On the link scale and on an identity link J = e_j, so the effect's SE is `StdErrors` bit for bit and needs no V — which is why OLS margins stream. Under Resample every replicate re-derives the effects and the replicate SE replaces the delta method. Contract and refusals: `docs/src/regression.md` (Marginal effects), rule `internal/regmargins`.
- **Return.** `regressions[*].vcov` / `.correlation` / `.covariance` are in `standard` (so an opted-in matrix survives the MCP default), not `minimal`; every float is rounded by `precision`.
