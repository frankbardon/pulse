## Regression vcov — `RegressionSpec.Vcov` (U24 E4)

Opt-in per regression: `vcov: true` (a flat `RegressionSpec` field — regressions carry flat params, there is no `params` object) adds `RegressionResult.Vcov` and `.Correlation`, both a `*types.MatrixValues` (`square_symmetric`, `full`, keys `(intercept)` then the predictors in spec order). Off by default: both slots are `omitempty` pointers, so a fit without it is byte-identical (`TestRegressionVcov_OffByDefault`). No feature row (a param, like the rank methods), so the ungated `regressions` slot makes `MatrixValues` reachable on an instance with `capability:matrices` hidden (`TestPayloadSchema_MatricesHidden`).

- **Sources** (`internal/processing/regression/vcov.go`). `REG_OLS` unpenalized: σ̂²·M2_xx⁻¹ for the slopes, intercept row Cov(β₀, β_j) = −Σ_k μ_x[k]·Cov(β_k, β_j) (ȳ is uncorrelated with the centred slopes), Var(β₀) as the SE reads it; ridge: the same assembly over the sandwich. `REG_GLM`: φ·(XᵀWX)⁻¹ at the CONVERGED β's working weights — φ = 1 (binomial / poisson), gamma's φ̂ = Pearson χ²/(N* − p − 1) (reference-oracles E2-S3); under `penalty: l2` the penalised-Fisher sandwich H⁻¹·XᵀWX·H⁻¹, H = XᵀWX + N*·α·D (`glmPenalty.covariance`), √diag = StdErrors; `l1` / `elasticnet` refuse vcov on both types (`internal/regpenalty.VcovRefusal`, shared with predict). `REG_BAYES_LINEAR`: the POSTERIOR covariance b_n/(a_n−1)·Λ_n⁻¹ (NaN → `null` when a_n ≤ 1) — not StdErrors² on the diagonal (those are the marginal-t scales; the ratio is a_n/(a_n−1)).
- **Diagonal = SE² exactly** on OLS / ridge / GLM: the diagonal is the clamped pre-square-root variance the standard error is `math.Sqrt` of, so `√diag == StdErrors` bit for bit. Weighted fits inherit the N* basis (Σw frequency, n_eff probability) because σ̂² and the GLM prior weights already sit on w*.
- **Correlation** is R's `cov2cor` (`(s_i·V_ij)·s_j`, s = √(1/diag), unit diagonal), computed on the upper triangle and mirrored so both matrices are exactly symmetric; a zero or undefined variance makes its row / column `null`.
- **Modifiers** (`resample.go`, `modifier_engine.go`; owner call (e), 2026-10-10). Under Resample the vcov is the REPLICATE covariance its SEs are the √diag of, over the same replicate set the SE sums (a skipped bootstrap replicate is absent from both; a failed jackknife refit fails the fit): jackknife (g−1)/g·Σ(β₋ₖ−β̄)(β₋ₖ−β̄)ᵀ over its g replicates (g = n leave-one-out; `jackknife_groups` / `jackknife_by` delete groups, U49 E3-S2 — R oracle `jackknife.json`), bootstrap the B−1 sample covariance, deterministic for a seed (`replicateCov`, which forms the off-diagonal only when `vcov` is set). The base fit's analytical matrix is replaced, never kept. Under Selection it is the inner engine's matrix from the final refit on the selected predictors (keys `(intercept)` + `selected_features` order; an intercept-only OLS result carries the 1×1 Var(ȳ)); Selection + Resample follows the resample SEs over the selected set. Bayes never reaches a modifier (`PROCESSING_CONFIG`).
- **Refusal.** Lasso / elastic net (`REG_OLS` and `REG_GLM`) — alone or under a modifier (no sampling covariance of a data-dependent active set — never approximated) → `PROCESSING_REGRESSION_VCOV_UNSUPPORTED`, `details.reason` `penalty` — consistent with their `StdErrors` / `PValues` / intervals, which are null on every key without a resample (`PULSE_ADVISORY_PENALIZED_INFERENCE_UNDEFINED`, reference-oracles E2-S2; refusal kept rather than an all-null matrix, so a caller never mistakes an asked-for matrix for a computed one); predict and the engine (`validateVcov`) apply the one rule, `internal/regpenalty.VcovRefusal` (`TestRegressionVcov_Refusals`, `TestVcov_ModifierRefusals`, `TestRegPenalty_PredictRuntimeParity`).
- **Oracle.** `mv_vcov.json` `cases` (vcov(lm), vcov(glm) binomial / poisson; mtcars, attitude, weighted; unweighted, frequency, probability): `TestRegressionVcov_MatchesROracle`. OLS at 1e-10 (worst seen 3e-13). GLM at 1e-11 (worst seen 2.1e-13): R's raw vcov(glm) inverts XᵀWX at the working weights from the START of glm.fit's last iteration, one β update behind its coefficients (≈ 1e-7 on the near-separated mtcars binomial fit), so the generator refines each fit by Fisher-scoring steps to the IRLS fixed point and inverts there (`glm_fixed_point`), the point Pulse evaluates at. `jackknife_cases` (leave-one-out lm) and `selection_cases` (`stats::step`, whose extractAIC differs from Pulse's criterion by a constant) pin the modifiers at 1e-10 (`TestRegressionVcov_ModifiersMatchROracle`); bootstrap has no oracle and is pinned by invariants (diag = SE², symmetry, PSD, seed determinism, the hand-computed replicate covariance: `TestVcov_Bootstrap_*`).
- **Robust covariance (U25 E5-S1).** `RegressionSpec.Covariance {type, cluster, order_by, lags}` (absent = `classical`, byte-identical: `TestRegressionCovariance_ClassicalByteIdentical`) swaps the estimator behind `StdErrors`, `PValues`, the intervals AND `Vcov` on `REG_OLS`: `hc0`–`hc3`, `cluster` (CR1, G/(G−1)·(N*−1)/(N*−k), inference on G − 1 df, < 2 clusters refused), `hac` (Newey–West Bartlett, `prewhite = FALSE`, N*/(N*−k), rows sorted by `order_by`, a repeated value refused, `lags` an int or `"auto"` = ⌊4(n/100)^(2/9)⌋ over the fit's rows). The engine (`covariance.go` `sandwich`) is engine-free — bread, per-row unit-weight score, w*, leverage, keys — and REG_OLS feeds it from a buffered SECOND pass (`ols_covariance.go`, centred coordinates, bread diag(1/N*, M2⁻¹/c), mapped back by J = [[1, −μᵀ],[0, I]]); √diag == `StdErrors` bit for bit (the clamped diagonal IS the variance). A robust type makes `RegressionSpec.Streamable` false (predict names the reason), its `cluster` / `order_by` enter projection and the field-reference rule, a null key drops the row listwise, and `RegressionResult.Covariance` echoes `{type, cluster, clusters, order_by, lags}`. One rule for predict and runtime: `internal/regcov.Check` (shape → `PROCESSING_CONFIG`; beside a penalty / resample / selection or on a non-OLS type → `PROCESSING_REGRESSION_VCOV_UNSUPPORTED` `details.reason`; the engine adds `clusters` / `order_by_ties`). Cluster keys read the optional `regression.LabeledRecord.StringValue` (categorical label), else `NumericValue` — `Record` itself stays one method. Oracle `mv_robust_vcov.json` (`gen_robust_vcov.R`: `sandwich` 3.1-3 `vcovHC` / `vcovCL(type = "HC1")` / `NeweyWest`, `lmtest::coeftest` p-values) at 1e-10. **E5-S2 lifts `REG_GLM` and `REG_BAYES_LINEAR`** (`regcov.robustTypes`; `ReasonType` is now reachable only by a type without the estimators). GLM (`glm_covariance.go`): the same sandwich over the IRLS scores at the converged weights — unit score μ'·(y − μ)/V(μ)·x, bread the classical (XᵀW*X)⁻¹, unit leverage μ'²/V·xᵀBx, w* = the prior weight — so it is R `sandwich` on `glm` (dispersion cancels, every family); inference stays Wald z, `cluster` included (no `DF`). Rows with a null key drop in `buildWeightedDesign` (`robustKeyReader`). Bayes (`bayes_covariance.go`): Müller's (2013) sandwich posterior — μ_n KEPT, the posterior covariance REPLACED by Λ_n⁻¹·M·Λ_n⁻¹ (bread the posterior precision, σ²-free; score (y − xᵀμ_n)·x; leverage xᵀΛ_n⁻¹x) — with NORMAL credible / confidence intervals and no `DF`, √diag(`Vcov`) = `StdErrors` (unlike its classical posterior vcov); forces the buffered path (`fitRow` second pass). Oracle `mv_robust_vcov_glm.json` (`gen_robust_vcov_glm.R`: binomial / poisson against `sandwich` on a `glm` refit from the polished MLE, `coeftest` z p-values; Bayes closed form, checked = the `lm` sandwich at precision 0) at 1e-10 (`TestRegressionCovariance_MatchesROracle/REG_GLM+REG_BAYES_LINEAR`). The model file records the estimator (`model_format_version` 2, byte-layout.md "Model file").
- **Return.** `regressions[*].vcov` / `.correlation` / `.covariance` are in `standard` (so an opted-in matrix survives the MCP default), not `minimal`, excludable like any path, every float rounded by `precision` (`TestReturn_RegressionVcov`, `TestPrecision_FloatLeavesClassified`).
