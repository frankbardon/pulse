## Overlays

`Request.Overlays []*OverlaySpec`, `Response.Overlays []*OverlayLayer`. Additive post-result decorations attached to an already-computed base result. Each spec produces one `OverlayLayer` in matching slot order; layers carry the host-shape payload and never mutate the base payload — overlays are read-only siblings keyed to host coordinates. Catalog at `types.AllOverlayKinds()` + `types.OverlayStreamability`; per-kind capability at `descriptor.overlayCapabilityFor` (surfaced on `Manifest.Overlays`).

Buffered-by-default rule: `OverlayStreamability[kind] == false` for every kind in the initial catalog. The overlay family covers index/share/delta/cumulative/rolling shapes across cell/row/column/total scopes. Forward-compat: `Request.Overlays` is omitempty so `CanonicalHash`/`Request.Hash` stay byte-identical for requests that omit the slot. A crosstab carrying `Request.Overlays` no longer falls back to buffered — the MATRIX fold runs at the fused exit through the same hook (see "Fused crosstab" above); the flag table stays all-`false` because that fold is post-`Finalize`, not in-pass. Failures: `PULSE_OVERLAY_KIND_UNKNOWN`, `PULSE_OVERLAY_SCOPE_UNSUPPORTED`, `PULSE_OVERLAY_REF_INCOMPATIBLE_WITH_SHAPE`, `PULSE_OVERLAY_HOST_NOT_SUPPORTED`, `PULSE_OVERLAY_LEVEL_OUT_OF_RANGE`.

**Level / Within composition.** The share / index / delta / zscore family honours `OverlaySpec.Level` (same-axis prefix truncation) and `OverlaySpec.Within` (opposite-axis prefix fixing). `Level=0, Within=0` preserves the leaf-margin denominator and is byte-identical to the no-Level/no-Within handler output. Composition mirrors the buffered crosstab `normalize_level` / `normalize_within` semantics (byte-equivalent for summable cell aggregators) and reuses the same prefix-key helpers (`processing.SameAxisPrefixDepth` / `processing.OppositeAxisPrefixDepth` / `processing.AxisKeyPrefix`). Out-of-range slots fire `PULSE_OVERLAY_LEVEL_OUT_OF_RANGE` at both predict and runtime; the χ² / Fisher inferential family rejects non-zero values with the same code (implicit-margin contract).

**Excluded overlays are not folded (U18 E3-S1).** Every request-host fold (`applyOverlaysToResponse`, `applyOverlaysSeriesToResponse`) and the Compose barrier consult the run's `processing.ComputePlan`: a layer a `return` excludes runs no handler and raises nothing unless a resolved multiplicity family claims it; dispatch (`canStream`, fusion) still reads the original request. Long form: `.claude/reference/response-components.md` (the Compute plan paragraph, Overlays). Tests / post-tests (per entry, same veto) and regressions (whole) skip at their build points (`buildRowTests` / `buildPostTests` / the fit calls) — the merge gate still refuses fan-out on the original request (E3-S2).

**Grouped Process wiring.** The SERIES-host overlay fold (`processing.ApplyOverlaysSeries`) attaches at the grouped Process exit in both `internal/processing/processor.go` paths (buffered + streaming). No-op when `req.Overlays` is empty, when `req.Crosstab` is set, or when the request has no `Groups`. Mixed-mode downgrade rule: a Request mixing streamable overlay kinds with non-streamable kinds forces the entire request to the buffered path via `processing.canStreamOverlays`.

**FACET-host wiring.** The FACET-host overlay fold (`processing.ApplyOverlaysFacet`) attaches at the FacetSchema buffered exit in `internal/service/facet_rich.go` via `service.applyFacetOverlays`. `FacetRequest.Overlays []*OverlaySpec` is the FACET-host slot; the four FACET-host kinds MUST attach there, not on `Request.Overlays` — the Request-host validator rejects FACET kinds with a `PULSE_OVERLAY_REF_INCOMPATIBLE_WITH_SHAPE` redirect message. Per-spec host-field selection via `OverlaySpec.Params["field"]`. Service-layer wiring recurses `FacetSchema` against `Ref.Population.Cohort`, caches per-cohort+field tuples. `FacetResult.Overlays []OverlayLayer` is omitempty. Predict equivalent: `descriptor.ValidateFacetOverlays` — per-kind Ref / Scope / Level / Within gates; CHISQ rejects numeric hosts; KS rejects categorical hosts. Predict surface: `FacetValidationResult.OverlaysApplied` + `FacetValidationResult.OverlayCost` mirror the Request-host shape. Manifest: `Manifest.Facet` carries `SupportsOverlays: true` + `SupportedOverlayKinds: ["OVERLAY_CHISQ_VS_POP", "OVERLAY_INDEX_VS_POP", "OVERLAY_KS_VS_POP", "OVERLAY_ZSCORE_VS_POP"]`.

**CHAIN-host wiring.** The CHAIN-host overlay fold (`processing.ApplyChainOverlays`) attaches at the post-stage-loop barrier inside `service.ProcessChain` (`service.applyChainOverlays` hook). Dispatcher chassis ships stub handlers for the two whole-chain kinds (`OVERLAY_INDEX_VS_STAGE`, `OVERLAY_DELTA_VS_STAGE`) so the round-trip path is exercised end-to-end without per-kind arithmetic; per-stage `Stages[i].Overlays` is left UNTOUCHED.

**FORMULA kind.** `OVERLAY_FORMULA` is a caller-supplied expression-driven projection compiled ONCE per spec via `expr-lang/expr` (the same evaluator that backs `ATTR_FORMULA` / `FILTER_EXPRESSION`) and run per cell / entry / scalar against a per-host-shape variable namespace (MATRIX: `cell` / `margin_*` / `sd_*`; SERIES: `value` / `total` / `prior` / `baseline`; SCALAR: `value`; Compose hosts add the dotted `slot.<label>.{cell|value}` namespace). Inherently buffered across every host shape. `pulse.Options.Extensions.ExprFunctions` flow through the evaluator (functions widen the function surface only; the variable surface stays fixed per-host-shape). Failures: `PULSE_OVERLAY_FORMULA_PARSE_ERROR` / `PULSE_OVERLAY_FORMULA_TYPE_MISMATCH` / `PULSE_OVERLAY_FORMULA_INVALID_IDENT`. **Request-host gate (U35 #440, #432):** `formulaident.RequestSpecRefusal` (formula param, parse, `total()`, built-ins, `baseline_position`, identifiers) runs in predict AND the runtime MATRIX / SERIES dispatch before compile, identical both sides (`TestRequestFormula_IdentRefusalMatchesPredict`). The SERIES arm: `overlays-series.md`.

Surface: `types/overlay.go`, `types/overlay_streamability.go`, `internal/processing/overlay.go`, `internal/processing/crosstab.go` (hook), `internal/processing/crosstab_normalize.go` (shared prefix helpers), `internal/processing/overlay_series.go` (SERIES fold engine), `internal/processing/overlay_series_response.go` (grouped Process wiring + mixed-mode gate), `internal/processing/overlay_facet_dispatch.go` (FACET dispatch table) + `internal/processing/overlay_facet_pop.go` (FACET population resolver), `internal/processing/overlay_chain_dispatch.go` (CHAIN dispatch table + StageRef resolver), `internal/descriptor/overlay.go`, `internal/descriptor/overlay_facet.go`, `internal/descriptor/capabilities_overlay.go`, `internal/descriptor/capabilities_facet.go`, `internal/descriptor/manifest.go`, `internal/descriptor/predict.go`, `internal/descriptor/facet.go`, `internal/service/facet_overlay.go`, `internal/service/chain.go` (`applyChainOverlays` hook), `types/facet.go`, `types/chain.go`. **Weighted hosts.** Share / index kinds carry no weight logic: they read the already-weighted host payload on every arm (MATRIX buffered + fused, SERIES buffered + streaming fold, COMPOSE). The lifted `Inferential` kinds (U12 E3) read the host's weighted floor keys for N* — the mean kinds through `CrosstabHostView.MeanLeg`, the contingency / proportion kinds through `CellFloor` / `RowMarginFloor` / `ColumnMarginFloor` / `BaseFloor` and the Kish scale of a Σw table or base — with the MATRIX arm's basis taken from the STAMPED crosstab cell weight (`applyOverlaysToResponse` → `withCellWeight`, both crosstab arms) and Compose slots' inferred from the floor keys; `OVERLAY_FISHER_EXACT_CELL` is frequency-only (host refusal at dispatch), `OVERLAY_PAIRWISE_TWO_MEANS_Z` / `_PROBIT_T` stay refused, and the weighted twin takes an `AGG_WEIGHTED_MEAN` or weighted `AGG_AVERAGE` cell: `.claude/reference/weighting.md` (Overlays).

**Overlay knobs** (relocated from CLAUDE.md "Build / Env"). `OverlaySpec.Options`: `DictPrefixFast bool` (default `false`) matches Compose multi-slot overlay schemas by byte-equal dictionary PREFIX probe and requires the embedder to have verified prefix-equal dicts; `MaxPanelTargets int` (default `16`) caps Targets on multi-reference Compose overlays, overflow → `PULSE_OVERLAY_PANEL_TARGETS_OVER_CAP`.
