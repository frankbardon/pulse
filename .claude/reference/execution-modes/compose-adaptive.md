# Execution modes — Adaptive sweeps

Per-topic slice of the execution-modes reference. Index (Mode index + section map): `.claude/reference/execution-modes.md` — load it first, then only the slice(s) your engine work touches. The phase-0 schedule it runs inside is `execution-modes/compose.md` (Compose fits, sweep-bound fits).

## Adaptive sweeps

An **adaptive** sweep mode chooses each round's points from the ranked values of the rounds before. The executor is shared (`internal/sweep/adaptive.go`); a mode supplies only a `sweep.Strategy`, registered once from an `init` with `sweep.RegisterAdaptive(sweep.AdaptiveMode{Mode, Validate, New})`. `sweep.IsAdaptive` / `AdaptiveModes` read the registry, so predict, the runtime and the mode lists see the same set. Gated by `capability:compose_sweep_adaptive` (depends on `compose_sweep` AND `compose_sweep_sampling`): hidden, `budget` is `PULSE_REQUEST_UNKNOWN_FIELD`, an adaptive mode takes the unknown-mode refusal, and the `SweepMode` enum and MCP sweep schema drop them.

**Request shape.** `budget` (`SweepSpec.Budget`, `omitempty`, so an existing spec's derived seed never moves) and `rank` are required: `PULSE_SWEEP_INVALID` `adaptive_requires_budget` / `budget_invalid` / `adaptive_requires_rank`. Refused under an adaptive mode (`PULSE_SWEEP_MODE_MISMATCH`): `samples` (`samples_under_adaptive`) and `sweep.overlays` (`overlays_under_adaptive` — a per-slot overlay names slots whose labels are unknown until their round). `budget` under any other mode is `budget_without_adaptive`. An axis is a list axis (`values`) or a range axis (`range`), never both (`values_and_range`), never neither (`values_empty`). `rng_seed` is allowed; `EffectiveSeed` seeds the strategy and is echoed as `sweep_seed`. `Count` = budget, so the MaxComposeSlots preflight bounds it before anything renders.

**Expansion.** `sweep.Expand` builds the strategy and proposes round 0 from an empty history — a function of the spec alone. The slot list is sized to the budget: round 0's slots render with real bodies and labels; every later slot is a placeholder rendered at the representative point (`sweep.Representative`: range midpoint u = ½, each list axis's first value) labelled `sample=<slot>`. Every adaptive label is `sample=<slot>_<pattern>`; duplicate proposals are accepted and evaluated, and the ordinal keeps labels unique. For a placeholder, `Labels[i]` is `""` and `Axes[i]` nil.

**Execution (phase 0).** An adaptive sweep always runs sweep-first (it binds even without a `from_sweep` fit): authored fits, then `runAdaptiveSweep` (`internal/service/compose_adaptive.go`). Each round is a barrier:

1. Its slots, in slot-index order, are installed at their fixed batch indices (top-level params inherited, model files reloaded, the label-resolved clone collision-checked — `PULSE_COMPOSE_LABEL_COLLISION` — and the rank's axes set).
2. The multiplicity plan is re-resolved, the round runs through the orchestrator's round runner (serial, or parallel with per-slot errors located `request <i>: …` exactly as the serial loop does), and its slot-local families fold.
3. Each slot's value is read by `sweep.Objective` (Rank's own rule, typed zero included; a refusing path stops the batch).

Slot indices are round-major, so `failed_indices`, `ran` masks, `RankEntry.Slot`, multiplicity and `result()` indices stay stable. Rows still emit only after every round.

**Failures.** A failed point is penalised and the search goes on: its response is a stub carrying only its label, the rank skips it, and the batch warns `PULSE_SLOT_FAILED` once, `details {slot_kind: "sweep", failed_indices (batch, ascending), first_error}`. A rank-excluded point (null / missing at `rank.by`) is penalised too, keeping its `PULSE_SWEEP_RANK_PATH` warning. Fail-fast (`ComposeParallel`) aborts at the failing round with the located error; Strict fails the batch with the slot's own located error. A done ctx is the batch's error, never a penalised point. A later round's render fault is its `PULSE_SWEEP_INVALID`; expansion narrows that to range values by rendering every list-axis value once up front (`Adaptive.probeListValues`), so predict and runtime give the same `PULSE_SWEEP_INVALID` (`details.slot` = the first placeholder).

**Strategy contract.** `Propose(round, history, limit)` returns 1..limit points (`Point{U, Index}`: range axes' unit coordinates in [0, 1], list axes' value indices). `history` is a fresh copy ordered by slot: `Observation{Slot, Round, Point, Loss, Penalised}`, `Loss` the value to MINIMISE (negated under rank order `desc`), a penalised entry at the worst unpenalised loss of that history (0 while none), recomputed every round. Proposals must be bit-identical on every arch (`float64(x*y)` barriers, `linalg/detmath`, seeded raw-word PCG draws, deterministic tie-breaks). A malformed batch is `PROCESSING_INTERNAL` naming mode and round. The test-only strategy `internal/sweep/sweeptest` (mode `test_fixed`) guards the barrier and is imported by test files only.

**Predict.** `sweepSummary` reports `expanded_count` = budget, `adaptive: true`, `rng_seed`, a range axis's `count` = budget, and `labels` with round 0's real labels and `""` (null on the wire) after. Every slot is judged statically (round 0 real, the rest representative). `result()`: `descx.AdaptiveStaticView` nils the placeholders before the optimize checks, so a read of a later round's slot is `PULSE_RESULT_INVALID` `slot_unknown` on both sides, while a read of a round-0 or explicit slot passes and runs after phase 0. No per-round trace is exposed.

## Mode `de`

`internal/sweep/de.go`: differential evolution, strategy **rand/1/bin** (Storn & Price; DEoptim strategy 1, SciPy `rand1bin`). Knobs ride `SweepSpec.DE` (`de {population, f, cr}`, each a nil-able pointer, gated with `budget`; `sweep.ResolveDE`): `population` 4..budget, default 10 × axes capped at the budget; `f` in (0, 2], default 0.8; `cr` in [0, 1], default 0.9. Refusals (shared by predict and runtime through `sweep.Validate`): `PULSE_SWEEP_INVALID` `de_population_invalid` / `de_population_over_budget` / `de_f_invalid` / `de_cr_invalid`; `de` under another mode `PULSE_SWEEP_MODE_MISMATCH` `de_without_de_mode`.

**Search.** Every axis is a unit coordinate: a range axis maps through `RangeValue` (`integer` / `log` honoured), a list axis takes ⌊u·L⌋ clipped into [0, L). Round 0 is a Latin hypercube of `population` points; each later round is one generation — per target i draw r1, r2, r3 distinct from i and each other and a crossover axis jrand, mutant `x[r1] + float64(F·(x[r2] − x[r3]))`, axis j crossing when its draw is below CR or j = jrand, then clipped into [0, 1]. Selection is synchronous after the round: a trial replaces its target when it is unpenalised and the target is penalised or the trial's loss is `<=` the target's. budget ÷ population rounds run; a remainder r is a final partial generation (targets 0..r−1). One PCG stream over the effective seed, raw words only, draw order: hypercube, then per trial r1, r2, r3, jrand, one crossover draw per axis.

**Proof.** `internal/sweep/de_test.go`; the SciPy oracle (`make reference-sweep-de`) pins the outcome, not the trajectory (different streams, and SciPy resamples out-of-bound trials): every seed within 1e-3 of the Rosenbrock optimum, medians within two decades.

## Mode `bo`

`internal/sweep/bo.go`: Bayesian optimisation over the `internal/gp` surrogate (Matérn-5/2 ARD, ML-II refit every round, seeded restarts) with **expected improvement** (scikit-optimize `gp_minimize`, `acq_func="EI"`). Knobs ride `SweepSpec.BO` (`bo {init, n_init, batch}`, each optional, gated with `budget`; `sweep.ResolveBO`): `init` `lhs` (default) or `random`; `n_init` 1..budget, default 2 × axes capped at the budget; `batch` 1..budget, default 1. Refusals (shared through `sweep.Validate`): `PULSE_SWEEP_INVALID` `bo_init_invalid` / `bo_n_init_invalid` / `bo_n_init_over_budget` / `bo_batch_invalid` / `bo_batch_over_budget`; `bo` under another mode `PULSE_SWEEP_MODE_MISMATCH` `bo_without_bo_mode`. A surrogate that cannot be fitted (a non-finite loss; every `gp:` error) is the run-time `PULSE_SWEEP_INVALID` `bo_surrogate_failed` (`details {mode, round, cause}`), never `PROCESSING_INTERNAL`.

**Search.** A range axis enters the surrogate as its unit coordinate; a list axis one-hot (`gp.Dim{Levels}`), proposed as index ⌊u·L⌋. Round 0 is the initial design (`n_init` points: lhs, or uniform draws under `random`). Each later round fits the GP to every observation (`Loss`, so `rank.order` holds; a penalised point at the worst loss), then proposes min(`batch`, budget left) points, each maximising EI = (y* − μ)·Φ(z) + σ·φ(z), z = (y* − μ)/σ, with no exploration margin, EI 0 where the latent variance is 0. Maximiser: `BOCandidates` Latin-hypercube candidates scored, the `BOPolish` best (ties: earlier) polished by SLSQP over the continuous coordinates (list indices held; −EI ÷ the losses' population SD; central-difference gradient), a polish winning only when strictly better. `batch > 1` fills by constant liar (cl_min): each pick joins at the lowest y and the GP is re-conditioned at the round's fitted hyperparameters; candidates are drawn once per round. Duplicates are accepted (CholeskyRidge jitter). One PCG stream, raw words only, draw order: the initial design, then per round one word seeding the GP fit and the candidate hypercube.

**Proof.** `internal/sweep/bo_test.go`; the scikit-optimize oracle (`make reference-sweep-bo`) pins the outcome on Branin over 20 seeds (every seed within 0.05 of the optimum value, medians within 0.005), and `TestBO_BeatsRandom` requires the median best to beat a same-budget `random` sweep.
