# Execution modes — Adaptive sweeps

Per-topic slice of the execution-modes reference. Index (Mode index + section map): `.claude/reference/execution-modes.md` — load it first, then only the slice(s) your engine work touches. The phase-0 schedule it runs inside is `execution-modes/compose.md` (Compose fits, sweep-bound fits).

## Adaptive sweeps (compose-sweep-2 E3-S2)

An **adaptive** sweep mode chooses each round's points from the ranked values of the rounds before. The executor is shared (`internal/sweep/adaptive.go`); a mode supplies only a `sweep.Strategy`, registered once from an `init` with `sweep.RegisterAdaptive(sweep.AdaptiveMode{Mode, Validate, New})`. `sweep.IsAdaptive` / `AdaptiveModes` read the registry, so predict (`internal/descriptor`), the runtime and the mode lists (`valid` on `mode_unknown`) see the same set. Gated by `capability:compose_sweep_adaptive` (depends on `compose_sweep` AND `compose_sweep_sampling`): hidden, `budget` is `PULSE_REQUEST_UNKNOWN_FIELD` and an adaptive mode the unknown-mode refusal (`sweep.NonAdaptiveModeRefusal`, `nestedSweepAdaptiveRefusal`), the `SweepMode` enum and the MCP `sweepSchema` (third variant, `nonAdaptiveSweepSchema`) drop them.

**Request shape.** `budget` (`SweepSpec.Budget`, `omitempty` — an existing spec's derived seed never moves) and `rank` are required: `PULSE_SWEEP_INVALID` `adaptive_requires_budget` / `budget_invalid` / `adaptive_requires_rank`. Refused under an adaptive mode (`PULSE_SWEEP_MODE_MISMATCH`): `samples` (`samples_under_adaptive`), `sweep.overlays` (`overlays_under_adaptive` — a per-slot overlay names slots whose labels are unknown until their round). `budget` under any other mode is `budget_without_adaptive`. An axis is a list axis (`values`) or a range axis (`range`, the sampling rules), never both (`values_and_range`), never neither (`values_empty`). `rng_seed` is allowed; `EffectiveSeed` seeds the strategy and is echoed as `sweep_seed`. `Count` = budget, so the MaxComposeSlots preflight bounds it before anything renders.

**Expansion.** `sweep.Expand` (`expandAdaptive`) builds the strategy (`StrategyConfig{Dims, Budget, Seed, Spec}`) and proposes round 0 from an empty history — a function of the spec alone. The slot list is sized to the budget: round 0's slots render with real bodies and labels; every later slot is a placeholder rendered at the representative point (`sweep.Representative`: range midpoint u = ½, each list axis's first value) labelled `sample=<slot>` (`PendingLabel`). Every adaptive label is `sample=<slot>_<pattern>` (`AdaptiveLabelPrefix` + the authored pattern or the default) — duplicate proposals are accepted and evaluated, the ordinal keeps labels unique. `Expansion.Adaptive` / `banner.Expansion.SweepAdaptive` carry the executor; `Labels[i]` is `""` and `Axes[i]` nil for a placeholder.

**Execution (phase 0).** An adaptive sweep always runs sweep-first (`newSweepBinding` binds even without a `from_sweep` fit): authored fits, then `runAdaptiveSweep` (`internal/service/compose_adaptive.go`) drives `Adaptive.Run`. Each round is a barrier: its slots, in slot-index order, are installed at their fixed batch indices (`installAdaptiveSlot`: top-level params inherited via `descx.InheritRequestParams`, the slot's model files reloaded into `composeModels.slots`, the label-resolved run clone collision-checked — `PULSE_COMPOSE_LABEL_COLLISION` — and the rank's axes set), the multiplicity plan re-resolved into the orchestrator's own variable, the round run through the orchestrator's `composeRoundRunner` (serial loop; parallel `launch` with per-slot errors handed back and cleared from `errs`, each located `request <i>: …` as the serial loop does), its slot-local families folded, then each slot's value read by `sweep.Objective` (Rank's own rule, typed zero included; a refusing path stops the batch). Slot indices are round-major, so `failed_indices`, `ran` masks, `RankEntry.Slot`, multiplicity and `result()` indices stay stable. Rows still emit only after every round (the stream writer reads the finished response).

**Failures.** A failed point is penalised and the search goes on: its response is a stub carrying only its label, the rank skips it (`withoutFailed`), and the batch warns `PULSE_SLOT_FAILED` once, `details {slot_kind: "sweep", failed_indices (batch, ascending), first_error}`. A rank-excluded point (null / missing at `rank.by`) is penalised too, keeping its `PULSE_SWEEP_RANK_PATH` warning, not listed. Fail-fast (`ComposeParallel`) aborts at the failing round with the pool's located error; Strict fails the batch with the slot's own located error. A done ctx is the batch's error, never a penalised point. A later round's render fault is returned as its `PULSE_SWEEP_INVALID`. Expansion narrows that to range values: `Adaptive.probeListValues` renders every list-axis value once (that value, every other axis at the representative) as slot `First` and refuses an undecodable one up front, so predict and the runtime give the same `PULSE_SWEEP_INVALID` (`details.slot` = the first placeholder); a sweep with no later round probes nothing.

**Strategy contract.** `Propose(round, history, limit)` returns 1..limit points (`Point{U, Index}`: range axes' unit coordinates in [0, 1], list axes' value indices). `history` is a fresh copy, ordered by slot: `Observation{Slot, Round, Point, Loss, Penalised}`, `Loss` the value to MINIMISE (negated under rank order `desc`), a penalised entry at the worst unpenalised loss of that history (0 while none), recomputed every round. Proposals must be bit-identical on every arch (`float64(x*y)` barriers, `linalg/detmath`, seeded raw-word PCG draws, deterministic tie-breaks). A malformed batch is `PROCESSING_INTERNAL` naming mode and round (`checkPoints`). Test-only strategy: `internal/sweep/sweeptest` (mode `test_fixed`, three points a round, guards the barrier itself) — imported by test files only.

**Predict.** `sweepSummary` reports `expanded_count` = budget, `adaptive: true`, `rng_seed`, a range axis's `count` = budget, and `labels` with round 0's real labels and `""` (null on the wire, `SweepSummary.MarshalJSON`) after. Every slot is judged statically (round 0 real, the rest representative). `result()` reads: `descx.AdaptiveStaticView` nils the placeholders before `OptimizeCheck` / `OptimizeRefusal`, so a read of a later round's slot is `PULSE_RESULT_INVALID` `slot_unknown` on both sides, and a read of a round-0 or explicit slot passes and runs after phase 0 (the result pre-phase skips slots phase 0 ran). No per-round trace is exposed. Parity: `compose_sweep_adaptive_test.go` (root), `internal/service/compose_adaptive_test.go`, `internal/descriptor/compose_sweep_adaptive_gate_test.go`, `internal/sweep/adaptive_test.go`.

## Mode `de` (compose-sweep-2 E3-S3)

`internal/sweep/de.go`, registered from its `init`: differential evolution, strategy **rand/1/bin** (Storn & Price; DEoptim strategy 1, SciPy `rand1bin`). Knobs ride `SweepSpec.DE` (`de {population, f, cr}`, every field a nil-able pointer, gated with `budget`; resolved by `sweep.ResolveDE`): `population` 4..budget, default 10 × axes capped at the budget; `f` in (0, 2], default 0.8; `cr` in [0, 1], default 0.9. Refusals (`validateDE`, shared by predict and the runtime through `sweep.Validate`): `PULSE_SWEEP_INVALID` `de_population_invalid` / `de_population_over_budget` / `de_f_invalid` / `de_cr_invalid`; `de` under another mode `PULSE_SWEEP_MODE_MISMATCH` `de_without_de_mode`.

**Search.** Every axis is a unit coordinate: a range axis maps through `RangeValue` (`integer` / `log` honoured), a list axis takes the rounded index ⌊u·L⌋ clipped into [0, L). Round 0 is a Latin hypercube of `population` points (the lhs draw); each later round is one generation — per target i the trial draws r1, r2, r3 distinct from i and each other and a crossover axis jrand, mutant `x[r1] + float64(F·(x[r2] − x[r3]))`, axis j crossing when its draw is below CR or j = jrand, then clipped into [0, 1]. Selection is synchronous after the round: a trial replaces its target when it is unpenalised and the target is penalised or the trial's loss is `<=` the target's. budget ÷ population rounds run; a remainder r is a final partial generation (targets 0..r−1). One PCG stream over the effective seed, raw words only, draw order: hypercube, then per trial r1, r2, r3, jrand, one crossover draw per axis.

**Proof.** `internal/sweep/de_test.go` (knobs, known optimum over every axis form, rounds 20/20/5, determinism per seed, penalised region, list probe); `de_oracle_heavy_test.go` against SciPy (`testdata/de_oracle.json`, `make reference-sweep-de`: trajectories cannot match — different streams, SciPy resamples out-of-bound trials — so the outcome is pinned: every seed within 1e-3 of the Rosenbrock optimum, medians within two decades); the `sweep.de(...)` figures in `internal/fingerprint`; root `TestComposeSweepDE_RunsInGenerations` and the de cases of `TestComposeSweepAdaptive_RefusalParity` / `_HiddenParity`.

## Mode `bo` (compose-sweep-2 E4-S2)

`internal/sweep/bo.go`, registered from its `init`: Bayesian optimisation over the `internal/gp` surrogate (Matérn-5/2 ARD, ML-II refit every round, seeded restarts) with **expected improvement** (scikit-optimize `gp_minimize`, `acq_func="EI"`). Knobs ride `SweepSpec.BO` (`bo {init, n_init, batch}`, each optional, gated with `budget`; resolved by `sweep.ResolveBO`): `init` `lhs` (default) or `random` (`types.SweepBOInit`); `n_init` 1..budget, default 2 × axes capped at the budget; `batch` 1..budget, default 1. Refusals (`validateBO`, shared by predict and the runtime through `sweep.Validate`): `PULSE_SWEEP_INVALID` `bo_init_invalid` / `bo_n_init_invalid` / `bo_n_init_over_budget` / `bo_batch_invalid` / `bo_batch_over_budget`; `bo` under another mode `PULSE_SWEEP_MODE_MISMATCH` `bo_without_bo_mode`. A surrogate that cannot be fitted (a non-finite loss; every `gp:` error) is the run-time `PULSE_SWEEP_INVALID` `bo_surrogate_failed` (`details {mode, round, cause}`), never `PROCESSING_INTERNAL`.

**Search.** A range axis enters the surrogate as its unit coordinate (`RangeValue` renders it, `integer` / `log` honoured); a list axis one-hot (`gp.Dim{Levels}`), proposed as index ⌊u·L⌋. Round 0 is the initial design (`n_init` points: the lhs draw, or uniform draws point by point under `random`). Each later round fits the GP to every observation (`Loss`, so `rank.order` holds; a penalised point at the worst loss), then proposes min(`batch`, budget left) points, each maximising EI = (y* − μ)·Φ(z) + σ·φ(z), z = (y* − μ)/σ, with no exploration margin (scale-invariant argmax), EI 0 where the latent variance is 0. Maximiser: `BOCandidates` (1000) Latin-hypercube candidates scored, the `BOPolish` (5) best (ties: earlier) polished by SLSQP over the continuous coordinates (list indices held; −EI ÷ the losses' population SD; central-difference gradient), a polish winning only when strictly better. `batch > 1` fills by constant liar (cl_min): each pick joins at the lowest y and the GP is re-conditioned at the round's fitted hyperparameters; candidates are drawn once per round. Duplicates are accepted (CholeskyRidge jitter). One PCG stream, raw words only, draw order: the initial design, then per round one word seeding the GP fit and the candidate hypercube.

**Proof.** `internal/sweep/bo_test.go` (knobs, known optimum incl. a list and an integer axis, rounds 4/4/2 and the defaults, determinism per seed at batch 1 and 3, constant-liar distinctness, desc ≡ negated asc, initial design, penalised region, EI closed form), `bo_fault_test.go` (the `gp:` mapping); `bo_oracle_heavy_test.go` against scikit-optimize (`testdata/bo_oracle.json`, `make reference-sweep-bo`: trajectories cannot match — different streams, L-BFGS-B polish — so the outcome is pinned on Branin over 20 seeds: every seed within 0.05 of the optimum value, medians within 0.005) and `TestBO_BeatsRandom` (median best below a same-budget `random` sweep's); the `sweep.bo(...)` figures in `internal/fingerprint`; root `TestComposeSweepBO_RunsInRounds` and the bo cases of `TestComposeSweepAdaptive_RefusalParity` / `_HiddenParity`.
