# Execution modes — Scalar-expression slots

Per-topic slice of `.claude/reference/execution-modes.md` (index). Load it before changing `internal/scalarslot`, any number-or-expression request slot, or predict's `unresolved_scalars`.

## Scalar-expression slots

**What a scalar slot is (library-gaps E1-S1, G11).** A request slot whose value is a JSON number or an expression string, evaluated ONCE before anything executes, never per record. Shipped slots: the scalar window params (Window params, below) and an optimize variable's `lower` / `upper` / `start` (`types.OptimizeBound`: `BoundValue`, `BoundParam` = the expression `"params.<name>"`, `BoundExpr`; `IsExpr` / `Expr`, and `IsParam` / `Param` only for exactly `params.<identifier>`). The wire round-trips byte for byte, so every `"params.x"` request and golden is unchanged; a blank string is a decode error, every other string an expression.

**The one evaluator, `internal/scalarslot`.** A no-execute leaf (`TestScalarSlot_ImportBoundary`: types, errors, `exprenv`, `exprident`, `model`, `coefcall`, `tablecall` only) that `internal/descriptor` and the runtime both import. `Env{Params, Fits, Tables, Extensions, Lookup}`; `Env.Declared()` is the placeholder `exprenv.Bound`. `Compile(src, kind, env, bound)` runs, in order: `exprenv.ParamsRefusal`; free identifiers ⊆ `params` (anything else → `ReasonInvalid` + `identifier`); `expr.Compile` over an EMPTY declared env plus `bound.Options()` (so an undeclared function fails compile, `ReasonInvalid` + `compile_error`); a numeric result type (`ReasonNotNumeric` + `result_type`); `coefcall.StaticRefusal` (literal `coef()` / `sweep_axis()`); `tablecall.Refusal`. `Program.Run()` evaluates with no env: a function's coded error is returned as `Refusal.Coded` UNCHANGED (a failed fit keeps Cause `model.ErrFitFailed`), any other fault `PROCESSING_RUNTIME`; a non-number `ReasonNotNumeric`; NaN / ±Inf `ReasonNotFinite` (`value` as a string); kind `Integer` also refuses a fraction or |v| > 2^53 (`ReasonNotInteger`). `Eval(src, kind, env, bound, run)` = Compile, then Run when `run` OR the program is `Static()` (calls none of `coef`, `sweep_axis`, `lookup`, `range_label`, an embedder function — `exprident.Callees`). A caller maps the slot-neutral reason under its own code and prefix and locates a `Coded` refusal keeping its code.

**Predict vs runtime.** A static judgement (predict, and the runtime's pre-fit `descx.OptimizeRefusal`) passes `Env.Declared()` and `run=false`: an expression over literals + params + built-ins is evaluated and range-checked exactly as a literal; one calling a request-bound function is compiled and checked but NOT run — `Value.Resolved` false, `Value.Reads` the functions — unless it reads only a loaded model (Loaded-model fold, below). Its range checks wait for the runtime, which passes the bound implementations and `run=true`. Predict reports such a slot under the dedicated field `unresolved_scalars [{path, expression, reads}]` (`descriptor.UnresolvedScalar`) — never a warning, never a refusal; a resolved slot is never listed.

**Loaded-model fold (U67 E5-S1, #708 part 1).** `Env.Loaded *model.Set` (nil folds none) is the set a static judgement may READ: a request's own loaded `models` / `populations` entries, whose figures exist before anything runs. `Declared()` then binds `coef()` / `sweep_axis()` / `response()` as `model.Folding` over the engine's own implementations (`model.CoefBuiltin` / `SweepAxisBuiltin` / `ResponseBuiltin` in `internal/model/builtins.go`, moved out of `internal/processing/expr_env_coef.go`; the engine binds the same three over its full set), and `Eval` with `run=false` RUNS a program whose request-bound reads are only those three (none an embedder shadows): a call naming a loaded fit returns the runtime's value or refusal; one naming any other fit returns `model.ErrNotFolded` and the slot stays unresolved. So predict resolves and range-checks the value, refusing with the runtime's code, message and details (intervals unavailable, kind mismatch, a computed term). Predict's transport: `loadedCatalog` / `predictModels` return a `loadedFitCatalog` (the signatures + the Set `(*model.Set)(nil).WithLoaded` binds); `windowScalarEnv` (windows, `AGG_CONSTANT`) reads it back through `loadedModels(opts.boundModels())`; PredictChain judges a stage's body over the stage's own catalog (`validateRequestBodyAt`, as ProcessChain binds it). Compose `fits`, registered populations, `lookup()` / `range_label()` / embedder functions and `result()` stay unresolved. Extension params (E5-S2) read the same env (`foldingScalarEnv`: Process / Compose slots through `resolveExtensionScalarsStatic`, a facet's filterers and their spec-only `Validate` view over the facet's catalog). Optimize (E5-S2): `optblock.Env.Fold` — set by predict's `descx.OptimizeCheck` AND the runtime's pre-fit `OptimizeRefusal` (E5-G1: a folded refusal fires before any fit on both sides, so a multi-fault batch reports the same first error; `Compile` still evaluates every value after the fits) — makes `CheckAll` bind the block's loaded files into a Set (`WithLoaded` over the block's `models`, as `runComposeOptimize` binds them) and judge with that env's own `Declared()`; ANY static caller setting `Env.Loaded` must pass `env.Declared()` as the bound, or a foldable read runs a placeholder (`PROCESSING_INTERNAL`). Gates: `TestScalarFold_*` (`internal/descriptor`), `TestEval_FoldsLoadedModels`, `TestWindowScalar_LoadedModelsFoldAtPredict`, `TestConstant_LoadedModelFoldsAtPredict`, `TestConstant_ChainStageModelFolds`, `TestExtensions_ParamsExpressionFold*`, `TestExtensions_SpecValidateSeesFoldedModelReads`, `TestOptimize_ExpressionBoundRefusalParity`, `TestOptimize_FoldedRefusalPrecedesFitFaults` (root).

**Optimize wiring.** `optblock.compile(…, run)`: `Compile` (runtime) runs every bound; `CheckAll` (static) returns `Checked{Loaded, Unresolved}`, `CheckLoaded` / `Check` wrap it. `bounds_crossed` / `start_out_of_bounds` run only when every value involved resolved. Reasons under `PULSE_OPTIMIZE_VARIABLE_INVALID`: `bound_` + the slot-neutral reason — `bound_invalid`, `bound_not_numeric`, `bound_not_finite` (a non-finite LITERAL too); `details.expression`, `details.param` for a bare params reference. Shared codes (`PULSE_PARAMS_UNDECLARED`, `PULSE_MODEL_*`, table codes) are located at the bound by `optblock.locate`, which keeps `Cause`. Runtime (`Service.solveOptimizeBlock`, both orchestrators): a failed-fit read in a bound fails the block ALONE with the fit's code (`optsolve.FailedFit`), as an objective read does; a runtime range refusal of a model-dependent value is fatal, the same code and reason predict gives a static one. `descx.OptimizeCheck` feeds `ComposeValidationResult.UnresolvedScalars` (a bound reading only the block's loaded `models` folds there — Loaded-model fold). Under a block's `posterior` the bounds and starts still read the posterior means: `Compile` runs them with the per-draw readers on the means (`drawView`, selection −1); only the objective and constraints are evaluated per draw.

**`result()` (E5-S1, G7).** `scalarslot.Env.Results` (a `resultcall.Catalog`, set only for an optimize block) puts `result(slot, aggregation)` in reach — declared, a request-bound read (`unresolved_scalars` `reads: ["result"]`), its literal slot and aggregation judged by `resultcall.Refusal`; with it nil (every other scalar slot) a call is `PULSE_RESULT_INVALID` `out_of_scope`, checked BEFORE the compile so it is never an undeclared-function error. Schedule and rules: `.claude/reference/execution-modes/compose.md` (Result pre-phase).

**Registration.** `internal/exprslots` lists the bound slots (`SlotOptimizeBound`, `Scalar: true`, owner `OptimizeVariable`; `TestTemplateExprSplice_SlotsCoverRequestRoots` accepts a `json.Unmarshaler` owner field for a `Scalar` slot), so a template `{{token}}` in a bound string is `PULSE_TEMPLATE_EXPR_SPLICE`. The reads walker (`request_reads.go` `optimizeBounds`) parses a bound string with `exprreads` like any expression slot (params, funcs, identifiers as `vars`).

**Window params (E1-S2, G8).** `internal/windowscalar` (no-execute leaf: types, errors, `exprenv`, `scalarslot`; `TestWindowScalar_ImportBoundary`) lists the scalar params — `WIN_DISTRIBUTED_LAG` `decay` / `shape` / `scale` (Real) and `max_lag` (Integer), `WIN_EWMA` `alpha` / `decay` (Real); every other window param (`WIN_LAG` / `WIN_LEAD` `offset`, `WIN_PCT_CHANGE` / `WIN_DELTA` `periods`) stays literal and refuses a string as "malformed params". `windowscalar.Resolve(w, env, bound, run)` is the pre-resolution pass: each JSON-string scalar param → `scalarslot.Eval` → the number rewritten into a COPY of `w.Params` (a Real as its shortest round-trip decimal, so EWMA's exact-decimal `decay` reads an expression yielding 0.7 as the literal 0.7; an Integer as an integer literal); a window with no expression comes back as the same pointer. A refused or unresolved param holds the stand-in `-1` and lands in `Resolved.Deferred`; `windowparams.CheckDeferred(w, deferred)` (→ `distlagparams.ResolveDeferred` / `ewmaparams.ResolveDeferred`) keeps every presence rule and skips each rule reading a deferred value (its range; the kernel weights, finiteness and mass). Reasons under `PULSE_WINDOW_INVALID`: `param_invalid`, `param_not_numeric`, `param_not_finite`, `param_not_integer` (`details.param`, `expression`); a shared code keeps its code, message prefixed `params.<key>: `, `details.param`. `windowscalar.Refusal.Coded()` is the runtime's `TYPE: rule`, `.At(i)` predict's `window[i] (TYPE): rule`. Runtime: `processing.Processor.resolveWindowScalars` at the top of `applyWindows` (every record-row, materialize and post-window run), env = the registry's params, `p.models` as Fits, `ExprBoundWithModels(p.models)`, run=true; first refusal raised. Predict: `validateWindows` runs the static pass (`windowScalarEnv` over `opts.boundModels()`, its loaded models folded) before `CheckDeferred`, reporting each refusal; `windowUnresolved` fills `PredictResult.UnresolvedScalars` (`windows[j].params.<key>`, the item-expanded request) and `composeWindowUnresolved` appends the slots' (`requests[i].`, slot catalog) and request-bound fits' (`fits[i].request.`) to `ComposeValidationResult.UnresolvedScalars` after the optimize bounds. Bindings: a Compose slot sees the batch fits (sweep winner included), a request its `models`, materialize its `models`; a fit request only its own loads. A sweep slot whose window reads the fit its sweep binds is `PULSE_FIT_INVALID` `from_sweep_window_cycle` (`model.SweepScope.WindowReads` = `descx.SweepSlotWindowReadsFit`; `details.slot`, `window`, `param`), checked per slot after `from_sweep_cycle`. Manifest: `descriptor.Param.Expression`. `exprslots.SlotWindowParam` (`Scalar`, owner `Window`, tails `windows.params.<key>`). Gates: `TestResolve_*`, `TestLiteralParamsStayLiteral` (`internal/windowscalar`); `TestWindowScalar_*` (`internal/integration`); `TestComposeWindowScalar_*` (root).

**Extension params (E1-S3).** An embedder number param declaring `ParamMeta.Expression` is a scalar slot too: `internal/extscalar` is its pre-resolution pass (Real kind; reasons `param_*` under `PULSE_REQUEST_PARAM_INVALID`), run ahead of every extension factory, its unresolved entries appended after the windows' in `unresolved_scalars` (a facet's filterers in `FacetPredictResult.UnresolvedScalars`, at `filterers[i].params.<key>`). Wiring: `.claude/reference/architecture.md` (Extension surface).

**Constant aggregator (E2-S1, G1).** `AGG_CONSTANT` `params{type, value | expr}` — fieldless, one typed constant in every row, group, crosstab cell and margin. `internal/aggconst` (no-execute leaf: types, errors, encoding, `exprenv`, `paramread`, `scalarslot`, `temporal`; `TestAggConst_ImportBoundary`) is the ONE reading predict and runtime share: `CheckSlot` (no `field` / `vector` / `fields`, a `label`), `Parse` (exactly one of value / expr, unknown key refused), `Literal` (per type: integer in range, `u64` ≤ 2^53, `f32` rounded through float32, `packed_bool` a JSON bool, `date` `YYYY-MM-DD`, `datetime` RFC 3339 with offset in whole seconds, years 0001–9999, an exact decimal string, a non-empty label, distinct member labels ≤ the type's ceiling, 2–1024 finite numbers), `FromNumber` (an expression's value held to the same range — `expr_out_of_range`). `expr` is Real-kind and only for the numeric family (`u*`, `f*`, `packed_bool`, `date`, `datetime`); any other type is `expr_type_unsupported`. Reasons under `PROCESSING_CONFIG` (`details.reason`): `params_invalid`, `type_invalid`, `value_and_expr`, `value_missing`, `value_invalid`, `expr_type_unsupported`, `expr_out_of_range`, `field_not_accepted`, `label_missing`, and `expr_` + the slot-neutral reason; a shared code keeps its code at `<slot>.params.expr`. `aggconst.ResolveRequest` is the pre-resolution pass over aggregations, the crosstab cell / cells and margin aggregations, copy-on-write rewriting `expr` into the literal `value` (a request with none comes back as the same pointer). Runtime: `processing.ResolveExtensionScalars` runs it FIRST (every Process, crosstab arm, materialize and reduce path already call that), run=true; the factory reads only the literal and refuses a leftover `expr` as `PROCESSING_INTERNAL`. Predict: `validateConstantSlots` (static, `windowScalarEnv`) and `constantUnresolved` (`<slot>.params.expr`, after the windows' entries). Non-numeric constants carry no single number: refused as a sort / window / post-test input (`non_scalar`), an overlay or two-sample input, a chain-stage feed (`vectors.IsNonScalarSlot`) and a crosstab normalize (`PULSE_CROSSTAB_NORMALIZE_MAP_VALUED`). `exprslots.SlotConstantExpr` (`Scalar`, owner `Aggregation`). Gates: `TestConstant_*` (`internal/integration`), `TestLiteral_PerType`, `TestResolveRequest_*` (`internal/aggconst`).

**Adding a scalar slot.** Resolve the slot's raw value through `scalarslot.Eval` before the operator's own resolver (window params: a pre-resolution pass rewriting the params map, so per-operator range checks stay untouched); pick `Integer` for an integer slot; add its `exprslots` entry (`Scalar: true`) and reads-walker arm; report unresolved slots under `unresolved_scalars` with a request-rooted `path`; give every new reason `codeMetadata` prose under the slot's code; add a predict ≡ runtime test per value kind (literal, params, `coef()`, `sweep_axis()`).

Gates: `TestEval_*`, `TestRun_KeepsAFailedFitsCause`, `TestScalarSlot_ImportBoundary` (`internal/scalarslot`); `TestOptimize_ExpressionBounds`, `TestOptimize_RefusalsTable` (`internal/optblock`); `TestOptimize_ExpressionBounds`, `TestOptimize_ExpressionBoundRefusalParity`, `TestOptimize_BoundFailedFitFailsAlone`, `TestOptimize_SweepAxisBound` (root); `TestOptimize_BoundWire` (`types`); `TestTemplateExprSplice_Refused`, `TestRequestReads_RootKinds`.

**Inline model numbers (E3-S3, G2).** A `models` entry's `inline` body (Request, FacetRequest, OptimizeSpec `models`) is a model-file document whose numbers may be scalar expressions: `scalarslot.InlineNumber` (Real; `n_obs` Integer) over the request's normalized params and the zero `exprenv.Bound` — no `coef()` / `sweep_axis()` / `lookup()` / `range_label()` / embedder function, so an inline number is always static (never under `unresolved_scalars`) and no model reads another (no cycle). Reasons `inline_` + the slot-neutral reason under `PULSE_MODEL_REF_INVALID` (`details.field`). `exprslots.SlotInlineModelNumber` (`Scalar`, owner `ModelRef`, tails under `models.inline` with the `exprslots.Wildcard` key for a coefficient term). Long form: `.claude/reference/byte-layout/long-form-and-model-files.md`, its **Inline models** paragraph.
