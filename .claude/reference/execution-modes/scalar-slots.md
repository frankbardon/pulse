# Execution modes — Scalar-expression slots

Per-topic slice of `.claude/reference/execution-modes.md` (index). Load it before changing `internal/scalarslot`, any number-or-expression request slot, or predict's `unresolved_scalars`.

## Scalar-expression slots

**What a scalar slot is (library-gaps E1-S1, G11).** A request slot whose value is a JSON number or an expression string, evaluated ONCE before anything executes, never per record. Shipped slots: the scalar window params (Window params, below) and an optimize variable's `lower` / `upper` / `start` (`types.OptimizeBound`: `BoundValue`, `BoundParam` = the expression `"params.<name>"`, `BoundExpr`; `IsExpr` / `Expr`, and `IsParam` / `Param` only for exactly `params.<identifier>`). The wire round-trips byte for byte, so every `"params.x"` request and golden is unchanged; a blank string is a decode error, every other string an expression.

**The one evaluator, `internal/scalarslot`.** A no-execute leaf (`TestScalarSlot_ImportBoundary`: types, errors, `exprenv`, `exprident`, `model`, `coefcall`, `tablecall` only) that `internal/descriptor` and the runtime both import. `Env{Params, Fits, Tables, Extensions, Lookup}`; `Env.Declared()` is the placeholder `exprenv.Bound`. `Compile(src, kind, env, bound)` runs, in order: `exprenv.ParamsRefusal`; free identifiers ⊆ `params` (anything else → `ReasonInvalid` + `identifier`); `expr.Compile` over an EMPTY declared env plus `bound.Options()` (so an undeclared function fails compile, `ReasonInvalid` + `compile_error`); a numeric result type (`ReasonNotNumeric` + `result_type`); `coefcall.StaticRefusal` (literal `coef()` / `sweep_axis()`); `tablecall.Refusal`. `Program.Run()` evaluates with no env: a function's coded error is returned as `Refusal.Coded` UNCHANGED (a failed fit keeps Cause `model.ErrFitFailed`), any other fault `PROCESSING_RUNTIME`; a non-number `ReasonNotNumeric`; NaN / ±Inf `ReasonNotFinite` (`value` as a string); kind `Integer` also refuses a fraction or |v| > 2^53 (`ReasonNotInteger`). `Eval(src, kind, env, bound, run)` = Compile, then Run when `run` OR the program is `Static()` (calls none of `coef`, `sweep_axis`, `lookup`, `range_label`, an embedder function — `exprident.Callees`). A caller maps the slot-neutral reason under its own code and prefix and locates a `Coded` refusal keeping its code.

**Predict vs runtime.** A static judgement (predict, and the runtime's pre-fit `descx.OptimizeRefusal`) passes `Env.Declared()` and `run=false`: an expression over literals + params + built-ins is evaluated and range-checked exactly as a literal; one calling a request-bound function is compiled and checked but NOT run — `Value.Resolved` false, `Value.Reads` the functions. Its range checks wait for the runtime, which passes the bound implementations and `run=true`. Predict reports such a slot under the dedicated field `unresolved_scalars [{path, expression, reads}]` (`descriptor.UnresolvedScalar`) — never a warning, never a refusal; a resolved slot is never listed.

**Optimize wiring.** `optblock.compile(…, run)`: `Compile` (runtime) runs every bound; `CheckAll` (static) returns `Checked{Loaded, Unresolved}`, `CheckLoaded` / `Check` wrap it. `bounds_crossed` / `start_out_of_bounds` run only when every value involved resolved. Reasons under `PULSE_OPTIMIZE_VARIABLE_INVALID`: `bound_` + the slot-neutral reason — `bound_invalid`, `bound_not_numeric`, `bound_not_finite` (a non-finite LITERAL too); `details.expression`, `details.param` for a bare params reference. Shared codes (`PULSE_PARAMS_UNDECLARED`, `PULSE_MODEL_*`, table codes) are located at the bound by `optblock.locate`, which keeps `Cause`. Runtime (`Service.solveOptimizeBlock`, both orchestrators): a failed-fit read in a bound fails the block ALONE with the fit's code (`optsolve.FailedFit`), as an objective read does; a runtime range refusal of a model-dependent value is fatal, the same code and reason predict gives a static one. `descx.OptimizeCheck` feeds `ComposeValidationResult.UnresolvedScalars`.

**Registration.** `internal/exprslots` lists the bound slots (`SlotOptimizeBound`, `Scalar: true`, owner `OptimizeVariable`; `TestTemplateExprSplice_SlotsCoverRequestRoots` accepts a `json.Unmarshaler` owner field for a `Scalar` slot), so a template `{{token}}` in a bound string is `PULSE_TEMPLATE_EXPR_SPLICE`. The reads walker (`request_reads.go` `optimizeBounds`) parses a bound string with `exprreads` like any expression slot (params, funcs, identifiers as `vars`).

**Window params (E1-S2, G8).** `internal/windowscalar` (no-execute leaf: types, errors, `exprenv`, `scalarslot`; `TestWindowScalar_ImportBoundary`) lists the scalar params — `WIN_DISTRIBUTED_LAG` `decay` / `shape` / `scale` (Real) and `max_lag` (Integer), `WIN_EWMA` `alpha` / `decay` (Real); every other window param (`WIN_LAG` / `WIN_LEAD` `offset`, `WIN_PCT_CHANGE` / `WIN_DELTA` `periods`) stays literal and refuses a string as "malformed params". `windowscalar.Resolve(w, env, bound, run)` is the pre-resolution pass: each JSON-string scalar param → `scalarslot.Eval` → the number rewritten into a COPY of `w.Params` (a Real as its shortest round-trip decimal, so EWMA's exact-decimal `decay` reads an expression yielding 0.7 as the literal 0.7; an Integer as an integer literal); a window with no expression comes back as the same pointer. A refused or unresolved param holds the stand-in `-1` and lands in `Resolved.Deferred`; `windowparams.CheckDeferred(w, deferred)` (→ `distlagparams.ResolveDeferred` / `ewmaparams.ResolveDeferred`) keeps every presence rule and skips each rule reading a deferred value (its range; the kernel weights, finiteness and mass). Reasons under `PULSE_WINDOW_INVALID`: `param_invalid`, `param_not_numeric`, `param_not_finite`, `param_not_integer` (`details.param`, `expression`); a shared code keeps its code, message prefixed `params.<key>: `, `details.param`. `windowscalar.Refusal.Coded()` is the runtime's `TYPE: rule`, `.At(i)` predict's `window[i] (TYPE): rule`. Runtime: `processing.Processor.resolveWindowScalars` at the top of `applyWindows` (every record-row, materialize and post-window run), env = the registry's params, `p.models` as Fits, `ExprBoundWithModels(p.models)`, run=true; first refusal raised. Predict: `validateWindows` runs the static pass (`windowScalarEnv` over `opts.boundModels()`) before `CheckDeferred`, reporting each refusal; `windowUnresolved` fills `PredictResult.UnresolvedScalars` (`windows[j].params.<key>`, the item-expanded request) and `composeWindowUnresolved` appends the slots' (`requests[i].`, slot catalog) and request-bound fits' (`fits[i].request.`) to `ComposeValidationResult.UnresolvedScalars` after the optimize bounds. Bindings: a Compose slot sees the batch fits (sweep winner included), a request its `models`, materialize its `models`; a fit request only its own loads. A sweep slot whose window reads the fit its sweep binds is `PULSE_FIT_INVALID` `from_sweep_window_cycle` (`model.SweepScope.WindowReads` = `descx.SweepSlotWindowReadsFit`; `details.slot`, `window`, `param`), checked per slot after `from_sweep_cycle`. Manifest: `descriptor.Param.Expression`. `exprslots.SlotWindowParam` (`Scalar`, owner `Window`, tails `windows.params.<key>`). Gates: `TestResolve_*`, `TestLiteralParamsStayLiteral` (`internal/windowscalar`); `TestWindowScalar_*` (`internal/integration`); `TestComposeWindowScalar_*` (root).

**Extension params (E1-S3).** An embedder number param declaring `ParamMeta.Expression` is a scalar slot too: `internal/extscalar` is its pre-resolution pass (Real kind; reasons `param_*` under `PULSE_REQUEST_PARAM_INVALID`), run ahead of every extension factory, its unresolved entries appended after the windows' in `unresolved_scalars`. Wiring: `.claude/reference/architecture.md` (Extension surface).

**Adding a scalar slot.** Resolve the slot's raw value through `scalarslot.Eval` before the operator's own resolver (window params: a pre-resolution pass rewriting the params map, so per-operator range checks stay untouched); pick `Integer` for an integer slot; add its `exprslots` entry (`Scalar: true`) and reads-walker arm; report unresolved slots under `unresolved_scalars` with a request-rooted `path`; give every new reason `codeMetadata` prose under the slot's code; add a predict ≡ runtime test per value kind (literal, params, `coef()`, `sweep_axis()`).

Gates: `TestEval_*`, `TestRun_KeepsAFailedFitsCause`, `TestScalarSlot_ImportBoundary` (`internal/scalarslot`); `TestOptimize_ExpressionBounds`, `TestOptimize_RefusalsTable` (`internal/optblock`); `TestOptimize_ExpressionBounds`, `TestOptimize_ExpressionBoundRefusalParity`, `TestOptimize_BoundFailedFitFailsAlone`, `TestOptimize_SweepAxisBound` (root); `TestOptimize_BoundWire` (`types`); `TestTemplateExprSplice_Refused`, `TestRequestReads_RootKinds`.
