# Execution modes — Scalar-expression slots

Per-topic slice of `.claude/reference/execution-modes.md` (index). Load it before changing `internal/scalarslot`, any number-or-expression request slot, or predict's `unresolved_scalars`.

## Scalar-expression slots

**What a scalar slot is.** A request slot whose value is a JSON number or an expression string, evaluated ONCE before anything executes, never per record. `internal/exprslots` is the list of slots (entries with `Scalar: true`); the families are optimize bounds, scalar window params, expression-flagged extension params, `AGG_CONSTANT` `expr` and inline model numbers. For an optimize bound (`types.OptimizeBound`) `IsParam` / `Param` are true only for exactly `params.<identifier>`; the wire round-trips byte for byte. A blank string is a decode error; every other string is an expression.

**The one evaluator, `internal/scalarslot`.** A no-execute leaf that `internal/descriptor` and the runtime both import (`TestScalarSlot_ImportBoundary` pins its imports). `Compile(src, kind, env, bound)` runs, in order: `exprenv.ParamsRefusal`; free identifiers ⊆ `params` (else `ReasonInvalid` + `identifier`); `expr.Compile` over an EMPTY declared env plus `bound.Options()` (an undeclared function fails compile, `ReasonInvalid` + `compile_error`); a numeric result type (`ReasonNotNumeric` + `result_type`); the literal `coef()` / `sweep_axis()` check; the table-call check. `Program.Run()`:

- a function's coded error is returned as `Refusal.Coded` UNCHANGED (a failed fit keeps Cause `model.ErrFitFailed`); any other fault is `PROCESSING_RUNTIME`;
- a non-number is `ReasonNotNumeric`; NaN / ±Inf `ReasonNotFinite` (`value` as a string); kind `Integer` also refuses a fraction or |v| > 2^53 (`ReasonNotInteger`).

`Eval(src, kind, env, bound, run)` = Compile, then Run when `run` OR the program is `Static()` (calls no request-bound function: `coef`, `sweep_axis`, `lookup`, `range_label`, an embedder function). A caller maps the slot-neutral reason under its own code and prefix, and locates a `Coded` refusal keeping its code.

**Predict vs runtime.** A static judgement (predict, and the runtime's pre-fit optimize refusal) passes `Env.Declared()` and `run=false`: an expression over literals + params + built-ins is evaluated and range-checked exactly as a literal; one calling a request-bound function is compiled and checked but NOT run — `Value.Resolved` false, `Value.Reads` the functions — unless it reads only a loaded model (below). Its range checks wait for the runtime, which passes the bound implementations and `run=true`. Predict reports such a slot under `unresolved_scalars [{path, expression, reads}]` (`descriptor.UnresolvedScalar`) — never a warning, never a refusal; a resolved slot is never listed.

**Loaded-model fold.** `Env.Loaded *model.Set` (nil folds none) is what a static judgement may READ: the request's own loaded `models` / `populations` entries, whose figures exist before anything runs. `Declared()` then binds `coef()` / `sweep_axis()` / `response()` over the engine's own implementations (`internal/model/builtins.go`), and `Eval` with `run=false` RUNS a program whose request-bound reads are only those three (none shadowed by an embedder): a call naming a loaded fit returns the runtime's value or refusal; one naming any other fit returns `model.ErrNotFolded` and the slot stays unresolved. So predict resolves and range-checks the value, refusing with the runtime's code, message and details.

- Folded everywhere a scalar slot is judged statically: windows, `AGG_CONSTANT`, extension params (Process / Compose slots and a facet's filterers), optimize bounds, and each chain stage over its own catalog.
- Compose `fits`, registered populations, `lookup()` / `range_label()` / embedder functions and `result()` stay unresolved.
- Optimize: the fold runs in predict AND the runtime's pre-fit refusal, so a folded refusal fires before any fit on both sides and a multi-fault batch reports the same first error.
- **Any static caller setting `Env.Loaded` must pass `env.Declared()` as the bound**, or a foldable read runs a placeholder (`PROCESSING_INTERNAL`).
- Pinned by `TestScalarFold_*` and `TestOptimize_FoldedRefusalPrecedesFitFaults`.

**Optimize wiring.** `optblock`: `Compile` (runtime) runs every bound; `CheckAll` (static) returns `Checked{Loaded, Unresolved}`. `bounds_crossed` / `start_out_of_bounds` run only when every value involved resolved. Reasons under `PULSE_OPTIMIZE_VARIABLE_INVALID`: `bound_` + the slot-neutral reason (`bound_invalid`, `bound_not_numeric`, `bound_not_finite` — a non-finite LITERAL too); `details.expression`, and `details.param` for a bare params reference. Shared codes (`PULSE_PARAMS_UNDECLARED`, `PULSE_MODEL_*`, table codes) are located at the bound, keeping `Cause`. At runtime a failed-fit read in a bound fails the block ALONE with the fit's code, as an objective read does; a runtime range refusal of a model-dependent value is fatal, with the same code and reason predict gives a static one. Under a block's `posterior` the bounds and starts read the posterior means; only the objective and constraints are evaluated per draw.

**`result()`.** `scalarslot.Env.Results` (set only for an optimize block) puts `result(slot, aggregation)` in reach — a request-bound read (`unresolved_scalars` `reads: ["result"]`), its literal slot and aggregation judged by `resultcall.Refusal`. With it nil (every other scalar slot) a call is `PULSE_RESULT_INVALID` `out_of_scope`, checked BEFORE the compile so it is never an undeclared-function error. Schedule and rules: `.claude/reference/execution-modes/compose.md` (Result pre-phase).

**Registration.** Each slot's `internal/exprslots` entry makes a template `{{token}}` in it `PULSE_TEMPLATE_EXPR_SPLICE`; the reads walker (`request_reads.go`) parses it like any expression slot.

**Window params.** `internal/windowscalar` (no-execute leaf) lists the scalar params — `WIN_DISTRIBUTED_LAG` `decay` / `shape` / `scale` (Real) and `max_lag` (Integer), `WIN_EWMA` `alpha` / `decay` (Real). Every other window param stays literal and refuses a string as "malformed params".

- `windowscalar.Resolve` is the pre-resolution pass: each JSON-string scalar param → `scalarslot.Eval` → the number written into a COPY of `w.Params` (a Real as its shortest round-trip decimal, so EWMA's exact-decimal `decay` reads an expression yielding 0.7 as the literal 0.7; an Integer as an integer literal). A window with no expression comes back as the same pointer.
- A refused or unresolved param holds the stand-in `-1` and is listed as deferred; `windowparams.CheckDeferred` keeps every presence rule and skips each rule reading a deferred value.
- Reasons under `PULSE_WINDOW_INVALID`: `param_invalid`, `param_not_numeric`, `param_not_finite`, `param_not_integer` (`details.param`, `expression`); a shared code keeps its code, message prefixed `params.<key>: `.
- Runtime resolves at the top of `applyWindows` (every record-row, materialize and post-window run), run=true, first refusal raised. Predict runs the static pass before `CheckDeferred` and lists unresolved params at `windows[j].params.<key>` (Compose: `requests[i].…` and `fits[i].request.…`).
- Bindings: a Compose slot sees the batch fits (sweep winner included), a request its `models`, materialize its `models`, a fit request only its own loads. A sweep slot whose window reads the fit its sweep binds is `PULSE_FIT_INVALID` `from_sweep_window_cycle` (`details.slot`, `window`, `param`).
- Manifest: `descriptor.Param.Expression`.

**Extension params.** An embedder number param declaring `ParamMeta.Expression` is a scalar slot too: `internal/extscalar` is its pre-resolution pass (Real kind; reasons `param_*` under `PULSE_REQUEST_PARAM_INVALID`), run ahead of every extension factory; its unresolved entries follow the windows' in `unresolved_scalars` (a facet's at `filterers[i].params.<key>`). Wiring: `.claude/reference/architecture.md` (Extension surface).

**Constant aggregator.** `AGG_CONSTANT` `params{type, value | expr}` — fieldless, one typed constant in every row, group, crosstab cell and margin. `internal/aggconst` (no-execute leaf) is the ONE reading predict and runtime share: `CheckSlot` (no `field` / `vector` / `fields`; a `label` required), `Parse` (exactly one of value / expr), `Literal` (the per-type literal rules), `FromNumber` (an expression's value held to the same range — `expr_out_of_range`).

- `expr` is Real-kind and only for the numeric family (`u*`, `f*`, `packed_bool`, `date`, `datetime`); any other type is `expr_type_unsupported`. Reasons under `PROCESSING_CONFIG` (`details.reason`) are the `aggconst` reason constants plus `expr_` + the slot-neutral reason; a shared code keeps its code at `<slot>.params.expr`.
- `aggconst.ResolveRequest` copy-on-write rewrites `expr` into the literal `value` over aggregations, crosstab cell / cells and margin aggregations. Runtime runs it FIRST inside `processing.ResolveExtensionScalars`; the factory reads only the literal and refuses a leftover `expr` as `PROCESSING_INTERNAL`. Predict lists an unresolved one at `<slot>.params.expr`.
- Non-numeric constants carry no single number: refused as a sort / window / post-test input (`non_scalar`), an overlay or two-sample input, a chain-stage feed (`vectors.IsNonScalarSlot`) and a crosstab normalize (`PULSE_CROSSTAB_NORMALIZE_MAP_VALUED`).

**Adding a scalar slot.** Resolve the slot's raw value through `scalarslot.Eval` before the operator's own resolver (a pre-resolution pass rewriting the params map, so per-operator range checks stay untouched); pick `Integer` for an integer slot; add its `exprslots` entry (`Scalar: true`) and reads-walker arm; report unresolved slots under `unresolved_scalars` with a request-rooted `path`; give every new reason `codeMetadata` prose under the slot's code; add a predict ≡ runtime test per value kind (literal, params, `coef()`, `sweep_axis()`).

**Inline model numbers.** A `models` entry's `inline` body is a model-file document whose numbers may be scalar expressions: `scalarslot.InlineNumber` (Real; `n_obs` Integer) over the request's normalized params and the zero `exprenv.Bound` — no request-bound function, so an inline number is always static (never under `unresolved_scalars`) and no model reads another (no cycle). Reasons `inline_` + the slot-neutral reason under `PULSE_MODEL_REF_INVALID` (`details.field`). Long form: `.claude/reference/byte-layout/long-form-and-model-files.md`, its **Inline models** paragraph.
