## Overlays — payload parts, MATRIX_RESULT host and the matrix kinds

Continues the `## Overlays` section of `.claude/reference/execution-modes/overlays.md` (Contributor wiring). The paired-flow kinds (MARKOV, SYMMETRY, RETENTION) are in `.claude/reference/execution-modes/overlays-flow-kinds.md`.

- **Parity overlays — Welford triple.** The Compose t / z kinds (cell, vs-ref) read `{n, mean, variance}` from `Response.Components.Crosstab.CellComponents[r][c]`, so the cell aggregator must emit that triple; with no triple at the coordinate they fall back to `params` (`variance_*`, `sample_size_*`).
- **Payload parts.** `types.OverlayPayload.Parts map[string]*OverlayPayload` (`parts`, `omitempty`) carries a multi-output kind's named secondary payloads beside the primary — one spec, one layer (a second series field or two-layer emission would break the fold, `return` and multiplicity keying).
  - A part is a plain scalar / series / matrix payload and never nests. **Every overlay dispatcher must call `overlayhost.PartsRefusal` right after a handler returns**; a nested, nil, unnamed or shapeless part is `PROCESSING_INTERNAL` (a handler fault, not a caller one). The payload schema's per-part definition omits `parts`.
  - A points × dimensions part keys its columns with `overlayhost.DimAxisKeys(n)` (`["dim_1"]` …).
  - `return` needs no part-specific code: `overlays[*].payload.parts.<part>` steps through a map like any other.
  - Export: NDJSON / Arrow / Parquet marshal the layer, parts included; the Excel writer carries the primary only and raises `PULSE_OVERLAY_EXPORT_PARTS_DROPPED` (details `layer_count`, `layer_names`, `parts`); CSV / TSV / SPSS drop the whole layer.
  - **Declared in the manifest:** `OverlayCapability.Parts` (`descriptor.OverlayPart{name, shape, when}`) is derived from the one `overlayPartShapes` table in `internal/descriptor`; the Interpretation resolver reads the same table, skipping a templated name (`step_<n>`), which only the manifest lists. `when` states a conditional part's condition; a kind without parts has no key.
- **`OVERLAY_STD_RESIDUAL`.** MATRIX (crosstab) host, scope `cell`, implicit-margin. Reads the host through the shared contingency-table reader (the `OVERLAY_CHISQ_MATRIX` table: absent cell = observed 0, totals recomputed from the cells, < 2×2 or zero grand total `PULSE_OVERLAY_REF_INCOMPATIBLE_WITH_SHAPE`, probability host scaled to its Kish n_eff) and emits the Haberman residual `(O − E) / sqrt(E (1 − r/N) (1 − c/N))` as the primary MATRIX, `parts.expected` and `parts.p` (two-sided normal) on the host coordinates. Every coordinate is present; a non-positive variance term (E = 0, or a row / column holding the whole table) is NaN → `null`; any E < 5 raises one `PULSE_OVERLAY_EXPECTED_LOW` `{kind, low_expected_cells, zero_expected_cells, expected_min}`. It joins the host-floor scaling (components-disabled probability refusal) and the inferential Level / Within gate. Multiplicity reads `parts.p` but writes `payload.p_adjusted` / `significant_adjusted` like every MATRIX p-site, and `row` / `column` key off the part's grid. Oracle: `chisq.test()$stdres` (`scripts/reference/gen_std_residual.R`).
- **MATRIX_RESULT host.** A third Process host shape beside MATRIX and SERIES: `overlayhost.ShapeMatrixResult` (`"matrix_result"`, a host-judging value only), the `Response.Matrices` of a request carrying `Request.Matrices` and no crosstab.
  - `overlayhost.JudgedShape(authored, matrices, route)` is the shape every gate judges a `Request.Overlays` spec by: a MATRIX_RESULT kind on a matrices request, and EVERY kind over a SCALAR authored shape that carries matrices, is judged against MATRIX_RESULT; a SERIES kind on a grouped request that also carries matrices keeps SERIES. Mismatches raise the shared `ShapeRefusal` (`shapes: ["matrix_result"]`). `Crosstab + Matrices` stays refused, so a request never carries both.
  - The reference arm is `OverlayRef.Matrix {name}`, naming a `Request.Matrices` spec by `EffectiveName`; the overlay reads EVERY group bucket of that spec.
  - Shared refusals (`overlayhost.MatrixResultRefusal`), in order: Ref.Matrix unset / empty or another arm populated (`PULSE_OVERLAY_REF_INCOMPATIBLE_WITH_SHAPE`), scope other than `matrix` (`_SCOPE_UNSUPPORTED`), non-zero Level / Within (`_LEVEL_OUT_OF_RANGE`), any params (`_PARAM_MISSING`), an unknown name (`PULSE_OVERLAY_REFERENCE_UNKNOWN`, `which: "matrix"`, `name`, `matrices`), no `Request.Groups` (`PULSE_OVERLAY_GROUPS_REQUIRED`, `{index, kind, name}`).
  - Reach: a process request and a Compose slot's own `Request.Overlays`. The Compose-host, chain and facet slots refuse the kind (hosts `["request"]`), and a ProcessChain stage's own overlays through the stage refusal (details `{index, kind, host: "chain", stage}`).
  - **Apply order: AFTER the multiplicity fold.** `processing.ApplyMatrixResultOverlays` runs right after `foldRequestMultiplicity`, so a handler reads every result as the caller receives it (`auxiliary.p_adjusted`, the `Multiplicity` echo). A Compose slot's pass is DEFERRED to just after `foldComposeMultiplicity`, before the sweep rank (`TestMatrixResultOverlays_RunAfterMultiplicityFold`).
  - The crosstab and SERIES dispatch loops skip a MATRIX_RESULT spec (its position stays a zero layer); the pass writes each layer at its spec's index, calls `PartsRefusal`, and promotes handler warnings to `Response.Warnings`. A request without one runs nothing — byte-identical. A computed one keeps `matrices` computed under a `return` that drops it. Feature edge: `capability:matrices`.
- **`OVERLAY_MATRIX_GROUP_SUMMARY`.** The first MATRIX_RESULT kind: scope `matrix`, descriptive (no p-site, no weight class), no params, buffered. Keys are the union of the buckets' `Primary` row / column keys in first-seen order (bucket order, then axis order); each bucket's `Primary` is expanded (`upper` → full, mirrored). Per cell over the buckets whose cell exists and is finite: `mean` = Σx / |G| summed in bucket order (UNWEIGHTED — every bucket counts once), `min`, `max`, `range` = max − min, `n_groups` = |G|. A cell with no contributing bucket is `null` in mean / min / max / range and 0 in `n_groups`; every cell is `present`. Primary MATRIX `mean`; parts `min`, `max`, `range`, `n_groups`. Default layer name `group_summary_<name>`.
- **`OVERLAY_CORRESPONDENCE`.** Simple CA (R `ca::ca`), MATRIX (crosstab) host, scope `matrix`, implicit-margin, descriptive (no p-site, no weight class: scale-invariant, so a weighted host's Σw table is read as is).
  - Cells: absent = 0; a known cell aggregation other than `AGG_COUNT` / `AGG_SUM`, or a negative / non-finite cell, is `PULSE_OVERLAY_NONNEGATIVE_REQUIRED`. Zero-total rows / columns are dropped with one `PULSE_OVERLAY_REF_ZERO` per axis `{kind, axis, dropped, dropped_keys, reason: "zero_margin"}`; < 2×2 kept is `PULSE_OVERLAY_REF_INCOMPATIBLE_WITH_SHAPE`.
  - `S = D_r^-1/2 (P − r cᵀ) D_c^-1/2` → `linalg.SVD`; K = min(r, c) − 1 inertias form the SERIES primary (`dim_k`, `share` / `cumulative_share` / `singular_value`), `Summary.Statistic` = Σ S² (χ²/n) with `dimensions`, `retained_share`, `share_dim_<k>`.
  - Parts on the KEPT keys × `DimAxisKeys(d)`: `row_` / `column_coordinates` (symmetric = both principal, `row_principal` = principal rows + standard columns, `column_principal` the mirror), `row_` / `column_contribution` (each dimension sums to 1), `row_` / `column_quality` (SERIES, Σ cos² over the retained dims). `row_` / `column_distance` (kept × kept): the chi-square profile distances `sqrt(Σ_j (O_ij/O_i· − O_kj/O_k·)² / c_j)` — full-space (independent of `dimensions` / `normalization`), symmetric bit for bit, diagonal exactly 0, always defined; Σ_i Σ_k m_i m_k d² = 2 × total inertia.
  - A dimension with σ ≤ `linalg.RankTolerance` has NaN coordinates / contributions; a profile on the centroid has NaN quality. Signs are `linalg.SVD`'s (V's dominant component positive), so R comparisons sign-normalize.
  - `dimensions` defaults to 2 CAPPED at K; an explicit value above K is `PULSE_OVERLAY_PARAM_MISSING` — predict judges it on the dictionary extent when known, runtime on the kept table (zero-margin drops can shrink it, a runtime-only refusal). Interpretation paths on a SERIES part are `parts.<part>.summary.<key>`.
- **`OVERLAY_RAKE`.** 2-D raking (iterative proportional fitting) of the crosstab to target margins: MATRIX (crosstab) host, scope `matrix`, implicit-margin, descriptive (no p-site, no weight class: a weighted host's Σw table is raked as is, and share targets scale to its Σw grand total). Read-only — the host payload is never written (`TestRake_DoesNotMutateHost`).
  - **Params** (`overlayhost.ParseRakeParams`, strict, `PULSE_OVERLAY_PARAM_MISSING`): `row_targets` / `col_targets` REQUIRED (non-empty key → finite ≥ 0 maps with a positive sum); `targets_as` `shares` (default: each axis ÷ its sum × the host grand total) | `counts` (as given; row and column totals differing by more than `tolerance` relative to the larger is `PULSE_OVERLAY_RAKE_TARGET_MISMATCH` reason `totals_differ`, params-only so predict and runtime alike); `max_iter` (default 100, 1–100,000, so one spec cannot ask for unbounded sweeps); `tolerance` (default 1e-8, in (0, 1)). Target sums run in sorted key order so both sides round alike.
  - **Keys.** A target key matches a host key by `overlayhost.RakeKeyName`; a mismatch either way is `PULSE_OVERLAY_RAKE_TARGET_MISMATCH` reason `keys` `{kind, reason, axis, target_only, host_only, index}` (row axis first) — refuse, never drop (a dropped key would mislabel the fit). Predict judges only target keys outside a single `GROUP_CATEGORY` axis's dictionary; a dictionary entry the records never hold is the runtime's call.
  - Cells: nonnegative refusals as CA; absent cell = 0; a zero grand total is `PULSE_OVERLAY_REF_INCOMPATIBLE_WITH_SHAPE`.
  - **Sweep:** rows with a positive total × target / total, then columns likewise; residual = max over both axes of `|margin − target| / target` (`|margin| / Σ targets` for a zero target); stop once residual ≤ `tolerance` or after `max_iter` sweeps. Every fitted cell is `obs · a_i · b_j`, so a structural zero stays zero and an all-zero row / column cannot reach a positive target.
  - Outputs: primary MATRIX fitted table (every cell present); part `factors` (fitted / observed, `null` where observed is 0); summary parameters `iterations`, `residual`, `converged` (1 / 0). A capped fit ships anyway with one `PULSE_OVERLAY_RAKE_NOT_CONVERGED` WARNING `{kind, iterations, residual, tolerance}` on `Response.Warnings`. Oracle: `stats::loglin` cross-checked against `survey::rake` (`scripts/reference/gen_rake.R`).

- **Spec refusals — one rule per host.** Each host's Ref / Scope contract is ONE function in `internal/overlayhost`, called by predict and by every runtime arm, so a bad spec refuses with one code, message and details (`index` included). The reason: when the runtime re-checked only part of it, a spec predict refused ran silently. Each host rule has a predict ≡ runtime parity test over every kind × fault × arm; find it with `git grep -n "func Test.*RefusalsMatchPredict"`.
  - *Crosstab* — `CrosstabSpecRefusal` over `specRules` (every MATRIX kind but `OVERLAY_FORMULA`: Ref empty for implicit-margin / pairwise kinds, else `Ref.Margin` with a known axis; plus its scope set). Predict: each validator first. Runtime: right after the shape refusal (fused + buffered crosstab, a Compose slot).
  - *SERIES* — `SeriesSpecRefusal` over `seriesRules` (every SERIES-host kind; `OVERLAY_SHARE_OF_TOTAL`'s SERIES dispatch adds details `host: "series"`). The kind's own Ref arm only — implicit-total kinds none, the prior pair `Ref.Prior` or none (`Lag` 0), rolling / YoY / baseline / sibling kinds their arm, required (sibling: `Field` then `Value` non-empty); EVERY Ref arm is judged. Scope `group`. Runtime: on a SERIES judged shape, before every payload guard (serial, parallel and empty-result tails); `Pulse.ApplySeriesOverlays` calls it too.
  - *Chain stages* — `descriptor.ChainStageOverlayRefusal` runs per stage, before the cohort opens, on predict-chain AND the runtime: the MATRIX_RESULT stage refusal, then the wrong-slot, wrong-shape and crosstab-or-SERIES spec refusal by the stage's authored shape, located by `details.stage`.
  - *FACET* — `FacetSpecRefusal`: any Ref arm but `Population`, `Population` unset, empty `Cohort`, a scope other than `group`, `Level` / `Within` ≠ 0 (`PULSE_OVERLAY_LEVEL_OUT_OF_RANGE`). Both sides run it after the wrong-slot refusal, before the host field.
  - *Compose host* — `ComposeSlotRefusals`: Reference empty / unknown (`PULSE_OVERLAY_REFERENCE_UNKNOWN`, alone), else no Targets, else each empty / unknown target (`PULSE_OVERLAY_TARGET_UNKNOWN`); details `{index, kind, which[, target_index][, slot_label]}`. Predict-compose reports every target refusal; the dispatcher raises the first. No scope rule.
  - *Whole-chain host* — `ResolveStageRef` (Ref / Target): Index and Name both set, neither on a Ref, an out-of-range Index, an unknown Name. No scope rule.
  - *SCALAR host* — a `Request.Overlays` host with no crosstab, no matrices and no grouped aggregations (ungrouped, or groups without aggregations) runs NO kind. `ScalarSpecRefusal` over `scalarRules` refuses every MATRIX / SERIES Process kind (the MATRIX_RESULT kind is `ShapeRefusal`'s): first the Ref / Scope table of the host the kind needs, then `HostRequiredRefusal` — `PULSE_OVERLAY_REF_INCOMPATIBLE_WITH_SHAPE` "requires a MATRIX host (Request.Crosstab); none present" `{index, kind[, axis]}` or "requires a SERIES host (grouped Process result: Request.Groups and Request.Aggregations non-empty, Request.Crosstab nil)" `{index, kind}`. Runtime: every arm (buffered, streaming routed buffered, shard-parallel, parallel decode, Compose slot, chain pre-pass). No kind is exempt.
  - *Compose slot* — PredictCompose judges a slot's own `Request.Overlays` with the Request-host rules above, located `details.request` (`predict-inspect.md`).
