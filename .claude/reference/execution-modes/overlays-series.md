# Execution modes — overlays: the grouped-Process SERIES host

Per-topic slice of the execution-modes reference. Index (Mode index + section map): `.claude/reference/execution-modes.md` — load it first, then only the slice(s) your engine work touches.

## Overlays — SERIES host (measure, partitions, FORMULA, rolling windows)

Continues the `## Overlays` section of `.claude/reference/execution-modes/overlays.md`.

- **Series measure (`params.field`).** Every process-host series kind that scores one aggregation (`internal/seriesfield.Kinds` is the list) reads `params.field`, an aggregation OUTPUT LABEL (`types.AggregationLabelOf`: explicit `Label`, else `TYPE_field`); absent or empty scores `Aggregations[0]`. `seriesfield.Resolve` runs once per spec and the host is built per distinct scored column, so the buffered, streaming and parallel tails agree. Predict runs the same `Resolve` on the defaults-resolved request: an unknown label or non-string field is `PULSE_OVERLAY_FIELD_UNKNOWN`, Details `{index, kind, field, available}`, identical on both sides. The scored label is not echoed on the wire (the default is documented instead). `Pulse.ApplySeriesOverlays` (caller-held points) has no aggregation and ignores the param. An extension kind joins this reading and the partition reading only by declaring `HonoursField` / `HonoursPartitionBy` (`.claude/reference/architecture/extension-models.md`).
  - **Element columns.** `params.field` may name an expanded element column `<label>[<element label>]` of a `params.expand` vector aggregation on all three hosts (Process, Compose, chain). `seriesfield.Columns` lists each aggregation's columns — predict over the schema the slot executes over, the runtime from the same schema — read only for a bracketed name. An element column is never `array_valued` (the bare label still is); an element the slot does not write is `PULSE_OVERLAY_FIELD_UNKNOWN`, its `available` listing every element column. A two-sample vs-ref kind reads an element as a bare mean (params triple required, `label` the column).
  - **A NaN host value is MISSING** on all three hosts (an unanswered element, or any undefined aggregate figure): the entry keeps its key but carries no `statistic` (absent, never `null`), raises no warning and stays out of the summary count. On the Process host it never poisons a `_TOTAL` and a `_PRIOR` kind compares across the gap; on a Compose / chain pair either side's NaN skips the pair before any kernel, so no spurious `PULSE_OVERLAY_REF_ZERO`. A `null` statistic is reserved for a figure the kind computed and found undefined (zero reference, degenerate test). Gate: `TestOverlayHosts_UndefinedValueIsMissing`.
- **Series partitions (`params.partition_by`).** With two or more groupers the grouped-Process host is the composite rows; every kind in `internal/seriespartition.Kinds` runs once per PARTITION — the rows sharing the first `depth` key elements. `seriespartition.Depth` is the one reading for predict and runtime: absent / null = every key but the last (one grouper ⇒ 0), an explicit list must be a LEADING PREFIX of the group key columns, `[]` = 0; anything else is `PULSE_OVERLAY_PARTITION_INVALID`, Details `{index, kind, partition_by, groups, reason, field}`, identical on both sides.
  - **Partition by KEY EQUALITY on the prefix, never contiguity** — a user `sort` can interleave buckets. The UNCHANGED handler runs on each sub-host (rows in host order, full key tuples) and the results merge: entries back on their host ordinals; summary Min / Max widen, Count sums, other fields the first partition's; warnings one per code (first raiser's message and Details, `group_count` restated as the host's, `partitions` = raising count). One partition runs the handler on the host itself, byte-identical.
  - Every tail (buffered, streaming, parallel) folds the finished host through the same hook, so streaming needs no change. `seriespartition.Partition` / `RowKeys` / `KeyColumns` are the reusable split for any consumer of composite rows by a key prefix.
  - The host keys each row on `vectors.GroupKeyField` (a vector-input grouper with no `Field` keys on `<TYPE>_<first field>`). A `_TOTAL` kind's total, or mean and SD, is therefore the partition's own; `partition_by: []` restores the grand total.
  - Predict adds `PULSE_ADVISORY_SERIES_AXIS_NOT_DATE` on an ordered kind whose implicit series axis (the last grouper) is not date-family (`predict-inspect.md`, Advisories).
- **YoY partitions.** `OVERLAY_YOY` is not a prefix kind: `seriespartition.YoY` (runtime and predict alike) requires EXACTLY ONE date grouper anywhere in `groups` and partitions on every OTHER key index (key equality on arbitrary indices). Shared refusals: a single non-date grouper is `{index, kind, host_grouper, required}`; zero or 2+ date groupers among N ≥ 2 are `PULSE_OVERLAY_REF_INCOMPATIBLE_WITH_SHAPE` `{index, kind, groupers, date_groupers, required}`; an explicit `partition_by` must name exactly the non-date columns in any order, else `PULSE_OVERLAY_PARTITION_INVALID` (`reason` `not_string_list` / `unknown_field` / `not_non_date_keys`). Each sub-host is PROJECTED onto the date key so the unchanged single-date handler runs inside each segment; the runner restores every entry's full composite key. The `frequency` fallback reads `seriespartition.DateGrouper` (wherever it sits). YoY stays outside `Ordered` and the series-axis advisory (its axis is the date grouper by construction). Gate: `TestMultiGrouper_YoYPerPartition`.
- **SERIES FORMULA.** `OVERLAY_FORMULA` on a grouped Process (groups + aggregations, no crosstab) runs once per host row (`internal/processing/overlay_formula_series.go`). Namespace: `value` (the scored aggregation — `params.field` applies), `total` (sum of the partition's present values), `prior` (the nearest earlier PRESENT row, NaN on the first — the Compose SERIES host's read), `baseline` (only with `params.baseline_position`, a 0-based row of the partition; NaN when that row has no value). With N ≥ 2 groupers none of these crosses a partition. A row with no value emits an entry with no statistic; a non-finite result stays in the payload (null) and out of `summary.count`; no `Baseline`.
  - Refusals, in predict's order and identical on both sides: `overlayhost.SeriesSpecRefusal` (empty `Ref`, scope `group`, details `host: "series"`), then `formulaident.RequestSpecRefusal` (no usable formula is `PULSE_OVERLAY_PARAM_MISSING {index, kind, param: "formula", reason}` — the rule of EVERY FORMULA arm; `PARSE_ERROR`; `total()`; vector built-ins; a bad `baseline_position` → `PULSE_OVERLAY_LEVEL_OUT_OF_RANGE`; unknown identifier → `INVALID_IDENT`), then the field / partition reads.
  - A `baseline_position` at or past a partition's length is `PULSE_OVERLAY_REF_UNKNOWN {index, kind, baseline_position, series_length}`. Predict raises it too when every in-partition grouper is a `GROUP_CATEGORY` over a categorical field (the bound is the product of dictionary sizes), on a spec no other rule refused; a data-dependent axis stays runtime-only.
  - **Escape analysis:** the SERIES host hands the handler a COPY of the extension registry — the compile captures it, and a leaked registry heap-allocated the grouped tail's per-run state on every run (`TestStreamingGrouped_SingleGrouperAllocCeiling`).
- **Rolling windows.** `rollingCarrier` (shared by `OVERLAY_INDEX_VS_ROLLING_MEAN` / `OVERLAY_ZSCORE_VS_ROLLING`) evicting the only value of a window-1 ring resets to the empty sample instead of dividing by `count - 1 == 0` (that NaN once nulled every row from the third on). Window 1 of the index equals `OVERLAY_INDEX_VS_PRIOR`. The floor is shared, `overlayhost.RollingWindowFloorRefusal`: `RollingWindowMin` is 1, or 2 for the z-score (a rolling sample SD over one point is undefined and would answer null at every row) — `PULSE_OVERLAY_LEVEL_OUT_OF_RANGE {kind, param, window, min}` (+ `index` in predict).
  - **Warm-up (`params.min_periods`).** `overlayhost.RollingMinPeriods` resolves it for predict and runtime: absent = the window, else an integer from `RollingWindowMin` to the window, otherwise `PULSE_OVERLAY_LEVEL_OUT_OF_RANGE {kind, param: "min_periods", min_periods, min, max}`. A present point gets a figure once the carrier holds `min_periods` present priors (absent points never count); before that `null`, no warning.
- **Prior-period tests.** `OVERLAY_T_VS_PRIOR` / `_Z_VS_PRIOR` / `_PROP_Z_VS_PRIOR` (`overlayhost.PriorTestKind`) test each period against the last present one (Ref `Prior`, lag 1) on TWO hosts: a grouped Process (SERIES) and a crosstab with NO column grouper (MATRIX, the rows of the implicit Total column; partitions are the leading row keys). Legs are read off components and run the pairwise kernels.
  - The first present period of each partition carries a NaN statistic (`null`) and NO `PValue`, so it is never a multiplicity member; a missing period keeps its key with no statistic and does not advance the carrier; a degenerate pair is NaN + one `PULSE_OVERLAY_REF_ZERO` per skip reason.
  - Shared refusals live in `internal/overlayhost/vs_prior.go` (predict calls them in the runtime's order): columns, multi-measure, Ref / Scope, Level / Within, measure type, normalized crosstab (proportion kind), components disabled.
  - Compute plan: a `return` keeps the scored aggregation's group components the legs read.
  - **Weighted** (`ClassAware`, both kinds): every leg reads N* = `sum_weights` (frequency) or `n_eff` (probability), and stamps NO `summary.parameters` weight keys (a partitioned layer merge would keep only the first partition's). Buffered (`Streamable() == false`).
