# Execution modes — Compose, fits and the result pre-phase

Per-topic slice of the execution-modes reference. Index (Mode index + section map): `.claude/reference/execution-modes.md` — load it first, then only the slice(s) your engine work touches.

## Compose fits

`ComposedRequest.Fits` (`[]types.FitSpec {name, request}`, gated by `capability:compose_fits`). Order inside `Service.compose` / `composeParallel`: sweep expansion → slot gate (`descx.SlotRefusal` also walks every fit request, located `details.fit`) → `model.CheckFits` (the one structural rule set, shared with `PredictCompose`: `PULSE_FIT_INVALID` reasons `name_missing` / `request_missing` / `regression_count` / `grouped`, then `PULSE_MODEL_NAME_COLLISION`) → the batch save + load pre-pass (`composeModelsPrepass`: `model.CheckComposeBatch` — every slot's save path, every save's uniqueness, every fit request's and slot's `models` entry against the fits' names — then every model file read; `PredictCompose` runs the same, so a refusal leaves nothing written) → multiplicity / `return` / labels → the fit pre-pass `runComposeFits` (`internal/service/compose_fits.go`) → slots → post-slot folds. Each fit runs as an ordinary standalone `Process` over `model.FitRequest` (a clone with `return` cleared, so a fit request's `return` can never skip the regression) under the Compose ctx BEFORE `withinCompose`, so a fit resolves its own multiplicity like a standalone request and never reads a slot's filters, features or weight. Serial Compose runs fits in order; `ComposeParallel` runs them concurrently on `MaxWorkers`, cancelling siblings on the first failure; either way the reported failure is the lowest-index fit (`failFastWinner`), its coded error kept with `details.fit` added (`descx.RefusalAt`). Results bind through `model.Bind` (predictor order = spec order, or the selection's retained predictors; full float64 coefficients, SE, vcov, family/link) into one `model.Set` (each Bound stamped `model.FitSource(i)`); `bindSlotModels` puts on every slot ctx that set plus the slot's own pre-loaded `models` (`Set.WithModels`), marked loaded (`withModelsBound`) so the slot's Process does not reload — sweep slots included, since the sweep expanded first. A fit request's Process gets its own loaded `models` alone. `internal/model` is a leaf (stdlib + types + errors, `TestModel_ImportBoundary`) so predict and the engine share the resolver (`Set.Lookup` → `PULSE_MODEL_UNKNOWN {name, available}`). `ComposedResponse.Fits` (map keyed by name) is nil without fits — byte-identical — and pinned outside the Compose `return` (`types/return_shape.go` `fitsKey`). The fits are not part of `--stream` output. Gates: `TestComposeFits_*` (`internal/service`, run-once counter, serial ≡ parallel bytes, refusals), `TestComposeFits_PredictRuntimeParity`, `TestHiddenComposeFits_RefusedAsUnknownField` (root), `TestCheckFits` (`internal/model`).

**A fit that fails on its data fails alone (U49 E1-S3).** A fit request whose regression or MAT_* battery comes back as a failed slot (`internal/slotfail`) is not a batch failure: `runComposeFits` keeps its `Fits[name]` entry with `error`, binds the name as a failed fit (`model.Set.AddFailed`, carried by every `Set` copy), lifts its `PULSE_SLOT_FAILED` warning with `details.fit` and runs every other fit and slot; an attribute reading it (scoring, a literal `coef()`, `params.fit`, a `{population}`) scores null + `PULSE_FIT_UNAVAILABLE`, a `MAT_*` `params.fit` slot fails alone, a `FILTER_EXPRESSION` `coef()` or a non-literal fit name is refused with the fit's own code (E1-S4). Under Strict the fit's Process fails and the lowest-index rule above applies — the parallel fit stage cancels only the fits after a failure, so it is deterministic. Long form: `.claude/reference/response-components.md` (Per-slot failures).

**Sweep-bound fits (mmm-followups E3-S2 static half, E3-S3 schedule).** A `fits` entry may carry `from_sweep {regression}` (`types.FitFromSweep`, `capability:compose_sweep_bind`) instead of `request`. `Service.expandCompose` builds `descx.SweepFitScope` (the as-written sweep / rank plus the expanded sweep slots, and `descx.SweepSlotReadsFit` — a literal `coef()` / `sweep_axis()` naming the fit in any `vectors.ExprSlots` expression or holdout, or a `params.fit` on an attribute or matrix); `checkComposeFits` runs `model.CheckFitsIn` over it in place of `model.CheckFits` (reasons `from_sweep_with_request` / `_no_sweep` / `_no_rank` / `_regression_unknown` / `_signature_varies` / `_cycle`; `PredictCompose` builds the same scope from the same `banner.Expansion`), then `model.ResolveSweepFits` fills each binding's request with `model.SweepFitRequest` over the FIRST sweep slot — the one rule for the fit request (the slot's rows and the named regression, `save` cleared, every part a fit refuses dropped) — so `CatalogFromFits`, `FitKindOf`, `CheckComposeBatch`, optimize and predict's `FitSummary` (which echoes `from_sweep` and skips re-judging the slot) all see an ordinary regression fit. The batch then runs on the resolved request; `NormalizedRequest` echoes the request as expanded. **The sweep-first schedule (E3-S3, `internal/service/compose_sweep_bind.go`).** A batch holding a from_sweep entry (`newSweepBinding`) runs, in BOTH orchestrators through `runComposeFitPhases` (each passes its slot runner — the serial loop or the parallel pool, `slotPoolFailure` reporting a pool's failure as the whole batch would): (1) the authored fits (`composeFitPass.execute` / `bind` over the non-from_sweep mask — the pre-pass split so a fit runs ONCE), bound into the set the sweep slots read; (2) phase 0 — the sweep slots, then `foldSweepSlotMultiplicity` (every slot-local family; the `compose` family pools slots not yet run, so it stays at the barrier and a `rank.by` on its adjusted figure resolves in no slot and is refused, never misread — the barrier later rewrites the slot-local figures from the same raw p), then the rank, computed ONCE (`composeRank.ranked` / `done`; `applyComposeRank` reports it, so exclusion warnings are not doubled); (3) each bound fit refitted as an ordinary regression fit over `model.SweepFitRequest(slot ranking[0].Slot)` with that slot's loaded `models` (`composeFitPass.bindWinner`; the static request stays slot 0's, axis-invariant) — so its numerics, its `save` file and the slots scoring it are an authored fit's of the winning body to the byte; (4) optimize, then every slot phase 0 did not run (`unranSlots`). Responses keep index order; sweep slots run once. An EMPTY ranking binds the fit FAILED (`Set.AddFailed`): its `Fits` entry is `{name, type, error}` with `PULSE_SWEEP_RANK_PATH` `reason: "empty"` (`sweep.RankReasonEmpty`), a `PULSE_SLOT_FAILED` warning lifts with `details.fit`, readers get `PULSE_FIT_UNAVAILABLE`; Strict fails the batch with that code (`slotfail.StrictError`, `details.fit`). No rank-2 fallback. A batch with no from_sweep entry takes `runComposeFits` unchanged — order and bytes identical. Explain reads a bound fit's subject off the sweep body (`guide.sweepBodyRegression`). Gates: `TestCheckFitsIn_FromSweep*`, `TestSweepFitRequest`, `TestResolveSweepFits_*` (`internal/model`), `TestComposeSweepBind_*` (`internal/service`: schedule + execution counts, hand-written equality incl. the model file, serial ≡ parallel bytes, empty ranking + Strict, slot-local adjusted p; root: facade binding), `TestPredictCompose_SweepBoundFit`, `TestHiddenSweepBind_RefusedAsUnknownField` (root), `TestExplainComposedResponse_SweepBoundFitReadsSweepBody` (`internal/guide`).

**Winning axes, `sweep_axis(fit, axis)` (mmm-followups E3-S4).** A reserved request-bound expr function (`model.SweepAxisFunc` = `exprenv.SweepAxisFunc`; `extensions_validate.go` refuses an embedder of that name, `PULSE_EXTENSION_NAME_RESERVED`), declared beside `coef` through `exprenv.Bound.SweepAxis` as `(string, string) → any` — the runtime's `processing.sweepAxisBuiltin` over the slot's `model.Set` (`exprOptionsWithModels`, `ExprBoundWithModels` for optimize), predict / optblock an `exprenv.Placeholder`. One rule, `model.CheckSweepAxis`: unknown fit → `PULSE_MODEL_UNKNOWN`; a fit whose `Signature.SweepBound` is false → `PULSE_MODEL_TERM_UNKNOWN` `reason: not_sweep_bound`; an axis outside `Signature.SweepAxes` (sorted; judged only when `SweepAxesKnown`) → same code `reason: axis_unknown` + `details.axes`. It runs on every all-literal call beside `coef()` in `coefcall.StaticRefusal` (field-reference walk, build, optblock; `SweepAxisRefusal` where an embedder `coef` shadows coef) and on every call at evaluation (`model.SweepAxis`, which then gives a failed fit's own refusal, else the value — numbers as `float64`, `json.Number` / Go ints converted). Static axes: `CatalogFromFits` marks a from_sweep entry `SweepBound`; `FitCatalog.WithSweepAxes(SweepScope.Axes)` (the as-written sweep's axis names, `descx.SweepFitScope`) names them in predict's slot catalog (`validateComposeSlots`), `descx.OptimizeRefusal` (both sides) and `runComposeOptimize`. Runtime: `composeFitPass.bindWinner` records `ranking[0].Axes` (`winnerAxes`) and `bind` sets `model.Bound.SweepBound` / `SweepAxes`; a failed bound fit's `AddFailed` signature carries the scope axes, so readers follow `PULSE_FIT_UNAVAILABLE` (a literal call lists the fit in `failedCoefFits` → null formula + warning; a filter refuses with the fit's code). Gates: `TestCheckSweepAxis` (`internal/model`), `TestStaticRefusal_SweepAxis` (`internal/model/coefcall`), `TestComposeSweepAxis_*` (root: winner read in formula / filter / optimize on both orchestrators, predict ≡ runtime refusals, reserved name; `internal/service`: failed fit).

**Steady-state response, `response(fit, channel, spend)` (library-gaps E4-S2).** Reserved (`model.ResponseFunc` = `exprenv.ResponseFunc`, refused in `extensions_validate.go`), declared `(string, string, float64) → float64` through `exprenv.Bound.Response` (runtime `processing.responseBuiltin`). Value `model.ResponseAt`: `beta · hill(m · spend, k, s)` off coef()'s point reads of `<ch>`, `k:<ch>`, `s:<ch>` — or, for a `REG_MMM_BAYES` fit whose curve record (`Bound.Saturation`, from `params.saturation`; model-file / inline feature `saturation`) names `logistic` / `michaelis_menten`, `model.CurveResponseAt` over `lam:<ch>` / `k:<ch>` (U70 E1-S3; `hill()` stays Hill-only) — `m = Adstock.SteadyState()` (`Weights` summed in lag order; FMA-free). Rule `model.CheckResponse`: unknown fit, kind, then no record → `PULSE_MODEL_TERM_UNKNOWN` `reason: adstock_unknown` + `details.channel` / `channels`, judged only when `Signature.AdstocksKnown`. Static records: `CatalogFromFits` → `StaticAdstockChannels` (lineage's structure, a window param still an expression assumed whole); a `from_sweep` entry is unknown (judged at run); `CatalogWithModels` → the file's `adstock`; `Bound.Signature` → `Bound.Adstocks`. Literal fit + channel calls ride `coefcall`. Overwrite guard: `model.FeatureMayWrite` / `AttributeMayWrite`, pinned in `internal/vectors`. Gates: `TestCheckResponse`, `TestStaticAdstockChannels_MatchesLineage`, `TestStaticRefusal_Response`, `TestResponse_*` (root, `internal/processing`).

**Optimize bounds as scalar expressions (library-gaps E1-S1).** An optimize `lower` / `upper` / `start` is a scalar-expression slot read once after the fits: params-only values are range-checked by predict, a `coef()` / `sweep_axis()` one is listed under `unresolved_scalars` and range-checked at runtime. Long form: `.claude/reference/execution-modes/scalar-slots.md`.

**Vector fits (U30 E2-S2).** A `fits` entry is a regression fit OR a vector fit (`model.FitKindOf`): a request with no regression and exactly one vector battery — one `matrices` entry or one `model.VectorFitAttributeTypes` attribute (`ATTR_MAHALANOBIS`, `ATTR_PC_SCORE`, `ATTR_FACTOR_SCORE`). `model.CheckFits` adds reasons `kind_ambiguous` (a regression AND a battery), `vector_count`, `vector_source` (`model.VectorSourceRefusal`: `params.missing` pairwise, `MAT_DISTANCE`, a `MAT_RELIABILITY` `reverse` list) (`vector_save` was lifted by E2-S3: a vector fit's `save` now writes a population file, judged by `model.CheckPopulationSavePath` — `PULSE_MODEL_SAVE_INVALID`); `regression_count` still covers "no battery"; a `REG_MULTINOMIAL` regression is `regression_type` (U65 E4-S2: nothing binds its per-level coefficients). `runComposeFits` runs a vector fit through `runVectorFit`: the fit request's Process gets its set copied with a fresh `model.VectorCapture` (`Set.WithCapture`, carried to every arm on the one ctx `model.Set`), the battery offers its closed listwise state at finalize, and exactly ONE offer (else `PROCESSING_INTERNAL`) is bound by `Set.AddVector` (`Source` = `FitSource(i)`); `ComposedResponse.Fits[name]` is `&types.FitResult{Vector: processing.VectorFitResult(vf)}`. One namespace, two kinds: `model.Signature` gains `Kind` (`types.FitKind`, empty reads regression — `EffectiveKind`) and `Members` (the runtime's labels; nil from predict's static `FitCatalog`); `Set.Names` / `Len` count both kinds (`RegressionNames` / `VectorNames` one each); a reference of the other kind is `PULSE_MODEL_KIND_MISMATCH {name, fit, kind, expected}` (`model.KindMismatch` — `Set.Lookup`, `LookupVector`, `CheckScore`, `CheckCoef`, `CheckVectorFit`), and `PULSE_MODEL_UNKNOWN`'s `available` lists the kind the reference reads (`model.NamesOfKind`). Every `params.fit` (fitted attribute, matrix) is judged at field-reference step 12 — runtime and `PredictCompose` alike; predict's `FitSummary` lists a vector fit as `{name, cohort, vector: {operator, labels, members}}` (`vectorFitAxis` resolves the battery against the fit request's schema). Gates: `TestCheckFits`, `TestCheckVectorFit`, `TestFitKindOf`, `TestVectorCapture` (`internal/model`), `TestComposeVectorFits_*` (`internal/service`, root — predict ≡ runtime parity, wire shape, every `MAT_*`). **A fit-bound attribute is ROW-LOCAL (U30 E2-S5).** An `ATTR_MAHALANOBIS` / `ATTR_PC_SCORE` / `ATTR_FACTOR_SCORE` / fitted `ATTR_VEC_DISTANCE` slot whose `params.fit` names a fit (`vectors.FitBound` — an in-batch Compose fit, a `populations` load or a registered population) holds its whole state before the scan: `bindFitOn` rebuilds AND closes it at bind (decomposition, fit warnings, a capture offer), its `PrePass` / `Finalize` are no-ops, and every routing site reads the one predicate — `attrRequiresTwoPassIn` (so `canStream` streams it beside groupers, features, matrices and tier-1 tests, and `hasTwoPassAttribute` never picks the two-pass drive for it), predict's `attrTwoPass`, the fused-crosstab facts (`crosstabfuse.Facts.AttributeSlotBound`), the two-pass planner (`prebuiltAttribute`: a bound slot is a row-local input, available on scan 0) and `mergegate` (the three `FittedAttributeTypes` only; a bound `ATTR_VEC_DISTANCE` stays off the list like its row-local metrics). Merged, it runs on the shard and parallel-decode reducers and in chain stages: the reducers resolve its vector input (`processing.ResolveAttributeInputs`), build it ONCE at the orchestrator for its fit warnings and capture offer (`boundAttributeWarnings`, prepended where the serial arms put row-local warnings) and bind each partition's copy with the capture stripped (`partitionModels`), so a Compose vector fit whose battery is a bound attribute still closes exactly one state. Scores are the two-pass `fit_on` run's to the bit (same state, same per-row kernel); `fit_on` behaviour is unchanged. Gates: `TestFittedState_BoundIsRowLocal`, `TestFittedState_PrebuiltMatchesFitOn` (every arm, grouped streaming included), `TestFitBound_*` (root: two-pass parity on Process / ProcessStream, the shard reducer, a chain stage, Compose on shards; `internal/service`: the parallel-decode reducer), `TestPredict_Streamable_MatchesRuntime`, `TestStreamability_CrosstabFusionPredictMatchesRuntime`, `TestMergeRefusal`.

**SEM fits (U59 E3-S2).** A `fits` entry whose request holds exactly one `MAT_SEM` matrix and no regression is kind `sem` (`types.FitKindSEM`; `model.IsSEMFitRequest`, checked BEFORE the vector arm of `model.FitKindOf` — a `MAT_SEM` battery is never a vector fit, so `matrixSlot.offerCapture` skips it). `runComposeFits` runs it through `runSEMFit`: the same `model.VectorCapture` handle, but `finalizeSEM` / `finalizeSEMGroups` offer a `model.SEMFit` (`OfferSEM`: the plan's model description and options, the slot's labels / members, the parsed model's `Observed` / `Inner` / `Latents`, the solver stop, `dof` / `n_params`, the nearest-PD eigenvalue, and per level its `n`, Σw and `sem.Params` — the sample mean filled for a covariance-only fit) from the merged state, once, on whichever arm runs; an undefined input fails the slot of a SEM fit request (`PULSE_MATRIX_INSUFFICIENT_N` / `_SINGULAR`) instead of nulling, so a fit always binds or fails. `Set.AddSEM` binds it (`sems`, carried by every `Set` copy; `Signature` kind `sem`, `Members` its labels); `ComposedResponse.Fits[name]` is `{"sem": SEMFitResult}` (`model.SEMFit.Result`), a failure `{"sem": {operator, error}}`. `ATTR_SEM_SCORE` `params.fit` (`vectors.SEMScoreConfig.Fit`; refused beside a model knob — `fit_and_model` — or `fit_on`) is judged at field-reference step 12 by `model.CheckSEMFit` (every other `params.fit` keeps `CheckVectorFit`, so the kind mismatch holds both ways) and bound in `semScoreAttribute.bindFit`: label alignment (`vectors.AlignFit`), the model re-specified from its description and options (`semScoreFitFromBound` — one model for every group; a model that does not reproduce the stored orders is `PROCESSING_INTERNAL`), the group field resolved on the scoring schema and each fit level matched by LABEL (`bindFitGroups`), then the inline fit's own refusals / notes and `closeFit` — the ONE scorer build the inline `Finalize` uses, so the scores are the inline fit's bits on the same rows. Bound, the slot is row-local: `vectors.FitBound` lists `ATTR_SEM_SCORE`, `prebuiltAttribute`, `mergegate` admits it, its unseen-level tally folds by `MergeTally` (`resetTally` for the two-pass emission scan), and projection decodes the fit's group field (`NeededFieldsWithModels`). A SEM fit's `save` (`.pulse-sem.json`, `model.CheckSEMSavePath` in `CheckFits`) is written in the fit's run step right after `runSEMFit` binds (`saveFitSEM`, under the fit's name; its `PULSE_MODEL_OVERWRITTEN` lifts to the batch, `details.fit`), and a `models` entry ending `.pulse-sem.json` loads it back as a SEM fit (`Set.WithLoaded` → `AddSEM`) scoring through the same `semScoreFitFromBound` — format and load: `.claude/reference/byte-layout.md` (SEM fit file). Gates: `TestSEMFit_*` (`internal/model`, root), `TestSEMScore_Bound*` (`internal/processing`).

**Population saves and loads (U30 E2-S3).** A vector fit's `save` (`.pulse-population.json`) is written in the fit's run step right after `runVectorFit` closes its state (`saveFitPopulation`, under the fit's NAME, not the summary — the stored listwise figures), so serial and parallel batches write the same bytes; its `PULSE_MODEL_OVERWRITTEN` warning lifts to `ComposedResponse.warnings` in entry order like a regression fit's. `Request.Populations` loads at the very point `models` loads (`bindRequestModels` / the Compose and chain pre-passes, through `model.Refs`), binding each file as a `model.VectorFit` beside the batch's fits — a plain `Process` therefore reads `params.fit` against a saved population exactly as a Compose slot reads a vector fit, and a pre-pass load reads the file as it was BEFORE the run (a population a fit in the same batch saves is not visible to that batch's slots). Format and load rules: `byte-layout.md` (Population file).

**Scoring a bound fit (`ATTR_REG_PREDICT`, U42 E1-S2).** The service hands `model.SetFrom(ctx)` to every processor it builds (`newProcessor` → `Processor.SetModels`), to the field-reference pass (`checkFieldRefs(ctx, …)` → `descx.ScopedFieldRefRefusalWithModels`; predict passes `model.CatalogFromFits(req.Fits)` per slot and nil for a fit request or a plain request, so both sides refuse an unbound name as `PULSE_MODEL_UNKNOWN {name, available}`), to the projected decode (`neededFields(ctx, …)` → `processing.NeededFieldsWithModels` adds the bound predictors the request never spells) and to the per-shard / parallel-decode reducers (`buildRowLocalAttrSpecs` binds through `processing.BindAttribute`). One rule judges a reference — `model.CheckScore` (params, fit name, scorable type, `terms`, `scale`) then each `Signature.Terms` column present (`PULSE_MODEL_PREDICTOR_MISSING`) and, when a schema field, numeric (`_NOT_NUMERIC`) — in the field-reference walk (predict ≡ runtime) and again at bind. `Signature.Terms` is the fit spec's candidate list, not the selection's kept subset, so predict (which never fits) judges exactly what the runtime judges. Bound, the attribute is ROW-LOCAL (not in `requiresTwoPass`; `canStream` admits it; `mergegate` lists it beside `ATTR_FORMULA` / `ATTR_DATE_PART`; Materialize admits it); the two-pass planner treats its inputs as unknown (it depends on every earlier attribute). Scoring is ONE path, `model.RowScorer` (custom-regressions E2-S1): `bindModels` calls `Bound.Scorer(source, params)`, which delegates to the fit type's `model.ScorerFactory`; the built-ins resolve through `regression.BuiltinScorer` (`model.ScorableType` is its static face for predict, `TestBuiltinScorer_MatchesScorableType`) — REG_OLS / REG_BAYES_LINEAR the linear scorer over `regression.LinearPredictor`, the ONE kernel `ATTR_REG_FITTED` / `RESIDUAL` / `LEVERAGE` and the GLM engine's own η also evaluate, REG_GLM that plus the engine's own `InverseLink` on the response scale — so a training row's score equals the fit's fitted value bit for bit. The source is the INSTANCE's (`ExtensionRegistry.RegressionScorer`, injected by `SetExtensions`; checked by `model.CheckScoreFor` over `ExtensionRegistry.ScorableRegression`, predict's twin `scorableRegression` off the snapshot): a registered regression's `Scorer` (whole model only; none → reason `no_scorer`), else `regression.BuiltinScorer` (custom-regressions E2-S2). A null input emits NaN, which every arm writes as a NULL through the `processing.NullEmitter` opt-in (`SetAttributeOutput`; buffered `applyAttributes`, streaming, two-pass, fused crosstab, both reducers), so a downstream aggregation counts the row in `n_null`; `ATTR_REG_FITTED` / `RESIDUAL` / `LEVERAGE` opt in the same way (null predictor, or null target for `RESIDUAL`; `TestAttrReg_Null*`). Gates: `TestRegPredict_*` (`internal/processing`, `internal/service`, root parity), `TestRowScorer_*` (root: every built-in's scores bit for bit against the frozen pre-RowScorer kernel, across workers and a saved-model round trip), `TestScorer_*` / `TestBuiltinScorer_*` / `TestBound_Scorer*` (`internal/processing/regression`), `TestCheckScore` / `TestSignature_RuntimeMatchesPredict` (`internal/model`).

**Reading a bound fit's figures (`bound`, `coef()`, U42 E2-S3).** `ATTR_REG_PREDICT` `params.bound` `lower` / `upper` swaps the coefficient for its confidence bound (`model.Bound.CILower` / `CIUpper`, full precision) in the built-in linear `model.RowScorer` (`regression.BuiltinScorer`); `model.CheckScore` refuses it unless `terms` is exactly one predictor (`PULSE_MODEL_SCORE_INVALID` `bound_terms`; an unknown value `bound_unknown`), and a term without a bound (lasso-dropped, selection-dropped candidate, df ≤ 0) scores null on every row. `coef(fit, term[, stat])` is a built-in expr function of `ATTR_FORMULA` and `FILTER_EXPRESSION` only (not `OVERLAY_FORMULA`): `processing.exprOptionsWithModels` registers it after the set helpers and before the embedder's `ExprFunctions` (an embedder `coef` shadows it and the static check stands down), closed over the request's `model.Set` — injected through `modelBinder` into the formula attribute (`BindAttribute`) and the expression filterer (`buildFilterFuncs`, `processing.BuildFiltersWithModels` for the shard / parallel-decode reducers; facet and filter-to-file pass nil). One rule, `model.CheckCoef` (fit → `PULSE_MODEL_UNKNOWN`, term → `_TERM_UNKNOWN`, stat → `_STAT_UNKNOWN`), runs on every all-literal call in the descriptor field-reference walk (predict ≡ runtime entry) and at build (`internal/model/coefcall`), and on every call at evaluation (`model.Coef`, which adds `_INTERVALS_UNAVAILABLE` for a fit with no standard errors — runtime only). `exprProgram.evalError` returns a `PULSE_MODEL_*` refusal under its own code, and a filter never reads one as a null-row UNKNOWN. An absent figure is NaN, never 0. `coef` is not pure for filter precompute. Gates: `TestCoef_*` (`internal/model`, `internal/model/coefcall`, `internal/processing`, `internal/service`, root parity), `TestRegPredict_Bound*` (`internal/processing`).

## Result pre-phase

**What (library-gaps E5-S1, G7).** `result("<slot label>", "<aggregation label>")` is a request-bound, reserved expr function (`exprenv.ResultFunc`; `extensions_validate.go` → `PULSE_EXTENSION_NAME_RESERVED`; a reserved decision-variable name) that reads one ungrouped aggregation of a Compose slot. It is in reach of an `optimize` block ONLY — bounds and starts (`scalarslot.Env.Results`), objective and constraints (`optblock.Env.Results`, judged in `compileExpr`). Every other scalar slot (window / extension / `AGG_CONSTANT` params, inline model numbers, any slot's or fit request's) compiles with a nil catalog and refuses a call as `PULSE_RESULT_INVALID` `out_of_scope` before compiling; a non-scalar expression slot (formula, filter) does not declare it, so a call there is that slot's ordinary compile error (`PULSE_FORMULA_COMPILE_ERROR` for a formula). Nothing a slot computes reads an optimize block, so the slot dependency graph is one level deep (optimize → slots) and a cycle cannot form — the decision delegated at organize, chosen over a `scalars` block.

**One rule set, `internal/resultcall`** (no-execute leaf: types, errors, `exprenv`; `TestResultCall_ImportBoundary`). `CatalogOf(requests)` over the EXPANDED slots (sweep and banner slots included; label = own or `request_<i+1>`; aggregation labels `types.AggregationLabelOf`; grouped = groups or crosstab). `Refusal(src, cat)`, in walk order: nil cat → `out_of_scope`; a two-argument call with a non-literal argument → `args_not_literal`; `slot_unknown` (`available` = slot labels), `aggregation_unknown` (`available` = the slot's labels), `grouped`, `not_numeric` (the aggregation writes no single number: `CatalogWith`'s judgement, `descx.ResultCatalog` = the instance's `vectors.AggregationKinds.IsNonScalarSlot` — a map- / array- / label-valued type or a non-numeric `AGG_CONSTANT`; E5-S2). Details `slot`, `aggregation` (never on `out_of_scope`, whose host locates it under its own `slot` key), plus `optimize` / `field` once `optblock.locate` places it. `descx.OptimizeCheck` builds the catalog from `req.Requests`, so predict and the runtime's `optimizeRefusal` (right after `checkComposeFits`) refuse identically; a reading bound is listed under `unresolved_scalars` with `reads: ["result"]` — its value is never known at predict.

**Schedule (`internal/service/compose_result.go`).** `runComposeResultPhase` runs between `runComposeFitPhases` and `runComposeOptimize` in BOTH orchestrators: `optblock.ResultSlots` (every literal call in a bound, start, objective or constraint, sorted, unique) minus the slots phase 0 already ran (`ran`), through the orchestrator's own runner (serial loop / parallel pool) over the bound set — so a referenced slot sees the fits exactly as it would later, runs ONCE, keeps its index in `responses`, and is marked in `ran` for the final `unranSlots` phase. `runComposeOptimize` then binds `resultcall.Reader{Catalog, Responses}` as `exprenv.Bound.Result`: `Reader.Value` reads `Data[0][label]` of the finished, unshaped response — a finite number, else `PULSE_RESULT_INVALID` `null` (nil or NaN), `not_numeric` (`type`), `not_finite` (`value`), `grouped` (not one row). A run-time refusal is FATAL, located at the bound or expression (a bound through `scalarslot`, an objective through `optsolve.locate`), like a model-dependent range refusal. The multiplicity barrier and the overlay fold still run after every slot.

**Execution modes (E5-S2).** *Parallel:* `ComposeParallel` runs the pre-phase slots on its pool (`MaxWorkers`) after the fit phases and before the blocks; the bytes equal serial `Compose`'s. *Failure:* `runComposeResultPhase` marks the slots in `ran` before running them, so none reruns. A failed read slot stops every optimize block (its dependents) and the comparisons. Serial and fail-fast parallel return at once with the slot's OWN coded error, located `details.request`, plus `details.result_slot` (its label) and `details.optimize` (the first block, in spec order, reading it) — `resultPhaseFailure`. A non-fail-fast pool still runs every other slot (nothing is cancelled), then returns the whole batch's `SERVICE_INTERNAL` aggregate (`failed_indices`, `first_error`) with `details.result_slots` (the failed read slots' labels, index order). *Stream:* `--stream` is written from the finished `ComposedResponse`, so a pre-phase slot's rows appear ONCE, at its slot index (index order, never run order), then the trailing lines as before. *Limits:* `MaxComposeSlots` counts the expanded slot list up front (`composeSlotsPreflight`, predict's `CheckComposeSlots`), and a pre-phase slot is one of them — counted once.
