## Convention registry

`internal/descriptor/conventions.go` (`builtinConventions`) is the ONLY source of built-in `Interpretation.Bands`: an Interpretation calls `conventionBands(id)` and `conventionCitation(id)` and never writes thresholds inline. Each entry carries an ID, a citation, the `Statistics` it may band, ascending `Thresholds`, `Labels` (one more than thresholds — the lowest band below Cohen's "small" is labelled `very small`, never "negligible" or "none"), `Abs` (bands read |value|) and `SymmetricLog` (a ratio statistic whose bands apply to max(x, 1/x)).

| ID | Statistics | Thresholds | Source |
|---|---|---|---|
| `cohen1988_d` | `cohens_d`, `hedges_g`, `glass_delta`, `cohens_h` | 0.2 / 0.5 / 0.8, `Abs` | Cohen (1988) |
| `cohen1988_eta2` | `eta_squared`, `omega_squared` | 0.01 / 0.06 / 0.14 | Cohen (1988) |
| `cohen1988_r` | `pearson_r` | 0.1 / 0.3 / 0.5, `Abs` | Cohen (1988) |
| `cohen1988_w` | `cohens_w`, `phi` | 0.1 / 0.3 / 0.5 | Cohen (1988) |
| `cohen1988_or` | `odds_ratio` | 1.44 / 2.48 / 4.27, `SymmetricLog` | Cohen's d benchmarks via d = ln(OR)·√3/π (Chinn 2000) |
| `cohen1988_r2` | `r_squared` | 0.02 / 0.13 / 0.26 | Cohen's f² benchmarks via R² = f²/(1+f²) (Cohen 1992) |

**Fixture contract.** `testdata/conventions.json` is transcribed independently from the sources, never generated from the Go registry. `TestConventionRegistryMatchesFixture` holds the two equal field by field, requires an https source URL plus a page / section locator per entry, and recomputes every derived threshold (η² from f, OR from d, R² from f²). Its `statistic_bindings` map a banded non-effect-size output to a registry statistic, and its `excluded` list names every output left unbanded on purpose WITH a reason (Interpretation section above). `TestBuiltinBandsCiteRegisteredConvention` binds each banded built-in Interpretation to exactly one registered convention (matched on Bands, Convention and `Abs`) whose `Statistics` cover the banded output, and refuses bands on an `excluded` output. Adding a convention means: source it, add the fixture entry and the registry entry in one change; an output with no sourced convention stays unbanded and carries a "no sourced bands" caveat (lint rule `ES-CONV`).

## Statistical primitives and the R oracle

Every p-value, critical value and interval rests on a small set of shared distribution primitives. Their numeric correctness is pinned to R, not to hand-pasted literals.

- **Generator.** `scripts/reference/gen_reference.R`, run by `make reference` (R 4.6.1 + `jsonlite`), writes one JSON per primitive into `internal/processing/testdata/reference/` — the R and package versions, the R expression, and every case at `%.17g` — then appends the `// golden-hash:` footer processing's `TestGoldensNotHandEdited` checks. **CI never runs R**; the goldens are committed. Where stock R is less accurate than the oracle needs (`ptukey` / `qtukey`, far-tail `qt`), the script refines in R (nested quadrature, Newton-polished quantiles) and keeps R's own value beside it (`r_ptukey_upper`, `r_qt`, …). Recipe: `docs/src/internals/regenerating-goldens.md`.
- **Multivariate goldens (U24).** `gen_reference.R` sources `scripts/reference/gen_multivariate.R`, which writes `mv_*.json` (rank / partial correlation, alpha + ω, one-factor minres, PCA + KMO + Bartlett, VIF + `colldiag`, `vcov(lm/glm)`, `nearPD`) on vendored `attitude` / `mtcars` plus seeded fixtures under `testdata/reference/fixtures/` (CSV + `.pulse` via `internal/tools/refcohorts`), with `psych` / `car` / `ppcor` / `perturb` / `corpcor` / `Matrix` pinned in its header. Consuming tests land with each matrix operator.
- **Tests.** `TestReferenceOracle_*` (`internal/processing/reference_oracle_test.go`, `internal/statdist/reference_oracle_test.go`) cover the Student-t family, `chiSquareSurvival`, `fSurvival`, `standardNormalCDF`, `standardNormalPPF`, `kolmogorovTwoLimitUpper` (the ks.test port's limiting kernel, untruncated), `studentizedRangeSurvival` and `studentizedRangeInverse`, with p down to ~1e-300.
- **Tolerance policy.** Relative `1e-10` (an absolute floor only at the representable tail edge). Never an absolute tolerance on a p-value, and never a looser one to make a case pass: amd64 and arm64 fuse `a*b+c` differently, so values drift by ulps and a relative bound is the only portable one. **A failure means the Go primitive is wrong — fix it; regenerate only to change the grid** (script and goldens committed together).
- **Normal tails.** A two-sided normal p is `normalTwoSidedP(z)` = `erfc(|z|/√2)` and a one-sided upper tail `normalUpperTailP(z)` = Φ(−z); never `2·(1 − Φ(|z|))`, which cancels to exactly 0 past |z| ≈ 8.3. Every normal-approximation family has a `*_TinyP` test at |z| ≈ 10 against R's `2*pnorm(-|z|)` (`internal/processing/normal_tail_test.go`, `TestNormalTwoSidedP_MatchesR`).
- **`internal/statdist`.** The Student-t family (`StudentTTwoSidedP`, `StudentTCDF`, `StudentTQuantile`, `StudentTInverseTwoSided`) and the regularized incomplete beta live once, in a leaf importable by `internal/processing` and `internal/processing/regression` (stdlib + gonum only, `TestStatdistImportBoundary`). `TestStudentTFormsAgree` pins the paired forms bit for bit. Helpers keep their function boundaries on purpose (FMA bit-identity). Chi-square, F, normal, Kolmogorov and studentized range still live in `internal/processing`; moving one to `statdist` is a refactor that must stay bit-identical.
- **Assembled outputs (U36).** `scripts/reference/gen_test_outputs.R` pins `TEST_ANOVA_RM`, `TEST_TUKEY_HSD` (q, `p_adj`, interval; refined like the primitives), `TEST_TREND` (S, τ-b, Z, p), `TEST_KS` (D and `ks.test`'s p in every regime: exact below n₁·n₂ = 10000, conditional on ties, else the limiting distribution at R's tol 1e-6 — `test_ks_smirnov.go` ports `psmirnov` / `K2l`), `TEST_KENDALL_TAU` with ties, the `TEST_PEARSON_R` Fisher-z interval, `TEST_SHAPIRO_WILK` (`nortest::sf.test`; n < 5 refused) and `TEST_BROWN_FORSYTHE` (`anova(lm(|x − median| ~ g))`, F = +Inf / NaN at zero within-group spread) and `TEST_FISHER_EXACT` (conditional MLE odds ratio, refined past `fisher.test`'s `uniroot()` tolerance; 0 / +Inf at the support's ends; the exact conditional `conf.int` at 0.95 and 0.90, refined the same way, lower 0 / upper +Inf at the ends; p under `fisher.test`'s relErr tie rule, d ≤ d_obs·(1 + 1e-7), with a near-tie table), unweighted, in `test_output_oracle_test.go` / `test_undefined_oracle_test.go` / `test_fisher_oracle_test.go`. `gen_post_tests.R` pins every post-test family over rows holding nulls (listwise, R's NA default) and `TestPostTwins_MatchRowVariant` each post twin to its row variant (`test_post_oracle_test.go`).
- **Regressions (U36).** `scripts/reference/gen_ols_lm.R` pins unpenalised `REG_OLS` to stock `lm()` — coefficients, SE, t, p, `confint()` at 0.95 and 0.90, R², adjusted R², σ̂, df — plain and frequency-weighted (lm on the `rep()` expansion), at relative 1e-10 (`TestReferenceOracle_RegOLSMatchesLM`, `ols_lm.json`); a predictor on a 1e6 offset is fitted on its exact shift, because stock `lm()`'s raw QR misses 1e-10 there (stock figures kept as `r_*`). It replaced a snapshot of Pulse's own output. The `glm_irls.json` SEs are evaluated at the MLE by a warm-started refit (glm's own lag one IRLS update, ~5e-9), so `glm_irls` / `glm_penalty` / `ols_penalty` pin every figure at relative 1e-10 with no absolute floor above 1e-14 (`oracleClose`). `scripts/reference/gen_glm_gamma.R` pins `REG_GLM` gamma under `summary.glm`'s ESTIMATED dispersion (Pearson χ² / df.residual): SE, t p-values, `df`, t intervals and `vcov(glm)` (`TestReferenceOracle_GLMGammaMatchesR`, `glm_gamma.json`); the weighted rows and the robust gamma sandwich (dispersion-free) ride `reg_reference.R` and `gen_robust_vcov_glm.R`. `scripts/reference/gen_glm_gamma_selection.R` pins the gamma `selection` score to R's `AIC(glm)` / `BIC(glm)` (gamma log-likelihood at φ = deviance / N*, φ counted) on every subset of three predictors, plain, frequency (the `rep()` expansion, BIC on log Σw) and probability (`glm(weights = w*)`, BIC on log n_eff), and the forward / backward / stepwise × aic / bic final models to `step()`'s on a fixture where the φ = 1 score diverges (`TestReferenceOracle_GLMGammaAICMatchesR`, `TestReferenceOracle_GLMGammaSelectionMatchesStep`, `glm_gamma_selection.json`). `scripts/reference/gen_bayes_linear.R` pins `REG_BAYES_LINEAR`'s conjugate NIG posterior by R matrix algebra (self-checked against `lm.fit` on the augmented design): mean, marginal t scale, credible / conf intervals, df, σ scale, R², adjusted R², posterior covariance; default and informative priors, plain and frequency-weighted (`TestReferenceOracle_RegBayesLinearMatchesR`, `bayes_linear.json`); `gen_bayes_precision.R` the per-coefficient `prior_precision` (Λ₀ = diag(v), flat and pinning entries; `bayes_precision.json`), and `gen_ols_penalty.R`'s `ridge_unpenalized_*` cases ridge `unpenalized` via glmnet `penalty.factor` (U53 E3-S1).
- **Contract gates (U36).** Beside the oracles: `TestPostTwins_MatchRowVariant` (every post twin equals its row variant), `TestWeightedTests_FrequencyFloorIsExpansion` / `TestMatrixInference_FrequencyFloorIsExpansion` / `TestWeightedMVTests_FrequencyFloorIsExpansion` / `TestWeightedRegression_FrequencyFloorIsExpansion` (a minimum-n floor reads Σw under `frequency`, `weighting.Basis.FloorN`), `TestSlotFailure_Shapiro*` (n < 5 and zero variance fail the slot alone), `TestAPI_InfiniteTestStatisticsAreNull` (`--json` always encodes), `TestRegOLS_LassoElasticNetInferenceNull` + `TestRegPenalty_InferenceAdvisoryPredictRuntimeParity` + `TestRegPenalty_PValueCountPredictRuntimeParity` + `TestPredict_AdvisoryPenalizedInference*` (l1 / elastic net inference is `null` with `PULSE_ADVISORY_PENALIZED_INFERENCE_UNDEFINED`, predict and runtime agree, the fold counts no null p), and `TestOverlayKSVsPop_HistogramPIsTestKS`. **Decisions the oracles recorded:** Fisher's odds ratio and `conf.int` are refined past `fisher.test`'s `uniroot` tolerance (R's own value kept beside the golden) and its p uses R's relErr 1 + 1e-7 tie rule; Shapiro-Francia refuses n < 5 and a constant group (`nortest::sf.test` stops / answers NA); gamma dispersion is estimated (Pearson χ² / df, as `summary.glm`) and gamma selection scores R's `AIC()` / `BIC()`; penalised l1 / elastic net inference is undefined, not approximated; `TEST_KS` and `OVERLAY_KS_VS_POP` p are `ks.test`'s. **Tolerance:** relative 1e-10 throughout; the only written exceptions are the generator's refinements (Tukey, Fisher) and the `ks.test` cases where R's own cumsum D lands an ulp above 1 (`psmirnov` value pinned, R's figure kept as `r_*`). **Still open:** `pwr` is installed but unused by any generator; Kendall is a single-precision cross-check only; the asymptotic `TEST_KS` branch (Σw₁·Σw₂ ≥ 10000) carries no ties warning (U12 review WS-10).
- **Overlays (U36).** `scripts/reference/gen_overlays.R` writes `overlay_*.json`, and no overlay test derives its expectation from the helper the overlay calls (`TestReferenceOracle_Overlay*`, relative 1e-10): `OVERLAY_CHISQ_VS_POP` (`chisq.test(x[C], p, rescale.p = TRUE)`), `OVERLAY_CHISQ_VS_REF` (the same over C = cells with a positive reference count; a target count outside C warns `PULSE_OVERLAY_REF_ZERO` — before U36 it stayed in the target total), `OVERLAY_KS_VS_POP` (D = the bucket-edge gap, cross-checked against `ks.test`'s statistic on the bucketised samples, or the `approx(rule = 2)` gap on percentiles; p = `ks.test`'s through `TEST_KS`'s port since E3-S4: exact on the bucketised tie pattern when m·n < 10000 else the limiting form (histogram), the uncorrected limiting form (percentile); `TestOverlayKSVsPop_HistogramPIsTestKS` holds it equal to `TEST_KS` on the expanded bucket indices; the old Stephens figure stays as `r_stephens_p`), `OVERLAY_PAIRWISE_PROBIT_T` (its 1/√n design formula, pinned as is), `OVERLAY_FISHER_EXACT_CELL` (`fisher.test` per cell), the shared two-sample kernels (`welchTTest` / `welchZTest` / `twoProportionZ`; routing tests may run them on their expected legs, the kernel being pinned once), and the weighted-host unit fixtures. `OVERLAY_T_VS_REF` / `Z_VS_REF` over an ENGINE `AGG_WELFORD` series: `TestReferenceOracle_ComposeWelfordSeriesVsRef` (root, `overlay_mean_vs_ref.json`, `t.test` per group) and the weight fixture's `ov_compose_series_welford` (both kinds).

## Extension hook

All nine root operator `*Registration` structs take an optional `Purpose *descriptor.Purpose`; `TestRegistration` and `RegressionRegistration` also take `Interpretation []descriptor.Interpretation`. At every `pulse.New`, AFTER naming/shape validation, the probe and the `DependsOn` check, `validateExtensionGuidance` (`extensions_guidance.go`) runs the SAME `ValidatePurpose` the built-in tier uses (plus cross-operator `KnownAs` uniqueness against built-ins and earlier extensions), resolving `NotFor.Use` and `FollowUps.Use` against the instance (built-ins, the feature table AND other extensions), then `ValidateInterpretations` in STRUCTURE-ONLY mode for a test (nil resolver: path syntax and content, never key existence) and against `descx.ExtensionRegressionOutputResolver` for a regression (the figures a model can report, `<map>.*` for a coefficient-keyed one, plus `outputs.<key>` for each declared `OutputSchema` key). First invalid wins (category order, then slice index; Purpose before Interpretation) → `PULSE_EXTENSION_PURPOSE_INVALID`, details `category`, `name`, `index`, `part`, the first failing rule and every violation. Only the Purpose's sorted intent IDs project to `OperatorMeta.intents`; prose never enters the manifest (`TestExtensions_PurposeProseNeverInManifest` — per instance, so outside `GuidanceProse`). An absent Purpose projects no `intents` key and keeps the extension out of the coverage report by construction. Embedder prose: `docs/src/internals/extension-points.md`.
