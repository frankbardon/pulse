# Architecture — Extension models

Per-topic slice of the architecture reference (Extension models: the matrix-operator and regression-model extension categories, split out of `architecture/extension-surface.md` at U53 E1-S3). Index (preamble + section map): `.claude/reference/architecture.md` — load it first, then only the slice(s) your change touches. The rules shared by every category (snapshot, naming, params validation, weights, components) stay in `architecture/extension-surface.md`.

## Extension models

- **Matrix operators (`MatrixOps`, U30 E1).** `Extensions.MatrixOps []MatrixOpRegistration` registers `MAT_<NS>_<NAME>` operators authored against `extend.MatrixOperator` — FINALIZE-ONLY: the engine keeps accumulation (per-block `CoMoment`s, the 4096-row `MergeTree`, grouped buckets, missing modes, weights) and calls `Finalize(*extend.MatrixInput)` once per result with the merged, read-only `*linalg.CoMoment` (raw per-pair co-moment via the additive `CoMoment.PairM2`), members / labels, raw params, weight kind, the encoding and the `Want*` part flags (plus `MatrixRows` on a `Streamable:false` registration); `MatrixInput.Square` / `Rect` render in the slot's encoding, mirroring the engine's renderers. `BlockMerger` stays engine-only — a pure Finalize inherits the bit contract without it; `extend.MergeableAggregator.Merge` is within-ulp and never reaches a matrix. Registration validation (`validateMatrixOps`, after the shared naming / params pass with `categoryMatrix`, prefix `MAT`, collisions against `builtinMatrixNames()` = `types.AllMatrixTypes()`, regex-shaped built-ins such as `MAT_PARTIAL_CORRELATION` included): nil `Factory` (`missing_factory`), empty `OutputKeys.Primary` (`missing_output_keys`), an empty / repeated auxiliary / vectors / scalars key (`invalid_output_key`) — all `PULSE_EXTENSION_PARAM_INVALID`; `ComponentSchema` is empty or complete (Mergeability without Keys → `PULSE_EXTENSION_MISSING_COMPONENT_SCHEMA`; Keys without Mergeability `missing_mergeability`, an empty / repeated key `invalid_component_key`, a matrix-floor or weighted-floor key `reserved_component_key`, each `PULSE_EXTENSION_PARAM_INVALID`) — there is no `ComponentsFunc`: components ride `MatrixOutput.Components`. `looksLikeExtensionName` (feature universe) accepts an embedder `MAT_*` name; `mergeExtensions` / `hasAnyRegistrations` carry the slice. A present `Purpose` is validated like every category's (`PULSE_EXTENSION_PURPOSE_INVALID`, category `matrix`). **Run-probe** (`probeMatrixOps`, `extensions_probe_matrix.go`) — the one probe that feeds data: the factory is built against a synthetic schema of three `f64` members + a weight column, and `Finalize` runs under `recover()` over a six-row listwise `CoMoment` with every part wanted (rows only on `Streamable:false`; a `WeightAware` registration is probed again weighted, `details.weighted`): factory / Finalize panic or error → `PULSE_EXTENSION_FACTORY_PANIC` (`details.stage`); a `Streamable:true` Finalize that fails without `Rows` but passes with them → `PULSE_EXTENSION_STREAMABLE_MISMATCH` `reads_rows`; no `Primary` (`missing_primary`) or an auxiliary / vectors / scalars key `OutputKeys` does not declare (`undeclared_output_key`; a declared key left unfilled is fine — `OutputKeys` lists what the operator MAY fill) → `PULSE_EXTENSION_MATRIX_OUTPUT_MISMATCH`; a `Components` key outside `ComponentSchema.Keys` (no floor key tolerated) → `PULSE_EXTENSION_COMPONENT_SCHEMA_MISMATCH`. **Engine wiring (E1-S3).** `extensions_matrix_runtime.go` lifts the registration onto `processing.ExtensionRegistry.MatrixOps` (`processing.MatrixOp`: factory, declared tier, `Accepts`, auxiliary keys) and onto the snapshot (`ExtensionsSnapshot.MatrixOps` as `OperatorMeta` + `MatrixDetails`); resolution is `vectors.ResolveMatricesWith` (`MatrixResolve.Extension`, runtime `matrixExtension` / predict `matrixExtensionFor`): opaque params with the engine-owned `missing` / `max_drop_share` decoded and STRIPPED (a `ParamMeta` naming one is refused, `reserved_matrix_param`), `Accepts` narrowing (`PULSE_VECTOR_MEMBER_TYPE`), the declared tier as `Streamable` / `Mergeable`. The finalizer lookup is built-in first, then the slot's extension finalizer (`matrixSlot.finalize`), handed a per-call `CoMoment.Clone()` and wrapped so `OutputKeys` / `ComponentSchema` bind on every run. Instance-routed tier at every gate: `ExtensionRegistry.MatrixSpecStreamable` (`canStream`), `mergegate.Extensions.Matrix` (both adapters), predict `matrixSpecStreamable`. Weights: snapshot category `matrix` in `WeightAwareness` (a non-aware op is refused under any weight in force), `StampWeightsWith` stamps an aware one. Multiplicity opt-in through `MatrixOpRegistration.PValues` → `ResolvedMultiplicity.PValueKey`. Profiles: `withoutHiddenExtensions`, the feature universe (an implicit `capability:matrices` group) and the ontology (`requires_capability` edge). Gates: `TestExtensionMatrix_*` (root `extensions_matrix_engine_test.go`), `TestMatrixExtension_CanStream`. **Bit contract (E1-S4):** `TestExtensionMatrix_WorkerInvariant` (root `extensions_matrix_invariance_test.go`, public registration only) holds an extension `MAT_*` bitwise across `DecodeWorkers` / `ShardWorkers`, grouped and weighted, both tiers — scope in `execution-modes.md` (Blocked merge); falsified by `TestExtensionMatrix_WorkerInvariantGateBites`. Gates: `TestExtensions_MatrixOpRegistrationRefusals`, `TestExtensions_MatrixProbeRefusals`, `TestExtensions_MatrixProbeInput`, `TestExtensions_MatrixPurposeValidated`, `TestExtensionNameRegex_Matrix`, `TestLooksLikeExtensionName_Matrix`, `TestMergeExtensions_MatrixOps`, `TestMatrixInputSquare`, `TestCoMomentPairM2MatchesCov`.
- **Regression models (`Regressions`, U53 E1-S1).** `REG_<NS>_<NAME>` against `extend.Regression`: `StreamingRegression` (`UpdateRow` / `Merge` / `Finalize`; `Streamable: true`) or `BufferedRegression` (`Fit`). Root `extensions_regression.go`: `regressionDriver` admits rows (listwise on target + predictors; a valid positive weight on an aware slot), owns `n_obs` / `sum_weights` / `n_eff`, maps `extend.RegressionOutput` onto `RegressionResult` (`std_errors` / `statistics` / `p_values` keyed by every coefficient, absent = NaN) and runs `verifyRegressionOutput` on the probe and every run (`PULSE_EXTENSION_REGRESSION_OUTPUT_MISMATCH`). **Warnings (U62 E2-S1):** `RegressionOutput.Warnings` (registered codes only — `invalid_warning` / `unregistered_warning_code`; generic `PROCESSING_REGRESSION_DIAGNOSTIC`) are cloned onto `RegressionResult.Warnings`; `Service.process` (`internal/service/regression_warnings.go`) lifts them onto `Response.Warnings` (`details.regression` / `index`) after `slotfail.Apply`, or under Strict first turns each warned slot into a failed one with its first warning's code (`escalateRegressionWarnings`), so Apply refuses the run; `runComposeFits` lifts a fit's with `details.fit`. Gates `TestExtensions_RegressionWarnings*`. **Ctx (U62 E2-S2):** a buffered model implementing the optional sibling `extend.ContextRegression` (`FitContext` beside `Fit`) is fitted through it — `regressionEngine.FitBufferedContext` (a `ContextBufferedEngine`, so `FitEachBufferedWithContext` hands it the operation ctx), `regressionModifierEngine.refit(ctx, …)` and the probe (background ctx); gates `TestExtensions_RegressionFitContext*`. A streaming model routed buffered is still fed through `UpdateRow`. Probe: eight synthetic rows; form mismatch `PULSE_EXTENSION_STREAMABLE_MISMATCH` (`not_streaming` / `missing_merge` / `not_buffered`); a data-dependent refusal tolerated. Routing: `ExtensionRegistry.Regressions` ahead of the built-ins in `LookupRegression`; `RegressionSpecStreamable` (runtime) / `regressionSpecStreamable` (predict) fold the declared form with `RegressionSpec.StreamableAs`. Predict treats a snapshot name as known; Intervals: `conf_level` is an ACCEPTED field on every model — the adapter runs `regression.CheckConfLevel` (predict's `0 < c < 1` rule) and `regressionDriver.result` / `extensionResample` call `regression.AttachExtensionIntervals` (t on the reported `Fit.DF` when `df` is on `ReportedFigures`, else normal; normal on the replicate SE under resample, which drops `df` from `DF` and `ReportedFigures`; NaN SE → null bound); parity with `REG_OLS` intervals is pinned by the `conf` rows of the `regression` parity suite and `TestExtensions_RegressionResampleMatchesBuiltin`. `descx.ExtensionRegressionSlotRefusal` is the ONE declare-or-refuse rule, called by predict and the adapter: `internal/descriptor/extensions_regression_slots.go` classifies EVERY `RegressionSpec` key (identity / accepted / weight class / a slot rule whose `declared` predicate reads `Vcov` / `Penalty` / `SupportsSelection` / `CovarianceTypes` / the internal `Scorer`); an undeclared set slot is `PROCESSING_CONFIG {regression, slot[, key], name}`; resample (and its knobs) is an `optOut` slot rule (class `opt_out`) honoured unless `NoResample` (U62 E2-S2, `TestExtensions_RegressionNoResampleRefused`), `rng_seed` accepted, and selection a slot rule on `SupportsSelection`; a modifier-bearing slot builds `regressionModifierEngine`, whose `regression.RunExtensionModifiers` reuses the built-in replicate loops (`resample_core.go`: `jackknifeCore` / `groupedJackknifeCore` / `bootstrapCore`, ctx read per refit via `ContextBufferedEngine` + `FitEachBufferedWithContext`) and `runSelectionCtx` (AIC/BIC on the reported deviance, k = coefficient count; `missing_deviance` / `replicate_coefficients` mismatches), the adapter also running `descx.RegressionSelectionCriterionRefusal` + `regresample.Check`; a declared covariance runs `regcov.CheckDeclared` (shape + penalty/resample/selection, never `robustTypes`). The manifest's slot params come from the same predicates (`regressionSlotParamsFor`). Gate `TestExtensions_RegressionSharedSlotsRefused` reflects over the spec. Weights: snapshot category `regression`. Multiplicity: `RegressionRegistration.PValues` (`descx.ExtensionRegression.PValues`) gates it — declared, `ResolvedMultiplicity.ResultCoefficients` makes the default family the result's p-valued coefficients; undeclared, `multResolver.regression` refuses a non-`none` method (`PULSE_MULTIPLICITY_INVALID`, the Bayes rule, shared by predict and runtime), predict counts none, `RunExtensionModifiers(…, pValues, …)` writes NaN replicate p-values, and `verifyRegressionOutput` refuses a finite p (`undeclared_p_value`); the manifest row lists the `multiplicity` slot param and its `emits_type_note` says so (`extensionRegressionEmitsNote`). **Self-description (U53 E1-S5).** `Purpose` / `Interpretation` / `DependsOn` / `Accepts` / `FieldInputs` as every category: guidance through `guidanceEntries` (the Interpretation resolver is `descx.ExtensionRegressionOutputResolver` — the figures an `extend.RegressionOutput` can carry plus `outputs.<declared key>`, never structure-only); `DependsOn` in `newFeatureUniverse` (no implicit capability edge — the built-in REG_* rows carry none); `Accepts` through `fieldaccept.CheckExtensionRegression` (empty = REG_OLS's analytics-numeric row; non-empty = exactly the list; `invalid_accepts` at `pulse.New`), called by `descx.ExtensionRegressionFieldTypeRefusal` in the adapter (after the slot refusal, predict's order) and by predict's `regressionSlotFieldCheck`; `FieldInputs` on the runtime registry and the snapshot (`checkInputs("regression", …)` in the field-ref walk, `NeededFieldsWithModels` widens without one). Enums: `enumValues` (payload schema) and MCP `extensionNames` carry `snap.Regressions`; a hidden model is dropped by `withoutHiddenExtensions`, so it is never-registered everywhere, and `pruneOntology`'s all-REG-hidden rule counts visible extension models. Predict `p_values` (a `PValues` model only): an explicit member list exact, else one per non-intercept predictor on `lower_bound`. Sweep: the adapter lists reported fit figures on `RegressionResult.ReportedFigures` (`json:"-"`), which `sweep.figureComputed` reads before `computedZeroFigures`. Parity: the `regression` suite in `TestExtensions_BuiltinParity` (OLS clones vs `REG_OLS`, tolerance compare `assertRegressionParity`), `TestExtensions_RegressionWorkerInvariant`. Gates: `TestExtensions_Regression*`, `TestPanicRecovery_ExtensionRegression`.
- **Regression scoring, probe params, shared options (U53 E2 / E3 / E4).** `RegressionRegistration.Scorer` (`extend.RegressionScorerFactory`, built from `extend.FittedRegression` alone, so a fit and its reloaded model file score identically) feeds `ATTR_REG_PREDICT` and `save` (model file version 3 carrying `outputs`; `PULSE_MODEL_REGRESSION_UNREGISTERED` on reload without the type; no Scorer = `no_scorer`). The `pulse.New` probe hands every category's factory a params object satisfying its declaration (ONE shared synthesizer over `ParamMeta`: each `Required` param and the first of every `ExactlyOneOf` group get its `ParamMeta.Example`, else a `JSONType` placeholder; a `Required` array on a regression gets the probe predictors), so a factory may refuse an absent `Required` param — a factory refusing the placeholder is `PULSE_EXTENSION_FACTORY_PANIC` with `details.probe_params`. The built-in knobs added with it (`REG_OLS` `unpenalized` / `bounds`, `REG_BAYES_LINEAR` vector `prior_precision`) are classified slots a registered model never honours (`{regression, slot}` refusals). The embedder recipe is `docs/src/internals/adding-regression.md`; its examples are the in-repo `REG_TESTNLS_EXP` (`extensions_testnls_exp_test.go`) and the OLS clone.
