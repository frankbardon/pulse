# What can Pulse answer?

<!-- docgen:preserve begin questions-intro -->
Most analysis starts from a question, not from an operator name. Find the kind of question you are asking in the table below and open its guide: each one says what the question means in plain words, which analysis fits the data you have, shows a worked example with its real result, explains how to read that result, and lists the traps to avoid.

The guides are a starting point, not a rulebook. When a question spans two kinds — "did the typical value change after the launch?" is both describing a measure and change over time — read both guides.
<!-- docgen:preserve end questions-intro -->

| Question kind | Sounds like |
|---|---|
| [Describe a measure](questions/describe.md) | What's the typical value of X? |
| [Compare groups](questions/compare_groups.md) | Do A and B differ? |
| [Relationship between measures](questions/relationship.md) | Do X and Y move together? |
| [Find drivers](questions/drivers.md) | What explains Y? |
| [Change over time](questions/change_over_time.md) | Is it going up? |
| [Mix and share](questions/composition.md) | What's the mix? |
| [Benchmark against a reference](questions/benchmark.md) | How does this compare to the total? |
| [Distribution shape](questions/distribution_shape.md) | Is it normally distributed? |
| [Segment into groups](questions/segment.md) | Are there natural groups of customers? |
| [Measure a construct](questions/measure_construct.md) | Do these questions measure one thing? |
| [Flows between states](questions/flows.md) | Where do customers move between states? |
| [Data quality](questions/data_quality.md) | Is this data trustworthy? |

Some jobs are not analysis questions, so they have no guide here; Pulse routes them to its data tools instead:

- **Prepare data** — Keep only last year's rows.
- **Simulate data** — Generate a synthetic copy of this cohort.
- **Look up records** — Show me the record for this ID.
