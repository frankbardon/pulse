# U67 — predict-extension-parity-2

**Outcome:** An extension or an unusual request is judged the same way by predict and by the runtime, with no runtime-only refusal left.

**Track:** API & release · **Size:** L · **Depends on:** U77, U78 (CI and test hygiene land first)

## Summary

The residue of predict / runtime parity and extension validation: extension factories and window-label reads that only the runtime can judge, a standalone public post-window classifier, `u64` binding past 2^53, a single expression-slot walk, extension attributes with output dictionaries, embedder-registered overlay kinds, and a general `target` / `predictors` refusal on non-regression attributes.

| Epic | Surface | Items | Stories |
|---|---|---|---|
| E1 | Extension specs are judged at predict: a spec-only `Validate` hook on every extension category, `PULSE_EXTENSION_SPEC_REFUSED`, predict handing the hook the runtime's rewritten spec | #559 | E1-S1, E1-S2, E1-S3 |
| E2 | Embedder overlay kinds (`OVERLAY_<NS>_<NAME>`) on the crosstab, SERIES and Compose hosts, with p-values under `multiplicity`, weight and streaming rules, discoverability, feature-profile hiding and the `adding-overlay.md` recipe | #676 | E2-S1, E2-S2, E2-S3, E2-S4, E2-S5 |
| E3 | Extension aggregators and groupers reading a window label turn windows-first on; extension attributes inherit a source dictionary | #577, #486 | E3-S1, E3-S2 |
| E4 | `u64` exact past 2^53 through `$env`, `let` and formula aliases; feature `fit_on` expressions walked by every reference check | #523, #524 | E4-S1, E4-S2, E4-S3 |
| E5 | Predict folds loaded model values (windows, constants, extension params, optimize), `Pulse.ClassifyPostWindow`, Compose slot `sizes`, `PULSE_ADVISORY_FORMULA_NULLABLE_RESULT` | #708, #573, #466, #475 | E5-S1, E5-S2, E5-S3, E5-S4, E5-S5 |
| E6 | `WIN_FORMULA` with typed record and output-row cells; `target` / `predictors` (and the penalty keys) refused on every non-regression attribute; `internal/codein` | #479, #244, #245 | E6-S1, E6-S2, E6-S3, E6-S4 |
| E7 | Close-out: roadmap, migration doc, CLAUDE.md companion, recipe Go snippets compile-checked | — | E7-S1 |

E1-S3, E6-S3 and E6-S4 were added during the effort by the owner to close known limits found by earlier stories. The overlay epic (E2) ran in a parallel worktree and landed on the effort branch before close-out. Breaking and behaviour changes are listed in [the embedder migration guide](../v1.0.0-api-and-release/03-embedder-migration.md) under "Changes from predict-extension-parity-2 (U67)".
